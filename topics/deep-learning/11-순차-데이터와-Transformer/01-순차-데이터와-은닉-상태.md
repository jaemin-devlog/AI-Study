# 순차 데이터와 은닉 상태

> Day 5 이론 1, 1~4절 (1~8쪽)

## 단어의 순서도 정보임

“별로지만 추천해요”와 “추천하지만 별로예요”는 비슷한 단어를 사용해도 강조하는 내용이 달라짐. 텍스트, 음성, 시간별 기온처럼 앞뒤 순서가 의미를 가지는 데이터를 순차 데이터라고 함.

CNN이 가까운 픽셀의 공간적 관계를 활용했다면, RNN은 같은 시퀀스에서 앞서 계산한 정보를 다음 계산으로 전달함. 서로 다른 리뷰의 상태를 무조건 이어 붙이는 것은 아님. 보통 리뷰마다 새로운 초기 상태에서 시작함.

## 셀, 타임스텝, 은닉 상태

| 용어 | 의미 | 문장 예시 |
| --- | --- | --- |
| 셀 | 현재 입력과 이전 상태로 새 상태를 계산하는 단위 | 단어를 읽는 계산 규칙 |
| 타임스텝 | 입력 하나를 처리하는 단계 | I, am, a, boy의 네 단계 |
| 은닉 상태 | 앞에서 처리한 정보가 반영된 숫자 벡터 | 두 번째 상태에는 I와 am의 영향이 담김 |

```text
초기 상태 h0 + I   → h1
          h1 + am  → h2
          h2 + a   → h3
          h3 + boy → h4 → 분류층
```

h2는 I를 처리한 h1과 현재 입력 am으로 계산함. h1과 am을 원문 그대로 보관하는 것이 아니라 가중치와 활성화 함수를 거쳐 새로운 벡터로 바꿈. 따라서 마지막 상태에 앞의 모든 내용이 완벽하게 남는다고 볼 수 없음.

## tanh를 사용하는 이유

가중합 뒤에 비선형 함수를 적용하면 단순한 선형 변환의 반복으로 표현하기 어려운 관계를 학습할 수 있음. 기본 RNN은 주로 tanh를 사용하며 각 성분의 값을 -1과 1 사이로 바꿈.

범위가 제한되어도 여러 성분의 조합으로 다양한 정보를 표현할 수 있음. 큰 숫자를 허용하는 것과 복잡한 관계를 표현하는 것은 서로 다른 문제임. 다만 tanh의 입력이 너무 크거나 작으면 출력이 양끝에 가까워지고 기울기가 작아져 오래전 정보를 학습하기 어려울 수 있음.
