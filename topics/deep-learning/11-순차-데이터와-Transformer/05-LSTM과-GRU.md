# LSTM과 GRU

> Day 5 이론 3, 1~4절 (1~11쪽), 5절 (12~24쪽)

## 오래전 정보를 유지하기 어려운 이유

“처음에는 지루했지만 … 마지막 장면 덕분에 좋았다”처럼 떨어져 있는 정보가 함께 필요한 관계를 장기 의존성이라고 함. 기본 RNN은 매 단계 상태를 바꾸면서 이전 정보의 영향이 약해질 수 있음. 학습할 때도 여러 시점을 거꾸로 거치며 기울기가 작아져 앞부분에 필요한 정보를 배우기 어려울 수 있음.

LSTM과 GRU는 게이트를 학습해 정보가 유지되고 갱신되는 정도를 조절함. 긴 문장을 완벽하게 기억하게 만드는 장치는 아니지만 기본 RNN의 어려움을 완화함.

## LSTM의 두 상태

은닉 상태 h는 현재 단계에서 밖으로 전달하는 표현이고, 셀 상태 c는 정보를 유지하며 갱신하는 별도의 경로임. 셀 상태도 숫자 벡터이며 문장을 원문 그대로 저장하는 보관함은 아님.

| 게이트 | 하는 일 | 읽기 비유 |
| --- | --- | --- |
| 망각 게이트 | 이전 셀 상태의 유지 정도 조절 | 기존 메모에서 남길 내용 결정 |
| 입력 게이트 | 새 후보 정보의 반영 정도 조절 | 새 메모 추가 |
| 출력 게이트 | 갱신한 셀 상태에서 은닉 상태 생성 조절 | 현재 판단에 꺼내 쓸 내용 결정 |

게이트는 보통 0~1 값을 여러 개 계산함. 항상 열림과 닫힘 중 하나만 고르는 스위치는 아님. 어떤 정보는 많이 남기고 다른 정보는 조금 남길 수 있으며, 이 기준은 정답과의 손실을 줄이는 과정에서 학습함.

## GRU의 두 게이트

GRU는 별도 셀 상태 없이 은닉 상태를 사용함. 리셋 게이트는 새로운 후보를 만들 때 과거 정보를 얼마나 활용할지 조절하고, 업데이트 게이트는 이전 상태와 새 후보를 얼마나 섞을지 조절함.

같은 입력과 은닉 크기라면 일반적으로 GRU가 LSTM보다 파라미터가 적음. 그렇다고 모든 데이터에서 더 빠르거나 정확하다고 단정하지 않고 같은 분할과 학습 조건에서 비교함.

## 층을 쌓는 것과 시간을 진행하는 것

타임스텝은 단어 순서이고, 층은 같은 시퀀스의 표현을 위로 전달하는 깊이임. 2층 LSTM은 첫 층의 시점별 출력을 두 번째 층의 입력으로 사용함.

```python
from torch import nn

lstm = nn.LSTM(16, 8, num_layers=2,
               dropout=0.2, batch_first=True)
gru = nn.GRU(16, 8, num_layers=2,
             dropout=0.2, batch_first=True)
# vectors: (배치, 길이, 16)의 임베딩 출력
output_lstm, (hidden_lstm, cell) = lstm(vectors)
output_gru, hidden_gru = gru(vectors)
```

두 모델의 최종 은닉 상태는 `(2, 배치, 8)`임. `hidden_lstm[-1]`과 `hidden_gru[-1]`을 각각 분류층으로 전달함. LSTM만 셀 상태를 추가 반환함. 여기의 dropout은 순환층 사이의 출력에 적용되며 마지막 층 뒤에 자동으로 적용되는 별도 Dropout층은 아님.

실험 기록에는 검증 정확도, 검증 손실, 최적 에포크, 학습 시간을 함께 남김. PDF의 비교 표도 정확도를 고정값으로 제시하지 않고 실행 결과로 채우도록 되어 있음.
