# RNN 계산과 입출력

> Day 5 이론 1, 5~6절 (8~19쪽)

## 같은 가중치로 다른 상태 계산

기본 계산은 $h_t=\tanh(x_tW_x+h_{t-1}W_h+b)$임. 입력에 곱하는 가중치와 이전 상태에 곱하는 가중치는 서로 다르지만, 각각의 가중치는 모든 타임스텝에서 공유함. 문장이 길어지면 계산 횟수가 늘어날 뿐, 시점마다 새 가중치를 만들지는 않음.

다음은 강의의 1차원 계산을 옮긴 예시임. 학습 과정 없이 주어진 가중치로 순전파만 수행함.

```python
import torch

def run_sequence(values):
    h = torch.tensor(0.0)
    for x in values:
        h = torch.tanh(torch.tensor(float(x)) + 0.5 * h)
    return round(h.item(), 4)

print(run_sequence([1, 0]))
print(run_sequence([0, 1]))
```

강의에 제시된 결과:

```text
0.3634
0.7616
```

두 번째 입력이 0이어도 이전 상태가 남아 결과가 0이 아닐 수 있음. 입력의 순서를 바꾸면 상태를 갱신하는 순서도 달라져 마지막 결과가 달라짐.

## 입력과 출력의 축

`batch_first=True`인 단방향 RNN을 기준으로 읽음.

| 값 | 형태 | 의미 |
| --- | --- | --- |
| 입력 | (B, T, D) | 배치 수, 시퀀스 길이, 토큰 특성 수 |
| 전체 출력 | (B, T, H) | 마지막 순환층의 시점별 은닉 상태 |
| 최종 상태 h_n | (L, B, H) | 순환층별 마지막 은닉 상태 |

L은 층 수임. `h_n[-1]`은 마지막 층을 고르는 표현임. 한 층·단방향 모델에서는 `output[:, -1, :]`과 같은 마지막 상태를 얻음. 양방향 모델이나 패딩을 따로 처리하는 모델에는 이 관계를 그대로 적용하지 않음.

## 가중치 수를 셀 때

입력 특성 4개, 은닉 뉴런 3개인 교재 수식은 입력 가중치 12개, 순환 가중치 9개, 편향 3개로 총 24개임. PyTorch의 기본 `nn.RNN(4, 3)`은 입력 쪽과 은닉 쪽 편향을 별도로 두므로 총 27개임. 수식의 편향 개수와 라이브러리의 저장 방식을 구분해야 함.
