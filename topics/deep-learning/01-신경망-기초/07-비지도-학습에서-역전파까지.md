# 비지도 학습에서 역전파까지


같은 이미지라도 무엇을 알고 싶은지에 따라 학습 방법이 달라짐.

## 데이터에서 구조 찾기

k-평균의 결과는 각 이미지의 소속이고 PCA의 결과는 새로운 축에서의 좌표임. 둘 다 정답 이름 없이 계산하지만 한쪽은 그룹을, 다른 쪽은 표현을 구함.

## 정답으로 모델 학습하기

신경망의 순전파는 입력으로 예측을 계산함. 학습할 때는 정답과 비교해 손실을 만들고 역전파로 각 매개변수의 기울기를 구함. 옵티마이저가 그 값을 사용해 매개변수를 바꿈.

## 결과를 읽는 기준

클러스터 번호, 주성분 좌표, 예측 클래스, 손실은 서로 다른 출력임. 숫자를 해석할 때 어떤 데이터에서 무엇을 계산한 값인지부터 확인함.

## 같은 사진에서 서로 다른 결과 읽기

| 질문 | 방법 | 결과 한 개를 읽는 법 |
| --- | --- | --- |
| 어떤 사진끼리 비슷한가? | k-평균 | 중심과 가까운 그룹의 번호 |
| 사진의 차이를 적은 숫자로 남길 수 있는가? | PCA | 평균 중심에서 주성분 방향으로 투영한 좌표 |
| 정답 종류를 예측할 수 있는가? | 신경망 | 학습된 가중치로 계산한 클래스별 점수 |

세 방법 모두 숫자 배열을 받지만, 학습에 필요한 정보가 다름. k-평균은 중심까지 거리를, PCA는 투영한 데이터의 분산을 사용함. 지도학습 신경망은 예측과 실제 정답의 손실을 사용함. 따라서 주성분의 설명 분산이나 이너셔를 분류 정확도처럼 읽으면 각 값의 의미가 달라짐.

## 스스로 계산을 확인하는 방법

순전파에서는 어느 입력이 어느 가중치와 곱해졌는지 표시함. 역전파에서는 손실에서 시작해 같은 연산을 역순으로 지나며 국소 미분을 곱함. 마지막으로 작은 변화량을 넣어 손실이 실제로 예상 방향으로 움직이는지 살펴봄. 세 계산을 구분하면 예측값 3, 손실 2, 가중치 기울기 −4가 왜 각각 다른 숫자인지 설명할 수 있음.
