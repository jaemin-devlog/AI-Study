# Git과 GitHub

파일 변경 이력 기록, 과거 상태 확인, 나눠 작업한 내용 병합에 사용.

## 도구 구분

| 도구 | 하는 일 |
| --- | --- |
| Git | 내 컴퓨터에서 파일의 변경 이력을 관리 |
| GitHub | Git 저장소를 온라인에 두고 공유·리뷰 |
| VS Code 소스 제어, SourceTree | Git 작업을 화면에서 실행 |

- 로컬 Git 작업: GitHub 계정 없이 가능
- 원격 저장소 접근 권한: Git 작성자 설정과 별개

## 저장소 위치

- 로컬 저장소: 내 컴퓨터에 보관. 일반적으로 `.git` 폴더에 이력·관리 정보 저장
- 원격 저장소: GitHub 같은 서버에 보관. 다른 컴퓨터와 이력 공유
- 로컬 커밋: 원격으로 자동 업로드 안 됨
- 로컬에만 기록한 경우: 컴퓨터를 잃으면 이력도 함께 잃을 수 있음

## 저장, add, commit, push

| 작업 | 남는 결과 |
| --- | --- |
| 파일 저장 | 편집 내용을 실제 파일에 반영 |
| `git add` | 다음 커밋에 넣을 파일 상태 준비 |
| `git commit` | 준비한 상태를 로컬 이력에 기록 |
| `git push` | 로컬 커밋을 원격 저장소로 전송 |

## 커밋

- 스냅샷: 특정 시점에 Git이 관리하는 파일들의 상태
- 새 커밋 생성 후에도 이전 커밋 유지
- 변경 없는 파일 데이터는 재사용
- 작성자, 메시지, 부모 커밋 정보 등 포함
- 커밋 해시: 각 커밋을 식별하는 값
