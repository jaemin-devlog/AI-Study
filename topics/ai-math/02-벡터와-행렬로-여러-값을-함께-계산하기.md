# Day 1. 벡터와 행렬로 여러 값을 함께 계산하기

> 여러 입력과 출력을 벡터와 행렬로 표현하고 Linear 계층과 ReLU의 계산을 연결한다.

## 1. 스칼라, 벡터, 행렬과 Shape

스칼라는 숫자 하나, 벡터는 순서가 있는 숫자 묶음, 행렬은 숫자를 행과 열로 배열한 것이다. Shape는 배열의 크기와 형태를 나타낸다. 공부 시간과 연습 문제 수가 각각 2와 1인 학생의 입력은 $[2,1]$이다. 두 학생의 입력을 행으로 쌓으면 $X=\begin{bmatrix}1&0\\2&1\end{bmatrix}$이고 Shape는 `(2, 2)`다. 행은 학생, 열은 특징이다.

## 2. 가중합과 내적

두 특징에 가중치 $[3,2]$, 편향 1을 적용하면 다음과 같다.

$$
\hat y=2\times3+1\times2+1=9
$$

가중합은 각 값에 가중치를 곱해 더하는 계산이다. 같은 위치의 원소를 곱하고 합하는 **내적**으로 $x\cdot w=8$이라 쓸 수 있다. 원소별 곱은 `[6, 2]`처럼 각 결과를 유지하지만 내적은 더해 하나의 값 8을 만든다.

## 3. 행렬곱과 배치

두 출력의 가중치를 열로 배치하고 편향을 더한다. 여기서는 입력을 행 벡터로 두는 표기다.

$$
[2\ 1]\begin{bmatrix}3&-1\\2&1\end{bmatrix}+[1\ 0]=[9\ -1]
$$

첫 출력은 $2\times3+1\times2+1=9$, 둘째는 $2\times(-1)+1\times1+0=-1$이다. 행렬곱은 앞 행렬의 각 행과 뒤 행렬의 각 열을 내적한다. `(m, n) × (n, p)`에서 안쪽 크기 $n$이 같아야 하며 결과는 `(m, p)`다.

여러 학생을 행으로 묶어 같은 가중치와 편향을 적용하면 한 번에 계산할 수 있다. 이렇게 처리하는 데이터 묶음이 배치다. 위 $X$에 같은 가중치와 편향을 적용하면 결과는 $\begin{bmatrix}4&-1\\9&-1\end{bmatrix}$다.

## 4. Linear와 ReLU

Linear 계층은 $Z=XW+b$로 입력 특징을 새로운 특징으로 변환한다. ReLU는 각 원소에 $\max(0,z)$를 적용하므로 `[9, -1]`은 `[9, 0]`이 된다. Shape는 바뀌지 않는다.

Linear 계층만 연속하면 전체를 하나의 선형 변환과 편향으로 합칠 수 있다. ReLU를 사이에 넣으면 음수와 양수에서 서로 다른 규칙이 적용되어 비선형 관계를 표현할 수 있다.

## 5. 두 층의 순전파

첫 계층의 출력 `[9, -1]`에 ReLU를 적용하고, 두 번째 계층의 가중치 $[1,2]^T$와 편향 0을 적용한다.

| 단계 | 값 | Shape |
| --- | --- | --- |
| 입력 | `[2, 1]` | `(1, 2)` |
| 첫 Linear | `[9, -1]` | `(1, 2)` |
| ReLU | `[9, 0]` | `(1, 2)` |
| 두 번째 Linear | `[9]` | `(1, 1)` |

ReLU가 없다면 최종값은 $9-2=7$이다. 각 계층의 출력을 다음 계층에 넣어 예측을 계산하는 과정을 **순전파**라고 한다. 이 예측 9와 실제 점수 6의 차이는 학습을 통해 줄여야 한다.

## 핵심 정리

- 내적은 하나의 가중합을, 행렬곱은 여러 행과 열에 대한 내적을 표현한다.
- 행렬곱의 안쪽 차원은 같아야 하며 배치를 사용해 여러 입력을 함께 처리한다.
- Linear와 비선형 활성화 함수를 연결해 복잡한 함수를 구성한다.
