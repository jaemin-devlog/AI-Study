학습 범위: 14에서 16쪽

## 지도학습과 다른 학습 방식

지도학습은 입력과 정답을 함께 제공. 비지도학습은 정답 없이 비슷한 샘플의 구조를 찾고, 강화학습은 행동 결과의 보상을 이용해 더 나은 행동을 학습함.

비지도학습으로 생선을 두 무리로 나눴다고 모델이 도미와 빙어라는 이름을 알아낸 것은 아님. 어떤 특성 때문에 묶였는지와 무리의 의미를 별도로 확인해야 함.

## 학습할 생선과 평가할 생선 분리

훈련 세트는 모델을 학습할 때 사용하고 테스트 세트는 학습 후 새로운 입력에 대한 성능을 평가할 때 사용. 테스트에도 정답은 있지만 그 정답을 학습에 사용하지 않음.

```python
train_input = fish_data[:35]
train_target = fish_target[:35]
test_input = fish_data[35:]
test_target = fish_target[35:]

kn = KNeighborsClassifier()
kn.fit(train_input, train_target)
print(kn.score(test_input, test_target))
```

```text
0.0
```

`[:35]`는 0번부터 34번까지, `[35:]`는 35번부터 끝까지. 원래 도미 다음에 빙어가 들어 있었으므로 훈련에는 도미만, 테스트에는 빙어만 들어감.

훈련에서 본 이웃이 모두 도미여서 빙어를 전부 도미로 예측한 결과임. 모델을 바꾸기 전에 각 세트에 어떤 생선이 들어갔는지 확인해야 함.

선택한 샘플이 한쪽으로 치우쳐 전체의 특성을 반영하지 못하는 것을 샘플링 편향이라고 함. 단순히 두 세트로 나눴다는 사실만으로 적절한 평가 데이터가 준비되는 것은 아님.
