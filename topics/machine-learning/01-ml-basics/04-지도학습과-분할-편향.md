# 4. 지도학습과 분할 편향

훈련 정확도가 100%였다는 것은 모델이 학습에 사용한 사례를 잘 맞혔다는 뜻. 새로운 생선도 잘 맞히는지 확인하려면 정답을 알고 있는 데이터 일부를 학습에서 빼 두어야 함. 그 생선을 예측한 뒤 실제 종류와 비교하면 됨.

## 지도학습에서 정답을 쓰는 두 시점

지도학습은 입력과 정답을 함께 제공해 대응 관계를 배우는 방식임. 훈련에서는 둘을 함께 모델에 전달함. 테스트에서도 정답은 있지만 학습에는 주지 않고 예측을 채점하는 데 사용함.

| 데이터 | 사용하는 목적 | 코드에서의 위치 |
| --- | --- | --- |
| 훈련 세트 | 모델을 학습 | fit(훈련 입력, 훈련 정답) |
| 테스트 세트 | 새 데이터의 성능 평가 | score(테스트 입력, 테스트 정답) |

비지도학습은 정답 없이 비슷한 샘플이나 데이터의 구조를 찾음. 생선이 두 무리로 나뉘어도 각 무리가 도미와 빙어라는 이름까지 알아낸 것은 아님. 무엇을 기준으로 묶였는지 확인해야 함. 강화학습은 행동 결과의 보상을 이용해 더 나은 행동을 배우는 방식임.

여기서는 정답이 있는 분류 문제를 계속 다룸. 정답을 학습에 사용하는지, 평가에만 사용하는지가 훈련과 테스트를 나누는 기준임.

## 앞부분과 뒷부분을 그대로 나눠 보기

```python
train_input = fish_data[:35]
train_target = fish_target[:35]
test_input = fish_data[35:]
test_target = fish_target[35:]

kn = KNeighborsClassifier()
kn.fit(train_input, train_target)
print(kn.score(test_input, test_target))
```

```text
0.0
```

`[:35]`는 0번부터 34번까지, `[35:]`는 35번부터 마지막까지 선택함. 모델을 기본 설정으로 새로 만든 뒤 앞 35마리로 학습하고 뒤 14마리로 평가했는데 정확도는 0임.

원래 데이터는 도미 35마리 다음에 빙어 14마리 순서였음. 따라서 훈련에는 도미만, 테스트에는 빙어만 들어감. 가까운 이웃이 전부 도미인 모델은 테스트 생선도 모두 도미로 판단하므로 빙어를 하나도 맞히지 못함.

이 결과는 단순히 KNN이 생선을 잘 분류하지 못한다는 뜻이 아님. 모델을 바꾸기 전에 어떤 생선으로 학습했고 어떤 생선으로 평가했는지 확인해야 함.

## 샘플링 편향이 생긴 이유

![분할과 편향](../assets/pdf/분할과-편향.png)

선택된 샘플이 한쪽으로 치우쳐 전체 데이터의 특성을 제대로 반영하지 못하는 문제를 샘플링 편향이라고 함. 이번에는 종류별로 정렬된 목록을 그대로 잘라 두 세트의 구성이 극단적으로 달라졌음.

그림에서는 훈련과 테스트가 두 종류를 모두 담고 있는지 확인해야 함. 두 묶음을 만들었다는 사실만으로 적절한 평가가 준비된 것은 아님. 모델이 배워야 하는 종류가 훈련에 포함되고 평가할 범위도 전체 문제를 반영해야 함.

다음에는 순서를 섞어 다시 나눔. 단, 입력과 정답을 각각 따로 섞으면 생선의 측정값과 종류가 어긋남. 같은 행 번호로 두 데이터를 함께 선택하는 방법을 사용함.
