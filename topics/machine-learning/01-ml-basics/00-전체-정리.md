# 머신러닝의 기본 흐름과 데이터 준비

생선의 길이와 무게로 도미와 빙어를 분류하면서 데이터 준비, 학습, 평가, 표준화 과정을 정리

## 1. 인공지능과 머신러닝

인공지능은 인식이나 판단처럼 사람의 지능이 필요한 작업을 컴퓨터가 수행하게 만드는 기술 전반

머신러닝은 그중 데이터에서 패턴을 학습하는 방법

딥러닝은 머신러닝 중 여러 층의 신경망을 사용하는 방법

생선의 길이와 무게, 실제 종류를 함께 주고 학습시키는 방식은 지도학습

정답을 주지 않고 비슷한 데이터끼리 묶는 방식은 비지도학습

## 2. 생선 데이터 준비

목표는 길이와 무게를 입력받아 도미인지 빙어인지 예측하는 것

| 용어 | 이번 예제 |
| --- | --- |
| 샘플 | 생선 한 마리 |
| 특성 | 길이와 무게 |
| 타깃 | 실제 생선 종류 |
| 클래스 | 도미와 빙어 |

도미 35마리, 빙어 14마리를 사용

![생선의 길이와 무게](../assets/pdf/생선-산점도.png)

점 하나는 생선 한 마리, 가로축은 길이, 세로축은 무게

이 데이터에서는 도미가 길고 무거운 쪽, 빙어가 짧고 가벼운 쪽에 모여 있음

## 3. 모델에 넣을 입력과 정답

실습 데이터에서 준비한 도미와 빙어의 길이, 무게 리스트를 사용

```python
length = bream_length + smelt_length
weight = bream_weight + smelt_weight
fish_data = [[l, w] for l, w in zip(length, weight)]
fish_target = [1] * 35 + [0] * 14
```

`zip()`으로 같은 위치의 길이와 무게를 묶어 `[길이, 무게]` 형태로 만듦

도미를 1, 빙어를 0으로 표시. 입력과 정답은 같은 생선끼리 같은 순서여야 함

첫 도미의 입력이 `[25.4, 242.0]`이면 같은 위치의 정답은 `1`

## 4. KNN 분류 모델 학습과 예측

```python
from sklearn.neighbors import KNeighborsClassifier

kn = KNeighborsClassifier()
kn.fit(fish_data, fish_target)
print(kn.score(fish_data, fish_target))
print(kn.predict([[30, 600]]))
```

```text
1.0
[1]
```

`fit()`으로 길이, 무게와 정답을 전달. KNN은 이후 비교할 훈련 사례를 보관

`score()`의 1.0은 학습에 사용한 49마리를 다시 평가해 모두 맞혔다는 뜻

훈련 데이터를 그대로 평가했으므로 새로운 생선에서도 100% 정확하다는 뜻은 아님

`predict([[30, 600]])`의 `[1]`은 길이 30cm, 무게 600g인 생선을 도미로 예측했다는 뜻

안쪽 리스트는 생선 한 마리의 특성, 바깥쪽 리스트는 모델에 전달하는 샘플 목록

실제 정답을 확인하지 않았다면 이 예측이 맞았는지는 모름

## 5. 이웃 수와 예측

KNN은 새 생선과 가까운 훈련 생선의 정답을 참고

기본 설정은 이웃 5마리의 다수결. 이웃 수는 `n_neighbors`로 변경

49마리 모두를 이웃으로 쓰면 도미 35마리가 빙어 14마리보다 많아 어떤 입력도 도미로 예측

훈련 정확도는 $35 / 49 \approx 0.714$

이웃을 늘린다고 항상 정확도가 높아지는 것은 아님. 여러 k는 검증 데이터로 비교

## 6. 훈련 세트와 테스트 세트

학습에 사용하지 않은 데이터에서 성능을 확인하기 위해 데이터를 분리

훈련 입력과 정답으로 학습한 뒤 테스트 입력을 예측하고 실제 정답과 비교

정답을 알고 있는 테스트 데이터라도 그 정답은 학습이 아닌 채점에 사용

도미 35마리 다음에 빙어 14마리가 있는 데이터를 순서대로 자르면 훈련에는 도미만, 테스트에는 빙어만 들어감

이 경우 모델은 도미만 학습해 테스트 정확도가 0.0이 됨. 입력과 정답의 짝을 유지하면서 섞어야 함

![분할 결과 비교](../assets/데이터-분할-비교.png)

왼쪽은 순서대로 분할, 오른쪽은 섞은 뒤 분할한 결과. 원은 훈련, x는 테스트 생선

테스트 정확도 100%는 그 테스트 생선을 모두 맞혔다는 뜻. 앞으로 만날 모든 생선을 맞힌다는 보장은 없음

## 7. 무작위 분할과 층화 분할

```python
from sklearn.model_selection import train_test_split

train_input, test_input, train_target, test_target = train_test_split(
    fish_data, fish_target, stratify=fish_target, random_state=42
)
```

49마리가 훈련 36마리, 테스트 13마리로 분리

`stratify`는 도미와 빙어의 비율을 고려. `random_state`는 같은 분할을 다시 만들기 위한 설정

## 8. 스케일과 표준화

훈련한 KNN의 테스트 정확도는 1.0이지만 `[25, 150]`을 넣으면 빙어 `[0.]`로 예측

표준화 전 가까운 이웃은 도미 1마리와 빙어 4마리

길이는 약 10\~40cm, 무게는 수 g에서 1,000g 정도까지 퍼져 있어 거리 계산에 무게 차이가 크게 반영됨

표준화는 특성별 평균을 빼고 표준편차로 나누어 비교 기준을 맞추는 방법

$$
z = \frac{x - \mu}{\sigma}
$$

$x$는 원래 값, $\mu$는 훈련 데이터의 평균, $\sigma$는 훈련 데이터의 표준편차

```python
mean = np.mean(train_input, axis=0)
std = np.std(train_input, axis=0)
train_scaled = (train_input - mean) / std
test_scaled = (test_input - mean) / std
new = (np.array([25, 150]) - mean) / std

kn.fit(train_scaled, train_target)
print(kn.score(test_scaled, test_target))
print(kn.predict([new]))
```

```text
1.0
[1.]
```

평균과 표준편차는 훈련 데이터에서만 구함. 테스트 데이터와 새 생선에도 같은 기준을 적용해 데이터 누수를 막음

![표준화 전후 이웃](../assets/pdf/표준화-전후.png)

왼쪽은 원래 값, 오른쪽은 실제 입력을 표준화한 결과. 표시된 원은 모델이 선택한 이웃

축 표시 범위만 바꾸면 모델의 입력이 바뀌지 않아 예측도 그대로. 표준화 후에는 이웃이 도미 5마리로 바뀌어 `[1.]`을 예측

테스트 정확도는 전후 모두 1.0. 테스트에 없는 새 생선은 이웃이 달라져 예측이 바뀔 수 있음
