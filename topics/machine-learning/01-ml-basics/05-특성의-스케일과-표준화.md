# 특성의 스케일과 표준화

본문 코드는 개념별 부분 코드. 데이터 준비부터 독립 실행할 때는 [전체 실습](07-표준화-예제.md)을 사용.


## 테스트 정확도는 100%인데 예측이 다른 이유

- 층화 분할한 훈련 데이터로 KNN을 학습하고 테스트하면 정확도는 1.0이다.

- 하지만 실제 도미인 길이 25cm, 무게 150g의 생선을 예측하면 결과가 `[0.]`, 즉 빙어로 나온다.

```python
kn.fit(train_input, train_target)
print(kn.score(test_input, test_target))  # 1.0
print(kn.predict([[25, 150]]))           # [0.]

distances, indexes = kn.kneighbors([[25, 150]])
print(train_target[indexes])  # [[1. 0. 0. 0. 0.]]
```

- `kneighbors()`는 가까운 이웃까지의 거리와 훈련 데이터의 행 번호를 반환한다.

- 선택된 이웃 5마리 중 도미는 1마리이고 빙어는 4마리다. 다수결로 빙어를 예측한다.

## 특성의 스케일

- 길이는 대략 10\~40cm 범위이고 무게는 수 g에서 약 1,000g 범위다.

- KNN은 기본적으로 두 특성의 숫자 차이를 이용해 거리를 계산한다.

두 생선의 길이를 각각 $l_1, l_2$, 무게를 $w_1, w_2$라고 하면 유클리드 거리는 다음과 같다.

$$
d = \sqrt{(l_1-l_2)^2 + (w_1-w_2)^2}
$$

- 숫자 범위가 큰 무게의 차이가 거리 계산에 더 크게 반영될 수 있다. 모델이 cm와 g의 단위를 이해해서 자동으로 균형을 맞추지는 않는다.

- `plt.xlim()`은 그래프의 축 표시 범위만 바꾼다. 실제 데이터가 바뀌지 않으므로 예측 결과도 달라지지 않는다.

### 실제 거리 계산에서 무게의 영향

새 생선 $[25, 150]$과 빙어 $[15, 19.9]$를 비교하면 길이 차이는 10, 무게 차이는 130.1이다.

$$
d = \sqrt{10^2 + 130.1^2} = \sqrt{100 + 16926.01} \approx 130.5
$$

길이 차이의 제곱은 100인데 무게 차이의 제곱은 16,926.01이다. 이 입력에서는 무게의 숫자 차이가 거리를 크게 좌우한다. 산점도는 가로축과 세로축의 눈금이 다를 수 있으므로 화면상 거리만 보고 모델의 이웃을 판단하면 안 된다.

### 전처리와 데이터 누수

전처리는 모델에 넣기 전 데이터를 정리하거나 변환하는 과정이다. KNN처럼 거리로 이웃을 찾는 모델은 특성의 숫자 범위가 다르면 범위가 큰 특성의 영향을 많이 받을 수 있다.

데이터 누수는 평가에만 사용해야 할 정보가 모델 학습이나 전처리 기준을 정하는 과정에 들어가는 경우다. 전체 데이터의 평균과 표준편차를 먼저 계산한 뒤 분할하면 테스트 데이터의 분포도 전처리에 반영된다. 먼저 분할하고 훈련 세트에서만 기준을 구한다.

## 표준화

- 표준화는 각 특성에서 평균을 빼고 표준편차로 나누어 비교 기준을 맞추는 방법이다.

$$
z = \frac{x - \mu}{\sigma}
$$

- $x$: 원래 특성값, $\mu$: 훈련 데이터의 해당 특성 평균, $\sigma$: 훈련 데이터의 해당 특성 표준편차, $z$: 표준점수

- 표준점수가 -1이면 해당 특성의 평균보다 표준편차 하나만큼 작다는 뜻이다. 표준화한 값이 반드시 0과 1 사이에 들어가는 것은 아니다.

```python
mean = np.mean(train_input, axis=0)
std = np.std(train_input, axis=0)
train_scaled = (train_input - mean) / std
```

- `axis=0`은 각 열의 통계를 계산한다. 길이의 평균과 표준편차, 무게의 평균과 표준편차를 각각 구한다.

- 훈련 데이터의 모양은 `(36, 2)`이고 평균과 표준편차는 각각 `(2,)`다. NumPy의 브로드캐스팅으로 두 기준을 모든 행에 적용할 수 있다.

### 새 생선을 같은 기준으로 바꾸면?

이 실습의 훈련 데이터에서 구한 평균은 약 $[27.3, 454.1]$, 표준편차는 약 $[9.98, 323.3]$이다. 이를 새 생선 $[25, 150]$에 적용하면 다음과 같다.

$$
\left[\frac{25-27.3}{9.98},\ \frac{150-454.1}{323.3}\right]
\approx [-0.23, -0.94]
$$

길이는 평균보다 약 0.23 표준편차, 무게는 평균보다 약 0.94 표준편차 작다는 뜻이다. 훈련 데이터도 같은 기준으로 바꾸어야 이 값들과 비교할 수 있다.

## 테스트 데이터와 새로운 입력에도 같은 기준 적용

```python
test_scaled = (test_input - mean) / std
new = (np.array([25, 150]) - mean) / std

kn.fit(train_scaled, train_target)
print(kn.score(test_scaled, test_target))  # 1.0
print(kn.predict([new]))                  # [1.]
```

- 평균과 표준편차는 훈련 데이터에서만 구한다. 테스트 데이터의 정보가 전처리 기준에 포함되는 데이터 누수를 막기 위해서다.

- 테스트 데이터와 새 생선에도 훈련 데이터에서 구한 같은 기준을 적용한다. 훈련 데이터는 표준점수인데 새 생선만 원래 cm와 g 값으로 넣으면 서로 다른 기준을 비교하게 된다.

- 표준화 후 새 생선의 가까운 이웃 5마리는 모두 도미이며 예측 결과도 도미로 바뀐다. 테스트 13마리의 정확도는 표준화 전후 모두 1.0이다.

- 같은 테스트 정확도가 나왔어도 테스트에 포함되지 않은 새 데이터의 예측은 달라질 수 있다. 표준화는 거리 계산의 기준을 조정하는 방법이며 모든 경우에 정확도를 높인다고 보장하지는 않는다.

## 표준화 전후 출력 비교

층화 분할한 `train_input`, `test_input`, `train_target`, `test_target`과 학습한 `kn`을 사용한다.

```python
# 원래 값으로 다시 학습한 뒤 표준화 전 예측 확인
kn.fit(train_input, train_target)
print(kn.predict([[25, 150]]))
distances, indexes = kn.kneighbors([[25, 150]])
print(train_target[indexes])

mean = np.mean(train_input, axis=0)
std = np.std(train_input, axis=0)
train_scaled = (train_input - mean) / std
test_scaled = (test_input - mean) / std
new = (np.array([25, 150]) - mean) / std

kn.fit(train_scaled, train_target)
print(np.round(new, 2))
print(kn.score(test_scaled, test_target))
print(kn.predict([new]))
```

```text
[0.]
[[1. 0. 0. 0. 0.]]
[-0.23 -0.94]
1.0
[1.]
```

코드에서 확인할 부분:

- `kneighbors()`의 `distances`는 이웃까지의 거리, `indexes`는 훈련 배열에서 해당 이웃의 행 번호다. `train_target[indexes]`로 이웃의 종류를 확인한다.
- `mean`과 `std`는 훈련 입력의 열별 평균과 표준편차다. `np.round(new, 2)`는 표시할 때만 소수 둘째 자리로 반올림한다.
- `kn.fit(train_scaled, train_target)`으로 이전 모델을 표준화된 값으로 다시 학습한다. 테스트 값과 새 입력에도 훈련 기준을 적용한다.

표준화 전에는 가까운 5마리 중 빙어가 4마리여서 빙어로 예측한다. 훈련 데이터의 평균과 표준편차를 세 입력에 같은 방식으로 적용한 뒤에는 도미로 예측한다. 테스트 13마리의 점수는 1.0으로 유지된다.
