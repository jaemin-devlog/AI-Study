# 8. 표준화와 새 데이터 평가

앞에서는 무게의 큰 숫자 범위가 거리에 크게 작용했음. 이를 조절하려면 길이와 무게를 각자의 평균에서 얼마나 떨어져 있는지라는 공통 기준으로 표현할 수 있음. 이 변환이 표준화이며 데이터 전처리의 한 방법임.

## 평균을 빼고 표준편차로 나누기

$$
z=\frac{x-\mu}{\sigma}
$$

$x$는 원래 값, $\mu$는 해당 특성의 평균, $\sigma$는 표준편차. 평균은 중심이고 표준편차는 평균 주변에서 값이 퍼진 정도를 나타냄. 먼저 평균을 빼서 중심으로부터의 차이를 구하고, 표준편차로 나눠 그 차이를 상대적인 퍼짐의 단위로 표현함.

표준점수 -1은 평균보다 표준편차 하나만큼 작다는 뜻. 길이와 무게의 원래 단위가 달라도 각자의 평균과 퍼짐 기준으로 비교할 수 있게 됨.

```python
mean = np.mean(train_input, axis=0)
std = np.std(train_input, axis=0)
train_scaled = (train_input - mean) / std
print(np.round(mean, 2))
print(np.round(std, 2))
```

```text
[ 27.3 454.1]
[  9.98 323.3 ]
```

`axis=0`은 행들을 따라 계산해 열마다 통계를 구함. 첫 평균 27.3은 길이, 둘째 454.1은 무게이며 표준편차도 같은 순서임. 계산에는 출력용 반올림값이 아닌 원래 `mean`, `std`를 사용함.

`train_input`은 `(36, 2)`이고 기준은 각각 두 값. NumPy는 첫 기준을 모든 행의 길이에, 둘째 기준을 모든 행의 무게에 적용함. 이런 모양의 배열 계산을 브로드캐스팅이라고 함. 결과의 행과 열 수는 그대로이고 훈련 열별 평균은 약 0, 표준편차는 약 1이 됨. 값의 범위가 0에서 1로 제한되는 것은 아님.

## 새 입력도 훈련 기준으로 바꾸기

```python
new = (np.array([25, 150]) - mean) / std
test_scaled = (test_input - mean) / std
kn.fit(train_scaled, train_target)
print(np.round(new, 2))
print(kn.score(test_scaled, test_target))
print(kn.predict([new]))
_, indexes = kn.kneighbors([new])
print(train_target[indexes])
```

```text
[-0.23 -0.94]
1.0
[1.]
[[1. 1. 1. 1. 1.]]
```

새 생선의 길이 점수는 약 $(25-27.3)/9.98=-0.23$, 무게 점수는 약 $(150-454.1)/323.3=-0.94$임. 훈련 평균보다 길이는 약 0.23 표준편차 짧고 무게는 약 0.94 표준편차 가볍다는 뜻임.

`fit(train_scaled, train_target)`은 변환된 사례로 KNN을 다시 준비함. 새 생선과 테스트도 같은 기준으로 변환한 뒤 비교함. 이제 선택된 다섯 이웃이 모두 도미라 예측은 1로 바뀜. `[new]`로 감싸는 것은 한 마리를 2차원 샘플 목록으로 전달하기 위한 것임.

![표준화 전후 비교](../assets/pdf/표준화-전후.png)

그림에서 표준화는 화면만 바꾼 것이 아니라 거리를 계산할 입력을 바꾼 것임. 테스트 정확도는 전후 모두 100%지만 새 생선은 빙어에서 도미로 바뀜. 따라서 테스트 점수 하나만으로 전체 입력 범위의 판단을 알 수는 없음.

평균과 표준편차는 훈련에서만 구함. 테스트나 새 생선에서 따로 계산하면 비교 기준이 달라짐. 테스트 정보를 기준 학습에 쓰면 평가 정보가 준비 과정에 반영되는 데이터 누수도 생길 수 있음. 표준화된 훈련 입력에 원래 단위의 새 생선을 그대로 비교하지 않도록 주의함.

## 테스트 100%를 해석하는 조건

이번 결과는 테스트 13마리를 모두 맞혔다는 뜻. 모든 새 생선에서 100%의 정확도를 보장하는 값은 아님. 실제 사용할 종류와 측정 범위를 테스트가 반영하는지, 샘플 수가 충분한지 확인해야 함.

새 입력이 학습 범위와 비슷한지도 중요함. 테스트 결과를 계속 보며 설정을 바꾸면 그 정보가 모델 선택에 들어가므로 최종 평가는 독립적으로 남긴 데이터에서 확인함. 정확도와 함께 데이터의 대표성, 양, 입력 범위, 평가의 독립성을 살펴보는 이유임.
