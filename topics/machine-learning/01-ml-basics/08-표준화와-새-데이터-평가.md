# 8. 표준화와 새 데이터 평가

학습 범위: 31에서 35쪽

## 훈련 데이터로 변환 기준 계산

$$
z=\frac{x-\mu}{\sigma}
$$

$x$는 원래 값, $\mu$와 $\sigma$는 해당 특성의 훈련 평균과 표준편차. 평균을 빼서 중심을 옮기고 표준편차로 나누어 상대적인 퍼짐 기준으로 표현함.

```python
mean = np.mean(train_input, axis=0)
std = np.std(train_input, axis=0)
train_scaled = (train_input - mean) / std
print(np.round(mean, 2))
print(np.round(std, 2))
```

```text
[ 27.3 454.1]
[  9.98 323.3 ]
```

`axis=0`은 행들을 따라 계산해 길이 열과 무게 열의 통계를 각각 구함. `(36, 2)` 입력에 `(2,)` 평균과 표준편차를 적용하는 계산이 브로드캐스팅. 작은 두 값이 각 행의 같은 열에 적용됨.

표준화한 훈련 입력은 각 열의 평균이 약 0, 표준편차가 약 1이 됨. 값의 범위가 0과 1 사이로 제한되는 것은 아님.

## 테스트와 새 생선도 같은 기준 적용

```python
new = (np.array([25, 150]) - mean) / std
test_scaled = (test_input - mean) / std
kn.fit(train_scaled, train_target)
print(np.round(new, 2))
print(kn.score(test_scaled, test_target))
print(kn.predict([new]))
_, indexes = kn.kneighbors([new])
print(train_target[indexes])
```

```text
[-0.23 -0.94]
1.0
[1.]
[[1. 1. 1. 1. 1.]]
```

새 생선은 훈련 평균보다 길이가 약 0.23 표준편차 짧고 무게가 약 0.94 표준편차 가벼움. 선택한 이웃이 모두 도미가 되어 예측도 도미로 바뀜.

![표준화 전후 비교](../assets/pdf/표준화-전후.png)

테스트 정확도는 전후 모두 100%지만 새 생선은 빙어에서 도미로 바뀜. 테스트 점수는 그 13마리에 대한 결과이며 입력 범위 전체의 판단을 다 설명하지는 못함.

평균과 표준편차는 훈련 데이터에서만 계산. 테스트에서 다시 계산하면 기준이 달라지고 평가 정보가 준비 과정에 반영될 수 있음. 표준화한 훈련 입력과 원래 단위의 새 생선을 그대로 비교하는 것도 피해야 함.

## 테스트 100%를 어떻게 읽을까?

테스트 정확도는 해당 테스트 생선의 결과. 모델을 신뢰할 근거를 판단할 때는 다음 조건도 함께 봐야 함.

- 대표성: 테스트 생선의 종류와 측정 범위가 실제 사용할 데이터와 비슷한가?
- 샘플 수: 13마리를 모두 맞힌 결과와 훨씬 많은 샘플을 맞힌 결과는 근거의 양이 다름.
- 입력 범위: 새로운 생선이 학습한 범위와 비슷한가?
- 평가의 독립성: 테스트 결과를 계속 보면서 모델 설정을 바꾸지 않았는가?
