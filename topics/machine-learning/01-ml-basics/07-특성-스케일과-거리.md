# 7. 특성 스케일과 거리

훈련과 테스트를 적절히 나누어도 입력 특성을 어떤 숫자로 표현했는지가 예측에 영향을 줌. 앞 파일의 층화 분할로 KNN을 학습하고 길이 25cm, 무게 150g인 생선을 예측함.

## 어떤 이웃이 빙어라는 예측을 만들었을까?

```python
kn = KNeighborsClassifier()
kn.fit(train_input, train_target)
print(kn.score(test_input, test_target))
print(kn.predict([[25, 150]]))
distances, indexes = kn.kneighbors([[25, 150]])
print(train_target[indexes])
print(np.round(distances, 1))
```

```text
1.0
[0.]
[[1. 0. 0. 0. 0.]]
[[ 92.  130.5 130.7 138.3 138.4]]
```

테스트 정확도는 1.0인데 새 생선의 예측은 0, 즉 빙어임. 산점도에서는 도미 쪽에 가까워 보일 수 있어도 모델이 실제로 선택한 이웃부터 확인해야 함.

`kneighbors()`는 가까운 이웃들의 거리와 훈련 행 번호를 반환함. `indexes`로 훈련 정답을 선택하니 `[1, 0, 0, 0, 0]`임. 도미 한 마리와 빙어 네 마리가 투표했으므로 빙어가 선택된 것임. 이웃 선택은 거리로, 최종 종류 선택은 이웃의 정답으로 이루어짐.

## 길이와 무게가 같은 비중으로 쓰이지 않는 이유

두 생선 사이의 기본 유클리드 거리는 다음과 같이 계산함.

$$
d=\sqrt{(l_1-l_2)^2+(w_1-w_2)^2}
$$

$l$은 길이, $w$는 무게. 새 생선 `[25, 150]`과 빙어 `[15, 19.9]`를 비교하면 길이 차이는 10, 무게 차이는 130.1임. 제곱한 값은 각각 100과 16,926.01이므로 무게 차이가 훨씬 크게 반영됨.

| 특성 | 두 생선의 차이 | 차이를 제곱한 값 |
| --- | ---: | ---: |
| 길이 | 10cm | 100 |
| 무게 | 130.1g | 16,926.01 |

거리 식에는 이 두 제곱값이 더해지므로, 이 비교에서는 무게 항이 훨씬 큰 영향을 줌.

길이는 대략 수십 단위인데 무게는 수백에서 천 단위까지 퍼짐. 이렇게 특성의 크기와 퍼짐이 다른 것을 스케일이 다르다고 함. 모델은 cm와 g의 의미를 알아서 조정하지 않고 입력된 숫자 차이로 계산함.

## 그래프의 축 변경과 입력 변환 구분하기

```python
plt.scatter(train_input[:, 0], train_input[:, 1])
plt.scatter(25, 150, marker='^')
plt.xlim((0, 1000))
plt.show()
```

![원본과 축 변경 및 표준화](../assets/표준화와-이웃.png)

`xlim((0, 1000))`은 가로축의 표시 범위를 늘림. 길이 값이 왼쪽의 좁은 범위에 모여 무게 방향의 숫자 범위가 훨씬 크다는 것을 보기 쉬워짐. 화면에서 비슷한 거리로 보이는 것과 숫자로 계산한 거리는 다를 수 있음.

그림의 축을 바꿔도 실제 입력은 그대로라 이웃과 예측은 바뀌지 않음. 모델의 거리 기준을 바꾸려면 각 특성의 실제 숫자를 변환해야 함. 오른쪽의 표준화는 이런 변환을 적용한 결과로 다음 파일에서 계산함.
