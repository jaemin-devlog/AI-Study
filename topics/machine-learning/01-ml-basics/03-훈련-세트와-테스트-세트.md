# 훈련 세트와 테스트 세트

본문 코드는 개념별 부분 코드. 데이터 준비부터 독립 실행할 때는 [전체 실습](06-생선-분류-예제.md)을 사용.


## 데이터를 나누는 이유

- 훈련 데이터로 모델을 학습하고, 학습에 사용하지 않은 테스트 데이터로 예측한 뒤 실제 정답과 비교하여 정확도를 평가한다.

- 테스트 데이터에도 정답은 있지만 모델 학습이 아닌 평가에 사용한다.

```python
kn.fit(train_input, train_target)
print(kn.score(test_input, test_target))
```

정확도는 전체 평가 샘플 중 예측이 맞은 샘플의 비율이다.

$$
\mathrm{Accuracy} = \frac{\text{올바르게 예측한 샘플 수}}{\text{평가한 전체 샘플 수}}
$$

- 훈련 정확도와 테스트 정확도가 둘 다 1.0이어도 의미는 다르다. 전자는 학습에 사용한 데이터의 결과이고, 후자는 학습에 사용하지 않은 데이터의 결과다.

- 테스트 정확도가 100%여도 새로운 데이터에서 항상 정답을 맞힌다는 보장은 없다.

- 성능을 판단할 때는 테스트 데이터가 실제 상황을 대표하는지, 데이터 수가 충분한지, 새 입력이 학습 데이터의 범위와 비슷한지, 평가 데이터가 독립적으로 유지되었는지 함께 확인해야 한다.

### 테스트 점수는 무엇을 보여 줄까?

훈련 점수는 학습할 때 사용한 사례를 얼마나 잘 맞혔는지 보여 준다. 테스트 점수는 학습에 사용하지 않은 사례에서 예측과 실제 정답이 얼마나 일치하는지 보여 준다.

예를 들어 테스트 생선 14마리를 모두 맞혔다면 그 14마리에 대한 정확도는 100%다. 그러나 14마리가 실제로 만날 생선 전체의 다양한 크기와 종류를 충분히 대표하지 않을 수 있으므로 이후의 모든 예측까지 보장하지는 않는다.

테스트 결과를 반복해서 확인하며 모델이나 설정을 바꾸면 테스트 데이터가 모델 선택에도 영향을 준다. 실제 모델 선택에서는 검증 데이터로 설정을 비교하고 테스트 데이터는 최종 평가에 사용한다.

### 훈련, 검증, 테스트의 역할

| 데이터 | 역할 |
| --- | --- |
| 훈련 세트 | 전처리 기준과 모델을 학습 |
| 검증 세트 | 모델과 하이퍼파라미터 후보 비교 |
| 테스트 세트 | 선택을 마친 모델의 최종 평가 |

검증 세트를 따로 두거나 훈련 데이터 안에서 교차 검증을 사용해 후보를 비교할 수 있다. 테스트 점수를 반복해 보면서 설정을 고르면 테스트 데이터에 맞춰 선택하게 되어 최종 평가가 낙관적일 수 있다.

## 샘플링 편향

- 원래 데이터는 도미 35마리 다음에 빙어 14마리가 들어 있다.

```python
train_input = fish_data[:35]
train_target = fish_target[:35]
test_input = fish_data[35:]
test_target = fish_target[35:]
```

- 순서대로 나누면 훈련 세트에는 도미만, 테스트 세트에는 빙어만 들어간다.

- KNN은 도미만 학습했으므로 테스트 생선도 모두 도미로 예측한다. 따라서 테스트 정확도는 0.0이다.

- 샘플링 편향은 선택된 샘플이 한쪽으로 치우쳐 전체 데이터의 특성을 제대로 반영하지 못하는 문제다.

- 데이터를 나눈 뒤에는 훈련과 테스트 세트가 필요한 종류와 실제 데이터의 특성을 적절히 반영하는지 확인해야 한다.

## 데이터를 섞을 때 주의할 점

- 입력과 정답을 각각 따로 섞으면 같은 생선의 길이와 무게에 다른 생선의 정답이 붙을 수 있다.

- 같은 행 번호를 사용하여 입력과 정답을 함께 선택해야 짝이 유지된다.

- 섞은 뒤 35마리로 학습하고 남은 14마리로 평가한 실습에서는 테스트 정확도가 1.0이었다. 이는 해당 테스트 14마리를 모두 맞혔다는 뜻이다.
