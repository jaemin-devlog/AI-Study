# 1. 인공지능과 생선 분류 문제

생선의 길이와 무게를 알려 주면 도미인지 빙어인지 판단하는 프로그램을 만들려고 함. 사람이 직접 “길이가 이 값 이상이면 도미”라는 규칙을 작성할 수도 있음. 이번에는 실제 생선의 측정값과 종류를 제공하고, 그 사례를 바탕으로 새 생선을 판단하게 만드는 방법을 사용함.

## 인공지능 안에서 머신러닝의 위치

인공지능은 인식, 추론, 판단처럼 사람의 지능이 필요한 작업을 컴퓨터가 수행하도록 만드는 기술 전반. 사람이 작성한 규칙으로 작동할 수도 있으므로 모든 인공지능이 스스로 학습하는 것은 아님.

머신러닝은 데이터에서 패턴을 학습하는 인공지능의 한 방법. 생선을 나눌 조건을 사람이 하나씩 지정하는 대신 길이와 무게, 실제 종류를 제공함. 학습된 모델은 이 데이터를 바탕으로 새 측정값에 대한 종류를 예측함. 모델은 데이터를 사용해 예측하는 대상이며, 어떤 방식으로 데이터를 활용하는지는 알고리즘에 따라 달라짐.

딥러닝은 여러 층의 신경망을 사용하는 머신러닝의 한 종류. 여러 층을 거치며 단순한 특징부터 복잡한 특징까지 학습할 수 있고 이미지, 음성, 텍스트 처리에 사용됨. 포함 관계로 보면 인공지능 안에 머신러닝이 있고 그 안에 딥러닝이 있음.

머신러닝을 사용해도 문제를 정하는 일은 남아 있음. 어떤 정보를 입력으로 줄지, 무엇을 정답으로 삼을지, 어느 데이터에서 평가할지는 사람이 정해야 함. 이번에는 이 세 가지를 생선 문제에 맞춰 구체적으로 정함.

## 생선 한 마리를 숫자로 표현하기

| 용어 | 의미 | 이번 문제 |
| --- | --- | --- |
| 샘플 | 데이터 한 건 | 생선 한 마리 |
| 특성 | 예측에 사용하는 입력 정보 | 길이(cm), 무게(g) |
| 타깃 | 모델이 예측할 정답 | 생선 종류 |
| 클래스 | 분류할 수 있는 범주 | 도미, 빙어 |

길이 25.4cm, 무게 242g인 생선을 `[25.4, 242.0]`으로 표현하면 이 두 값이 한 샘플의 입력이 됨. 그 생선이 도미라는 정보는 타깃으로 따로 제공함. 측정값만 주었다고 해서 모델이 어느 점을 도미라고 부르는지 알 수 있는 것은 아님.

여러 생선의 입력과 실제 정답을 함께 주는 방식이 지도학습. 모델은 입력과 정답의 대응 관계를 바탕으로 예측을 준비함. 이후 처음 보는 생선의 입력을 주면 그 생선의 정답을 예측하게 됨.

## 종류를 고르는 분류와 수치를 구하는 회귀

이번 목표는 도미와 빙어라는 두 종류 중 하나를 고르는 것. 이런 문제를 분류라고 함. 정답을 도미 1, 빙어 0으로 표시해도 숫자는 이름표일 뿐이므로 분류 문제임. 1이 0보다 좋은 생선이라는 뜻도 아님.

반면 길이만 보고 무게가 몇 g인지 예측하면 회귀 문제. 같은 생선 데이터라도 무엇을 정답으로 정했는지에 따라 문제가 달라짐. 여기서는 길이와 무게를 모두 입력으로 사용하고 종류를 예측하는 것부터 시작함.

다음 파일에서는 실제 측정값을 준비하고, 모델에 넣을 입력과 정답을 같은 순서로 구성함.
