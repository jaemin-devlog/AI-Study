# 1. 인공지능과 생선 분류 문제

학습 범위: 1에서 2쪽

## 인공지능, 머신러닝, 딥러닝

인공지능은 인식, 추론, 판단 같은 작업을 컴퓨터가 수행하게 만드는 기술 전반. 사람이 작성한 규칙으로 작동할 수도 있음.

머신러닝은 데이터에서 패턴을 학습하는 인공지능의 한 방법. 사람이 생선을 구분하는 규칙을 일일이 정하는 대신 여러 생선의 측정값과 종류를 제공하고 새 생선을 예측하도록 함.

딥러닝은 여러 층의 신경망을 사용하는 머신러닝의 한 종류. 따라서 인공지능 안에 머신러닝, 그 안에 딥러닝이 포함됨.

모델을 사용해도 무엇을 예측할지, 어떤 데이터를 준비할지, 결과를 어떻게 평가할지는 사람이 정해야 함.

## 생선 한 마리를 데이터로 표현

이번 목표는 길이와 무게로 도미와 빙어를 구분하는 것.

| 용어 | 이번 문제의 의미 |
| --- | --- |
| 샘플 | 생선 한 마리 |
| 특성 | 길이(cm), 무게(g) |
| 타깃 | 모델이 예측할 정답인 생선 종류 |
| 클래스 | 도미, 빙어라는 두 범주 |

입력과 정답을 함께 주므로 지도학습. 도미와 빙어 중 하나를 예측하므로 분류 문제임. 정답을 1과 0으로 표시하더라도 숫자의 크기를 예측하는 문제는 아님.

생선의 무게처럼 수치 자체를 예측하면 회귀. 무엇을 정답으로 정했는지에 따라 문제가 달라짐.
