# 2. 생선 데이터와 입력 구성

도미와 빙어를 분류하려면 먼저 실제 측정값과 종류를 준비해야 함. 길이 목록과 무게 목록에서 같은 위치는 같은 생선의 정보라는 점부터 맞춰야 함. 길이만 따로 정렬하거나 무게만 섞으면 한 생선의 길이에 다른 생선의 무게가 붙게 됨.

## 도미 35마리와 빙어 14마리 준비하기

```python
import matplotlib.pyplot as plt

bream_length = [
    25.4, 26.3, 26.5, 29.0, 29.0, 29.7, 29.7, 30.0, 30.0, 30.7,
    31.0, 31.0, 31.5, 32.0, 32.0, 32.0, 33.0, 33.0, 33.5, 33.5,
    34.0, 34.0, 34.5, 35.0, 35.0, 35.0, 35.0, 36.0, 36.0, 37.0,
    38.5, 38.5, 39.5, 41.0, 41.0,
]

bream_weight = [
    242.0, 290.0, 340.0, 363.0, 430.0, 450.0, 500.0, 390.0, 450.0, 500.0,
    475.0, 500.0, 500.0, 340.0, 600.0, 600.0, 700.0, 700.0, 610.0, 650.0,
    575.0, 685.0, 620.0, 680.0, 700.0, 725.0, 720.0, 714.0, 850.0, 1000.0,
    920.0, 955.0, 925.0, 975.0, 950.0,
]

smelt_length = [
    9.8, 10.5, 10.6, 11.0, 11.2, 11.3, 11.8, 11.8, 12.0, 12.2,
    12.4, 13.0, 14.3, 15.0,
]

smelt_weight = [
    6.7, 7.5, 7.0, 9.7, 9.8, 8.7, 10.0, 9.9, 9.8, 12.2,
    13.4, 12.2, 19.7, 19.9,
]
```

첫 도미는 길이 목록의 첫 값 25.4와 무게 목록의 첫 값 242.0이 한 쌍. 나머지 생선도 같은 위치끼리 짝지어 읽음. 도미는 35마리, 빙어는 14마리이므로 전체 샘플은 49개임.

아직 이 목록은 모델에 바로 넣을 입력 모양은 아님. 먼저 그래프로 측정값이 어떤 분포인지 살펴보고, 그다음 생선 한 마리씩 묶음.

## 산점도의 점과 생선 연결하기

```python
plt.scatter(bream_length, bream_weight, label='Bream')
plt.scatter(smelt_length, smelt_weight, label='Smelt')
plt.xlabel('Length (cm)')
plt.ylabel('Weight (g)')
plt.legend()
plt.show()
```

![생선의 길이와 무게](../assets/pdf/생선-산점도.png)

`scatter()`는 가로축 값과 세로축 값을 한 쌍씩 받아 점으로 표시함. 가로 위치는 길이, 세로 위치는 무게이므로 점 하나가 생선 한 마리임. 색은 실제 종류를 구분하고 `label`과 `legend()`는 어느 색이 어떤 종류인지 표시함.

빙어는 왼쪽 아래의 짧고 가벼운 쪽, 도미는 오른쪽 위의 길고 무거운 쪽에 모여 있음. 같은 종류 안에서도 길이와 무게가 다르지만 두 무리가 다른 영역에 있다는 것을 볼 수 있음. 새 생선이 들어오면 어느 무리의 생선과 가까운지 참고해 종류를 판단해 볼 수 있음.

이 그림은 현재 데이터의 분포를 확인한 것. 모든 도미와 빙어가 언제나 이렇게 완전히 나뉜다고 결론 내리는 것은 아님. 모델이 실제로 어떻게 예측하는지와 새 데이터의 결과는 이후에 평가함.

## 한 행에 생선 한 마리 넣기

사이킷런의 이번 모델에는 입력을 행은 샘플, 열은 특성인 2차원 형태로 전달함. 따라서 길이 목록과 무게 목록을 따로 주는 대신 `[길이, 무게]`를 한 행으로 묶음.

```python
length = bream_length + smelt_length
weight = bream_weight + smelt_weight
fish_data = [[l, w] for l, w in zip(length, weight)]
fish_target = [1] * 35 + [0] * 14
print(fish_data[:3])
print(len(fish_data), len(fish_target))
```

```text
[[25.4, 242.0], [26.3, 290.0], [26.5, 340.0]]
49 49
```

리스트에 사용하는 `+`는 두 목록을 이어 붙임. `length`에는 도미 길이 35개 다음에 빙어 길이 14개가 오고 `weight`도 같은 순서임.

`zip(length, weight)`는 같은 위치의 길이와 무게를 하나씩 꺼내 짝지음. 반복할 때 길이는 `l`, 무게는 `w`가 되고 `[l, w]`가 한 마리의 입력이 됨. 이 행을 모은 `fish_data`는 49행이며 각 행에 두 특성이 들어 있음.

## 입력마다 정답 하나씩 붙이기

`fish_target`은 `[1] * 35 + [0] * 14`로 만듦. 앞의 35행이 도미이므로 앞의 정답 35개는 1이고 나머지 빙어 14개는 0임. 리스트의 `*`는 이 경우 원소를 반복하는 역할을 함.

입력 수와 정답 수가 모두 49여야 하고 같은 위치는 같은 생선을 가리켜야 함. 측정값을 묶는 것과 정답을 붙이는 것은 서로 다른 작업임. 이제 모델에 `fish_data`와 `fish_target`을 함께 전달할 준비가 됐음.
