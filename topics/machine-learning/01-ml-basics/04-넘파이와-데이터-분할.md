# NumPy와 데이터 분할

본문 코드는 개념별 부분 코드. 데이터 준비부터 독립 실행할 때는 [전체 실습](06-생선-분류-예제.md)을 사용.


## NumPy 배열

- NumPy는 숫자 데이터를 배열로 다룰 때 사용하는 파이썬 라이브러리다.

```python
import numpy as np

input_arr = np.array(fish_data)
target_arr = np.array(fish_target)
print(input_arr.shape)   # (49, 2)
print(target_arr.shape)  # (49,)
```

- 입력의 `(49, 2)`는 생선 49마리와 특성 2개를 뜻한다. 정답의 `(49,)`는 정답 49개가 들어 있는 1차원 배열이다.

- `input_arr[:, 0]`은 모든 생선의 길이, `input_arr[:, 1]`은 모든 생선의 무게를 선택한다.

- 행 번호는 0부터 시작하고 슬라이싱의 끝 번호는 포함하지 않는다.

## 같은 인덱스로 섞기

```python
np.random.seed(42)
index = np.arange(49)
np.random.shuffle(index)

train_input = input_arr[index[:35]]
train_target = target_arr[index[:35]]
test_input = input_arr[index[35:]]
test_target = target_arr[index[35:]]
```

- 0부터 48까지의 행 번호를 섞은 뒤 입력과 정답에 같은 번호를 적용한다. 순서가 바뀌어도 입력과 정답의 짝이 유지된다.

- `seed(42)`는 같은 무작위 순서를 재현하기 위한 설정이다. 42 자체가 정확도를 높이는 것은 아니다.

### 배열을 열로 합치는 과정

`column_stack()`은 같은 위치의 값을 한 행으로 묶는다. 예를 들어 `[1, 2, 3]`과 `[4, 5, 6]`은 `[[1, 4], [2, 5], [3, 6]]`이 된다. 생선 예제에서는 첫 열이 길이, 두 번째 열이 무게다.

`np.ones(35)`와 `np.zeros(14)`는 기본적으로 실수 배열을 만든다. 출력이 `1.`과 `0.`이어도 각각 도미와 빙어라는 클래스 의미는 같다.

## 배열 만들기

```python
fish_data = np.column_stack((length, weight))
fish_target = np.concatenate((np.ones(35), np.zeros(14)))
```

- `column_stack()`은 길이와 무게를 각각 열로 나란히 붙여 `(49, 2)` 형태의 입력을 만든다.

- `ones()`와 `zeros()`는 각각 1과 0으로 채운 배열을 만들고, `concatenate()`는 배열을 이어 붙인다. 정답은 도미 35개 다음 빙어 14개 순서여야 한다.

### 배열의 행과 열

| 표현 | 선택하는 데이터 |
| --- | --- |
| `input_arr[0]` | 첫 번째 생선의 길이와 무게 |
| `input_arr[:35]` | 0번부터 34번까지 생선 35마리 |
| `input_arr[[1, 3]]` | 1번과 3번 행의 생선 |
| `input_arr[:, 0]` | 모든 행의 길이 열 |

예를 들어 섞인 인덱스의 첫 값이 13이면 입력과 정답에서 모두 13번을 선택한다. 그래서 순서가 바뀌어도 한 생선의 입력과 정답이 함께 이동한다.

## train_test_split과 층화 분할

```python
from sklearn.model_selection import train_test_split

train_input, test_input, train_target, test_target = train_test_split(
    fish_data, fish_target, stratify=fish_target, random_state=42
)
```

- 입력과 정답의 짝을 유지하며 무작위로 섞어 훈련과 테스트 세트로 나눈다.

- 기본 테스트 비율은 25%이므로 49개 중 훈련 36개, 테스트 13개로 나뉜다. `test_size`로 비율을 변경할 수 있다.

- `random_state=42`는 같은 분할을 재현하기 위한 설정이다.

- `stratify=fish_target`은 각 세트의 클래스 비율이 전체와 비슷하도록 분할한다. 데이터 개수는 정수이므로 비율이 완전히 같지는 않을 수 있다.

- 이 실습에서는 전체 도미 35마리와 빙어 14마리 중, 층화 분할한 테스트 세트에 도미 9마리와 빙어 4마리가 들어간다.

### 무작위 분할과 층화 분할 비교

| 구분 | 테스트 도미 | 테스트 빙어 |
| --- | --- | --- |
| 일반 무작위 분할 | 10마리 | 3마리 |
| 층화 분할 | 9마리 | 4마리 |

전체 데이터는 도미 35마리, 빙어 14마리다. 일반 무작위 분할에서는 각 종류가 고르게 포함된다는 보장이 없다. 층화 분할은 전체의 클래스 비율을 고려하지만, 데이터의 다른 특성까지 자동으로 대표하게 해 주지는 않는다. 위 숫자는 `random_state=42`와 자료의 데이터에서 나온 결과다.
