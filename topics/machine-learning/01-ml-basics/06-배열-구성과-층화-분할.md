# 6. 배열 구성과 층화 분할

학습 범위: 23에서 26쪽

## 두 열을 붙이고 정답을 연결

```python
fish_data = np.column_stack((length, weight))
fish_target = np.concatenate((np.ones(35), np.zeros(14)))
print(fish_data[:3])
print(fish_data.shape, fish_target.shape)
```

```text
[[ 25.4 242. ]
 [ 26.3 290. ]
 [ 26.5 340. ]]
(49, 2) (49,)
```

`column_stack()`은 길이와 무게를 열로 나란히 붙임. `ones(35)`와 `zeros(14)`로 정답 배열을 만들고 `concatenate()`로 앞뒤를 연결. `1.`과 `0.`은 실수 표현이며 도미와 빙어라는 이름표의 의미는 같음.

## train_test_split 사용

```python
from sklearn.model_selection import train_test_split

train_input, test_input, train_target, test_target = train_test_split(
    fish_data, fish_target, random_state=42
)
print(train_input.shape, test_input.shape)
print(np.count_nonzero(test_target == 1), np.count_nonzero(test_target == 0))
```

```text
(36, 2) (13, 2)
10 3
```

함수의 결과 순서는 훈련 입력, 테스트 입력, 훈련 정답, 테스트 정답. 기본 테스트 비율 25%에 따라 36마리와 13마리로 나뉨. 앞의 수동 분할 35마리와 14마리와는 개수가 다름.

## 클래스 비율을 고려한 층화 분할

```python
train_input, test_input, train_target, test_target = train_test_split(
    fish_data, fish_target, stratify=fish_target, random_state=42
)
print(np.count_nonzero(test_target == 1), np.count_nonzero(test_target == 0))
```

```text
9 4
```

전체는 도미 35마리와 빙어 14마리로 2.5:1. 일반 무작위 분할은 테스트 10:3, 층화 분할은 9:4가 됨. 샘플 수는 정수이므로 비율을 완전히 일치시키지는 못함.

`stratify`는 클래스 비율을 고려하고 `random_state`는 분할 재현을 담당. 두 설정의 역할은 다름. 이후 표준화에서는 이 훈련 36마리, 테스트 13마리를 그대로 사용함.
