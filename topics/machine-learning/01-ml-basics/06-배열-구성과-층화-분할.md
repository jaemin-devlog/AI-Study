# 6. 배열 구성과 층화 분할

앞에서는 행 번호를 직접 섞어 데이터를 나눴음. 같은 작업을 NumPy와 사이킷런 함수로 처리할 수 있음. 여기서는 입력을 만드는 방식과 분할하는 방식을 차례로 바꾸며, 각 함수가 어떤 모양의 데이터를 반환하는지 확인함.

## 두 목록을 열로 나란히 붙이기

```python
fish_data = np.column_stack((length, weight))
fish_target = np.concatenate((np.ones(35), np.zeros(14)))
print(fish_data[:3])
print(fish_data.shape, fish_target.shape)
```

```text
[[ 25.4 242. ]
 [ 26.3 290. ]
 [ 26.5 340. ]]
(49, 2) (49,)
```

`column_stack((length, weight))`는 길이를 첫 열, 무게를 둘째 열로 붙임. 같은 위치의 값이 한 행이 되므로 앞에서 만든 `[길이, 무게]`와 같은 의미임. 괄호 안 두 목록을 묶어 전달하고 입력 결과는 `(49, 2)`가 됨.

`ones(35)`는 1이 35개인 배열, `zeros(14)`는 0이 14개인 배열. `concatenate()`는 이를 앞뒤로 이어 도미 정답 다음에 빙어 정답을 붙임. 출력의 `1.`과 `0.`은 실수 표현이며 클래스 이름표라는 의미는 같음.

## 입력과 정답을 함께 나누는 함수

```python
from sklearn.model_selection import train_test_split

train_input, test_input, train_target, test_target = train_test_split(
    fish_data, fish_target, random_state=42
)
print(train_input.shape, test_input.shape)
print(np.count_nonzero(test_target == 1), np.count_nonzero(test_target == 0))
```

```text
(36, 2) (13, 2)
10 3
```

`train_test_split()`은 입력과 정답을 같은 행 기준으로 나눔. 반환 순서는 훈련 입력, 테스트 입력, 훈련 정답, 테스트 정답이므로 변수의 순서를 맞춰 받아야 함.

기본 테스트 비율은 25%라 훈련 36마리와 테스트 13마리로 나뉨. 앞에서 직접 정한 35마리와 14마리와 다름. 이후 출력값을 비교할 때 이 차이를 알아야 함. 테스트에서 `== 1`과 `== 0`인 위치를 세면 도미 10마리와 빙어 3마리임.

## 클래스 비율을 고려한 층화 분할

전체는 도미 35마리와 빙어 14마리로 2.5:1임. 무작위로 섞더라도 작은 테스트 세트에서 이 비율이 비슷하게 유지된다는 보장은 없음. `stratify`에 정답을 넘기면 클래스 비율을 가능한 한 유지하도록 분할함. 이를 층화 분할이라고 함.

```python
train_input, test_input, train_target, test_target = train_test_split(
    fish_data, fish_target, stratify=fish_target, random_state=42
)
print(np.count_nonzero(test_target == 1), np.count_nonzero(test_target == 0))
```

```text
9 4
```

테스트가 도미 9마리와 빙어 4마리로 바뀜. 생선 수는 정수이므로 전체 비율과 완전히 같지는 않지만 일반 분할의 10:3보다 전체 구성에 가까움.

`random_state`는 같은 분할을 재현하고 `stratify`는 클래스 비율을 고려함. 서로 다른 역할임. 층화 분할을 했다고 길이와 무게의 모든 분포까지 완벽히 같아지는 것은 아니므로 실제 구성도 확인함.

이후에는 마지막 층화 분할의 훈련 36마리와 테스트 13마리를 사용함. 다음에는 이 분할로 높은 점수를 얻어도 특정 새 생선에서 예상과 다른 판단이 나오는 이유를 살펴봄.
