# 3. 최근접 이웃 학습과 예측

학습 범위: 8에서 13쪽

## 모델 생성과 학습

앞에서 만든 `fish_data`, `fish_target`을 사용.

```python
from sklearn.neighbors import KNeighborsClassifier

kn = KNeighborsClassifier()
kn.fit(fish_data, fish_target)
print(kn.score(fish_data, fish_target))
print(kn.predict([[30, 600]]))
```

```text
1.0
[1]
```

`KNeighborsClassifier()`로 모델 객체를 만들고 `fit()`에 입력과 정답을 전달. 기본 이웃 수는 5개이며 가까운 이웃의 다수결로 생선 종류를 예측함.

`score()`는 이 분류 모델에서 정확도를 반환.

$$
\mathrm{Accuracy}=\frac{\text{정답과 일치한 예측 수}}{\text{평가한 샘플 수}}
$$

1.0은 학습에 사용한 49마리를 모두 맞혔다는 뜻. 같은 데이터로 다시 평가한 결과이므로 새로운 생선에서도 항상 맞힌다고 보장하지는 못함.

`predict([[30, 600]])`의 결과 1은 도미로 예측했다는 뜻. 실제 정답을 모르면 맞았는지는 알 수 없음. 안쪽 목록은 한 마리의 특성, 바깥 목록은 샘플 목록이어서 한 마리도 2차원 입력으로 전달함.

## KNN은 무엇을 저장할까?

KNN은 예측에 참고할 훈련 사례와 정답을 보관함. 새 입력이 들어오면 가까운 훈련 사례를 찾아 예측에 사용하므로 별도의 직선 계수로 관계를 표현하는 모델과 다름.

`_fit_X`, `_y`는 보관된 데이터를 살펴볼 수 있는 내부 속성. 학습 과정에는 데이터 검증과 이웃 검색을 위한 자료구조 준비도 포함될 수 있음. 데이터가 많아지면 저장 공간과 이웃 탐색 비용도 고려해야 함.

## 이웃 수를 늘리면 항상 좋을까?

```python
kn49 = KNeighborsClassifier(n_neighbors=49)
kn49.fit(fish_data, fish_target)
print(kn49.score(fish_data, fish_target))
```

```text
0.7142857142857143
```

이웃 49개는 전체 생선 49마리가 투표한다는 뜻. 어느 위치에서 예측하더라도 도미 35마리가 빙어 14마리보다 많으므로 모두 도미로 예측. 정확도는 35/49임.

```python
for k in range(5, 50):
    model = KNeighborsClassifier(n_neighbors=k)
    model.fit(fish_data, fish_target)
    score = model.score(fish_data, fish_target)
    if score < 1:
        print(k, score)
        break
```

```text
18 0.9795918367346939
```

`range(5, 50)`은 5부터 49까지 반복. `break`는 첫 오답이 생긴 설정을 찾으면 반복을 끝냄. 여기서는 이웃 18개에서 49마리 중 48마리를 맞힘.

이것은 훈련 점수의 변화를 관찰한 결과. 이 표만으로 새 데이터에 가장 좋은 이웃 수를 정할 수는 없고 검증 데이터에서 후보를 비교해야 함.
