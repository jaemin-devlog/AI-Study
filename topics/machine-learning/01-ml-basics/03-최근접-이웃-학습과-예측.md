# 3. 최근접 이웃 학습과 예측

앞 파일에서 `fish_data`에는 49마리의 길이와 무게가, `fish_target`에는 같은 순서의 도미 1과 빙어 0이 들어 있음. 이 데이터를 이용해 가까운 생선의 종류로 판단하는 KNN 분류 모델을 만듦.

## 가까운 이웃이 투표하는 방법

k-최근접 이웃은 새 입력과 가까운 훈련 샘플 k개를 찾는 알고리즘. 분류에서는 그 이웃 가운데 가장 많은 클래스를 예측함. 기본 설정은 이웃 5개가 같은 비중으로 한 표씩 투표하는 방식임.

예측에 참고하는 것은 새 생선의 정답이 아니라 이미 종류를 알고 있는 훈련 생선들의 정답. 새 생선의 길이와 무게로 이웃을 찾은 뒤 그 이웃의 종류를 세는 순서임.

```python
from sklearn.neighbors import KNeighborsClassifier

kn = KNeighborsClassifier()
kn.fit(fish_data, fish_target)
print(kn.score(fish_data, fish_target))
print(kn.predict([[30, 600]]))
```

```text
1.0
[1]
```

`KNeighborsClassifier()`로 모델 객체를 만들고 `kn`에 저장함. `fit()`의 첫 인수는 입력, 둘째는 그 입력의 정답. `score()`는 예측 결과와 실제 정답을 비교한 정확도를 반환함.

$$
\mathrm{Accuracy}=\frac{n_{\mathrm{correct}}}{n_{\mathrm{evaluated}}}
$$

분자는 맞힌 샘플 수, 분모는 평가한 샘플 수. 1.0은 이번에 평가한 49마리를 모두 맞혔다는 뜻임. 다만 학습에 사용한 생선을 그대로 다시 평가했으므로 처음 보는 생선에 대한 결과는 아직 모름.

## 예측한 이름과 맞힌 결과 구분하기

`predict([[30, 600]])`은 길이 30cm, 무게 600g인 생선을 입력함. 안쪽 목록은 한 마리의 특성이고 바깥 목록은 모델에 전달할 샘플들을 담음. 한 마리여도 학습 때와 같은 2차원 입력이어야 함.

결과 `[1]`은 도미로 예측했다는 뜻. 이 생선의 실제 종류를 모르면 예측이 맞았는지는 알 수 없음. 예측은 답을 내는 과정이고 평가는 그 답을 실제 정답과 비교하는 과정임.

## KNN의 학습에서 보관하는 것

KNN은 직선의 기울기 같은 관계식을 학습하는 대신 훈련 사례와 정답을 예측의 참고 자료로 보관함. 새 입력이 들어올 때 그 사례들에서 이웃을 찾아 정답을 사용함. `_fit_X`, `_y`는 보관된 내용을 살펴볼 수 있는 내부 속성임.

학습에는 데이터 검증과 이웃 검색을 위한 자료구조 준비도 포함될 수 있음. 데이터가 많아지면 보관할 공간과 이웃 탐색 비용도 늘어날 수 있음.

## 이웃을 모두 참고하면 어떻게 될까?

```python
kn49 = KNeighborsClassifier(n_neighbors=49)
kn49.fit(fish_data, fish_target)
print(kn49.score(fish_data, fish_target))
```

```text
0.7142857142857143
```

전체가 49마리인데 이웃도 49개로 정하면 어디서 예측하든 모든 생선이 투표함. 도미 35마리가 빙어 14마리보다 많으므로 항상 도미를 선택함. 도미만 맞히므로 정확도는 $35/49\approx0.7143$이 됨. 가까운 주변의 특성이 전체 다수에 묻힌 결과임.

```python
for k in range(5, 50):
    model = KNeighborsClassifier(n_neighbors=k)
    model.fit(fish_data, fish_target)
    score = model.score(fish_data, fish_target)
    if score < 1:
        print(k, score)
        break
```

```text
18 0.9795918367346939
```

반복문은 이웃 수를 5부터 49까지 바꿔 같은 데이터의 정확도를 확인함. 처음으로 점수가 1보다 낮아지면 `break`로 종료함. 이 데이터에서는 18개에서 처음 오답이 발생해 49마리 중 48마리를 맞힘.

이웃 수가 너무 작으면 개별 사례에 민감하고 너무 크면 주변 특징을 놓칠 수 있음. 하지만 지금 본 것은 훈련 점수이므로 최적 이웃 수를 정한 것은 아님. 다음에는 학습에 사용하지 않을 생선을 남겨 예측 성능을 확인함.
