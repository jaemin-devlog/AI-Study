# 생선 데이터와 KNN

본문 코드는 개념별 부분 코드. 데이터 준비부터 독립 실행할 때는 [전체 실습](06-생선-분류-예제.md)을 사용.


## 데이터의 구성

- 목표는 생선의 길이와 무게를 입력하여 도미인지 빙어인지 예측하는 것이다.

- 샘플: 데이터 한 건 → 생선 한 마리
- 특성: 예측에 사용하는 입력 정보 → 길이와 무게
- 타깃: 모델이 맞혀야 하는 정답 → 생선의 종류
- 클래스: 분류할 범주 → 도미와 빙어

- 도미 35마리와 빙어 14마리, 총 49마리의 데이터를 사용한다.

- 산점도에서 점 하나는 생선 한 마리이고, 가로축은 길이, 세로축은 무게를 나타낸다. 이 데이터에서는 도미와 빙어가 서로 다른 영역에 모여 있다.

## 입력과 정답 만들기

```python
length = bream_length + smelt_length
weight = bream_weight + smelt_weight
fish_data = [[l, w] for l, w in zip(length, weight)]
fish_target = [1] * 35 + [0] * 14
```

- 리스트를 합치면 도미가 먼저, 빙어가 나중에 들어간다.

- `zip()`은 같은 위치의 길이와 무게를 짝지어 준다. 각 생선은 `[길이, 무게]` 형태로 표현되며 전체 입력은 49행 2열이다.

- 정답은 도미를 1, 빙어를 0으로 정한다. 입력과 정답은 같은 생선끼리 같은 위치에 있어야 한다.
- 예를 들어 도미의 입력 `[25.4, 242.0]`과 정답 `1`은 같은 위치에 둔다. 순서가 어긋나면 다른 생선의 정답으로 학습하게 된다.

## KNN 모델 학습과 예측

```python
from sklearn.neighbors import KNeighborsClassifier

kn = KNeighborsClassifier()
kn.fit(fish_data, fish_target)
print(kn.score(fish_data, fish_target))  # 1.0
print(kn.predict([[30, 600]]))           # [1]
```

- KNN 분류 모델 객체를 생성한다.

- `fit()`에 생선의 길이와 무게, 정답 레이블을 전달해 모델을 학습한다.

- `score()` 결과가 1.0이면 학습에 사용한 49마리 모두를 맞혔다는 뜻이다. 학습에 사용한 데이터로 다시 평가했으므로 새로운 데이터에서도 100% 정확하다는 뜻은 아니다.

- `predict([[30, 600]])`의 결과 `[1]`은 길이 30cm, 무게 600g인 생선을 도미로 예측했다는 뜻이다. 실제 정답을 모르면 예측이 맞았는지는 확인할 수 없다.

- 안쪽 리스트는 생선 한 마리의 특성이고 바깥쪽 리스트는 여러 샘플을 담는 구조다. 한 마리만 예측해도 2차원 형태로 전달한다.

## 학습, 예측, 평가의 차이

| 메서드 | 입력 | 결과 |
| --- | --- | --- |
| `fit(X, y)` | 훈련 입력과 정답 | 모델이 예측에 사용할 정보를 준비 |
| `predict(X)` | 예측할 입력 | 예측한 클래스 |
| `score(X, y)` | 평가 입력과 정답 | 이 분류 모델에서는 정확도 |

KNN은 훈련 사례를 보관한 뒤 새 입력이 들어오면 가까운 사례를 찾아 비교한다. 분류에서는 기본 설정으로 이웃의 정답을 같은 비중으로 투표해 더 많은 클래스를 선택한다. 예측 시 실제 정답을 입력하지 않으며, 예측이 맞았는지는 정답과 비교해야 알 수 있다.

## KNN이 예측하는 방법

- KNN은 새로운 입력과 가까운 훈련 데이터 k개를 찾아 이웃들의 정보를 이용한다.

- 기본 분류 설정에서는 가장 가까운 이웃 5개의 정답을 다수결하여 종류를 예측한다.

- KNN은 훈련 데이터를 보관하고 예측할 때 이웃을 찾는다. 데이터가 많으면 저장 공간과 이웃을 찾는 데 드는 시간이 늘어날 수 있다.

```python
kn49 = KNeighborsClassifier(n_neighbors=49)
kn49.fit(fish_data, fish_target)
print(kn49.score(fish_data, fish_target))  # 약 0.714
```

이웃을 49개로 설정하면 모든 생선이 투표한다. 도미 35마리와 빙어 14마리 중 도미가 더 많으므로 어떤 입력이든 도미로 예측한다. 훈련 정확도는 다음과 같다.

$$
\mathrm{Accuracy} = \frac{35}{49} \approx 0.714
$$

강의 실습에서는 k를 5부터 늘렸을 때 18에서 처음으로 49마리 중 한 마리를 틀려 훈련 정확도가 약 0.9796이 된다.

k가 너무 작으면 특이한 데이터에 영향을 받기 쉽고, 너무 크면 가까운 이웃의 특징이 묻힐 수 있다. 이웃 수를 많이 늘린다고 항상 정확해지지는 않는다. 여러 k를 검증 데이터로 비교하고 테스트 데이터는 최종 평가에 사용한다.

## 산점도로 데이터 분포 확인

도미와 빙어의 길이와 무게 리스트는 첨부 실습의 `1-3.ipynb`에서 준비한 값을 사용한다.

```python
import matplotlib.pyplot as plt

plt.scatter(bream_length, bream_weight, label='Bream')
plt.scatter(smelt_length, smelt_weight, label='Smelt')
plt.xlabel('Length (cm)')
plt.ylabel('Weight (g)')
plt.legend()
plt.show()
```

![도미와 빙어의 길이 및 무게 분포](../assets/생선-분포.png)

`scatter(x, y)`는 같은 위치의 길이와 무게를 한 점으로 표시한다. `label`과 `legend()`는 두 종류를 구분하는 범례를 만든다. `xlabel()`과 `ylabel()`은 축 이름을 붙인다.

가로축은 길이(cm), 세로축은 무게(g)이고 점 하나가 생선 한 마리다. 파란 도미는 주로 오른쪽 위, 주황 빙어는 왼쪽 아래에 모인다. 이 데이터에서는 길이와 무게가 비슷한 생선끼리 같은 종류일 가능성이 높아 주변 이웃을 참고하는 KNN을 시도할 수 있다. 다만 산점도의 눈금과 모델이 계산하는 실제 거리는 별도로 확인해야 한다.

그래프는 실습 데이터를 사용해 직접 생성했다.
