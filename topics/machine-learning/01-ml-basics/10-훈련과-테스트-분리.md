# 훈련 데이터와 테스트 데이터

학습에 사용하지 않은 데이터에서 성능을 확인하기 위해 데이터를 분리

훈련 입력과 정답으로 학습한 뒤 테스트 입력을 예측하고 실제 정답과 비교

정답을 알고 있는 테스트 데이터라도 그 정답은 학습이 아닌 채점에 사용

도미 35마리 다음에 빙어 14마리가 있는 데이터를 순서대로 자르면 훈련에는 도미만, 테스트에는 빙어만 들어감

이 경우 모델은 도미만 학습해 테스트 정확도가 0.0이 됨. 입력과 정답의 짝을 유지하면서 섞어야 함

![분할 결과 비교](../assets/pdf/분할과-편향.png)

위쪽은 순서대로 분할, 아래쪽은 섞은 뒤 분할한 결과. 색은 도미와 빙어, 경계선은 훈련과 테스트의 구분

테스트 정확도 100%는 그 테스트 생선을 모두 맞혔다는 뜻. 앞으로 만날 모든 생선을 맞힌다는 보장은 없음

## 7. 무작위 분할과 층화 분할

```python
from sklearn.model_selection import train_test_split

train_input, test_input, train_target, test_target = train_test_split(
    fish_data, fish_target, stratify=fish_target, random_state=42
)
```

49마리가 훈련 36마리, 테스트 13마리로 분리

`stratify`는 도미와 빙어의 비율을 고려. `random_state`는 같은 분할을 다시 만들기 위한 설정
