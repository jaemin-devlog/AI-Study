# 머신러닝의 기본 흐름과 데이터 준비 그림 살펴보기

### 생선의 길이와 무게

![생선 산점도](../assets/pdf/생선-산점도.png)

가로축은 길이(cm), 세로축은 무게(g). 점 하나가 생선 한 마리를 뜻함. 파란 점은 도미, 주황 점은 빙어로 두 종류가 서로 다른 위치에 모여 있음. 길이와 무게를 특성으로 사용해 생선 종류를 구분할 수 있는 이유를 보여줌.

그래프를 보면 왼쪽 아래의 빙어는 길이가 약 10\~15cm이고, 오른쪽 위의 도미는 대체로 약 25\~42cm에 모여 있음. 같은 종류 안에서도 길이와 무게가 서로 조금씩 다르기 때문에 한 마리의 값만으로 모든 생선을 설명할 수는 없음.

새로운 생선이 들어오면 모델은 이 두 숫자를 기존 생선의 숫자와 비교함. 예를 들어 길이와 무게가 도미가 모인 영역에 가까우면 주변 이웃에도 도미가 많을 가능성이 있음. 다만 이 그림의 데이터가 잘 구분된다고 해서 모든 생선이 항상 이렇게 나뉜다는 뜻은 아님.

### 생선 분포

![생선 분포](../assets/생선-분포.png)

같은 생선 데이터를 도미와 빙어로 나누어 표시한 그림. 도미는 대체로 길고 무겁고 빙어는 짧고 가벼움. 산점도의 가까운 점들을 살펴보면 새로운 생선이 어느 종류에 가까운지 짐작할 수 있음.

가로 방향으로 움직이면 길이가 달라지고, 세로 방향으로 움직이면 무게가 달라짐. 두 특성을 함께 보면 같은 길이에서도 무게가 다를 수 있다는 것을 확인할 수 있음.

KNN은 새 생선과 훈련 데이터 사이의 거리를 계산한 뒤 가까운 생선들의 종류를 살펴봄. 단, 그래프에서 눈으로 보이는 거리와 모델이 계산하는 거리는 축의 표시 비율에 따라 다르게 느껴질 수 있으므로 특성의 스케일도 확인해야 함.

### 순서대로 나눈 데이터의 문제

![분할과 편향](../assets/pdf/분할과-편향.png)

파란색은 도미, 주황색은 빙어. 위처럼 순서대로 나누면 훈련 세트에 도미만, 테스트 세트에 빙어만 들어감. 아래처럼 섞으면 두 종류가 양쪽에 포함됨. 데이터를 나누기 전 순서와 분포를 확인해야 하는 이유임.

전체 49마리가 도미 35마리 다음에 빙어 14마리 순서로 저장돼 있다고 가정함. 앞의 35마리로 훈련하고 뒤의 14마리로 평가하면 훈련에는 도미만, 테스트에는 빙어만 들어감.

이때 모델은 훈련 과정에서 빙어를 한 번도 보지 못했기 때문에 두 종류를 구분하는 방법을 제대로 배울 수 없음. 그림 아래에서는 섞은 뒤 훈련에 도미 27마리와 빙어 8마리, 테스트에 도미 8마리와 빙어 6마리가 들어감. 섞기는 편향을 줄이는 데 도움이 되지만, 종류별 비율까지 맞추려면 층화 분할도 고려해야 함.

### 훈련 데이터와 테스트 데이터 분포

![데이터 분할 비교](../assets/데이터-분할-비교.png)

파란 점은 훈련 데이터, 주황색 ×는 테스트 데이터. 왼쪽은 순서대로 나누어 테스트에 빙어만 들어갔고, 오른쪽은 섞은 뒤 나누어 두 종류가 양쪽에 들어감. 무작위 분할도 항상 비율을 보장하는 것은 아니므로 결과를 확인해야 함.

각 점의 위치는 생선의 길이와 무게를 나타내고, 색상과 모양은 생선 종류가 아니라 어느 세트에 들어갔는지를 나타냄. 왼쪽에서는 주황색 테스트 점이 왼쪽 아래에만 몰려 있음.

오른쪽은 테스트 점이 양쪽에 분포하므로 훈련에 사용하지 않은 도미와 빙어를 모두 평가할 수 있음. 다만 특정 무작위 분할의 결과일 뿐이므로 세트마다 샘플 수와 종류별 비율을 확인하는 것이 중요함.

### 표준화 전후 이웃 비교

![표준화 전후](../assets/pdf/표준화-전후.png)

삼각형은 새 생선, 동그라미로 표시한 점은 선택된 이웃. 왼쪽은 무게의 숫자 범위가 길이보다 커서 거리에 미치는 영향이 큼. 오른쪽은 각 특성을 표준화한 결과이며 이웃이 달라져 예측도 빙어에서 도미로 바뀜.

새 생선의 원래 값은 길이 25cm, 무게 150g임. 표준화 전에는 숫자 차이가 큰 무게의 영향으로 선택된 다섯 이웃 중 빙어가 네 마리여서 빙어로 예측함.

표준화 후에는 훈련 데이터에서 계산한 평균과 표준편차로 각 값을 변환함. 새 생선도 같은 기준으로 바꾸고 거리를 다시 계산하니 선택된 다섯 이웃이 모두 도미가 됨. 즉 생선 자체가 바뀐 것이 아니라 거리의 기준이 바뀐 것임.

### 표준화와 축의 차이

![표준화와 이웃](../assets/표준화와-이웃.png)

세 그림은 원래 데이터, 축 범위만 변경한 그림, 표준화한 데이터를 차례로 보여줌. 빨간 마름모는 이웃, 검은 삼각형은 새 생선. 축 범위만 바꾸면 화면 모습만 바뀌지만 표준화는 실제 입력값과 거리 계산을 바꿔 이웃 선택에도 영향을 줌.

왼쪽과 가운데는 같은 원본 데이터임. 가운데에서 가로축을 세로축과 비슷한 숫자 범위로 표시하면 점들이 한쪽에 몰려 보이지만, 축의 눈금만 바꿨으므로 실제 데이터와 모델의 이웃은 변하지 않음.

오른쪽은 각 특성에서 훈련 평균을 빼고 훈련 표준편차로 나눈 값임. 따라서 가로축과 세로축의 단위가 원래 cm와 g이 아닌 표준화된 값이 됨. 새 생선에도 훈련 데이터에서 구한 평균과 표준편차를 적용해야 같은 기준으로 거리를 비교할 수 있음.
