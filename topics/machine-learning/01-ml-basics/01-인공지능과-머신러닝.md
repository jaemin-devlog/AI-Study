# 인공지능과 머신러닝

본문 코드는 개념별 부분 코드. 데이터 준비부터 독립 실행할 때는 [전체 실습](06-생선-분류-예제.md)을 사용.


## 인공지능, 머신러닝, 딥러닝의 관계

- 인공지능(AI)은 인식, 추론, 판단처럼 사람의 지능이 필요한 작업을 컴퓨터가 수행하도록 만드는 기술 전반을 뜻한다.

- 인공지능이 반드시 데이터에서 학습하는 것은 아니다.

- 사람이 판단 규칙을 직접 작성해 동작하도록 만들 수도 있다.

- 머신러닝(ML)은 인공지능을 구현하는 방법 중 하나로, 사람이 모든 규칙을 직접 작성하는 대신 데이터에서 패턴을 학습하도록 하는 방법이다.

- 예를 들어 생선의 길이가 특정 값 이상이면 도미라고 규칙을 직접 정하는 대신, 생선의 길이와 무게, 실제 종류를 제공하여 새로운 생선의 종류를 예측하도록 한다.

- 딥러닝(DL)은 머신러닝의 한 종류로, 여러 층으로 구성된 신경망을 사용해 데이터의 패턴을 학습한다.

- 관계 정리 → 인공지능 ⊃ 머신러닝 ⊃ 딥러닝

### 세 개념을 구분하는 이유

사람이 "길이가 25cm 이상이면 도미"처럼 기준을 직접 정할 수 있다. 머신러닝에서는 여러 생선의 측정값과 종류를 제공하고, 그 사례를 바탕으로 새로운 생선의 종류를 판단한다.

머신러닝을 사용할 때도 무엇을 예측하고 어떤 데이터를 모을지는 사람이 정해야 한다. 예측이 잘 되었는지 평가할 기준도 정해야 한다.

## 머신러닝의 학습 방식

- 지도학습은 입력 데이터와 정답을 함께 제공하여 학습하는 방법이다.

- 생선의 길이와 무게를 입력하고 실제 종류를 정답으로 제공하는 생선 분류가 지도학습에 해당한다.

- 비지도학습은 정답 없이 입력 데이터의 비슷한 점이나 구조를 찾는 방법이다.

- 생선의 종류를 알려 주지 않고 크기가 비슷한 생선끼리 묶는 것이 예시다. 다만 비슷한 생선끼리 묶였다는 것만으로 각 무리가 도미인지 빙어인지 알 수 있는 것은 아니다.

- 강화학습은 행동의 결과로 받은 보상을 바탕으로 더 많은 보상을 얻는 행동을 배우는 방법이다.

## 지도학습의 입력과 정답

입력은 예측할 때 모델에 제공하는 정보, 타깃은 예측하고 싶은 정답이다. 생선 분류에서는 길이와 무게가 입력이고 종류가 타깃이다. 훈련할 때 입력과 타깃을 함께 제공한 뒤, 새 생선의 입력으로 종류를 예측한다.

비지도학습에서 비슷한 생선끼리 묶더라도 그룹의 이름을 자동으로 도미와 빙어라고 알게 되는 것은 아니다. 정답 없이 어떤 기준으로 묶였는지 따로 살펴봐야 한다.

## 분류와 회귀

- 분류는 도미와 빙어처럼 어느 종류에 속하는지 예측하는 문제다.

- 회귀는 생선의 무게처럼 연속적인 수치를 예측하는 문제다.

- 생선 종류를 1과 0으로 표현하더라도 숫자는 종류를 구분하기 위한 이름표이므로 분류 문제다.
