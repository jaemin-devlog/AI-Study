# 특성 스케일과 표준화

훈련한 KNN의 테스트 정확도는 1.0이지만 `[25, 150]`을 넣으면 빙어 `[0.]`로 예측

표준화 전 가까운 이웃은 도미 1마리와 빙어 4마리

길이는 약 10\~40cm, 무게는 수 g에서 1,000g 정도까지 퍼져 있어 거리 계산에 무게 차이가 크게 반영됨

표준화는 특성별 평균을 빼고 표준편차로 나누어 비교 기준을 맞추는 방법

$$
z = \frac{x - \mu}{\sigma}
$$

$x$는 원래 값, $\mu$는 훈련 데이터의 평균, $\sigma$는 훈련 데이터의 표준편차

```python
mean = np.mean(train_input, axis=0)
std = np.std(train_input, axis=0)
train_scaled = (train_input - mean) / std
test_scaled = (test_input - mean) / std
new = (np.array([25, 150]) - mean) / std

kn.fit(train_scaled, train_target)
print(kn.score(test_scaled, test_target))
print(kn.predict([new]))
```

```text
1.0
[1.]
```

평균과 표준편차는 훈련 데이터에서만 구함. 테스트 데이터와 새 생선에도 같은 기준을 적용해 데이터 누수를 막음

![표준화 전후 이웃](../assets/pdf/표준화-전후.png)

왼쪽은 원래 값, 오른쪽은 실제 입력을 표준화한 결과. 표시된 원은 모델이 선택한 이웃

축 표시 범위만 바꾸면 모델의 입력이 바뀌지 않아 예측도 그대로. 표준화 후에는 이웃이 도미 5마리로 바뀌어 `[1.]`을 예측

테스트 정확도는 전후 모두 1.0. 테스트에 없는 새 생선은 이웃이 달라져 예측이 바뀔 수 있음
