# 특성 공학과 규제

농어의 길이뿐 아니라 높이와 두께도 사용하고, 특성을 확장한 뒤 모델의 복잡도를 조절하는 과정

## 1. 다중 회귀

길이가 같아도 높이나 두께가 다르면 무게가 달라질 수 있음

다중 회귀는 여러 입력 특성을 사용해 하나의 숫자를 예측하는 선형 회귀

$$
\hat{y} = w_1x_1 + w_2x_2 + w_3x_3 + b
$$

$x_1, x_2, x_3$은 길이, 높이, 두께. $w_1, w_2, w_3$은 각 특성의 계수, $b$는 절편

## 2. CSV와 데이터 준비

CSV는 쉼표로 값을 구분한 파일. pandas의 `read_csv()`는 이 파일을 행과 열이 있는 DataFrame으로 읽음

```python
import pandas as pd

df = pd.read_csv(csv_path, skipinitialspace=True)
print(df.head())
```

`csv_path`는 실습의 `perch_full.csv` 경로. `head()`로 앞의 다섯 행을 확인

`length`, `height`, `width`가 입력 열. 왼쪽 행 번호는 DataFrame의 인덱스이며 입력 특성이 아님

`df.to_numpy()`로 입력을 배열로 바꾸고 같은 순서의 농어 무게 56개를 정답으로 사용

분할 후 입력은 훈련 `(42, 3)`, 테스트 `(14, 3)`. 코드에서 사용하는 실제 경로 설정은 [데이터 준비와 실행](../실행-안내.md) 참고

## 3. 특성 공학

특성 공학은 기존 입력을 가공하거나 조합해 새로운 특성을 만드는 작업

길이, 높이, 두께 3개에 제곱과 서로의 곱을 추가하면 2차 특성 9개가 됨

```python
from sklearn.preprocessing import PolynomialFeatures

poly = PolynomialFeatures(include_bias=False)
poly.fit(train_input)
train_poly = poly.transform(train_input)
test_poly = poly.transform(test_input)
print(train_poly.shape)
```

```text
(42, 9)
```

`fit()`은 만들 조합을 준비하고 `transform()`은 실제 특성값을 계산

농어 42마리는 그대로이고 한 마리를 나타내는 열이 3개에서 9개로 늘어남

`include_bias=False`는 상수항 1의 열을 제외. 회귀 모델의 절편을 없애는 설정은 아님

## 4. 특성이 많으면 무조건 좋을까?

`degree=5`로 확장하면 훈련 입력이 `(42, 55)`가 됨

```python
poly5 = PolynomialFeatures(degree=5, include_bias=False)
poly5.fit(train_input)
train_poly5 = poly5.transform(train_input)
test_poly5 = poly5.transform(test_input)
print(train_poly5.shape)
```

```text
(42, 55)
```

5차 모델의 훈련 R²가 거의 1이었지만 테스트 R²는 약 -144.4로 떨어짐

고차 특성은 계산이 수치적으로 불안정할 수 있어 데이터와 계산 조건에 따라 결과가 달라질 수 있음

![차수별 점수](../assets/pdf/특성과-과대적합.png)

막대는 특성 수에 따른 훈련과 테스트 R². 차수와 특성 수가 늘었다고 항상 새 데이터에서 더 좋은 것은 아님

## 5. 규제와 표준화

일반 선형 회귀는 실제값과 예측값의 제곱오차를 줄이는 방향으로 계수를 학습

규제는 예측 오차에 계수 크기에 대한 벌점도 더해 훈련 데이터에 지나치게 맞춰지는 것을 억제

`alpha`가 작으면 규제가 약하고, 크면 강해짐. 너무 강하면 중요한 관계도 충분히 학습하지 못할 수 있음

규제 전에는 단위에 따라 계수의 크기가 달라지지 않도록 특성의 스케일을 맞춤

```python
from sklearn.preprocessing import StandardScaler

ss = StandardScaler()
ss.fit(train_poly5)
train_scaled = ss.transform(train_poly5)
test_scaled = ss.transform(test_poly5)
```

평균과 표준편차는 훈련 데이터에서만 계산. 테스트에도 같은 기준을 적용해 데이터 누수를 막음

## 6. 릿지와 라쏘

릿지는 계수의 제곱합에 벌점을 주는 L2 규제

라쏘는 계수의 절댓값 합에 벌점을 주는 L1 규제. 일부 계수를 정확히 0으로 만들 수 있음

```python
from sklearn.linear_model import Ridge, Lasso

ridge = Ridge(alpha=0.1)
ridge.fit(train_scaled, train_target)
lasso = Lasso(alpha=10, max_iter=10000)
lasso.fit(train_scaled, train_target)
print(ridge.score(test_scaled, test_target))
print(lasso.score(test_scaled, test_target))
print((lasso.coef_ == 0).sum())
```

```text
0.9827976465386983
0.9830309645308444
48
```

55개 특성 중 48개 계수가 0. 입력 열이 삭제된 것은 아니고 해당 특성이 이 모델의 예측에 직접 기여하지 않는다는 뜻

`max_iter`는 계수를 찾기 위한 최대 반복 횟수이며 규제 강도가 아님

## 7. 같은 입력에서 모델 비교

같은 표준화 입력으로 비교한 이번 실행 결과

| 모델 | 훈련 R² | 테스트 R² | 0인 계수 |
| --- | --- | --- | --- |
| 규제 없는 선형 회귀 | 0.9997 | -4.3927 | 0 |
| 릿지 `alpha=0.1` | 0.9904 | 0.9828 | 0 |
| 라쏘 `alpha=10` | 0.9888 | 0.9830 | 48 |

규제 없는 모델은 훈련 점수에 비해 테스트 점수가 크게 낮음. 고차 무규제 회귀의 정확한 수치는 환경에 따라 달라질 수 있음

![계수 및 규제 강도 비교](../assets/계수와-규제강도.png)

왼쪽 가로축은 특성 번호, 세로축은 계수. 오른쪽은 alpha별 테스트 R²

라쏘의 작은 alpha 일부에서는 수렴 경고가 나왔으므로 해당 점수는 주의해서 해석

실습에서 테스트 점수를 반복해 비교했지만 실제 모델 설정은 검증 데이터로 고르고 테스트 데이터는 최종 평가에 사용
