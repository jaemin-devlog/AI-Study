# 5. 규제와 특성 표준화

규제는 계수의 크기를 기준으로 벌점을 줌. 그런데 계수의 숫자는 입력을 어떤 단위로 나타냈는지에 따라 달라짐. 같은 의미의 입력을 비교 가능한 기준으로 바꾸지 않으면 단위가 벌점에 영향을 줄 수 있음.

## 같은 길이인데 계수가 달라지는 이유

길이 10cm와 100mm는 같은 길이지만 입력 숫자는 열 배임. 같은 예측을 유지하려면 그 길이에 곱할 계수는 10분의 1이 되어야 함. 예측 관계는 같아도 계수 크기만 다르게 보이는 것임.

특성 55개에는 길이, 제곱, 여러 곱처럼 숫자 범위가 다른 열이 함께 있음. 이 상태에서 계수의 크기를 제한하면 입력 표현의 차이가 규제에 작용할 수 있음. 따라서 다항 특성을 만든 다음 각 열을 표준화함.

## 훈련 기준으로 각 열 변환하기

$$
z=\frac{x-\mu}{\sigma}
$$

$x$는 해당 특성의 원래 값, $\mu$와 $\sigma$는 훈련 데이터에서 구한 평균과 표준편차. 평균을 빼고 그 열의 퍼짐 단위로 나누는 방식은 기초 파트에서 사용한 것과 같음. 이번에는 직접 계산 대신 `StandardScaler`를 사용함.

```python
from sklearn.preprocessing import StandardScaler

ss = StandardScaler()
ss.fit(train_poly)
train_scaled = ss.transform(train_poly)
test_scaled = ss.transform(test_poly)
print(train_scaled.shape, test_scaled.shape)
```

```text
(42, 55) (14, 55)
```

`ss.fit(train_poly)`는 55개 열 각각의 평균과 스케일을 준비함. `mean_`에 훈련 평균, `scale_`에 변환용 스케일이 저장됨. `transform()`은 그 기준을 각 행에 적용함.

결과는 훈련 `(42, 55)`, 테스트 `(14, 55)`로 모양이 그대로임. 농어 수와 특성 수를 늘리거나 줄인 것이 아니라 각 열을 표현하는 숫자 기준을 바꿨음. 표준화한 훈련 열은 평균 약 0, 표준편차 약 1이며 값이 모두 0과 1 사이가 되는 것은 아님.

## 테스트에 새 기준을 만들지 않기

테스트는 `fit()` 없이 `transform()`만 수행함. 모델이 학습한 입력 기준과 예측할 입력 기준이 같아야 하기 때문임. 테스트 평균까지 기준 계산에 쓰면 평가 정보가 학습 준비에 들어가는 데이터 누수가 생길 수 있음.

이제 `train_scaled`, `test_scaled`는 같은 기준으로 변환된 55개 다항 특성임. 다음 릿지와 라쏘는 이 입력을 사용해 서로 다른 계수 벌점을 적용함. 규제 강도를 올리면 제약이 강해지지만, 너무 강하면 중요한 관계도 놓칠 수 있다는 점을 함께 살펴봄.
