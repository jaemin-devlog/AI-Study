# 5. 규제와 특성 표준화

학습 범위: 17에서 19쪽

## 단위가 계수 크기를 바꿈

길이 10cm와 100mm는 같은 값. 입력 숫자가 10배가 되면 같은 예측을 유지하는 계수는 10분의 1이 되어야 함.

단위만 바꿨는데 계수 숫자가 달라지므로 원래 계수의 크기로 벌점을 매기면 단위가 규제에 영향을 줌. 특성마다 기준을 맞춘 다음 규제를 적용하는 이유임.

## StandardScaler로 55개 특성 표준화

$$
z=\frac{x-\mu}{\sigma}
$$

$\mu$와 $\sigma$는 해당 특성의 훈련 평균과 표준편차. 다항 특성을 만든 뒤 각 열을 표준화함.

```python
from sklearn.preprocessing import StandardScaler

ss = StandardScaler()
ss.fit(train_poly)
train_scaled = ss.transform(train_poly)
test_scaled = ss.transform(test_poly)
print(train_scaled.shape, test_scaled.shape)
```

```text
(42, 55) (14, 55)
```

배열의 행과 열 수는 그대로이며 숫자를 표현하는 스케일만 바뀜. `mean_`은 훈련 평균, `scale_`은 변환에 쓰는 스케일을 저장함.

테스트에는 별도로 `fit()`하지 않고 훈련 기준을 적용. 평가 정보를 학습 준비에 넣지 않고, 학습과 예측에 같은 변환을 유지해야 함.

규제 강도를 크게 할수록 계수 제약은 강해지지만 너무 강하면 중요한 관계도 반영하지 못하는 과소적합이 생길 수 있음.
