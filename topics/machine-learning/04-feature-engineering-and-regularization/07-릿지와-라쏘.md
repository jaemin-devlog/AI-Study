# 릿지와 라쏘 회귀

릿지와 라쏘는 선형 회귀에 규제를 적용하는 모델. 계수에 벌점을 주는 방식이 다름

## 1. 릿지 회귀

릿지는 L2 규제를 사용해 계수의 제곱합에 벌점을 줌

계수가 3과 -4라면 제곱합은 다음과 같음

$$
3^2 + (-4)^2 = 25
$$

릿지는 계수들을 전반적으로 작게 만드는 경향이 있음

```python
from sklearn.linear_model import Ridge

ridge = Ridge(alpha=0.1)
ridge.fit(train_scaled, train_target)
print(ridge.score(train_scaled, train_target))
print(ridge.score(test_scaled, test_target))
```

```text
0.9903815817570368
0.9827976465386983
```

훈련 R² 약 0.9904, 테스트 R² 약 0.9828

## 2. 라쏘 회귀

라쏘는 L1 규제를 사용해 계수의 절댓값 합에 벌점을 줌

계수가 3과 -4라면 절댓값 합은 다음과 같음

$$
|3| + |-4| = 7
$$

![L1과 L2 벌점 비교](../assets/pdf/릿지와-라쏘-벌점.png)

L1은 0에서 뾰족한 V자, L2는 곡선 형태. 라쏘는 일부 계수를 정확히 0으로 만들 수 있음

```python
from sklearn.linear_model import Lasso

lasso = Lasso(alpha=10, max_iter=10000)
lasso.fit(train_scaled, train_target)
print(lasso.score(test_scaled, test_target))
print((lasso.coef_ == 0).sum())
```

```text
0.9830309645308444
48
```

테스트 R² 약 0.9830이고 계수 55개 중 48개가 0

입력 열은 삭제되지 않음. 계수가 0인 특성은 현재 모델의 예측에 직접 기여하지 않는다는 뜻

`max_iter`는 계수를 찾기 위한 최대 반복 횟수이며 규제 강도가 아님. 수렴 조건을 먼저 만족하면 더 일찍 멈출 수 있음

## 3. 릿지와 라쏘 비교

| 구분 | 릿지 | 라쏘 |
| --- | --- | --- |
| 규제 방식 | L2 | L1 |
| 벌점 기준 | 계수 제곱합 | 계수 절댓값 합 |
| 특징 | 계수를 전반적으로 줄이는 경향 | 일부 계수를 정확히 0으로 만들 수 있음 |

두 모델 모두 훈련 데이터에 지나치게 맞춰지는 것을 억제하기 위해 사용

## 4. alpha에 따른 점수

![릿지의 alpha와 점수](../assets/pdf/릿지-규제강도.png)

릿지의 `alpha`를 바꾸며 확인한 훈련과 테스트 R²

이번 실습에서는 `alpha=0.1`에서 테스트 R²가 약 0.9828

![라쏘의 alpha와 점수](../assets/pdf/라쏘-규제강도.png)

라쏘도 같은 방식으로 alpha를 변경해 비교. 이번 실습에서는 `alpha=10`에서 테스트 R²가 약 0.9830

| 라쏘 alpha | 0인 계수 수 | 테스트 R² |
| --- | --- | --- |
| 0.1 | 42개 | 0.9824 |
| 1 | 47개 | 0.9802 |
| 10 | 48개 | 0.9830 |
| 100 | 52개 | 0.9091 |

`alpha=100`에서는 0인 계수가 더 많아졌지만 테스트 점수는 낮아짐. 규제가 너무 강하면 중요한 관계까지 충분히 학습하지 못할 수 있음

릿지와 라쏘는 벌점 계산 방식이 달라 alpha 숫자만으로 규제 강도를 직접 비교할 수 없음

## 5. 같은 입력에서 규제 전후 비교

규제 없는 선형 회귀, `Ridge(alpha=0.1)`, `Lasso(alpha=10)`을 같은 표준화 입력으로 비교

| 모델 | 훈련 R² | 테스트 R² | 0인 계수 |
| --- | --- | --- | --- |
| 규제 없는 선형 회귀 | 거의 1.0 | 크게 하락 | 0개 |
| 릿지 | 약 0.9904 | 약 0.9828 | 0개 |
| 라쏘 | 약 0.9888 | 약 0.9830 | 48개 |

규제 없는 모델은 훈련 점수는 높지만 테스트 점수는 크게 낮음

고차 무규제 회귀는 수치적으로 불안정할 수 있어 정확한 점수는 계산 조건에 따라 달라질 수 있음

alpha의 영향을 살펴볼 때 테스트 점수를 여러 번 비교했지만, 실제 모델 설정은 검증 데이터로 선택하고 테스트 데이터는 최종 평가에 사용

## 6. 코드 역할 정리

| 코드 | 역할 |
| --- | --- |
| `PolynomialFeatures()` | 다항 특성 변환기 생성 |
| `poly.fit()` | 특성 조합 준비 |
| `poly.transform()` | 실제 특성값 변환 |
| `StandardScaler()` | 표준화 변환기 생성 |
| `ss.fit()` | 훈련 데이터의 평균과 표준편차 계산 |
| `ss.transform()` | 같은 기준으로 값 변환 |
| `Ridge()`, `Lasso()` | 규제 회귀 모델 생성 |
| `coef_` | 학습한 계수 |
| `score()` | 이 회귀 모델의 R² 평가 |

같은 `fit()`이라도 변환기는 변환 기준을 준비하고 회귀 모델은 계수와 절편을 학습
