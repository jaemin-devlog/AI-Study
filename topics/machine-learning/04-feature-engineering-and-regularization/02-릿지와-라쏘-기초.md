# 규제, 릿지와 라쏘

본문 코드는 개념별 부분 코드. 데이터 준비부터 독립 실행할 때는 [전체 실습](03-특성-공학과-규제-예제.md)을 사용.


## 손실함수와 규제

손실함수는 학습 과정에서 예측이 얼마나 틀렸는지 수치화하는 기준이다. 선형 회귀는 실제값과 예측값의 차이를 제곱해 더한 잔차제곱합(RSS)을 줄이도록 계수와 절편을 찾는다. 제곱하면 양수와 음수 오차가 서로 상쇄되지 않고 큰 오차가 더 크게 반영된다. 계산 과정과 MSE는 [오차와 손실함수](../02-knn-regression/04-오차와-손실함수.md)에 정리했다.

훈련 오차만 줄이면 훈련 데이터의 우연한 차이까지 맞추는 모델이 될 수 있다. 규제는 오차와 함께 계수 크기에 대한 벌점을 고려해 이런 경향을 줄이려는 방법이다.

## 규제와 표준화

- 규제는 모델의 학습 기준에 계수 크기에 대한 벌점을 추가해 훈련 데이터에 지나치게 맞춰지는 것을 억제한다.
- 계수의 크기는 특성의 단위와 스케일에 영향을 받는다. 그래서 규제 전에 특성별 스케일을 맞춘다.

```python
from sklearn.preprocessing import StandardScaler

ss = StandardScaler()
ss.fit(train_poly)
train_scaled = ss.transform(train_poly)
test_scaled = ss.transform(test_poly)
```

- 평균과 표준편차는 훈련 데이터에서만 구한다. 테스트 데이터는 같은 기준으로 `transform()`하여 데이터 누수를 막는다.
- 이 예제의 `train_poly`, `test_poly`는 5차로 확장한 특성 55개다.

표준화는 각 특성에 훈련 데이터의 평균 $\mu$와 표준편차 $\sigma$를 적용한다.

$$
z = \frac{x-\mu}{\sigma}
$$

### 규제 전에 스케일을 맞추는 이유

길이를 cm 대신 mm로 표시하면 같은 생선의 숫자는 10배가 된다. 같은 예측을 유지하려면 길이에 곱하는 계수는 10분의 1로 바뀐다. 입력 단위가 다르다는 이유만으로 계수 크기에 대한 벌점도 달라질 수 있으므로, 규제 전에 훈련 데이터 기준으로 특성을 표준화한다.

## 릿지와 라쏘 비교

| 구분 | 릿지 Ridge | 라쏘 Lasso |
| --- | --- | --- |
| 규제 | L2: 계수의 제곱합에 벌점 | L1: 계수의 절댓값 합에 벌점 |
| 특징 | 계수를 전반적으로 줄이는 경향 | 일부 계수를 정확히 0으로 만들 수 있음 |

릿지와 라쏘는 각각 다음 계수 벌점을 사용한다. $w_j$는 $j$번째 특성의 계수, $p$는 특성 수, $\alpha$는 규제 강도다.

$$
\text{L2 벌점} = \alpha \sum_{j=1}^{p} w_j^2
$$

$$
\text{L1 벌점} = \alpha \sum_{j=1}^{p} |w_j|
$$

- 두 방식 모두 예측 오차와 벌점을 함께 고려한다. 구현마다 오차 항의 정규화 방식이 달라 같은 $\alpha$를 직접 비교할 수 없다.

### 벌점이 학습 기준을 바꾸는 예

두 후보의 훈련 제곱오차 합이 각각 10과 15이고, 계수의 제곱합이 각각 100과 9라고 가정한다. 규제가 없으면 오차가 작은 A가 더 좋지만, $\alpha=0.1$인 L2 벌점을 함께 고려하면 다음과 같다.

$$
\begin{aligned}
\text{모델 A} &: 10 + 0.1 \times 100 = 20 \\
\text{모델 B} &: 15 + 0.1 \times 9 = 15.9
\end{aligned}
$$

B는 훈련 오차가 조금 더 크지만 계수 벌점을 포함한 기준은 더 작다. 규제는 오차를 완전히 무시하거나 계수를 모두 0으로 만드는 것이 아니라 두 기준을 함께 고려한다. 이것은 설명을 위한 가상의 숫자다.

```python
from sklearn.linear_model import Ridge, Lasso

ridge = Ridge(alpha=0.1)
ridge.fit(train_scaled, train_target)
lasso = Lasso(alpha=10, max_iter=10000)
lasso.fit(train_scaled, train_target)
print(ridge.score(train_scaled, train_target), ridge.score(test_scaled, test_target))
print(lasso.score(train_scaled, train_target), lasso.score(test_scaled, test_target))
print((lasso.coef_ == 0).sum())
```

실행 결과 (환경에 따라 소수점 끝자리가 달라질 수 있음):

```text
0.9903815817570368 0.9827976465386983
0.9887624603020236 0.9830309645308444
48
```

- 실습 결과: 릿지 훈련 R² 약 0.9904, 테스트 약 0.9828. 라쏘 훈련 약 0.9888, 테스트 약 0.9830이다.
- 라쏘에서는 55개 중 48개 계수가 0이었다. 입력 열이 삭제된 것은 아니며, 현재 데이터와 설정에서 해당 특성이 예측에 직접 기여하지 않는다는 뜻이다.
- `max_iter`는 라쏘 최적화의 최대 반복 횟수다. 수렴 경고가 있다면 반복 횟수와 설정을 점검한다.

![계수와 테스트 점수 비교](../assets/계수와-규제강도.png)

왼쪽 가로축은 55개 특성의 번호, 세로축은 모델이 학습한 계수다. 생선의 길이나 무게가 아니다. 라쏘는 이 조건에서 48개 계수가 정확히 0이며 입력 열은 남아 있다. 오른쪽 가로축은 로그 눈금의 alpha, 세로축은 테스트 R²다. `10^-1`은 0.1이다. 한 점은 특정 alpha로 학습한 모델 하나의 점수다. 약한 라쏘 규제에서 수렴 경고가 나왔으므로 그 결과는 신중히 해석한다. 실제 후보 선택은 테스트가 아닌 검증 데이터로 수행한다.

## alpha와 모델 선택

- `alpha`가 작으면 규제가 약하고, 크면 강하다. 너무 약하면 과대적합, 너무 강하면 과소적합할 수 있다.
- 릿지와 라쏘는 벌점과 목적함수의 기준이 다르므로 alpha 숫자만으로 두 모델의 규제 강도를 직접 비교할 수 없다.
- 수업에서는 테스트 점수로 alpha의 영향을 관찰했지만, 실제 선택은 검증 데이터나 교차 검증으로 하고 테스트 데이터는 최종 평가에 남겨 둔다.
- 전처리도 교차 검증의 각 훈련 구간에서만 학습해야 한다. `Pipeline`을 사용하면 분할별 전처리와 모델을 함께 적용할 수 있다.
- 같은 표준화 입력에서 비교한 결과, 규제가 없는 선형 회귀는 훈련 점수가 거의 1이지만 테스트 점수는 크게 떨어졌다. 수치적으로 불안정하여 정확한 점수는 환경에 따라 달라질 수 있다.

### 라쏘 결과를 읽을 때

`alpha`는 벌점의 강도이고 `max_iter`는 해를 찾기 위한 최대 반복 횟수다. 반복 횟수를 늘리면 계산을 더 진행할 수 있다. 규제 강도가 달라지는 것은 아니다. 수렴 조건을 먼저 만족하면 최대 횟수 전에 끝날 수 있고, 수렴 경고가 나온 결과는 충분히 학습되지 않았을 수 있다.

이번 실습에서 `alpha=10`일 때 48개 계수가 0이었지만, `alpha=100`으로 더 강하게 규제하자 0인 계수는 52개로 늘고 테스트 R²는 약 0.9091로 낮아졌다. 계수가 0인 특성이 많을수록 항상 좋은 것은 아니다.

## 규제 강도에 따른 점수

앞에서 준비한 5차 다항 특성의 `train_scaled`, `test_scaled`와 무게 정답을 사용한다.

```python
import matplotlib.pyplot as plt
from sklearn.linear_model import Ridge

alphas = [0.001, 0.01, 0.1, 1, 10, 100]
train_scores, test_scores = [], []
for alpha in alphas:
    model = Ridge(alpha=alpha).fit(train_scaled, train_target)
    train_scores.append(model.score(train_scaled, train_target))
    test_scores.append(model.score(test_scaled, test_target))

print([round(float(x), 4) for x in train_scores])
print([round(float(x), 4) for x in test_scores])
plt.semilogx(alphas, train_scores, 'o-', label='Train R²')
plt.semilogx(alphas, test_scores, 'o-', label='Test R²')
plt.xlabel('alpha')
plt.ylabel('R²')
plt.legend()
plt.grid(alpha=0.25)
plt.show()
```

```text
[0.993, 0.9918, 0.9904, 0.9896, 0.9887, 0.9842]
[0.9569, 0.98, 0.9828, 0.9791, 0.9725, 0.9627]
```

![릿지 규제 강도에 따른 훈련 및 테스트 점수](../assets/릿지-규제강도.png)

반복문은 `alphas`의 값을 하나씩 사용해 릿지 모델을 다시 만들고 학습한다. 각 모델의 훈련 R²와 테스트 R²를 별도 리스트에 저장한다. `round(float(x), 4)`는 출력할 때 소수 넷째 자리로 반올림한다.

`semilogx()`는 가로축에 로그 눈금을 사용한다. 따라서 0.001, 0.01, 0.1처럼 10배씩 커지는 값들이 일정한 간격으로 표시된다. 세로축은 결정계수 R²이며, 파란 선은 훈련 점수, 주황 선은 테스트 점수다.

이 실습에서 alpha가 커질수록 훈련 점수는 낮아진다. 테스트 점수는 0.001에서 0.1까지 높아진 뒤 100으로 갈수록 낮아진다. 그래프의 세로축이 0.95 부근부터 시작하므로 선 사이의 차이가 확대되어 보이는 점도 확인한다.

실습에서는 `alpha=0.1`에서 테스트 점수가 약 0.9828로 가장 높았다. 이 그래프는 영향을 관찰하기 위해 테스트 점수를 반복 확인한 사례다. 실제 모델 선택은 검증 세트나 교차 검증으로 수행하고 테스트 세트는 최종 평가에 사용한다.
