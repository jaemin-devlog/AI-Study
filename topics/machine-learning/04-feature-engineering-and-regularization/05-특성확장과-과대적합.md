# 특성 확장과 과대적합

특성을 늘리면 더 복잡한 관계를 표현할 수 있지만, 새로운 데이터에서도 잘 예측하는지는 따로 확인해야 함

## 1. 2차 특성으로 학습

앞에서 만든 9개 특성의 `train_poly`, `test_poly`와 농어의 실제 무게를 사용

```python
from sklearn.linear_model import LinearRegression

lr = LinearRegression()
lr.fit(train_poly, train_target)
print(lr.score(train_poly, train_target))
print(lr.score(test_poly, test_target))
```

실습 결과: 훈련 R² 약 0.9903, 테스트 R² 약 0.9715

회귀의 `score()`는 정확도가 아닌 결정계수 R²를 반환

## 2. 5차 특성으로 확장

```python
from sklearn.preprocessing import PolynomialFeatures

poly5 = PolynomialFeatures(degree=5, include_bias=False)
poly5.fit(train_input)
train_poly5 = poly5.transform(train_input)
test_poly5 = poly5.transform(test_input)
print(train_poly5.shape)
```

```text
(42, 55)
```

`degree=5`는 5차까지의 제곱과 특성 간 곱을 생성한다는 뜻

훈련 농어는 42마리 그대로이고 특성 수만 55개가 됨

```python
lr5 = LinearRegression()
lr5.fit(train_poly5, train_target)
print(lr5.score(train_poly5, train_target))
print(lr5.score(test_poly5, test_target))
```

## 3. 특성 수에 따른 결과

| 구분 | 2차 특성 9개 | 5차 특성 55개 |
| --- | --- | --- |
| 훈련 데이터 | 42마리 | 42마리 |
| 훈련 R² | 약 0.9903 | 거의 1.0 |
| 테스트 R² | 약 0.9715 | 약 -144.4 |

![특성 확장에 따른 성능 변화](../assets/pdf/특성과-과대적합.png)

훈련 점수는 거의 1인데 테스트 점수가 크게 떨어짐

훈련 데이터의 우연한 차이까지 지나치게 반영해 새로운 데이터의 성능이 떨어지는 현상을 과대적합이라고 함

R²가 음수면 평가 데이터의 실제 무게 평균으로만 예측하는 것보다 제곱오차가 크다는 뜻

특성 수가 훈련 샘플 수보다 많다고 항상 과대적합이 발생하거나 학습이 불가능한 것은 아님

고차 특성은 수치적으로 불안정할 수 있어 데이터와 계산 조건에 따라 결과가 달라질 수 있음
