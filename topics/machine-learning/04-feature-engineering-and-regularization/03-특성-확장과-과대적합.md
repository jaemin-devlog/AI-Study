# 3. 특성 확장과 과대적합

학습 범위: 8에서 11쪽

## 9개 특성으로 학습

```python
from sklearn.linear_model import LinearRegression

lr2 = LinearRegression()
lr2.fit(train_poly2, train_target)
print(round(lr2.score(train_poly2, train_target), 4),
      round(lr2.score(test_poly2, test_target), 4))
```

```text
0.9903 0.9715
```

높은 점수지만 앞의 길이²과 길이만 사용한 모델보다 테스트 점수가 반드시 높은 것은 아님. 특성이 많다는 사실과 성능 향상은 구분해야 함.

## 5차까지 55개 특성 생성

```python
poly5 = PolynomialFeatures(degree=5, include_bias=False)
poly5.fit(train_input)
train_poly = poly5.transform(train_input)
test_poly = poly5.transform(test_input)
lr5 = LinearRegression()
lr5.fit(train_poly, train_target)
print(train_poly.shape)
print(lr5.score(train_poly, train_target), lr5.score(test_poly, test_target))
```

`degree=5`는 길이의 5제곱뿐 아니라 길이²×높이³처럼 지수의 합이 5 이하인 조합을 생성. 입력 모양은 `(42, 55)`가 됨.

![특성 확장에 따른 성능](../assets/pdf/특성과-과대적합.png)

| 특성 | 훈련 샘플 | 훈련 R² | 테스트 R² 실험 예시 |
| --- | --- | --- | --- |
| 9개 | 42개 | 0.9903 | 0.9715 |
| 55개 | 42개 | 거의 1 | 약 -144.4 |

그림은 훈련 데이터를 거의 완벽히 맞혔지만 테스트 성능이 크게 나빠진 과대적합 사례. R²가 음수라는 것은 평가 정답의 평균으로 예측하는 기준보다 제곱오차가 크다는 뜻.

고차 다항 특성은 수치적으로 불안정할 수 있어 정확한 점수는 계산 조건에 따라 크게 달라질 수 있음. 특성 수 자체보다 실제 훈련과 테스트 결과를 확인해야 함.

## 표현력과 일반화 구분

계수 55개와 절편을 훈련 농어 42마리로 정해야 하고, 다항 특성에는 비슷한 정보를 담은 열도 많음. 계수를 안정적으로 정하기 어려울 수 있지만 특성이 샘플보다 많다고 반드시 학습이 실패하는 것은 아님.

표현력은 복잡한 관계를 나타내는 능력, 일반화 성능은 새 데이터에서도 예측이 잘 되는 정도. 표현력이 커져도 일반화가 자동으로 좋아지는 것은 아니므로 계수의 사용을 조절할 필요가 있음.
