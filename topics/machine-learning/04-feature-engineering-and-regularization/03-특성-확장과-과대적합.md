# 3. 특성 확장과 과대적합

아홉 개의 다항 특성을 준비했으므로 각 열에 대응하는 계수를 학습할 수 있음. 입력이 늘어도 `fit()`에 훈련 입력과 실제 무게를 전달하고 훈련과 테스트의 R²를 확인하는 흐름은 같음.

## 아홉 특성으로 얻은 결과

```python
from sklearn.linear_model import LinearRegression

lr2 = LinearRegression()
lr2.fit(train_poly2, train_target)
print(round(lr2.score(train_poly2, train_target), 4),
      round(lr2.score(test_poly2, test_target), 4))
```

```text
0.9903 0.9715
```

`train_poly2`와 `test_poly2`는 앞 변환기로 만든 2차 특성임. 훈련 R² 약 0.9903, 테스트 약 0.9715로 높은 값을 얻음. 하지만 앞 파트의 길이와 길이 제곱만 사용한 테스트 약 0.9776보다 반드시 좋아진 것은 아님.

특성을 추가하면 더 다양한 관계를 표현할 수 있지만, 그 관계가 새로운 농어의 예측에 도움이 되는지는 별도 결과로 봐야 함. 이를 더 뚜렷하게 확인하기 위해 특성을 많이 늘려 봄.

## 최대 5차까지 확장하기

```python
poly5 = PolynomialFeatures(degree=5, include_bias=False)
poly5.fit(train_input)
train_poly = poly5.transform(train_input)
test_poly = poly5.transform(test_input)
lr5 = LinearRegression()
lr5.fit(train_poly, train_target)
print(train_poly.shape)
print(lr5.score(train_poly, train_target), lr5.score(test_poly, test_target))
```

`degree=5`는 각 원래 특성의 5제곱만 만든다는 뜻이 아님. 길이²×높이³처럼 지수의 합이 5인 곱도 포함하고 그보다 낮은 차수의 항도 만듦. 상수항을 제외하면 특성이 총 55개가 되어 훈련 입력은 `(42, 55)`임.

![특성 확장에 따른 성능](../assets/pdf/특성과-과대적합.png)

| 특성 수 | 훈련 농어 | 훈련 R² | 테스트 R² 비교 결과 |
| --- | --- | --- | --- |
| 9개 | 42마리 | 0.9903 | 0.9715 |
| 55개 | 42마리 | 거의 1 | 약 -144.4 |

그림은 55개 모델이 훈련 무게를 거의 완벽히 맞히면서도 테스트에서 크게 실패한 결과임. R²가 음수인 것은 정확도가 음수라는 뜻이 아니라 테스트 정답 평균으로만 예측하는 기준보다 제곱오차가 크다는 뜻임. 두 그래프의 세로축 범위가 달라 막대 높이만 비교하면 안 됨.

고차 다항 특성의 계수 추정은 수치 계산에 민감해 정확한 테스트 값은 계산 조건에 따라 크게 달라질 수 있음. -144.4라는 한 숫자를 반드시 재현해야 한다고 생각하기보다 같은 분할과 변환을 사용했는지 확인하고 실제 출력의 훈련과 테스트 차이를 읽음.

## 훈련을 잘 맞추는 능력과 일반화 구분하기

훈련 농어 42마리로 계수 55개와 절편을 정해야 함. 다항 특성에는 비슷한 정보를 담은 항도 있어 계수를 안정적으로 추정하기 어려울 수 있음. 다만 특성이 샘플보다 많다고 무조건 학습이 실패하거나 과대적합하는 것은 아님.

이번 과대적합의 근거는 개수 자체가 아니라 훈련 점수는 거의 1인데 테스트 결과가 크게 떨어졌다는 사실임. 훈련의 우연한 차이까지 지나치게 반영한 관계는 새 농어에서 큰 오차를 낼 수 있음.

복잡한 관계를 나타내는 능력이 표현력이고 학습하지 않은 데이터에서도 잘 예측하는 능력이 일반화임. 표현력을 늘린 만큼 계수를 사용하는 정도도 조절할 필요가 있음. 다음에는 특성 55개를 유지하면서 계수에 벌점을 주는 규제를 배움.
