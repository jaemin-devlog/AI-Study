# 다중 회귀와 특성 공학

농어의 길이 하나로 무게를 예측하던 선형 회귀에 높이와 두께를 추가하고, 기존 특성을 조합해 새로운 특성을 만드는 과정

## 1. 다중 회귀

길이가 같은 농어라도 높이와 두께가 다르면 무게도 달라질 수 있음

길이, 높이, 두께를 함께 사용해 농어의 무게를 예측하는 방식이 다중 회귀

다중 회귀는 여러 입력 특성을 사용해 하나의 수치를 예측하는 선형 회귀

$$
\hat{y} = w_1x_1 + w_2x_2 + w_3x_3 + b
$$

$x_1$, $x_2$, $x_3$은 각각 길이, 높이, 두께. $w_1$, $w_2$, $w_3$은 모델이 학습한 계수이고 $b$는 절편

## 2. 농어 데이터 준비

pandas는 표 형태의 데이터를 다루는 라이브러리

CSV 파일은 값을 쉼표로 구분해 저장한 파일. `pd.read_csv()`로 읽으면 행과 열을 가진 DataFrame이 만들어짐

```python
import pandas as pd

df = pd.read_csv(csv_path, skipinitialspace=True)
print(df.head())
```

```text
   length  height  width
0     8.4    2.11   1.41
1    13.7    3.53   2.00
2    15.0    3.82   2.43
3    16.2    4.59   2.63
4    17.4    4.59   2.94
```

`csv_path`는 실습의 `perch_full.csv` 경로. 행 번호는 인덱스이며 입력 특성은 길이, 높이, 두께 세 열

`df.to_numpy()`로 입력을 배열로 변환하고 같은 순서의 농어 무게 56개를 정답으로 사용

입력과 무게는 같은 행이 같은 농어를 가리켜야 함

훈련 42마리, 테스트 14마리로 분리하면 입력 모양은 `(42, 3)`, `(14, 3)`

```python
from sklearn.model_selection import train_test_split

perch_input = df.to_numpy()
train_input, test_input, train_target, test_target = train_test_split(
    perch_input, perch_weight, random_state=42
)
print(train_input.shape, test_input.shape)
```

```text
(42, 3) (14, 3)
```

`perch_weight`는 같은 실습의 농어 무게 배열.

## 3. 특성 공학

특성 공학은 기존 특성을 가공하거나 조합해 새로운 특성을 만드는 작업

기존의 `[길이, 높이, 두께]`에 제곱과 곱을 추가하면 특성이 3개에서 9개가 됨

| 기존 특성 | 새로 만든 특성 |
| --- | --- |
| 길이, 높이, 두께 | 길이², 길이×높이, 길이×두께, 높이², 높이×두께, 두께² |

![3개 특성이 9개로 확장되는 과정](../assets/pdf/다항-특성-확장.png)

농어 수가 늘어난 것이 아님. 한 농어를 나타내는 특성이 3개에서 9개로 늘어난 것

훈련 데이터의 모양: `(42, 3)` → `(42, 9)`

## 4. PolynomialFeatures

`PolynomialFeatures`는 다항 특성을 만들어 주는 변환기

```python
from sklearn.preprocessing import PolynomialFeatures

poly = PolynomialFeatures(include_bias=False)
poly.fit(train_input)
train_poly = poly.transform(train_input)
test_poly = poly.transform(test_input)
print(train_poly.shape)
```

```text
(42, 9)
```

`poly.fit()`은 입력 특성으로 어떤 조합을 만들지 준비

`poly.transform()`은 준비한 조합으로 실제 특성값을 계산

`include_bias=False`는 상수 1의 열을 제외. 회귀 모델의 절편을 없애는 설정은 아님

회귀 모델의 `fit()`은 계수와 절편을 학습하므로 변환기의 `fit()`과 역할이 다름

2차가 기본 설정이며, 길이의 제곱과 길이×높이처럼 차수가 2인 항까지 생성
