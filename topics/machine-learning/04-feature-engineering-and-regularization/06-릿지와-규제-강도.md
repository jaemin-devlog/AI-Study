# 6. 릿지와 규제 강도

앞에서는 규제가 계수 벌점을 더하는 방식이고 표준화가 필요한 이유까지 확인했음. 릿지는 그 벌점을 계수의 제곱합으로 계산하는 회귀 모델. 이 방식을 L2 규제라고 함.

## 제곱합으로 큰 계수 제한하기

$$
P_{L2}(\mathbf w)=\sum_{j=1}^{m}w_j^2
$$

$m$은 특성 수이고 $w_j$는 각 특성의 계수. 계수가 3과 -4이면 $3^2+(-4)^2=25$임. 제곱하므로 부호와 관계없이 크기에 벌점이 생기고 큰 계수에 더 큰 부담을 줌.

학습은 예측 오차와 이 벌점을 함께 줄이도록 계수를 찾음. 여러 계수를 전반적으로 작게 만드는 경향이 있으며 기본 릿지에서는 절편을 별도로 학습하고 계수에 규제를 적용함.

```python
from sklearn.linear_model import Ridge

ridge_default = Ridge()
ridge_default.fit(train_scaled, train_target)
print(round(ridge_default.score(train_scaled, train_target), 4),
      round(ridge_default.score(test_scaled, test_target), 4))
```

```text
0.9896 0.9791
```

앞 파일의 표준화된 55개 특성으로 학습함. 기본 `alpha=1.0`에서 훈련 R² 약 0.9896, 테스트 약 0.9791을 얻음. 규제 없는 55개 모델과 표준화 조건까지 다르면 점수 차이를 전부 규제 효과라고 해석하지 않고 뒤의 동일 입력 비교에서 확인함.

## alpha를 바꾸는 의미

alpha가 작으면 벌점 비중이 낮아 훈련에 더 자유롭게 맞출 수 있음. 크면 계수를 더 강하게 제한하지만 필요한 관계까지 줄여 과소적합이 생길 수 있음. 데이터마다 적절한 범위가 다르므로 여러 후보의 결과를 비교함.

```python
import matplotlib.pyplot as plt

alpha_list = [0.001, 0.01, 0.1, 1, 10, 100]
train_score, test_score = [], []
for alpha in alpha_list:
    model = Ridge(alpha=alpha)
    model.fit(train_scaled, train_target)
    train_score.append(model.score(train_scaled, train_target))
    test_score.append(model.score(test_scaled, test_target))
plt.plot(alpha_list, train_score, marker='o', label='Train')
plt.plot(alpha_list, test_score, marker='o', label='Test')
plt.xscale('log')
plt.xlabel('alpha')
plt.ylabel('R2')
plt.legend()
plt.show()
```

![릿지 규제 강도](../assets/pdf/릿지-규제강도.png)

반복문은 alpha만 바꾸고 분할, 55개 입력, 평가 지표는 유지함. 훈련과 테스트 점수를 리스트에 저장해 그래프로 표시함. 가로축은 alpha, 세로축은 R²이고 `xscale('log')`는 10배씩 변하는 값을 읽기 쉽게 표시하는 설정임. 축 표시를 바꿔도 학습 결과는 바뀌지 않음.

그림의 매우 약한 규제에서는 훈련 점수가 높아도 테스트와 차이가 있음. 중간 범위에서는 테스트가 개선되고 너무 강한 100에서는 두 점수가 낮아짐. 선 사이의 간격뿐 아니라 각 점수의 수준도 함께 읽어야 함.

## alpha=0.1의 결과 확인하기

```python
ridge = Ridge(alpha=0.1)
ridge.fit(train_scaled, train_target)
print(round(ridge.score(train_scaled, train_target), 4),
      round(ridge.score(test_scaled, test_target), 4))
```

```text
0.9904 0.9828
```

훈련 약 0.9904, 테스트 약 0.9828임. 약한 규제를 조금 높여 테스트 결과가 좋아졌지만 계속 강하게 하면 좋아진다는 규칙은 아님.

여기서는 강도 변화가 미치는 영향을 관찰하려고 테스트 점수도 비교했음. 설정을 실제로 선택할 때는 검증 데이터나 교차 검증으로 alpha를 비교하고 테스트는 선택 후 최종 평가에 사용함. 다음에는 일부 계수를 정확히 0으로 만들 수 있는 라쏘를 배움.
