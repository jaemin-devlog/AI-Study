# 7. 라쏘와 0인 계수

학습 범위: 24에서 29쪽

## L1 규제와 계수 0

$$
P_{L1}(\mathbf w)=\sum_{j=1}^{m}|w_j|
$$

계수가 3과 -4이면 절댓값의 합은 7. 라쏘는 일부 계수를 정확히 0으로 만들 수 있어 현재 모델에서 해당 특성이 예측에 직접 기여하지 않게 할 수 있음.

![L1과 L2 벌점](../assets/pdf/릿지와-라쏘-벌점.png)

L2는 0 근처에서 곡선이 완만하고 L1은 뾰족한 V자. 이 벌점의 차이가 최적화 과정에서 계수를 줄이는 방식에 영향을 줌. 그림은 벌점 함수이며 실제 농어의 예측선이 아님.

## 기본 alpha와 반복 횟수

```python
from sklearn.linear_model import Lasso

lasso_default = Lasso(max_iter=10000)
lasso_default.fit(train_scaled, train_target)
print(round(lasso_default.score(train_scaled, train_target), 4),
      round(lasso_default.score(test_scaled, test_target), 4))
```

```text
0.9898 0.9802
```

alpha는 규제 강도, `max_iter`는 계수를 찾는 최적화 계산의 최대 반복 횟수. 최대 10,000회이며 수렴하면 먼저 종료할 수 있음. 반복 수를 늘리는 것은 규제를 강하게 만드는 일이 아님.

## alpha별 비교와 수렴 경고

```python
train_score, test_score = [], []
for alpha in alpha_list:
    model = Lasso(alpha=alpha, max_iter=10000)
    model.fit(train_scaled, train_target)
    train_score.append(model.score(train_scaled, train_target))
    test_score.append(model.score(test_scaled, test_target))
plt.plot(alpha_list, train_score, marker='o', label='Train')
plt.plot(alpha_list, test_score, marker='o', label='Test')
plt.xscale('log')
plt.legend()
plt.show()
```

![라쏘 규제 강도](../assets/pdf/라쏘-규제강도.png)

작은 alpha에서는 규제가 약해 계산이 충분히 수렴하지 못하고 `ConvergenceWarning`이 나올 수 있음. 해당 후보는 충분히 수렴한 결과인지 확인해야 함. alpha=100에서는 두 점수가 낮아져 지나친 제약의 영향을 볼 수 있음.

## alpha=10과 0인 계수 확인

```python
lasso = Lasso(alpha=10, max_iter=10000)
lasso.fit(train_scaled, train_target)
print(round(lasso.score(train_scaled, train_target), 4),
      round(lasso.score(test_scaled, test_target), 4))
print(np.sum(lasso.coef_ == 0))
```

```text
0.9888 0.983
48
```

`coef_ == 0`은 계수가 0인 위치를 True로 표시하고 `sum()`이 그 개수를 셈. 입력은 55열 그대로이고 48개에 계수 0이 적용돼 나머지 7개가 직접 예측에 기여함.

현재 데이터와 설정에서의 결과이지 48개 특성이 모든 문제에서 필요 없다는 뜻은 아님. 서로 비슷한 정보를 담은 특성끼리 기여가 나뉠 수도 있음.
