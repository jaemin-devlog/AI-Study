# 7. 라쏘와 0인 계수

릿지는 계수 제곱합을 줄이는 방향으로 학습했음. 라쏘는 계수의 절댓값 합을 벌점으로 사용하는 선형 회귀이며 이 방식을 L1 규제라고 함. 계수 크기를 줄이면서 일부 계수를 정확히 0으로 만들 수 있다는 차이가 있음.

## L1과 L2의 벌점 모양 비교하기

$$
P_{L1}(\mathbf w)=\sum_{j=1}^{m}|w_j|
$$

계수가 3과 -4이면 절댓값 합은 $3+4=7$. 같은 계수의 L2 제곱합은 25임. 두 방법 모두 부호가 아닌 크기에 반응하지만 증가하는 방식이 다름.

![L1과 L2 벌점](../assets/pdf/릿지와-라쏘-벌점.png)

가로축은 계수, 세로축은 벌점. L2는 0 근처에서 둥글고 벌점 변화가 완만해짐. L1은 0에서 뾰족한 V자이며 0에 도달할 때까지 일정한 비율로 벌점이 줄어듦. 이런 차이가 최적화에서 일부 계수를 0으로 선택할 수 있게 함. 그림은 생선의 예측 곡선이 아니라 계수 벌점의 모양임.

| 구분 | 릿지 | 라쏘 |
| --- | --- | --- |
| 규제 방식 | L2 | L1 |
| 계수 벌점 | 제곱합 | 절댓값 합 |
| 계수에 미치는 영향 | 여러 계수를 전반적으로 작게 만듦 | 일부 계수를 정확히 0으로 만들 수 있음 |

두 방법 모두 예측 오차와 벌점을 함께 고려함. 표의 효과는 각 방법의 경향이며 모든 데이터에서 같은 계수가 선택된다는 뜻은 아님.

계수가 0이면 그 항은 $0\times x_j=0$이 되어 해당 특성은 현재 예측에 직접 기여하지 않음. 입력 열을 삭제하는 작업과는 구분해야 함.

## 규제 강도와 반복 횟수 구분하기

```python
from sklearn.linear_model import Lasso

lasso_default = Lasso(max_iter=10000)
lasso_default.fit(train_scaled, train_target)
print(round(lasso_default.score(train_scaled, train_target), 4),
      round(lasso_default.score(test_scaled, test_target), 4))
```

```text
0.9898 0.9802
```

앞과 같은 표준화된 55개 특성에 기본 `alpha=1.0`을 사용함. 훈련 R² 약 0.9898, 테스트 약 0.9802임. `max_iter=10000`은 계수를 찾는 최대 반복 횟수이고 규제 강도는 alpha가 정함.

계수를 반복 조정하는 계산이 기준을 만족하며 안정되는 것을 수렴이라고 함. 최대 반복 수를 지정해도 더 일찍 수렴하면 종료할 수 있음. 정한 횟수 안에 만족하지 못하면 `ConvergenceWarning`이 나타날 수 있으며 반복을 늘리는 것은 규제를 강하게 만드는 일이 아님.

## 같은 반복 상한에서 alpha 비교하기

```python
train_score, test_score = [], []
for alpha in alpha_list:
    model = Lasso(alpha=alpha, max_iter=10000)
    model.fit(train_scaled, train_target)
    train_score.append(model.score(train_scaled, train_target))
    test_score.append(model.score(test_scaled, test_target))
plt.plot(alpha_list, train_score, marker='o', label='Train')
plt.plot(alpha_list, test_score, marker='o', label='Test')
plt.xscale('log')
plt.legend()
plt.show()
```

![라쏘 규제 강도](../assets/pdf/라쏘-규제강도.png)

앞 릿지에서 사용한 `alpha_list`로 비교하며 모든 후보의 반복 상한은 10,000으로 유지함. 작은 alpha의 약한 규제 구간에서는 이 상한으로도 수렴 경고가 날 수 있어 충분히 수렴한 결과인지 확인해야 함.

그림에서는 중간 범위의 테스트 점수가 높게 유지되다가 alpha=100에서 훈련과 테스트 모두 낮아짐. 강한 제약이 필요한 관계까지 억제한 모습으로 볼 수 있음. 경고가 표시된 값은 점수만 보고 다른 후보와 같은 상태의 해라고 판단하지 않음.

## 0인 계수와 예측 결과 함께 보기

```python
lasso = Lasso(alpha=10, max_iter=10000)
lasso.fit(train_scaled, train_target)
print(round(lasso.score(train_scaled, train_target), 4),
      round(lasso.score(test_scaled, test_target), 4))
print(np.sum(lasso.coef_ == 0))
```

```text
0.9888 0.983
48
```

alpha=10에서 훈련 약 0.9888, 테스트 약 0.9830이고 계수 55개 중 48개가 0임. `coef_ == 0`은 0인 위치를 참으로 표시하고 `np.sum()`은 그 수를 셈. 나머지 일곱 계수가 예측에 직접 기여함.

입력은 여전히 55열이며 모델이 48열에 0을 곱하는 것임. 이 열들이 모든 데이터에서 불필요하다는 뜻은 아님. 다른 특성과 정보가 겹치거나 현재 데이터와 규제 조건에서 사용되지 않았을 수 있음. 다음에는 규제 없는 모델까지 같은 입력에서 비교함.
