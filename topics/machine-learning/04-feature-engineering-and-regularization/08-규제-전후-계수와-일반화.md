# 8. 규제 전후 계수와 일반화

학습 범위: 30에서 38쪽

## 같은 표준화 입력에서 세 모델 비교

입력, 데이터 분할, 평가 기준을 유지하고 학습 기준이 다른 세 모델을 비교.

```python
models = [
    ('Linear', LinearRegression()),
    ('Ridge', Ridge(alpha=0.1)),
    ('Lasso', Lasso(alpha=10, max_iter=10000)),
]
for name, model in models:
    model.fit(train_scaled, train_target)
    print(name, round(model.score(train_scaled, train_target), 4),
          round(model.score(test_scaled, test_target), 4),
          round(np.linalg.norm(model.coef_), 2), np.sum(model.coef_ == 0))
```

출력 순서는 모델, 훈련 R², 테스트 R², 계수 L2 크기, 0인 계수 수. 릿지는 약 `0.9904 / 0.9828 / 146.03 / 0`, 라쏘는 약 `0.9888 / 0.9830 / 175.88 / 48`로 나타남.

규제 없는 고차 모델은 훈련에는 매우 잘 맞으면서 계수와 테스트 결과가 불안정해질 수 있음. 정확한 음수 점수 한 개를 실행 성공의 기준으로 삼기보다 같은 조건의 훈련과 테스트 성능을 확인해야 함.

$$
\|\mathbf w\|_2=\sqrt{\sum_{j=1}^{m}w_j^2}
$$

`np.linalg.norm()`은 계수 제곱합에 제곱근을 적용한 크기. 계수 전체를 비교하는 수치지만 작다고 무조건 예측 성능이 좋은 것은 아님.

```python
for name, model in models[1:]:

```

왼쪽은 계수, 오른쪽은 alpha별 테스트 점수. 릿지는 여러 계수를 작게 유지하고 라쏘는 많은 계수가 0에 있음. 그래프의 특성 번호는 같은 다항 입력 열의 순서.

## 0인 계수가 많으면 더 좋은 모델일까?

```python
for alpha in [0.1, 1, 10, 100]:
    model = Lasso(alpha=alpha, max_iter=10000)
    model.fit(train_scaled, train_target)
    print(alpha, np.sum(model.coef_ == 0),
          round(model.score(test_scaled, test_target), 4))
```

```text
0.1 42 0.9824
1 47 0.9802
10 48 0.983
100 52 0.9091
```

alpha=100은 0인 계수가 가장 많지만 점수는 낮음. 필요한 관계까지 제한하면 과소적합이 생길 수 있음. 같은 alpha라도 릿지와 라쏘는 벌점과 오차 계산 기준이 달라 규제 효과가 같지 않음.

## 특성 확장과 규제를 함께 사용하는 이유

특성 확장은 표현할 관계를 늘리고 규제는 계수를 통해 그 관계를 사용하는 정도를 제한함. 서로 대체하는 두 작업이 아니라 표현력과 일반화 사이의 균형을 조절하는 작업.

| 데이터 | 역할 |
| --- | --- |
| 훈련 | 전처리 기준과 계수 학습 |
| 검증 | 특성, 모델, alpha 등 후보 비교 |
| 테스트 | 선택이 끝난 모델의 성능 평가 |

테스트를 계속 보며 설정을 바꾸면 그 정보가 모델 선택에 영향을 줌. 최종 성능을 독립적으로 확인할 데이터를 남겨야 함.
