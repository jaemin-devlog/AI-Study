# 8. 규제 전후 계수와 일반화

릿지와 라쏘의 결과를 확인했으므로 규제 없는 선형 회귀까지 같은 조건에서 비교함. 입력과 분할을 유지해야 전처리나 데이터 차이보다 학습 기준의 차이를 읽기 쉬움. 세 모델 모두 앞에서 만든 표준화된 55개 특성을 사용함.

## 예측 성능과 계수 크기 나란히 보기

```python
models = [
    ('Linear', LinearRegression()),
    ('Ridge', Ridge(alpha=0.1)),
    ('Lasso', Lasso(alpha=10, max_iter=10000)),
]
for name, model in models:
    model.fit(train_scaled, train_target)
    print(name, round(model.score(train_scaled, train_target), 4),
          round(model.score(test_scaled, test_target), 4),
          round(np.linalg.norm(model.coef_), 2), np.sum(model.coef_ == 0))
```

출력은 모델 이름, 훈련 R², 테스트 R², 계수 L2 크기, 0인 계수 수 순서. `np.linalg.norm()`은 다음 값을 계산함.

$$
\|\mathbf w\|_2=\sqrt{\sum_{j=1}^{m}w_j^2}
$$

이 값은 여러 계수의 크기를 하나로 요약함. 앞의 L2 벌점인 제곱합에 제곱근을 취한 값이므로 벌점 그 자체와는 구분함.

| 모델 | 훈련 R² | 테스트 R² | 계수 L2 크기 | 0인 계수 |
| --- | --- | --- | --- | --- |
| 릿지, alpha=0.1 | 약 0.9904 | 약 0.9828 | 약 146.03 | 0개 |
| 라쏘, alpha=10 | 약 0.9888 | 약 0.9830 | 약 175.88 | 48개 |

규제 없는 고차 모델은 훈련 점수가 거의 1이어도 계수가 매우 크거나 테스트 결과가 불안정해질 수 있음. 정확한 음수 점수 하나를 정상 실행의 기준으로 삼지 않고 실제 훈련과 테스트 차이를 확인함.

릿지의 계수 크기가 라쏘보다 작아도 그것만으로 예측이 더 좋다고 할 수는 없음. 또한 릿지와 라쏘는 벌점 방식과 오차의 정규화가 달라 alpha의 숫자만으로 어느 규제가 강한지 직접 비교할 수 없음.

## 계수 그림에서 0의 의미 읽기

```python
for name, model in models[1:]:
    plt.plot(model.coef_, marker='o', linestyle='none', label=name)
plt.axhline(0, linestyle='--')
plt.xlabel('Feature index')
plt.ylabel('Coefficient')
plt.legend()
plt.show()
```

![계수와 규제강도 비교](../assets/계수와-규제강도.png)

코드는 각 특성 번호에 대응하는 계수를 점으로 표시함. 포함된 비교 그림의 왼쪽은 계수, 오른쪽은 alpha별 테스트 점수임. 특성 번호는 같은 다항 입력 열의 순서이므로 두 모델에서 같은 번호끼리 비교할 수 있음.

릿지는 여러 계수를 작게 유지하고 라쏘는 많은 값이 0에 놓임. 0인 특성은 현재 예측식에서 직접 기여하지 않으며 열이 삭제된 것은 아님. 계수 그림은 모델이 입력을 사용하는 방식을 보여 주고 점수 그림은 그 결과를 평가함.

## 0인 계수가 많을수록 좋을까?

```python
for alpha in [0.1, 1, 10, 100]:
    model = Lasso(alpha=alpha, max_iter=10000)
    model.fit(train_scaled, train_target)
    print(alpha, np.sum(model.coef_ == 0),
          round(model.score(test_scaled, test_target), 4))
```

```text
0.1 42 0.9824
1 47 0.9802
10 48 0.983
100 52 0.9091
```

alpha가 커지면서 0인 계수가 늘어나는 모습을 볼 수 있음. 그러나 alpha=100은 52개가 0인데 테스트 R²는 약 0.9091로 낮아짐. 필요한 관계까지 제한하면 훈련과 새 데이터의 무게를 충분히 표현하지 못할 수 있음.

alpha=10의 48개보다 더 많은 계수를 없앴다는 사실만으로 개선이라고 할 수 없음. 모델을 단순하게 만드는 것과 새 데이터에서의 오차를 줄이는 것은 구분해야 함.

## 특성 공학과 규제를 하나의 흐름으로 연결하기

길이만 사용하던 모델에 높이와 두께를 추가하고, 기존 값을 조합해 9개와 55개의 특성을 만들었음. 이 작업은 모델이 표현할 수 있는 관계를 늘림. 규제는 그 관계를 사용하는 계수에 제약을 주어 훈련의 우연한 차이에 지나치게 맞춰지는 것을 억제함.

훈련 데이터는 변환 기준과 계수를 학습하는 데 사용하고, 검증은 차수나 alpha 같은 설정을 비교하는 데 사용함. 테스트는 선택을 끝낸 모델의 성능을 평가함. 테스트를 계속 보며 설정을 바꾸면 그 정보가 모델 선택에 들어가므로 최종 평가의 독립성이 약해짐.
