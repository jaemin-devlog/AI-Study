# 1. 다중 회귀와 데이터 준비

앞에서는 농어 길이 하나로 무게를 예측했음. 하지만 길이가 같아도 높이와 두께가 다르면 무게가 다를 수 있음. 이번에는 이 세 측정값을 함께 사용해 무게를 예측함. 여러 입력 특성을 사용하는 선형 회귀를 다중 회귀라고 함.

## 입력이 늘면 식은 어떻게 달라질까?

$$
\hat y=w_1x_1+w_2x_2+w_3x_3+b
$$

$x_1,x_2,x_3$은 길이, 높이, 두께이고 각 계수는 해당 입력에 곱해짐. 절편은 마지막에 더함. 예측할 타깃은 여전히 무게 하나이므로 입력 특성이 여러 개라는 것과 정답이 여러 개라는 것은 구분해야 함.

길이 하나와 무게를 그리면 직선이었고, 입력 둘과 무게를 3차원에 놓으면 평면으로 표현할 수 있음. 입력이 늘어도 각 특성에 계수를 곱해 더하는 방식은 같음.

앞의 길이 제곱처럼 기존 입력을 가공하거나 서로 조합해 새 열을 만들 수도 있음. 이런 작업을 특성 공학이라고 함. 이번에는 우선 실제 측정 특성 세 개를 준비한 뒤 제곱과 곱을 만들어 확장함.

## 표 형태의 데이터 읽기

```python
import numpy as np
import pandas as pd

perch_full = pd.read_csv('https://bit.ly/perch_csv_data', skipinitialspace=True)
print(perch_full.head())

perch_weight = np.array([
    5.9, 32.0, 40.0, 51.5, 70.0, 100.0, 78.0, 80.0, 85.0, 85.0,
    110.0, 115.0, 125.0, 130.0, 120.0, 120.0, 130.0, 135.0, 110.0, 130.0,
    150.0, 145.0, 150.0, 170.0, 225.0, 145.0, 188.0, 180.0, 197.0, 218.0,
    300.0, 260.0, 265.0, 250.0, 250.0, 300.0, 320.0, 514.0, 556.0, 840.0,
    685.0, 700.0, 700.0, 690.0, 900.0, 650.0, 820.0, 850.0, 900.0, 1015.0,
    820.0, 1100.0, 1000.0, 1100.0, 1000.0, 1000.0,
])
```

```text
   length  height  width
0     8.4    2.11   1.41
1    13.7    3.53   2.00
2    15.0    3.82   2.43
3    16.2    4.59   2.63
4    17.4    4.59   2.94
```

CSV는 값을 쉼표로 구분해 저장한 파일. `pd.read_csv()`는 이를 행과 열이 있는 DataFrame으로 읽고 `head()`는 앞 다섯 행을 보여 줌. 왼쪽의 0, 1, 2는 행 인덱스이며 입력 특성이 아님. 실제 열은 `length`, `height`, `width` 세 개임.

`skipinitialspace=True`는 구분자 뒤의 공백을 건너뛰도록 함. 같은 CSV가 로컬에 있다면 URL 대신 경로를 사용할 수도 있음. 무게는 별도의 `perch_weight` 배열에 있으며 같은 행 위치의 측정값과 짝을 이루어야 함.

## 같은 농어를 같은 분할로 비교하기

```python
from sklearn.model_selection import train_test_split

train_input, test_input, train_target, test_target = train_test_split(
    perch_full, perch_weight, random_state=42
)
print(train_input.shape, test_input.shape)
```

```text
(42, 3) (14, 3)
```

입력과 정답을 함께 분리해 훈련 42마리, 테스트 14마리를 만듦. 앞의 길이만 사용한 데이터와 농어 수와 정답은 같고 입력 열만 세 개로 늘어났음. `random_state=42`로 분할을 재현하고 이후 특성 확장과 규제 비교에서도 이 분할을 유지함.

한 샘플의 정보가 늘어났다고 자동으로 더 좋은 모델이 되는 것은 아님. 추가 특성이 어떤 관계를 표현하게 하는지, 새 데이터에서도 도움이 되는지는 실제 평가로 확인함. 다음에는 세 특성을 계산으로 확장하는 변환기를 사용함.
