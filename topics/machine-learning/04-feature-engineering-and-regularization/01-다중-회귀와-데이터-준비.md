# 1. 다중 회귀와 데이터 준비

학습 범위: 1에서 4쪽

## 여러 입력으로 하나의 무게 예측

길이가 같은 농어라도 높이와 두께가 다르면 무게가 다를 수 있음. 여러 입력 특성을 사용하는 선형 회귀를 다중 회귀라고 함.

$$
\hat y=w_1x_1+w_2x_2+w_3x_3+b
$$

세 입력은 길이, 높이, 두께. 계수는 각 입력에 곱해지고 절편은 마지막에 더해짐. 입력 하나에서는 직선, 두 입력과 타깃을 그리는 3차원에서는 평면으로 표현할 수 있음.

새로운 측정값을 추가하는 것 외에 기존 특성을 제곱하거나 서로 곱해 새 특성을 만드는 방법도 있음. 이런 입력 가공 작업이 특성 공학이며 앞의 길이² 추가도 그 예임.

## 판다스로 표 읽기

CSV는 값을 쉼표로 구분한 파일. `read_csv()`는 표를 DataFrame으로 읽고 `head()`는 처음 다섯 행을 보여줌. 가장 왼쪽 인덱스는 입력 특성이 아니며 세 열이 길이, 높이, 두께.

로컬에 같은 CSV가 있다면 URL 대신 파일 경로를 넣을 수 있음. 입력 행 순서는 위 무게 배열과 같아야 함.

## 같은 분할 유지

```python
from sklearn.model_selection import train_test_split

train_input, test_input, train_target, test_target = train_test_split(
    perch_full, perch_weight, random_state=42
)
print(train_input.shape, test_input.shape)
```

```text
(42, 3) (14, 3)
```

길이 하나였던 앞의 실습과 샘플 수와 정답은 같고 특성 열이 세 개로 늘어남. 이후 비교에서도 이 분할을 유지함.
