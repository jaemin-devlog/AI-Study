# 다중 회귀와 특성 공학

본문 코드는 개념별 부분 코드. 데이터 준비부터 독립 실행할 때는 [전체 실습](03-특성-공학과-규제-예제.md)을 사용.


## 다중 회귀

- 다중 회귀는 여러 입력 특성을 사용해 하나의 수치를 예측하는 선형 회귀다.
농어의 길이, 높이, 두께를 각각 $x_1, x_2, x_3$으로 두면 예측 무게는 다음과 같다.

$$
\hat{y} = w_1x_1 + w_2x_2 + w_3x_3 + b
$$

- $w_1, w_2, w_3$은 각 특성의 계수, $b$는 절편이다.
- 특성 공학은 기존 특성을 변환하거나 조합해 새로운 입력 특성을 만드는 과정이다.

## CSV에서 농어 입력 준비

길이만으로 무게를 예측하는 회귀에서는 생선 한 마리에 입력 열이 하나였다. 다중 회귀에서는 길이, 높이, 두께 세 특성을 사용한다. 입력과 정답은 이전 문서의 변수와 이름이 같더라도 다른 배열이다.

pandas는 표 형태의 데이터를 다루는 라이브러리다. CSV는 값들을 쉼표로 구분해 저장한 텍스트 파일이고, DataFrame은 pandas가 행과 열로 관리하는 표다. `pd.read_csv()`는 CSV를 읽어 DataFrame을 반환한다.

로컬 실습 폴더를 `ML_NOTEBOOK_DIR`로 지정하면 해당 폴더에서 데이터를 읽는다. 지정하지 않으면 온라인 데이터를 불러온다.

```python
import os
from pathlib import Path
import pandas as pd

source_dir = Path(os.environ["ML_NOTEBOOK_DIR"])
csv_path = source_dir / "perch_full.csv"
perch_frame = pd.read_csv(csv_path, skipinitialspace=True)
print(perch_frame.head())
```

```text
   length  height  width
0     8.4    2.11   1.41
1    13.7    3.53   2.00
2    15.0    3.82   2.43
3    16.2    4.59   2.63
4    17.4    4.59   2.94
```

왼쪽 0부터 시작하는 값은 DataFrame의 행 인덱스다. `length`, `height`, `width`가 실제 입력 열이며 인덱스는 모델의 특성에 포함되지 않는다. `head()`는 앞의 다섯 행을 보여 주므로 데이터가 예상한 열과 순서로 읽혔는지 확인할 수 있다.

무게 정답은 같은 실습 폴더의 `3-1.ipynb`에 있는 `perch_weight` 배열을 사용한다. 두 파일의 행 순서가 같은 농어를 가리키는 실습 데이터이므로 같은 위치끼리 짝을 지을 수 있다. 임의의 CSV와 무게 배열을 결합할 때도 순서를 확인해야 한다.

```python
import sys
from sklearn.model_selection import train_test_split

# 저장소 루트에서 실행할 때 공통 데이터 로더를 찾는 경로
sys.path.insert(0, str(Path("topics/machine-learning/examples").resolve()))
from 자료_불러오기 import perch

perch_input = perch_frame.to_numpy()
perch_weight = perch()["perch_weight"]
print(type(perch_frame).__name__, type(perch_input).__name__)
print(perch_input.shape, perch_weight.shape)
train_input, test_input, train_target, test_target = train_test_split(
    perch_input, perch_weight, random_state=42
)
print(train_input.shape, test_input.shape)
```

```text
DataFrame ndarray
(56, 3) (56,)
(42, 3) (14, 3)
```

`to_numpy()`는 표의 값을 NumPy 배열로 바꾼다. 입력 56행은 농어 56마리이고 세 열은 각 농어의 특성이다. `train_test_split()`은 입력과 정답의 짝을 유지해 네 결과를 훈련 입력, 테스트 입력, 훈련 정답, 테스트 정답 순서로 반환한다. `random_state=42`는 같은 분할을 재현하기 위한 설정이다.

## 2차와 5차 결과 해석

2차와 5차는 별도의 `PolynomialFeatures` 변환기로 만들고 각각의 `LinearRegression` 모델로 학습한다. 바로 아래 코드의 입력은 위에서 준비한 세 특성이다.

```python
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression

for degree in [2, 5]:
    transformer = PolynomialFeatures(degree=degree, include_bias=False)
    train_features = transformer.fit_transform(train_input)
    test_features = transformer.transform(test_input)
    model = LinearRegression()
    model.fit(train_features, train_target)
    print(degree, train_features.shape,
          model.score(train_features, train_target),
          model.score(test_features, test_target))
```

이번 실습에서는 2차가 `(42, 9)`, 훈련 약 0.9903, 테스트 약 0.9715다. 5차는 `(42, 55)`, 훈련 약 0.9954, 테스트 약 0.9780이다. 다른 계산 조건에서는 5차의 훈련 점수가 거의 1이고 테스트가 약 -144.4였다. 다항 특성의 수치적인 불안정성과 환경 차이가 결과에 영향을 줄 수 있으므로 0.9780이라는 결과만 보고 성능이 크게 하락했다고 판단할 수 없다.

![2차와 5차 특성의 훈련 및 테스트 점수](../assets/특성차수별-점수.png)

각 막대는 한 차수로 학습한 모델의 R²다. 왼쪽은 훈련, 오른쪽은 테스트 점수이며 농어 한 마리의 결과가 아니다. 이 입력에서는 5차 테스트 점수가 2차보다 조금 높다. 이 그래프만으로 다른 분할이나 데이터에서도 5차가 좋다고 판단할 수 없다.

## PolynomialFeatures

```python
from sklearn.preprocessing import PolynomialFeatures

poly = PolynomialFeatures(include_bias=False)
poly.fit(train_input)
train_poly = poly.transform(train_input)
test_poly = poly.transform(test_input)
print(train_poly.shape)  # (42, 9)
print(poly.get_feature_names_out())
```

- 여기서 `train_input`, `test_input`은 길이, 높이, 두께 3개 열을 가진 입력이다. 농어 42마리의 훈련 입력 모양은 `(42, 3)`이고 2차 변환 후 `(42, 9)`가 된다.
- `poly.fit(train_input)`은 입력 열 수와 생성할 조합을 준비하고 `transform()`은 각 행의 제곱과 곱을 계산한다. `get_feature_names_out()`은 만들어진 열의 이름과 순서를 확인한다.
- 기본 2차 확장으로 원래 특성 3개, 제곱항 3개, 두 특성의 곱 3개를 만들어 총 9개가 된다.
- `include_bias=False`는 변환 결과에서 상수 1 열을 제외한다. `LinearRegression`의 절편을 없애는 설정은 아니다.
- `fit()`은 입력의 특성 수를 확인하고 변환에 사용할 조합을 준비한다.
- `transform()`은 준비한 조합으로 실제 특성값을 계산한다. 테스트 데이터에도 훈련 데이터로 준비한 변환기를 적용한다.

### 어떤 특성이 만들어지는가?

두 특성이 $x_1=2$, $x_2=3$일 때 `PolynomialFeatures()`의 기본 2차 변환은 다음 항들을 만든다.

$$
[1, x_1, x_2, x_1^2, x_1x_2, x_2^2] = [1, 2, 3, 4, 6, 9]
$$

상수 1은 `include_bias=False`로 제외할 수 있다. 농어의 길이, 높이, 두께에 적용하면 원래 세 특성에 각 제곱과 특성끼리의 곱이 더해진다. 농어 수가 늘어난 것이 아니라 한 농어를 표현하는 열이 3개에서 9개로 늘어난 것이다.

## 5차 다항 특성으로 확장

앞의 `train_input`과 `test_input`은 길이, 높이, 두께 3개 열이다. 5차로 다시 변환하면 특성 55개를 만든다.

```python
poly = PolynomialFeatures(degree=5, include_bias=False)
poly.fit(train_input)
train_poly = poly.transform(train_input)
test_poly = poly.transform(test_input)
print(train_poly.shape)  # (42, 55)
```

실행 결과:

```text
(42, 55)
```

이 배열을 다음 릿지와 라쏘 실습에서 사용한다.

### 선형 회귀에 확장된 입력 사용

확장된 입력은 각 행이 농어 한 마리이고 열은 원래 특성과 새로 만든 특성이다. 같은 변환을 테스트 입력에 적용한 뒤 선형 회귀의 훈련과 평가에 전달한다.

```python
from sklearn.linear_model import LinearRegression

lr = LinearRegression()
lr.fit(train_poly, train_target)
print(lr.score(train_poly, train_target))
print(lr.score(test_poly, test_target))
```

이 코드는 직전에 만든 5차 `train_poly`, `test_poly`와 앞에서 분할한 무게 타깃을 사용한다. 2차 배열을 사용하면 훈련 R²는 약 0.9903, 테스트 R²는 약 0.9715이고, 5차로 변환하면 결과가 아래 표처럼 달라진다.

## 특성을 늘릴 때 확인할 점

| 다항 차수 | 특성 수 | 훈련 R² | 테스트 R² |
| --- | --- | --- | --- |
| 2차 | 9개 | 약 0.9903 | 약 0.9715 |
| 5차 | 55개 | 거의 1.0 | 다른 조건에서 약 -144.4 |

- 5차 확장에서는 훈련 샘플이 42개인데 특성이 55개다. 훈련에 거의 완벽히 맞아도 테스트에서 크게 실패할 수 있다.
- 특성을 늘리면 표현력이 커지지만 과대적합과 수치적 불안정 가능성도 커진다. 환경에 따라 점수는 달라질 수 있다.

훈련 샘플 42개보다 계수 55개가 많다고 해서 반드시 학습에 실패하거나 과대적합하는 것은 아니다. 다만 서로 비슷한 정보를 담는 다항 특성이 많으면 계수를 안정적으로 추정하기 어려울 수 있다.

다른 계산 조건에서는 훈련 점수가 거의 1인데 테스트 점수가 크게 떨어져 과대적합을 의심했다. 표준화 전 5차 모델은 계산 조건에 따라 다른 결과가 나올 수 있다. 특성 확장은 다양한 관계를 표현할 수 있게 하지만, 새 데이터에서도 좋은 예측을 보장하지는 않는다.
