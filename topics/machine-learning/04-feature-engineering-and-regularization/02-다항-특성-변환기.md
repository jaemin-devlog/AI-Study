# 2. 다항 특성 변환기

특성 공학은 같은 샘플을 다른 입력 표현으로 바꾸는 작업. 길이 제곱을 하나씩 만드는 대신 여러 특성의 제곱과 곱을 자동으로 생성할 수 있음. 사이킷런의 `PolynomialFeatures`는 이 작업을 수행하는 변환기임.

## 숫자 두 개가 여러 특성이 되는 과정

입력이 `[2, 3]`이라면 원래 값, 두 값의 제곱, 두 값의 곱을 만들 수 있음. 기본 최대 차수는 2이며 상수항 1도 포함함.

```python
from sklearn.preprocessing import PolynomialFeatures

poly_demo = PolynomialFeatures()
poly_demo.fit([[2, 3]])
print(poly_demo.transform([[2, 3]]))
poly_demo = PolynomialFeatures(include_bias=False)
poly_demo.fit([[2, 3]])
print(poly_demo.transform([[2, 3]]))
```

```text
[[1. 2. 3. 4. 6. 9.]]
[[2. 3. 4. 6. 9.]]
```

첫 결과를 순서대로 읽으면 상수 1, 원래 입력 2와 3, $2^2=4$, $2\times3=6$, $3^2=9$임. 두 번째 결과는 `include_bias=False`를 사용해 맨 앞 1을 제외한 것임.

`LinearRegression`은 기본적으로 절편을 별도로 학습하므로 상수 열을 넣지 않아도 됨. 이 설정은 변환 결과에서 1을 빼는 것이며 회귀식의 절편 자체를 없애는 것은 아님.

## 변환기의 fit()과 모델의 fit() 구분하기

변환기의 `fit()`은 입력 열 수를 확인하고 어떤 특성 조합을 만들지 준비함. `transform()`은 준비한 조합에 실제 값을 넣어 새 열을 계산함. 이때 정답 무게는 전달하지 않음.

반면 회귀 모델의 `fit(입력, 정답)`은 예측값이 정답에 가까워지도록 계수와 절편을 찾음. 같은 이름의 메서드라도 객체가 변환기인지 예측 모델인지에 따라 하는 일이 다름. `PolynomialFeatures`는 평균이나 표준편차를 학습하는 변환기도 아님.

## 길이, 높이, 두께를 아홉 열로 확장하기

```python
poly2 = PolynomialFeatures(include_bias=False)
poly2.fit(train_input)
train_poly2 = poly2.transform(train_input)
test_poly2 = poly2.transform(test_input)
print(train_poly2.shape, test_poly2.shape)
print(poly2.get_feature_names_out())
```

```text
(42, 9) (14, 9)
['length' 'height' 'width' 'length^2' 'length height' 'length width'
 'height^2' 'height width' 'width^2']
```

기존 세 열에 제곱 세 개와 서로 다른 특성을 곱한 세 개가 추가됨. `get_feature_names_out()`은 각 출력 열의 의미를 보여 줌. `length height`는 두 이름이 붙은 새 측정값이 아니라 길이와 높이를 곱한 열임.

$$
[x_1,x_2,x_3,x_1^2,x_1x_2,x_1x_3,x_2^2,x_2x_3,x_3^2]
$$

![다항 특성 확장](../assets/pdf/다항-특성-확장.png)

그림에서 길이 19.6과 높이 5.14를 곱하면 새 특성은 100.744임. 같은 농어의 측정값을 가공한 것으로 새 농어가 추가된 것은 아님. 훈련은 `(42, 3)`에서 `(42, 9)`로 바뀌고 정답 무게 42개는 그대로임.

테스트에도 훈련에서 준비한 같은 변환기를 적용해 `(14, 9)`를 만듦. 그래야 열의 개수와 순서, 의미가 학습 때와 일치함. 이제 모델은 새 항마다 계수를 따로 학습할 수 있음. 다음에는 이 표현의 확장이 성능에도 도움이 되는지 확인함.
