# 2. 다항 특성 변환기

학습 범위: 5에서 7쪽

## PolynomialFeatures의 동작

```python
from sklearn.preprocessing import PolynomialFeatures

poly_demo = PolynomialFeatures()
poly_demo.fit([[2, 3]])
print(poly_demo.transform([[2, 3]]))
poly_demo = PolynomialFeatures(include_bias=False)
poly_demo.fit([[2, 3]])
print(poly_demo.transform([[2, 3]]))
```

```text
[[1. 2. 3. 4. 6. 9.]]
[[2. 3. 4. 6. 9.]]
```

기본 설정은 2차까지 생성. 1은 상수항, 2와 3은 원래 입력, 4와 9는 제곱, 6은 두 특성의 곱.

`fit()`은 입력 열 수를 확인하고 만들 조합을 준비하며 `transform()`은 그 조합을 실제 숫자로 계산함. 정답 무게를 학습하는 모델의 `fit()`과 역할이 다름.

`include_bias=False`는 변환 결과의 상수 1을 제외. `LinearRegression`이 별도로 절편을 학습하므로 이 설정이 회귀식의 절편을 없애는 것은 아님.

## 3개 특성을 9개로 확장

```python
poly2 = PolynomialFeatures(include_bias=False)
poly2.fit(train_input)
train_poly2 = poly2.transform(train_input)
test_poly2 = poly2.transform(test_input)
print(train_poly2.shape, test_poly2.shape)
print(poly2.get_feature_names_out())
```

```text
(42, 9) (14, 9)
['length' 'height' 'width' 'length^2' 'length height' 'length width'
 'height^2' 'height width' 'width^2']
```

![다항 특성 확장](../assets/pdf/다항-특성-확장.png)

기존 세 개에 제곱 세 개와 교차곱 세 개를 더해 아홉 개. 예를 들어 길이 19.6과 높이 5.14의 곱은 100.744.

농어 수가 늘어난 것이 아니라 같은 농어를 설명하는 열이 늘어남. 테스트 입력도 같은 변환기를 사용해 열의 수와 의미를 유지해야 함. 이 변환기는 특성 조합을 준비하며 평균이나 표준편차를 계산하는 변환기는 아님.
