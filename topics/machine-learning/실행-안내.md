# 데이터 준비와 실습 실행

## 처음 실행할 때

저장소 루트에서 다음 명령 실행. Python과 pip가 필요하며 첫 설치는 네트워크를 사용한다.

```powershell
python -m pip install -r topics/machine-learning/examples/필요-라이브러리.txt
python topics/machine-learning/examples/01-생선-분류.py
```

데이터 로더는 저자의 공개 저장소에서 `1-3.ipynb`, `3-1.ipynb`, `perch_full.csv`를 읽는다. 네트워크가 필요하다. 노트북 코드를 실행하지 않고 필요한 숫자 상수만 읽는다. 데이터 순서를 유지해 입력과 타깃을 맞춘다.

이미 실습 자료가 있으면 `ML_NOTEBOOK_DIR`에 그 폴더를 지정해 네트워크 없이 실행 가능. PowerShell에서 실제 폴더 경로를 값으로 설정한다. 폴더에는 위 세 파일이 필요하다.

```powershell
$env:ML_NOTEBOOK_DIR = (Resolve-Path ..\module1_ml_dl_basics).Path
python topics/machine-learning/examples/03-최근접-이웃-회귀.py
```

위 상대경로는 두 저장소가 같은 상위 폴더에 있을 때의 예시다. 다른 위치라면 실제 폴더로 바꾼다. 이번 실행은 제공받은 로컬 실습 폴더를 사용했다. 온라인 경로도 실행을 시도했으나 현재 환경에서 DNS 이름 확인 실패로 데이터를 읽지 못했다. 온라인 실행 결과는 검증하지 못했다.

각 `01`부터 `05` 실행 파일은 별도 Python 프로세스에서 독립적으로 시작한다. 계산, 분할과 변환은 파일 안에 드러나며 공통 모듈은 데이터 읽기만 담당한다. 생성 그래프는 `assets/`에 저장한다. 실행 결과 기록은 `examples/results/`에 있다.

## 실행 환경과 결과 해석

이번 실행 환경은 scikit-learn 1.9.1, NumPy 2.4.6, pandas 3.0.6, Matplotlib 3.11.2. `random_state=42`로 데이터 분할을 고정했다. 라이브러리와 선형대수 환경에 따라 소수점과 불안정한 고차 무규제 회귀 결과가 달라질 수 있다.

라쏘의 작은 alpha 후보에서 수렴 경고가 나왔다. 해당 후보의 숫자를 충분히 수렴한 최종 결과라고 해석하지 않는다. 경고를 숨기거나 점수를 교재 숫자에 맞추지 않았다.

본문의 짧은 코드 조각은 개념을 확인하는 부분 코드다. 새 프로세스에서 전체를 재현할 때는 각 주제의 실행 실습 문서 또는 연결된 `.py` 파일을 사용한다.

## 코드 조각을 실행하는 위치

실행 파일은 `python topics/machine-learning/examples/01-생선-분류.py`처럼 경로를 지정해 실행한다. Python은 파일이 있는 `examples` 폴더에서 `자료_불러오기.py`를 찾는다. `Path(__file__)`도 실행 파일 위치를 기준으로 그림을 저장한다. `matplotlib.use("Agg")`는 화면 창 대신 파일로 그림을 저장하기 위한 설정이다.

노트북이나 VS Code 인터프리터에는 `__file__`이 없을 수 있고 `from 자료_불러오기 import ...`도 자동으로 찾지 못할 수 있다. 문서의 단계별 조각을 복사할 때는 저장소 루트에서 먼저 아래 경로를 추가하고, 그래프 저장 경로를 `Path("topics/machine-learning/assets")`처럼 현재 작업 폴더에 맞게 바꾼다. 단계별 블록은 같은 세션에서 순서대로 실행한다.

```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path("topics/machine-learning/examples").resolve()))
```

로컬 환경 변수에 잘못된 폴더를 지정하면 필요한 파일을 열 때 `FileNotFoundError`가 나온다. 설정하지 않은 경우 원격 저장소에 접속하므로 네트워크나 URL 문제는 `URLError` 또는 시간 초과로 나타날 수 있다. 원격 로딩은 이번 제한된 네트워크 환경에서 실행 확인하지 못했다.
