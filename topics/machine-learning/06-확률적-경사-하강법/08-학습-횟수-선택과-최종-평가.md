# 8. 학습 횟수 선택과 최종 평가

앞에서 저장한 `train_score`와 `val_score`로 학습량을 비교함. 리스트의 첫 값은 1에포크 후 점수이지만 배열 위치는 0부터 시작하므로 번호를 연결할 때 주의함.

## 검증 최고값과 주변 기록 읽기

```python
best_epoch = int(np.argmax(val_score) + 1)
print(best_epoch, round(float(np.max(val_score)), 4))
for epoch in [11, 30, 60, 100, 200, 300]:
    print(epoch, round(train_score[epoch - 1], 4), round(val_score[epoch - 1], 4))
```

```text
11 0.9583
11 0.8842 0.9583
30 0.8105 0.875
60 0.8842 0.875
100 0.9368 0.9167
200 0.9579 0.9167
300 0.9684 0.9167
```

`argmax()`는 가장 높은 값의 위치를 반환하므로 1을 더해 에포크 번호로 바꿈. 최고값이 여러 개라면 첫 위치를 선택함. 이 기록의 첫 최고값은 11에포크의 약 0.9583임.

검증은 24개뿐이므로 23개를 맞히면 0.9583, 한 개 차이는 약 4.17%포인트. 최고값 한 번만으로 안정적인 성능이나 보편적인 최적 에포크가 증명되지는 않음. 30과 60에서 내려갔다가 이후 다시 달라지는 기록도 함께 봐야 함.

아래 코드는 학습 횟수를 고정한 재학습 과정을 보기 위해 100에포크를 사용함. 위 `best_epoch`를 자동으로 적용한 코드가 아니며, 최고 검증 점수로 100이 선택됐다고 읽으면 안 됨. 실제 설정 선택에는 충분한 검증과 분할에 따른 변동을 고려함.

## 전체 훈련 데이터로 다시 모델 만들기

학습 횟수를 비교하는 동안 24개는 검증을 위해 계수 학습에서 제외했음. 설정이 정해진 뒤에는 전체 훈련 119개로 새 모델을 학습할 수 있음. 표준화도 전체 훈련 기준으로 준비함. 여기서 `train_scaled`와 `test_scaled`는 앞서 전체 훈련 119개로 만든 `ss`의 변환 결과임.

```python
selected_epoch = 100
sc_final = SGDClassifier(loss='log_loss', max_iter=selected_epoch,
                         tol=None, random_state=42)
sc_final.fit(train_scaled, train_target)
print(round(sc_final.score(train_scaled, train_target), 4))
print(round(sc_final.score(test_scaled, test_target), 4))
```

```text
0.958
0.925
```

`tol=None`은 개선 정도에 따른 자동 종료를 사용하지 않고 지정한 에포크를 진행하게 함. 훈련 정확도는 약 0.9580, 테스트 정확도는 0.925임.

이 모델은 95개로 학습한 `sc_epoch`를 이어 쓰는 것이 아니라 119개로 새로 학습한 모델. 데이터와 호출 방식이 달라 검증 기록의 같은 에포크와 점수가 일치할 필요는 없음.

## 횟수 선택과 조기 종료 구분하기

여기서는 정해진 에포크 전체를 관찰한 뒤 기록을 비교했음. 학습 도중 검증 개선이 멈추면 자동으로 중단하는 조기 종료와는 절차가 다름. `early_stopping` 옵션은 후자와 관련됨.

테스트는 설정을 고른 후 마지막 결과를 확인하는 용도. 앞 실습처럼 학습 과정을 관찰하며 테스트를 여러 번 본 결과와, 설정 선택에서 독립적으로 남긴 최종 테스트 평가는 구분해야 함.
