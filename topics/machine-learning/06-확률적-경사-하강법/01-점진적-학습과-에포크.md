# 1. 점진적 학습과 에포크

로지스틱 회귀는 측정값에 계수를 곱하고 절편을 더해 예측했음. 이제 그 계수와 절편을 어떻게 찾는지 배움. 학습은 처음 정한 파라미터로 예측한 뒤 정답과 비교하고, 더 나은 예측을 하도록 파라미터를 수정하는 과정임.

## 기존 모델에서 학습을 이어가는 이유

생선 데이터가 새로 쌓일 때마다 기존 데이터와 합쳐 처음부터 학습할 수 있음. 하지만 데이터가 커지면 매번 전체를 다시 처리하는 시간과 자원도 늘어남. 이미 학습한 계수와 절편을 출발점으로 새 데이터의 정보를 반영하는 방법이 점진적 학습임.

새 데이터가 들어올 때마다 모델을 갱신하는 온라인 학습과도 연결됨. 모든 모델이 추가 학습을 지원하는 것은 아니며 새 데이터만 계속 반영하면 기존 관계가 약해질 수도 있어 평가가 필요함.

점진적 학습은 기존 상태에서 계속 배운다는 방식이고, 확률적 경사 하강법은 파라미터를 수정하는 구체적인 방법. 두 용어의 역할을 구분함.

## 경사를 따라 손실 줄이기

예측과 정답의 차이를 학습용 숫자로 나타낸 것이 손실. 산에서 낮은 곳을 찾는다고 생각하면 현재 위치는 계수와 절편, 높이는 손실임. 높이를 낮추기 위해 위치를 움직이듯 손실을 줄이기 위해 파라미터를 바꿈.

손실 값만으로는 계수를 늘릴지 줄일지 알 수 없음. 계수를 조금 바꿀 때 손실이 어느 방향으로 증가하는지 알려 주는 기울기가 경사임. 그 반대 방향으로 조금 이동하는 방법이 경사 하강법임. 입력과 정답은 고정하고 계수와 절편을 수정함.

확률적 경사 하강법인 SGD는 샘플 하나에서 손실과 경사를 계산해 한 번 수정함. 다음 샘플에서는 수정된 모델로 예측하고 다시 갱신함. 전체 데이터를 다 계산하기 전에 갱신할 수 있지만 한 샘플의 방향이 전체 손실을 줄이는 방향과 항상 같지는 않음.

## 한 번에 사용하는 샘플 수

| 방법 | 한 번 수정할 때 사용하는 데이터 | 샘플 12개를 한 번 사용할 때 수정 횟수 |
| --- | --- | --- |
| 확률적 경사 하강법 | 샘플 1개 | 12회 |
| 미니배치 경사 하강법 | 여기서는 4개씩 | 3회 |
| 배치 경사 하강법 | 전체 12개 | 1회 |

전체 훈련 데이터를 한 번 사용하면 1에포크. 같은 1에포크라도 수정 횟수는 묶음 크기에 따라 다름. 다음 에포크는 앞 에포크의 최종 파라미터에서 이어감. 마지막 묶음이 정한 크기보다 작을 수도 있음.

보통 훈련 순서를 섞어 특정 종류가 연속해서 나오는 영향을 줄임. 무작위인 것은 샘플을 사용하는 순서이며, 파라미터를 바꾸는 방향은 계산한 경사로 정함. 에포크는 전체 데이터의 반복 횟수이고 학습률은 한 번의 수정 크기를 조절하는 값임.
