# 9. 손실함수 비교와 다음 학습

SGD는 손실의 경사로 파라미터를 수정하는 방법. 손실 함수는 어떤 예측을 얼마나 나쁘게 평가할지 정함. 따라서 SGD라는 이름만으로 모델의 학습 기준이나 확률 출력 방식이 모두 정해지는 것은 아님.

## 로지스틱 손실과 힌지 손실

`log_loss`는 실제 정답에 부여한 확률을 반영함. 정답 확률이 높으면 손실이 작고 낮으면 큼. `hinge`는 선형 SVM의 손실로 올바른 클래스를 충분한 점수 차이로 구분하도록 학습함.

같은 데이터로 같은 횟수를 학습해도 손실 기준이 다르면 경사와 최종 계수가 달라질 수 있음. 힌지 손실의 점수를 로지스틱 확률과 같은 의미로 읽으면 안 됨.

## 같은 검증 조건에서 비교하기

앞에서 만든 학습용 `sub_scaled`, 검증용 `val_scaled`와 각각의 정답을 사용함. 분할과 반복 횟수는 유지하고 손실만 바꿔 비교함.

```python
for loss in ['log_loss', 'hinge']:
    model = SGDClassifier(loss=loss, max_iter=100, tol=None, random_state=42)
    model.fit(sub_scaled, sub_target)
    print(loss, round(model.score(sub_scaled, sub_target), 4),
          round(model.score(val_scaled, val_target), 4))
```

```text
log_loss 0.9579 0.9167
hinge 0.9368 0.9167
```

| 손실 함수 | 훈련 정확도 | 검증 정확도 |
| --- | ---: | ---: |
| `log_loss` | 0.9579 | 0.9167 |
| `hinge` | 0.9368 | 0.9167 |

동일한 학습용과 검증용 분할, 100에포크에서 손실 함수만 바꾼 결과임.

출력은 손실 이름, 훈련 정확도, 검증 정확도 순서. 훈련은 로지스틱 손실이 약 0.9579, 힌지가 약 0.9368로 다르지만 검증은 둘 다 약 0.9167임. 훈련을 더 많이 맞혔다고 검증 성능도 더 높다고 할 수 없음.

전체 훈련으로 100에포크를 사용한 비교에서는 로지스틱 손실의 훈련 약 0.9580, 힌지 약 0.9496이고 테스트는 모두 0.925였음. 정확도가 같아도 개별 예측이나 파라미터까지 같다는 뜻은 아님. 설정 선택에는 테스트가 아닌 검증을 사용함.

## 학습 과정의 역할 연결하기

입력을 받아 점수와 예측을 만드는 것은 모델, 정답과 비교하는 기준은 손실 함수, 파라미터 수정 방법은 SGD임. 에포크는 전체 데이터를 몇 번 사용할지, 학습률은 한 번의 수정 크기를 조절함.

이 역할을 구분하면 `loss`, `max_iter`, `partial_fit()`이 서로 어떤 부분에 작용하는지 읽을 수 있음. 다음 결정 트리는 계수와 절편 대신 데이터를 나누는 특성과 기준값을 학습함. 분류 결과까지 어떤 질문을 통과했는지 따라갈 수 있는 모델임.
