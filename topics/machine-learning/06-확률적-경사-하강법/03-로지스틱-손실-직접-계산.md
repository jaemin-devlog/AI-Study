# 3. 로지스틱 손실 직접 계산

앞에서 정답 클래스의 확률 $q$로 손실 $L=-\ln q$를 계산했음. 이번에는 숫자를 넣어 확률과 손실이 반대 방향으로 변하는지 확인함. 아래 배열은 양성 확률이 아니라 각 샘플의 실제 정답에 부여한 확률을 모은 것임.

## 확률을 로그 손실로 바꾸기

```python
import numpy as np

correct_probabilities = np.array([0.9, 0.6, 0.1])
losses = -np.log(correct_probabilities)
print(np.round(losses, 3))
```

```text
[0.105 0.511 2.303]
```

`np.log()`는 배열의 각 원소에 자연로그를 적용함. 0과 1 사이의 자연로그는 음수이므로 앞에 `-`를 붙이면 손실은 양수가 됨. `np.round()`는 보이는 자릿수를 줄일 뿐 계산 기준을 바꾸지 않음.

정답 확률이 0.9인 경우 손실은 약 0.105이고, 0.1인 경우 약 2.303임. 정답을 거의 선택하지 않은 예측에 더 큰 손실이 생김. 0.99와 0.01에서는 각각 약 0.010과 4.605로 차이가 더 커짐. 직접 계산에 0을 넣으면 로그가 정의되지 않으므로 여기서는 0보다 큰 값을 사용함.

## 맞힌 예측끼리도 차이가 생기는 이유

다음 두 샘플은 실제 정답이 모두 1임. 따라서 양성 확률이 곧 정답 확률임.

```python
positive_probabilities = np.array([0.6, 0.9])
predictions = (positive_probabilities > 0.5).astype(int)
print(predictions)
print(np.round(-np.log(positive_probabilities), 3))
```

```text
[1 1]
[0.511 0.105]
```

`> 0.5`는 양성을 선택할지 비교하고 `.astype(int)`는 참과 거짓을 1과 0으로 바꿈. 출력 `[1 1]`은 두 샘플 모두 양성으로 예측했다는 뜻. 실제 정답도 1이므로 둘 다 맞혔음.

그러나 확률 0.6의 손실은 약 0.511이고 0.9의 손실은 약 0.105. 학습 기준은 정답 여부뿐 아니라 정답에 부여한 확률도 구분함. 계수를 수정했을 때 최종 클래스가 그대로여도 확률과 손실은 달라질 수 있음.

실제 정답이 0이라면 양성 확률을 그대로 사용할 수 없음. 먼저 $1-p$로 음성 확률을 구해 로그에 넣어야 함. 정답을 모르는 새 생선에서는 예측 확률은 구할 수 있지만 정답과 비교한 손실은 바로 구할 수 없음.

## 문제에 따라 손실도 달라짐

| 문제 | 대표적인 손실 | 비교하는 내용 |
| --- | --- | --- |
| 이진 분류 | 로지스틱 손실 | 실제 정답 클래스의 확률 |
| 다중 분류 | 크로스 엔트로피 | 여러 클래스 중 정답 확률 |
| 회귀 | MAE | 예측값과 실제값 차이의 절댓값 |
| 회귀 | MSE | 예측값과 실제값 차이의 제곱 |
