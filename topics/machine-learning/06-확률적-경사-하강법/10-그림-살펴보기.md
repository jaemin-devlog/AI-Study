# 확률적 경사 하강법 그림 살펴보기

## 1. 에포크와 갱신 횟수

![에포크와 갱신 횟수](../assets/pdf/에포크와-갱신-횟수.png)

숫자 1부터 12는 서로 다른 훈련 샘플. 위에서부터 한 번의 갱신에 1개, 4개, 12개를 사용하는 경우를 보여줌. 파란 SGD는 12회, 초록 미니배치는 3회, 주황 배치는 1회 갱신함.

세 방법 모두 12개를 한 번씩 사용했으므로 1에포크. 따라서 에포크 수만 같다고 파라미터 갱신 횟수도 같은 것은 아님. 그림의 묶음 크기는 예시이며 실제 학습에서는 전체 샘플 수와 배치 크기를 함께 확인해야 함.

## 2. 정답 확률과 로지스틱 손실

![정답 확률과 손실](../assets/pdf/정답-확률과-로지스틱-손실.png)

왼쪽은 실제 정답이 1이면 양성 확률 p, 정답이 0이면 1-p를 고르는 과정. 오른쪽 가로축은 그렇게 선택한 정답 확률 q, 세로축은 -ln(q) 손실.

q=0.2에서는 약 1.609, q=0.8에서는 약 0.223. 예측한 클래스가 아니라 실제 정답의 확률을 기준으로 읽어야 함. 0에 가까운 정답 확률은 높은 손실이 되어 틀린 클래스에 대한 강한 확신을 더 크게 벌함.

## 3. 학습률에 따른 이동

![학습률 비교](../assets/pdf/학습률과-경사-하강법.png)

세로축은 손실, 가로축은 모델 계수. 파란 선의 점들은 적절한 수정 크기로 낮은 손실을 향해 이동하는 모습. 주황 선은 큰 학습률로 낮은 지점을 넘어 반대편까지 이동하며 흔들리는 모습.

가로축은 에포크가 아니라 파라미터 위치이므로 오른쪽으로 가는 것이 곧 학습 진전은 아님. 이 곡선은 원리를 보여주는 개념 그림이며 실제 SGD의 손실이 항상 이런 매끄러운 곡선으로 줄어든다는 뜻은 아님.

## 4. 예측에서 파라미터 수정까지

![학습 순환](../assets/pdf/모델-학습-순환.png)

입력과 정답에서 출발해 점수, 시그모이드 확률, 손실, 경사, 파라미터 수정, 다시 예측으로 이어지는 순환. 중심의 계수와 절편은 다음 샘플을 예측할 때 갱신된 값으로 사용됨.

정답과 입력을 수정하는 과정이 아니라 모델을 수정하는 과정. 손실은 현재 오류의 크기, 경사는 수정 방향, 학습률은 수정 크기를 결정함. 한 샘플에서 계산한 수정이 전체 훈련 손실을 매번 감소시키지는 않을 수 있음.

## 5. 에포크와 일반화의 개념

![에포크와 일반화](../assets/pdf/에포크와-과대적합-개념.png)

가로축은 에포크, 세로축은 정확도. 초록 훈련 곡선은 계속 높아지고 주황 검증 곡선은 중간부터 낮아지는 개념 예시. 점선은 검증 성능을 살펴 학습을 멈출 시점의 예를 표시함.

초기의 낮은 두 점수는 학습 부족을, 뒤쪽의 커지는 차이는 과대적합 가능성을 표현함. 실제 학습 기록과 달리 개념을 단순화한 그림이므로 이 모양만으로 특정 에포크를 정하면 안 됨.

## 6. 실제 에포크별 정확도

![훈련과 검증 정확도 기록](../assets/pdf/에포크별-훈련과-검증-정확도.png)

가로축은 1부터 300에포크, 세로축은 정확도. 초록은 학습용 95개의 훈련 정확도, 주황은 검증 24개의 정확도. 초반에는 두 선이 오르내리고 11에포크에서 검증 약 95.8%를 기록함.

100에서 300에포크 사이에는 훈련이 약 93.7%에서 96.8%로 높아져도 검증은 약 91.7%로 같음. 최고 검증값 한 점뿐 아니라 표본 수와 전체 추세를 함께 읽어야 함. 이 그림의 점선은 학습량 선택 예시이며 학습 도중 자동으로 중단한 기록은 아님.
