# 5. 생선 데이터와 추가 학습

이제 생선 7종을 분류하면서 실제로 학습을 이어감. `SGDClassifier`는 확률적 경사 하강법으로 선형 분류 모델의 파라미터를 학습하는 객체. 어떤 손실을 사용할지는 설정으로 정함.

## 입력과 정답, 표준화 기준 준비하기

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import SGDClassifier

fish = pd.read_csv('https://bit.ly/fish_csv_data')
fish_input = fish[['Weight', 'Length', 'Diagonal', 'Height', 'Width']]
fish_target = fish['Species']
train_input, test_input, train_target, test_target = train_test_split(
    fish_input, fish_target, random_state=42
)
ss = StandardScaler()
ss.fit(train_input)
train_scaled = ss.transform(train_input)
test_scaled = ss.transform(test_input)
```

입력은 무게, 길이, 대각선 길이, 높이, 두께이고 정답은 종류임. 훈련 119마리와 테스트 40마리로 나눈 뒤 훈련 데이터의 평균과 표준편차로 두 입력을 변환함. 표준화 기준을 배우는 `ss.fit()`과 분류 모델의 파라미터를 배우는 `sc.fit()`은 이름이 같아도 역할이 다름.

## 처음 학습한 뒤 한 번 더 학습하기

`loss='log_loss'`는 로지스틱 손실을 사용하겠다는 설정. `max_iter=10`은 `fit()`에서 훈련 데이터 전체를 최대 10에포크 사용하도록 함. `random_state=42`는 같은 조건의 계산을 재현하기 위한 값임.

```python
sc = SGDClassifier(loss='log_loss', max_iter=10, random_state=42)
sc.fit(train_scaled, train_target)
print(round(sc.score(train_scaled, train_target), 4),
      round(sc.score(test_scaled, test_target), 4))
sc.partial_fit(train_scaled, train_target)
print(round(sc.score(train_scaled, train_target), 4),
      round(sc.score(test_scaled, test_target), 4))
```

```text
0.7815 0.8
0.8067 0.825
```

첫 줄은 최초 학습 후 훈련과 테스트 정확도이고 둘째 줄은 추가 학습 후 정확도. 이 실행에서는 약 0.7815와 0.8000이 0.8067과 0.8250으로 높아졌음. 숫자의 상승과 함께 어느 데이터로 얼마나 더 학습했는지 연결해서 봄.

| 학습 상태 | 훈련 정확도 | 테스트 정확도 |
| --- | ---: | ---: |
| 최초 학습 후 | 0.7815 | 0.8000 |
| 추가 학습 후 | 0.8067 | 0.8250 |

다른 실행에서는 최초 학습 후 훈련 0.7731, 테스트 0.7750이고 추가 학습 후 훈련 0.7983, 테스트 0.7750인 결과도 있음. 이 경우 계수를 더 학습했어도 테스트에서 맞힌 개수는 그대로임. 라이브러리 버전 등의 차이에 따라 출력값은 달라질 수 있으므로 수치와 그 의미를 함께 확인함.

반복 횟수가 부족해 수렴 조건을 만족하지 못하면 `ConvergenceWarning`이 나타날 수 있음. 이미 학습한 파라미터는 남지만 충분히 안정됐다는 뜻은 아니므로 원인을 확인해야 함.

## partial_fit()이 이어가는 상태

`partial_fit()`은 현재 계수와 절편에서 주어진 데이터를 한 에포크 더 학습함. 이 호출은 `max_iter=10`을 다시 10번 반복하는 것이 아님. 전체 훈련 데이터를 넘기면 그 전체를 한 번 더 사용하고, 새 데이터를 넘기면 그 새 데이터를 사용함.

여기서는 새로운 생선이 아니라 같은 훈련 생선으로 추가 학습했음. 일반적인 `fit()` 재호출은 처음부터 학습하는 동작이므로 이어서 학습하려는 목적에는 `partial_fit()`을 사용함.

추가 학습 후 정확도가 늘어야 한다는 보장은 없음. 파라미터가 갱신됐는지와 새로운 데이터의 예측이 좋아졌는지는 별도로 확인해야 함. 다음 파일에서는 파라미터 자체를 비교함.
