## 실행 소스와 확인 범위

데이터 로더는 [저자의 노트북 및 CSV 저장소](https://github.com/rickiepark/hg-mldl)에서 읽는다. 해당 저장소는 [MIT License](https://github.com/rickiepark/hg-mldl/blob/master/LICENSE)를 명시한다. 강의 PDF 전체는 포함하지 않았고 일부 그림을 정리 자료에 사용했다. 이 저장소에서 제공하는 실행 코드는 학습 흐름에 맞춰 새로 작성했으며, 원 데이터 파일은 재배포하지 않고 실행 시 읽는다.

강의 자료 대응 번호:

1. 머신러닝의 기본 흐름과 데이터 준비: 35쪽
2. k-최근접 이웃 회귀: 28쪽
3. 선형 회귀: 31쪽
4. 특성 공학과 규제: 38쪽

이 번호는 대응표의 자료 위치를 밝히기 위한 용도이며 공개 자료 링크를 대신하지 않는다. 원본 PDF는 저장소에 포함하지 않는다.

## 강의 PDF 그림

주제별 정리에 포함된 일부 그림은 강의 PDF에서 발췌했다. 해당 그림의 공개 사용 조건은 확인되지 않았다. GitHub 공개 전 사용 가능 여부 확인 필요.
