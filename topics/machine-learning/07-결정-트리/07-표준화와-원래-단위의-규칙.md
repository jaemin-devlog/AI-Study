# 7. 표준화와 원래 단위의 규칙

지금까지는 로지스틱 회귀와 비교하기 위해 표준화한 와인으로 트리를 학습했음. 그러면 질문의 숫자도 표준화된 값이어서 원래 측정값과 바로 비교하기 어려움. 결정 트리는 일반적으로 표준화 없이 학습할 수 있어 원래 단위의 규칙을 확인할 수 있음.

## 순서가 유지되면 같은 분할을 표현할 수 있음

표준화는 모든 값에서 같은 평균을 빼고 같은 양의 표준편차로 나눔. 작은 값과 큰 값의 순서가 유지되므로 기준값에도 같은 변환을 적용하면 같은 샘플이 같은 쪽으로 나뉨.

KNN은 여러 특성의 숫자 차이를 거리로 합치므로 범위가 다른 특성에 영향을 받음. 트리는 한 노드에서 한 특성과 기준을 비교하므로 이런 거리 계산이 필요하지 않음. 수치 계산의 작은 차이는 가능하므로 모든 경우의 트리가 완전히 같아야 한다는 뜻은 아님.

```python
dt = DecisionTreeClassifier(max_depth=3, random_state=42)
dt.fit(train_input, train_target)
print(round(dt.score(train_input, train_target), 4),
      round(dt.score(test_input, test_target), 4))
```

```text
0.8455 0.8415
```

`dt`는 이제 원본 `train_input`으로 학습한 깊이 3 트리임. 훈련 0.8455와 테스트 0.8415로 표준화 모델과 같은 정확도를 얻었음. 이후 새 와인도 원래 측정값으로 입력함. 표준화 모델을 사용할 때는 그 모델에 맞는 변환을 적용해야 함.

## 원래 단위로 조건 따라가기

이번 트리에서 한 레드 와인 리프에 도착하는 순서는 다음과 같음.

1. 당도 4.325 이하이면 왼쪽.
2. 그중 당도 1.625 초과이면 오른쪽.
3. 그중 알코올 11.025 이하이면 왼쪽.

첫 질문은 표준화된 기준 약 -0.239에 대응함. 두 숫자는 같은 분할 위치를 각 입력 단위로 표현한 것임. 아래 질문은 앞 질문으로 남은 와인 집단에 적용됨. 모든 질문이 처음부터 전체 와인에 동시에 적용되는 것은 아님.

도착한 리프에는 레드 798개와 화이트 343개가 있음. 따라서 레드 확률은 다음과 같음.

$$
p_{\mathrm{red}}=\frac{798}{798+343}\approx0.6994
$$

숫자로 조건을 읽는 것에서 끝내지 않고 이 조건을 통과한 훈련 집단의 분포까지 연결해야 최종 예측을 설명할 수 있음. 다음에는 새 와인 하나로 이 경로를 직접 확인함.
