# 9. 특성 중요도와 모델 판단

앞에서는 한 와인의 이동 경로로 예측을 설명했음. 이번에는 트리 전체에서 어떤 특성이 분할에 많이 기여했는지 확인함. 한 샘플의 경로와 모델 전체의 특성 중요도는 서로 다른 관찰임.

## 특성 중요도의 근거

트리는 각 분할에서 불순도를 줄임. 이 감소량에 해당 노드의 샘플 비중을 반영하고 특성별로 모으면 분할에 대한 기여를 계산할 수 있음. `feature_importances_`는 이를 정규화한 상대적인 값임.

```python
print(np.round(dt.feature_importances_, 4))
```

```text
[0.1235 0.8686 0.0079]
```

입력 순서가 알코올, 당도, pH이므로 당도 0.8686이 가장 큼. 이 모델의 전체 불순도 감소에서 당도가 차지한 기여가 컸다는 뜻. 세 값의 합은 1임.

당도만 사용해 와인의 86.86%를 맞혔다는 뜻은 아니며, 당도가 종류를 결정하는 원인이라고 해석할 수도 없음. 현재 데이터와 깊이 3이라는 설정에서 학습된 분할에 대한 값임. 비슷한 정보를 주는 특성이 있거나 깊이가 제한되면 어떤 특성은 적게 사용될 수 있어 낮은 중요도를 곧바로 불필요함으로 판단하지 않음.

| 특성 | 중요도 | 이 트리에서의 상대적인 기여 |
| --- | ---: | --- |
| 알코올 도수 | 0.1235 | 두 번째로 큼 |
| 당도 | 0.8686 | 가장 큼 |
| pH | 0.0079 | 상대적으로 작음 |

중요도는 현재 데이터와 학습된 트리의 분할에서 불순도를 줄이는 데 기여한 정도임. 특성의 인과관계나 모든 상황에서의 중요도를 뜻하지는 않음.

## 정확도와 설명 가능성 함께 읽기

| 모델 | 훈련 정확도 | 테스트 정확도 |
| --- | --- | --- |
| 로지스틱 회귀 | 약 0.7808 | 약 0.7777 |
| 깊이 제한 없는 트리 | 약 0.9969 | 약 0.8592 |
| 깊이 3, 표준화 입력 | 약 0.8455 | 약 0.8415 |
| 깊이 3, 원본 입력 | 약 0.8455 | 약 0.8415 |

깊은 트리는 훈련 데이터를 거의 모두 맞히지만 테스트와의 차이가 큼. 깊이 3은 규칙이 단순하고 차이가 작지만 테스트 정확도도 조금 낮아졌음. 과대적합 가능성을 줄이는 것과 점수를 높이는 것이 항상 동시에 일어나지는 않음.

원본 입력과 표준화 입력은 이번 깊이 3 모델에서 같은 정확도를 얻었음. 원본 기준은 실제 당도나 알코올과 바로 비교할 수 있어 경로를 읽기 쉬움. 다만 각각 학습한 입력 단위에 맞춰 예측해야 함.

## 학습부터 새 와인 예측까지 연결하기

학습에서는 특성과 기준값을 고르고, 불순도 감소로 분할을 평가하며, 깊이 제한으로 복잡도를 조절함. 예측에서는 고정된 질문을 통과해 리프로 이동하고 그곳의 클래스 분포로 이름과 확률을 정함.

한 예측은 이동 경로로 설명하고 모델 복잡도는 깊이와 리프 수로 살펴보며 새로운 데이터의 성능은 별도 평가로 확인함. 설정을 선택할 때는 검증 데이터나 교차 검증을 사용함. 다음 학습은 이런 비교를 체계적으로 수행하는 교차 검증과 하이퍼파라미터 탐색으로 이어짐.
