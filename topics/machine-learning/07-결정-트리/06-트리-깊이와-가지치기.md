# 6. 트리 깊이와 가지치기

트리는 질문을 반복하며 훈련 와인을 더 작은 집단으로 나눔. 집단이 작아질수록 훈련 정답을 세밀하게 구분할 수 있지만 일부 사례에만 맞는 규칙도 만들 수 있음. 그 규칙이 새 와인에도 유효한지는 별도로 평가해야 함.

## 깊이로 질문의 연속 길이 제한하기

루트의 깊이는 0이며 가지를 한 번 내려갈 때마다 1 증가함. `max_depth=3`은 학습할 때 깊이 3까지만 성장하도록 제한함. 성장 단계에서 복잡도를 막는 사전 가지치기의 한 방법임.

```python
dt_scaled = DecisionTreeClassifier(max_depth=3, random_state=42)
dt_scaled.fit(train_scaled, train_target)
print(round(dt_scaled.score(train_scaled, train_target), 4),
      round(dt_scaled.score(test_scaled, test_target), 4))
```

```text
0.8455 0.8415
```

| 모델 | 훈련 정확도 | 테스트 정확도 |
| --- | --- | --- |
| 깊이 제한 없음 | 0.9969 | 0.8592 |
| 깊이 3 | 0.8455 | 0.8415 |

훈련과 테스트 차이는 크게 줄었지만 테스트 자체는 조금 낮아졌음. 복잡도를 줄였다는 것과 성능이 향상됐다는 것을 같은 의미로 읽으면 안 됨. 반대로 너무 얕으면 필요한 관계도 표현하지 못해 과소적합이 생길 수 있음.

```python
plt.figure(figsize=(18, 10))
plot_tree(dt_scaled, filled=True, feature_names=['alcohol', 'sugar', 'pH'])
plt.show()
```

![깊이 3 트리](../assets/pdf/깊이-3-결정-트리.png)

여기서는 모델 자체가 깊이 3이므로 그 전체를 그릴 수 있음. 앞에서 사용한 `plot_tree(max_depth=1)`은 그림만 생략했지만 이번 `DecisionTreeClassifier(max_depth=3)`은 실제 예측 규칙을 제한함.

## 깊이와 리프 수, 훈련 정확도 연결하기

```python
for depth in [1, 2, 3, 5, None]:
    candidate = DecisionTreeClassifier(max_depth=depth, random_state=42)
    candidate.fit(train_scaled, train_target)
    print(depth, candidate.get_depth(), candidate.get_n_leaves(),
          round(candidate.score(train_scaled, train_target), 4))
```

```text
1 1 2 0.7579
2 2 4 0.8099
3 3 8 0.8455
5 5 31 0.8672
None 21 799 0.9969
```

출력은 설정 깊이, 실제 깊이, 리프 수, 훈련 정확도 순서. 제한 없는 `None`에서는 깊이 21과 리프 799개가 만들어지고 훈련 정확도는 약 0.9969임. 깊이 3에서는 리프 8개와 약 0.8455임.

깊이 4를 추가하면 리프 16개와 약 0.8572, 깊이 7은 리프 100개와 약 0.8896임. 더 많은 리프는 훈련 데이터를 더 세밀하게 구분할 여지를 줌. 그러나 리프 수가 깊이마다 반드시 두 배가 되지는 않으며 더 이상 유효한 분할이 없으면 실제 깊이도 상한보다 작을 수 있음.

이 표는 훈련 성능만 보여 주므로 최적 깊이를 정할 수 없음. 검증이나 교차 검증으로 일반화 성능을 비교해야 함. 테스트와의 차이뿐 아니라 점수 자체도 함께 봄.
