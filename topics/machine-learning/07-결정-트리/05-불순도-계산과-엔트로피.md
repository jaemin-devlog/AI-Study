# 5. 불순도 계산과 엔트로피

앞의 식을 루트 분할의 실제 개수에 적용함. 부모와 자식에서 각각 클래스 비율을 구해 지니를 계산하고, 자식 값을 샘플 수로 가중평균한 뒤 부모에서 뺌. 앞 파일에서 가져온 `np`는 NumPy임.

## 클래스 개수에서 정보 이득까지

```python
parent_counts = np.array([1258, 3939])
left_counts = np.array([1177, 1745])
right_counts = np.array([81, 2194])

def gini(counts):
    probabilities = counts / counts.sum()
    return 1 - np.sum(probabilities ** 2)

parent_gini = gini(parent_counts)
left_gini = gini(left_counts)
right_gini = gini(right_counts)
print(round(parent_gini, 4), round(left_gini, 4), round(right_gini, 4))
weighted_gini = (left_counts.sum() * left_gini + right_counts.sum() * right_gini) / parent_counts.sum()
print(round(weighted_gini, 4), round(parent_gini - weighted_gini, 4))
```

```text
0.3669 0.4811 0.0687
0.3006 0.0664
```

`counts.sum()`은 한 노드의 전체 개수. 각 클래스 개수를 이 값으로 나누면 비율이 되고, 제곱해 합한 뒤 1에서 빼면 지니 불순도임. 부모는 약 0.3669, 왼쪽은 0.4811, 오른쪽은 0.0687임.

왼쪽과 오른쪽의 수가 다르므로 `weighted_gini`는 각 불순도에 해당 샘플 수를 곱해 합친 뒤 부모 수 5,197로 나눔. 결과 약 0.3006이 분할 후 전체 혼합 정도이고 부모에서 빼면 정보 이득 약 0.0664임. 중간 반올림 여부에 따라 마지막 자릿수는 달라질 수 있음.

## 나누기만 하면 좋아질까?

```python
other_left = np.array([629, 1970])
other_right = np.array([629, 1969])
other_weighted = (other_left.sum() * gini(other_left)
                  + other_right.sum() * gini(other_right)) / parent_counts.sum()
print(round(parent_gini - other_weighted, 4))
```

```text
0.0
```

이 분할은 두 자식의 클래스 비율이 부모와 거의 같음. 샘플은 나뉘었지만 어느 집단도 한 종류가 더 잘 모인 상태가 되지 않아 정보 이득이 약 0임.

따라서 트리는 자식이 두 개 생겼다는 사실보다 클래스 혼합이 얼마나 줄었는지를 비교함. 실제 당도 분할에서는 오른쪽에 화이트가 집중되어 전체 가중평균이 감소했고, 위 비교에서는 그 변화가 거의 없었음.

## 엔트로피라는 다른 기준

클래스의 혼합을 측정하는 다른 기준으로 엔트로피가 있음.

$$
H=-p_0\log_2p_0-p_1\log_2p_1
$$

한 종류만 있으면 0이고, 두 종류가 반반이면 1임. 비율이 0인 항은 극한에 따라 0으로 처리함. 같은 조건의 지니 최대값 0.5와 숫자 범위가 다르므로 기준이 다른 수치를 그대로 비교하면 안 됨.

사이킷런은 기본 `criterion='gini'`를 사용하고 `criterion='entropy'`로 바꿀 수 있음. 두 기준 모두 부모와 자식의 혼합 감소로 분할을 평가함. 분할을 계속하면 작은 집단까지 세밀하게 구분할 수 있지만, 다음에는 이 복잡도를 제한할 필요를 배움.
