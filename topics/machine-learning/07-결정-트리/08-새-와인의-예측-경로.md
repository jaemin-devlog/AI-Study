# 8. 새 와인의 예측 경로

앞 파일의 `dt`는 원래 단위의 세 특성으로 학습한 깊이 3 모델. 여기에 알코올 10.0, 당도 3.0, pH 3.2인 새 와인을 넣음. 예측하는 동안 질문과 기준값은 고정되어 있고 입력에 따라 이동할 길만 달라짐.

## 예측과 클래스 순서 확인하기

```python
new_wine = pd.DataFrame({'alcohol': [10.0], 'sugar': [3.0], 'pH': [3.2]})
print(dt.predict(new_wine))
print(dt.classes_)
print(np.round(dt.predict_proba(new_wine), 4))
```

```text
[0.]
[0. 1.]
[[0.6994 0.3006]]
```

`classes_`는 레드 0과 화이트 1 순서. 첫 열의 0.6994가 높아 레드로 예측함. 이 확률이 어디서 나왔는지 확인하려면 와인이 통과한 질문과 마지막 리프의 분포를 알아야 함.

## 루트에서 리프까지 이동하기

```python
node_ids = dt.decision_path(new_wine).indices
feature_names = list(new_wine.columns)
for node_id in node_ids:
    feature_index = dt.tree_.feature[node_id]
    if feature_index < 0:
        print('리프', node_id)
        continue
    name = feature_names[feature_index]
    threshold = dt.tree_.threshold[node_id]
    value = new_wine.iloc[0, feature_index]
    direction = '왼쪽' if value <= threshold else '오른쪽'
    print(name, round(value, 3), round(threshold, 3), direction)
```

```text
sugar 3.0 4.325 왼쪽
sugar 3.0 1.625 오른쪽
alcohol 10.0 11.025 왼쪽
리프 6
```

`decision_path()`는 통과한 노드를 표시함. 한 샘플이므로 `.indices`로 그 노드 번호를 읽음. `tree_.feature`는 질문에 사용하는 특성의 위치, `tree_.threshold`는 기준값임. 특성 번호가 음수면 더 비교할 특성이 없는 리프임.

당도 3.0은 4.325 이하라 왼쪽, 다음 기준 1.625보다 크므로 오른쪽, 알코올 10.0은 11.025 이하라 왼쪽으로 가 리프 6에 도착함. 반복문의 `.iloc[0, feature_index]`는 새 와인 첫 행에서 현재 질문의 특성값을 가져옴.

## 같은 리프의 훈련 와인 세기

```python
leaf_id = dt.apply(new_wine)[0]
train_leaf_ids = dt.apply(train_input)
leaf_targets = train_target[train_leaf_ids == leaf_id]
counts = leaf_targets.value_counts().sort_index()
print(counts.to_numpy())
print(len(leaf_targets))
print(np.round(counts.to_numpy() / len(leaf_targets), 4))
```

```text
[798 343]
1141
[0.6994 0.3006]
```

`apply()`는 입력마다 최종 리프 번호를 반환함. 훈련 와인 중 새 와인과 같은 리프에 도착한 위치를 골라 그 정답만 모음. `value_counts()`로 종류별 개수를 세고 `sort_index()`로 클래스 번호순으로 정렬함.

결과는 레드 798개, 화이트 343개, 합계 1,141개. 전체로 나누면 레드 $798/1141\approx0.6994$, 화이트 $343/1141\approx0.3006$으로 모델의 출력과 일치함. 가중치를 사용하지 않은 현재 설정에서의 계산임.

리프는 같은 조건을 통과한 훈련 집단이지 새 와인의 실제 정답을 확인한 집단은 아님. 예측이 맞았는지는 새 와인의 정답을 알아야 평가할 수 있음.

## 입력의 당도만 변경하기

```python
sweeter_wine = new_wine.copy()
sweeter_wine['sugar'] = 6.0
print(dt.predict(sweeter_wine))
print(np.round(dt.predict_proba(sweeter_wine), 4))
print(dt.apply(sweeter_wine))
```

```text
[1.]
[[0.0517 0.9483]]
[10]
```

당도를 6.0으로 바꾸면 루트에서 오른쪽으로 이동함. 이후 당도 6.45 이하, pH 3.255 이하를 통과해 리프 10에 도착함. 이곳의 레드 17개와 화이트 312개 비율로 화이트 확률 약 0.9483이 계산됨.

입력을 바꾸니 예측 경로와 확률, 이름이 바뀌었음. `predict()`가 새 기준을 학습한 것은 아님. 학습은 질문을 만드는 과정이고 예측은 그 질문을 적용하는 과정임.
