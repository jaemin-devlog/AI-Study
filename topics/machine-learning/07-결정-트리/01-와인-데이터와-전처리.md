# 1. 와인 데이터와 전처리

이번에는 알코올 도수, 당도, pH로 와인의 종류를 구분함. 측정값과 실제 종류를 함께 사용하므로 지도학습이고, 레드와 화이트 중 하나를 선택하므로 이진 분류임.

| 열 | 역할 |
| --- | --- |
| alcohol | 입력: 알코올 도수 |
| sugar | 입력: 당도 |
| pH | 입력: pH 값 |
| class | 정답: 레드 0, 화이트 1 |

새 와인에서 측정할 수 있는 세 값을 입력으로 사용하고 아직 모르는 종류를 예측함. 정답 열까지 입력하면 답을 미리 주는 셈이므로 분리해야 함.

## 데이터의 상태부터 확인하기

```python
import numpy as np
import pandas as pd

wine = pd.read_csv('https://bit.ly/wine_csv_data')
print(wine.head())
wine.info()
print(wine.describe())
```

```text
   alcohol  sugar    pH  class
0      9.4    1.9  3.51    0.0
1      9.8    2.6  3.20    0.0
2      9.8    2.3  3.26    0.0
3      9.8    1.9  3.16    0.0
4      9.4    1.9  3.51    0.0
```

한 행은 와인 한 개. `head()`는 앞 다섯 행을 보여 주고 `info()`는 전체 행 수, 열의 자료형, 누락되지 않은 값의 수를 보여 줌. 전체는 6,497행과 4열이며 모든 열이 float64이고 각 열의 유효값이 6,497개라 결측값은 없음.

`describe()`는 숫자 열의 개수, 평균, 표준편차, 최솟값, 사분위수, 최댓값을 요약함. 평균은 중심, 표준편차는 평균 주변의 퍼짐을 보는 값. 50%는 중앙값이고 25%와 75%는 각각 제1, 제3사분위수임. 특성의 숫자 범위가 얼마나 다른지 확인할 수 있음.

값이 빠져 평균으로 채워야 한다면 그 평균도 훈련 데이터에서 구해야 함. 여기서는 누락값이 없으므로 이 처리는 하지 않음.

## 입력과 정답을 같은 순서로 나누기

```python
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

data = wine[['alcohol', 'sugar', 'pH']]
target = wine['class']
train_input, test_input, train_target, test_target = train_test_split(
    data, target, test_size=0.2, random_state=42
)
ss = StandardScaler()
ss.fit(train_input)
train_scaled = ss.transform(train_input)
test_scaled = ss.transform(test_input)
print(train_input.shape, test_input.shape)
```

```text
(5197, 3) (1300, 3)
```

세 입력 열을 선택한 `data`는 2차원 표이고 `target`은 종류가 들어 있는 한 열임. `train_test_split()`에 함께 전달해 같은 와인의 측정값과 정답이 어긋나지 않게 나눔. 20%인 1,300개를 테스트에 남기고 5,197개로 학습함.

먼저 로지스틱 회귀와 비교할 것이므로 표준화함. `ss.fit(train_input)`은 훈련 데이터에서 각 특성의 평균과 표준편차를 구하고, 같은 기준으로 훈련과 테스트를 변환함. 테스트에서 별도로 기준을 학습하지 않음.

이제 `train_scaled`는 표준화된 훈련 입력, `train_target`은 그 와인들의 실제 종류임. 다음 파일에서 이 둘로 로지스틱 회귀와 결정 트리를 학습함.
