# 2. 로지스틱 회귀와 결정 트리

같은 와인 데이터를 서로 다른 분류 모델로 표현해 봄. 로지스틱 회귀는 세 입력을 하나의 선형 점수로 합친 뒤 확률로 바꿈. 결정 트리는 한 특성의 값이 기준 이하인지 묻는 질문을 여러 번 적용함.

## 로지스틱 회귀의 결과 읽기

```python
from sklearn.linear_model import LogisticRegression

lr = LogisticRegression()
lr.fit(train_scaled, train_target)
print(round(lr.score(train_scaled, train_target), 4),
      round(lr.score(test_scaled, test_target), 4))
print(np.round(lr.coef_, 4), np.round(lr.intercept_, 4))
```

```text
0.7808 0.7777
[[ 0.5127  1.6734 -0.6878]] [1.8177]
```

앞 파일의 표준화된 입력을 사용함. 계수는 알코올, 당도, pH 순서이므로 점수 식은 다음과 같음.

$$
z\approx0.5127x_{\mathrm{alcohol}}+1.6734x_{\mathrm{sugar}}-0.6878x_{\mathrm{pH}}+1.8177
$$

표준화된 입력을 넣고 시그모이드로 변환하면 양성인 화이트 확률이 나옴. 다른 특성을 고정했을 때 당도가 증가하면 점수가 커지고 pH가 증가하면 작아지는 방향임. 실제 입력에서는 세 항이 함께 더해지므로 한 계수만으로 최종 결과를 판단하지 않음.

훈련 약 0.7808, 테스트 약 0.7777로 차이는 작음. 그렇다고 충분한 모델이라는 뜻은 아님. 두 데이터에서 맞힌 비율이 어느 수준인지와 다른 모델이 관계를 더 잘 표현하는지도 봐야 함.

## 조건을 따라 분류하는 결정 트리

![질문을 따라 분류](../assets/pdf/결정-트리-질문-예시.png)

그림처럼 한 질문으로 데이터를 나누고 나뉜 집단에서 다시 질문함. 당도가 특정 값 이하인지 확인하고, 이후 다른 기준이나 특성을 비교하는 식임. 그림의 당도 2는 개념 설명용이며 아래 모델이 실제로 학습한 첫 기준과 구분함.

트리가 학습하는 것은 질문에 사용할 특성과 기준값. 훈련 정답을 보고 클래스가 더 잘 구분되는 분할을 선택함. 예측할 때는 이미 학습한 질문을 따라가고 마지막 집단의 클래스 분포로 종류와 확률을 정함.

```python
from sklearn.tree import DecisionTreeClassifier

dt_full = DecisionTreeClassifier(random_state=42)
dt_full.fit(train_scaled, train_target)
print(round(dt_full.score(train_scaled, train_target), 4),
      round(dt_full.score(test_scaled, test_target), 4))
```

```text
0.9969 0.8592
```

깊이 제한 없는 트리는 훈련 약 0.9969, 테스트 약 0.8592임. 테스트는 로지스틱 회귀보다 높아졌지만 훈련과의 차이도 커졌음. 훈련 사례에 지나치게 맞춘 과대적합 가능성을 살펴봐야 함.

질문으로 설명할 수 있다는 것과 새로운 와인을 정확하게 맞힌다는 것은 따로 평가함. 다음 파일에서는 실제 트리 그림에서 질문과 클래스 분포를 읽음.
