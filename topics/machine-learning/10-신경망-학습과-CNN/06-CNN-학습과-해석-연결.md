# CNN 학습과 해석 연결


초기화, 학습, 모델 선택, 해석은 서로 다른 질문에 답함. 필터 그림 하나만으로 모델이 일반화하는지 판단할 수 없고, 정확도 하나만으로 내부의 계산도 설명할 수 없음.

## 입력에서 예측까지

이미지에서 합성곱이 위치별 반응을 만들고 ReLU와 풀링을 지나며 채널별 특징이 남음. 분류층은 이를 클래스별 점수로 바꿈.

## 예측에서 학습까지

손실과 역전파로 필터를 포함한 모든 학습 대상의 기울기를 구함. 초기화는 시작 상태를, 옵티마이저는 갱신 방법을 정함. 검증 손실로 학습 시점을 선택한 뒤 별도 테스트로 평가함.

## 해석까지 연결하기

필터는 학습한 규칙, 특성 맵은 한 입력에 대한 반응, 로짓은 분류층의 점수임. 어떤 그림을 보고 있는지 먼저 구분하고, 같은 이미지의 여러 채널과 같은 채널의 다른 이미지를 비교해야 해석의 근거가 생김.

## 앵클부츠 한 장이 분류되는 과정

| 시점 | 확인할 값 | 읽는 방법 |
| --- | --- | --- |
| 입력 | 채널, 높이, 너비 | 회색조 픽셀 한 장 |
| 합성곱과 활성화 | 채널별 특성 맵 | 필터별로 반응한 위치와 크기 |
| 풀링과 Flatten | 줄어든 공간 크기와 펼친 길이 | 다음 Linear가 받을 특성 수 |
| 출력층 | 클래스별 로짓 | 가장 높은 점수의 열이 예측 클래스 |
| 학습 | 손실과 기울기 | 정답과 비교한 뒤 필터까지 거꾸로 미분 |
| 평가 | 검증 손실과 테스트 정확도 | 모델을 고르는 기준과 선택 후 평가 결과 |

정확도가 같은 두 모델도 서로 다른 샘플을 틀릴 수 있음. 성능을 묻는 경우에는 학습에 사용하지 않은 이미지의 예측과 정답을 비교함. 모델 내부를 묻는 경우에는 입력과 관찰할 층을 정하고 필터 또는 특성 맵을 확인함. 이 두 관찰을 연결하려면 어느 이미지에서 어느 클래스의 점수가 어떻게 달라졌는지도 함께 봐야 함.
