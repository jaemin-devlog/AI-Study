# 학습 안정화와 일반화


훈련 손실이 낮아졌다고 처음 보는 이미지에서도 잘 분류하는 것은 아님. 학습 과정 자체를 안정시키는 방법과 과대적합을 줄이는 방법을 구분함.

## BatchNorm

훈련 중 미니배치의 평균과 분산으로 중간 활성값을 정규화한 뒤 학습 가능한 크기와 이동량을 적용함. 평가할 때는 보통 훈련 중 누적한 통계를 사용함. 같은 이미지의 예측이 현재 평가 배치 구성에 좌우되지 않도록 모델 모드를 바꿔야 함.

## Weight Decay와 Dropout

Weight Decay는 가중치가 지나치게 커지는 것을 억제함. Dropout은 훈련 중 일부 활성값을 무작위로 꺼서 특정 뉴런 조합에만 의존하기 어렵게 함. 평가할 때에는 Dropout을 끄므로 model.eval()을 사용함.

## 검증 손실로 시점 선택

훈련 손실은 계속 낮아져도 검증 손실이 상승하면 추가 학습이 일반화에 도움이 되지 않을 수 있음. 검증 손실이 가장 낮은 시점의 가중치를 따로 저장함. 마지막 에포크가 최적이라는 보장은 없으며 테스트 세트는 선택 후 평가에 사용함.

## 배치 정규화에서 학습하는 값

특성 하나의 배치 평균이 4이고 표준편차가 2일 때 값 6은 평균보다 표준편차 하나만큼 큼. BatchNorm은 이렇게 중심과 스케일을 조정한 뒤 학습 가능한 계수와 편향을 적용함. 실제 계산은 분모에 작은 상수를 더해 분산이 0 부근에서도 안정적으로 동작하게 함. 전처리에서 훈련 데이터를 한 번 표준화하는 것과 달리, 신경망 내부의 출력은 가중치가 학습될 때마다 달라짐.

| 설정 | 훈련 중 | 검증과 예측 중 |
| --- | --- | --- |
| BatchNorm 기본 동작 | 현재 배치 통계로 정규화하고 통계를 누적 | 누적 통계로 정규화 |
| Dropout | 선택한 일부 활성값을 0으로 만듦 | 모든 활성값을 사용 |
| 기울기 기록 | backward에 필요한 중간값 저장 | 평가에서는 no_grad로 생략 가능 |

## 어떤 에포크의 모델을 저장할까?

검증 손실이 0.40, 0.33, 0.35 순서라면 세 번째 에포크에서 훈련 손실이 더 낮아도 검증 손실 기준으로는 두 번째 모델을 선택함. 매번 최솟값이 바뀔 때 그 시점의 가중치를 별도로 복사하거나 파일로 저장해야 함. 현재 모델을 가리키는 참조만 보관하면 다음 갱신에 따라 값이 바뀔 수 있음. 조기 종료는 개선이 일정 기간 없을 때 학습을 중단하는 규칙이고, 최적 가중치 저장은 선택한 상태를 보존하는 작업임.

## 조기 종료 기록 읽기

실습에서는 8번째 에포크의 검증 손실이 가장 낮았고 이후 두 번 개선되지 않아 10번째에서 중단했음. 최종 평가는 저장한 8번째 상태를 복원해서 수행함. 이 모델의 검증 정확도 0.8798은 검증 이미지 중 약 87.98%를 맞혔다는 뜻임. 모델을 저장하는 기준은 검증 손실이고, 저장한 모델을 설명할 때 보고한 값은 정확도임.
