# 합성곱과 풀링


이미지를 펼치면 픽셀값은 남지만 가까운 픽셀을 같은 규칙으로 처리한다는 구조는 모델에 주어지지 않음. CNN은 작은 필터를 여러 위치로 옮겨 같은 패턴에 반응하도록 학습함.

## 한 위치에서 한 값 계산

필터가 덮은 영역과 필터의 같은 위치 값을 곱해 모두 더하고 편향을 더함. 이를 여러 위치에서 반복한 결과가 특성 맵임. 다채널 입력에서는 모든 입력 채널의 기여를 합쳐 필터 하나당 출력 채널 하나를 만듦.

## 출력 크기

입력 한 변 N, 커널 K, 패딩 P, 스트라이드 S일 때 일반적인 합성곱의 출력 길이는 $\lfloor(N+2P-K)/S\rfloor+1$임. 28칸에 3칸 필터를 한 칸씩 움직이면 26개 위치가 나옴. 양끝에 한 칸씩 패딩을 두면 28개가 됨.

## 풀링이 줄이는 것

2×2 최대 풀링을 두 칸씩 이동하면 영역에서 최댓값만 남아 28×28이 14×14로 줄어듦. 채널 수는 그대로임. 위치 정보를 일부 잃지만 작은 위치 변화에도 특징을 유지하기 쉬워짐.

## 한 칸의 특성 맵을 손으로 계산하기

입력 영역이 [[1, 2], [3, 4]], 필터가 [[1, 0], [0, −1]], 편향이 0이면 결과는 $1×1+2×0+3×0+4×(-1)=-3$임. 다음 위치에서도 같은 네 가중치를 사용함. 위치마다 독립된 가중치를 두는 완전연결층과 달리, 같은 대비를 다른 위치에서도 감지할 수 있음.

## 필터의 개수와 채널의 관계

RGB 입력은 한 위치에 값이 세 개 있음. 3×3 필터 하나가 보는 값은 9개가 아니라 3×3×3=27개임. 채널별 곱셈 결과를 합해 출력값 하나를 만듦. 이 필터가 네 개면 출력 채널도 네 개임.

| 단계 | 샘플 한 장의 형태 | 계산 근거 |
| --- | --- | --- |
| 입력 | (3, 8, 8) | RGB 세 채널 |
| 3×3 합성곱, 패딩 1, 필터 4개 | (4, 8, 8) | 가장자리까지 한 칸씩 이동 |
| 2×2 풀링, 스트라이드 2 | (4, 4, 4) | 채널마다 공간 크기를 절반으로 줄임 |

패딩은 가장자리 밖을 어떤 값으로 채울지, 스트라이드는 필터를 몇 칸씩 옮길지 정함. 최대 풀링에는 새로 학습할 필터 가중치가 없음. 한 영역에서 가장 강한 반응만 남기기 때문에 풀링 전 어느 칸이 최대였는지는 출력값만으로 알기 어려움.
