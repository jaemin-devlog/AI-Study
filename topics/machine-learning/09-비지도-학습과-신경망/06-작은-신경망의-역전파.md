# 작은 신경망의 역전파


입력 x=2, 가중치 w=1, 편향 b=1, 정답 t=5를 사용함. 바꿀 수 있는 값은 입력과 정답이 아니라 w와 b임.

## 순전파

$z=2\times1+1=3$이고 ReLU는 양수 3을 그대로 통과시킴. 예측은 3이고 손실은 $L=(3-5)^2/2=2$. 이 2는 틀린 정도이지 수정할 방향이 아님.

## 역전파

예측값에 대한 기울기는 $3-5=-2$. ReLU 입력이 양수이므로 국소 미분은 1이고 기울기는 그대로 -2임. 편향은 덧셈을 거치므로 $\partial L/\partial b=-2$. 가중치는 입력 2와 곱해졌으므로 $\partial L/\partial w=-2\times2=-4$. 여기까지 가중치는 아직 1임.

## 갱신 후 검산

학습률 0.1에서 새 가중치는 $1-0.1(-4)=1.4$, 편향은 $1-0.1(-2)=1.2$. 다음 순전파의 예측은 4, 손실은 0.5로 줄어듦. 다음 갱신에는 이 새로운 위치에서 다시 계산한 기울기를 사용함.

```python
x, w, b, t = 2, 1, 1, 5
z = x*w+b
y = max(0,z)
dz = (y-t)*(z>0)
print(y, (y-t)**2/2, dz*x, dz)
```

```text
3 2.0 -4 -2
```

출력 순서는 예측, 손실, 가중치 기울기, 편향 기울기임.

| 단계 | 가중치 | 편향 | 예측 | 손실 |
| --- | ---: | ---: | ---: | ---: |
| 갱신 전 | 1 | 1 | 3 | 2 |
| 갱신 후 | 1.4 | 1.2 | 4 | 0.5 |

## 손실값 2에서 왜 기울기 1로 시작할까?

역전파가 구하는 것은 언제나 최종 손실 L에 대한 변화율임. 출발점에서 묻는 질문은 “L이 조금 달라지면 L 자체는 얼마나 달라질까?”임. 변화량이 같으므로 $\partial L/\partial L=1$. 손실값이 2여도 시작 기울기는 1임.

| 거꾸로 지나는 연산 | 전달받은 값 | 국소 미분 | 앞쪽에 전달하는 값 |
| --- | ---: | ---: | ---: |
| 제곱오차의 ½ 곱셈 | 1 | 0.5 | 0.5 |
| 오차 제곱 | 0.5 | 2 × (−2) | −2 |
| 예측에서 정답 빼기 | −2 | 1 | −2 |
| ReLU | −2 | 1 | −2 |
| 편향 더하기 | −2 | 1 | 편향에 −2 |
| 입력과 가중치 곱하기 | −2 | 입력 2 | 가중치에 −4 |

편향을 고정하고 가중치를 0.9와 1.1로 바꾸면 손실은 각각 2.42와 1.62임. 중앙 차분 $(1.62-2.42)/0.2=-4$가 역전파 결과와 맞음. 이 계산은 기울기를 검산하는 과정임. 실제 갱신에 쓸 학습률은 별도로 정함.
