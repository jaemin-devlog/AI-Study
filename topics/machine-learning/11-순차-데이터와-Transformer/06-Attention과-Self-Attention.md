# Attention과 Self-Attention

> Day 5 이론 4, 1~3절 (1~12쪽)

## 마지막 요약 상태의 한계

초기 RNN 기반 인코더-디코더는 인코더가 입력 문장을 읽고 마지막 은닉 상태에 담은 정보를 디코더로 전달함. 앞의 입력이 영향을 주지만 모든 원문과 모든 은닉 상태를 그대로 모아 놓은 것은 아님. 문장이 길면 필요한 정보를 충분히 전달하기 어려울 수 있음.

Attention은 디코더가 각 단어를 만들 때 인코더의 여러 시점 출력을 다시 참고하게 함. “나는 너를 사랑해”를 번역할 때 I를 만들 때와 love를 만들 때 참고할 정보의 비중이 달라질 수 있음.

## Attention의 계산 흐름

관련도 점수 계산 → Softmax로 가중치 변환 → 입력 표현의 가중합 → 현재 예측에 활용하는 순서임. 가장 높은 단어 하나만 선택하는 것이 아니라 여러 정보를 비율에 따라 섞음. RNN에 Attention을 붙여도 RNN의 순차 계산 자체는 남아 있음.

## Self-Attention은 같은 시퀀스 안에서 계산

“나는 / 너를 / 사랑해”의 각 토큰이 같은 문장 안의 토큰들을 참고해 자신의 표현을 새로 만듦. 자신도 참고 대상에 포함될 수 있음. 하나의 문장 요약만 만드는 것이 아니라 토큰마다 새로운 표현을 만듦.

| 벡터 | 역할 |
| --- | --- |
| Query | 현재 토큰이 어떤 정보를 참고할지 비교하는 기준 |
| Key | Query와 비교할 대상의 표현 |
| Value | 실제로 가중합하여 가져올 정보 |

Q·K·V는 입력 벡터에 서로 다른 학습 가능한 행렬을 적용해 만듦. 사람이 문법에 맞춰 질문과 답을 직접 작성하는 것은 아님.

## 점수에서 가중치로

Scaled Dot-Product Attention은 Q와 K의 내적을 구한 뒤 Key 차원의 제곱근으로 나눔. 차원이 커질 때 점수가 너무 커져 Softmax가 지나치게 한쪽에 몰리는 것을 완화하는 역할임.

$$Attention(Q,K,V)=softmax(QK^T/\sqrt{d_k})V$$

Softmax는 각 Query의 행별로 적용함. 정규화 직후 각 행의 가중치 합은 1이고, 열의 합까지 1일 필요는 없음. 아래는 PDF의 계산 설명용 가상 가중치임.

| Query / Key | 나는 | 너를 | 사랑해 |
| --- | ---: | ---: | ---: |
| 나는 | 0.5 | 0.2 | 0.3 |
| 너를 | 0.2 | 0.5 | 0.3 |
| 사랑해 | 0.2 | 0.5 | 0.3 |

마지막 행은 `0.2 × V(나는) + 0.5 × V(너를) + 0.3 × V(사랑해)`로 사랑해의 새로운 표현을 만든다는 의미임. Attention 가중치는 입력과 위치에 따라 계산되는 값이며, 학습 중 수정하는 Q·K·V 변환 행렬과 구분함.

## 긴 문장은 비용이 커짐

일반적인 전체 Self-Attention은 길이가 T이면 토큰 쌍 T×T의 점수를 계산함. 길이가 두 배이면 점수 개수가 네 배가 됨. 병렬 처리가 가능하더라도 긴 문장을 무제한으로 빠르게 처리하는 것은 아님. 이는 RNN의 순차 계산과 다른 종류의 계산 부담임.
