# Transformer 인코더와 디코더

> Day 5 이론 4, 4~7절 (12~27쪽)

## 여러 관점으로 정보를 결합하기

Multi-Head Attention은 서로 다른 Q·K·V 변환으로 Attention을 여러 번 병렬 계산하고, 결과를 연결한 뒤 선형 변환함. 다양한 관계를 표현할 여지를 주지만 “1번 Head는 주어 담당”처럼 역할이 미리 고정되어 있지는 않음.

## 인코더를 구성하는 요소

| 요소 | 역할 |
| --- | --- |
| Token Embedding | ID를 벡터로 변환 |
| 위치 정보 | 토큰이 등장한 위치를 표현에 반영 |
| Self-Attention | 다른 토큰의 정보를 결합 |
| 잔차 연결 | 입력을 변환 결과에 더해 정보와 기울기 전달 지원 |
| LayerNorm | 각 토큰의 특성 차원에서 값을 정규화 |
| FFN | 각 위치에 같은 신경망을 적용해 비선형 변환 |

순환 계산이 없으므로 순서를 알려 주는 위치 정보가 필요함. 위치 정보를 더하면 토큰의 의미 표현에 위치에 따른 차이가 들어감. FFN은 각 토큰을 개별적으로 변환하고, 토큰 사이 정보를 직접 섞는 역할은 Attention이 담당함.

원본 Transformer 인코더 블록의 흐름은 다음과 같음. 모델에 따라 정규화 위치는 다를 수 있음.

```text
토큰 임베딩 + 위치 정보
  → Multi-Head Self-Attention → 잔차 연결 + LayerNorm
  → FFN                     → 잔차 연결 + LayerNorm
  → 다음 인코더 블록 또는 인코더 출력
```

토큰이 100개라면 인코더는 일반적으로 100개 위치 각각의 문맥 벡터를 출력함. 마지막 토큰 벡터 하나로 모든 정보를 압축해 전달할 필요가 없음.

## 디코더의 두 Attention

Masked Self-Attention은 출력 시퀀스 안에서 현재 위치가 미래 정답 토큰을 참고하지 못하게 함. 예를 들어 “나는 오늘” 다음 단어를 예측할 때 뒤에 적힌 정답을 보면 학습 목적이 깨짐. 미래 위치의 점수를 Softmax 전에 가려 그 위치의 가중치가 0이 되게 함.

Cross-Attention은 디코더의 Query로 인코더 출력에서 만든 Key와 Value를 참고함. 같은 시퀀스 안에서 Q·K·V를 만드는 Self-Attention과 입력 출처가 다름.

```text
이전 출력 토큰 + 위치 정보
  → Masked Self-Attention
  → Cross-Attention으로 인코더 출력 참고
  → FFN
  → 어휘별 점수 → 다음 토큰 선택
```

각 주요 하위 연산에는 잔차 연결과 정규화가 함께 사용됨. 선택한 토큰을 다음 입력에 추가하며 종료 토큰이나 길이 조건까지 생성을 반복함.

## 병렬 학습과 순차 생성의 차이

정답 시퀀스가 주어진 학습에서는 마스크를 적용해 여러 위치의 계산을 병렬화할 수 있음. 실제 자동회귀 생성에서는 다음 토큰이 직전 생성 결과에 의존하므로 보통 토큰을 하나씩 생성함. Transformer라고 모든 생성 단계가 한 번에 끝나는 것은 아님.
