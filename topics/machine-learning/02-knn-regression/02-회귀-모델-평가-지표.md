# 회귀 모델 평가

본문 코드는 개념별 부분 코드. 데이터 준비부터 독립 실행할 때는 [전체 실습](05-최근접-이웃-회귀-예제.md)을 사용.


## 회귀에서 평가 지표가 필요한 이유

분류는 예측한 종류가 정답과 같은지 세지만, 회귀는 99g과 100g처럼 실제값에 얼마나 가까운지가 중요하다. R²는 평균으로 예측하는 기준과 제곱오차를 비교하고, MAE는 오차의 평균 크기를 타깃과 같은 단위로 보여 준다. 두 지표를 함께 보면 상대적인 성능과 실제 오차 크기를 확인할 수 있다.

## 결정계수 R²

$$
R^2 = 1 - \frac{\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}{\sum_{i=1}^{n}(y_i - \bar{y})^2}
$$

- $n$: 평가 샘플 수, $y_i$: 실제 값, $\hat{y}_i$: 예측값, $\bar{y}$: 평가 데이터의 실제 값 평균

- 평가 데이터의 모든 값을 타깃 평균으로 예측했을 때와 비교한다.
- R² = 1: 예측이 모두 실제 값과 일치
- R² = 0: 평균으로만 예측했을 때와 제곱오차가 같음
- R² < 0: 평균으로만 예측했을 때보다 제곱오차가 큼
- R²가 0.99라고 해서 예측이 99% 정확하거나 오차가 1%라는 뜻은 아니다.

### R² 직접 계산하기

| 농어 | 실제 무게 | 평균으로 예측 | 모델 예측 |
| --- | --- | --- | --- |
| 1 | 100g | 200g | 110g |
| 2 | 200g | 200g | 190g |
| 3 | 300g | 200g | 290g |

실제 무게의 평균은 200g이다. 평균으로만 예측한 제곱오차 합은 20,000이고, 모델 예측의 제곱오차 합은 300이다.

$$
R^2 = 1 - \frac{300}{20000} = 0.985
$$

이 예시의 모델은 평균값만으로 예측하는 기준보다 제곱오차가 98.5% 작다. R²는 각 예측이 실제값의 98.5%와 같다는 뜻이 아니다. 평가 데이터의 실제 값이 모두 같으면 분모가 0이어서 위 식으로는 R²를 계산할 수 없다.

## 평균 절댓값 오차 MAE

```python
from sklearn.metrics import mean_absolute_error

prediction = knr.predict(test_input)
mae = mean_absolute_error(test_target, prediction)
print(mae)  # 약 19.16g
```

$$
\mathrm{MAE} = \frac{1}{n}\sum_{i=1}^{n}\left|y_i - \hat{y}_i\right|
$$
- 실습에서 MAE는 약 19.16g이다. 테스트 농어 14마리의 실제 무게와 예측 무게가 평균적으로 약 19g 차이 났다는 뜻이다.
- 모든 농어의 오차가 19g 이내라는 뜻은 아니다. MAE는 타깃과 같은 단위라 실제 차이를 이해하기 쉽다.

### MAE를 숫자로 계산하기

실제 무게가 100, 200, 300g이고 모델 예측이 110, 190, 290g이면 오차의 절댓값은 각각 10g이다.

$$
\mathrm{MAE} = \frac{|100-110| + |200-190| + |300-290|}{3} = 10\,\mathrm{g}
$$

실제보다 크게 예측했는지 작게 예측했는지는 절댓값을 구할 때 사라진다. 이 계산 예시에서는 세 마리의 오차가 모두 10g이다. 일반적으로 평균 10g만 주어졌다면 각 오차가 10g이라는 뜻은 아니다. 예를 들어 0g, 10g, 20g도 평균은 10g이다.

## 잔차 확인

이 실습에서 잔차는 실제 값에서 예측값을 뺀 값이다.

$$
e_i = y_i - \hat{y}_i
$$

- 잔차가 양수면 실제보다 낮게, 음수면 실제보다 높게 예측했다.
- R²와 MAE는 전체 성능을 요약하고, 잔차 그래프는 특정 입력 구간에서 오차가 반복되는지 살펴보는 데 도움을 준다.
- 테스트 샘플이 적으면 그래프의 모양만으로 모든 구간의 성능을 단정할 수 없다.
