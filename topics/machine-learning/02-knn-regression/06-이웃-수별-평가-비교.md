# 6. 이웃 수별 평가 비교

학습 범위: 21에서 23쪽

## 같은 분할에서 k만 변경

```python
for k in [1, 3, 5, 10, 20, 42]:
    model = KNeighborsRegressor(n_neighbors=k)
    model.fit(train_input, train_target)
    mae = mean_absolute_error(test_target, model.predict(test_input))
    print(k, round(model.score(train_input, train_target), 4),
          round(model.score(test_input, test_target), 4), round(mae, 2))
```

```text
1 0.9853 0.9913 22.69
3 0.9805 0.9746 35.42
5 0.9699 0.9928 19.16
10 0.9616 0.9738 39.24
20 0.8613 0.8785 76.44
42 0.0 -0.0551 291.16
```

출력 순서는 k, 훈련 R², 테스트 R², 테스트 MAE(g). 각 후보를 같은 데이터로 비교해야 k를 바꾼 영향을 읽기 쉬움.

## k=1도 훈련 점수가 1이 아닐 수 있음

같은 길이인데 실제 무게가 다른 농어가 존재함. 길이만 입력하므로 거리가 0인 동률 샘플을 구분할 수 없어 다른 농어의 무게를 선택할 수 있음. 동률 처리에 따라 일부 수치도 달라질 수 있음.

## k=42는 훈련 평균을 반환

훈련 농어 전체를 이웃으로 선택하면 모든 입력의 예측값이 훈련 무게 평균이 됨. 훈련 R²는 0이지만 테스트 평균은 훈련 평균과 다르기 때문에 테스트 R²는 음수가 될 수 있음.

이번 후보 중 k=5는 테스트 R²가 가장 높고 MAE가 가장 낮음. 모든 데이터에서 5가 최적이라는 뜻은 아니며 설정 선택에는 검증 데이터나 교차 검증을 사용하고 테스트는 최종 평가에 남겨야 함.
