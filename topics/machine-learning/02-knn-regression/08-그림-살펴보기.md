# 최근접 이웃 회귀 그림 살펴보기

### 농어의 길이와 무게

![농어 측정값](../assets/pdf/농어-측정값.png)

가로축은 농어 길이(cm), 세로축은 무게(g). 점 하나가 농어 한 마리이며 길이가 길수록 무게도 늘어나는 경향이 있음. 길이와 무게 관계가 직선보다 휘어진 형태에 가까운지도 살펴볼 수 있음.

길이가 약 20cm인 농어들은 주로 낮은 무게 영역에 있고, 40cm 부근의 농어들은 수백 g에서 1,000g 안팎에 있음. 길이가 늘어날수록 무게가 늘어나는 폭도 커지는 모습을 볼 수 있음.

이 그림에서 길이는 모델의 입력, 무게는 모델이 맞혀야 할 정답임. 새로운 길이를 입력했을 때 무게처럼 연속적인 숫자를 예측하므로 분류가 아니라 회귀 문제에 해당함.

### 농어 데이터 분포

![농어 분포](../assets/농어-분포.png)

같은 농어 데이터를 산점도로 나타낸 그림. 가까운 길이를 가진 농어의 무게를 이용해 새로운 농어의 무게를 예측하는 것이 최근접 이웃 회귀의 출발점임. 같은 길이 근처에서도 무게가 조금씩 다름.

점들이 정확히 한 선 위에 놓이지 않는 이유는 비슷한 길이의 농어라도 높이, 두께 등 다른 조건이 달라 무게가 다를 수 있기 때문임. 길이 하나만 사용하면 이런 차이를 모두 반영하기 어려움.

최근접 이웃 회귀에서는 길이가 비슷한 농어를 k마리 찾고, 그 농어들의 무게를 평균해 예측함. 예를 들어 이웃 세 마리의 무게가 300g, 350g, 400g이라면 예측값은 350g임.

### 이웃 수 1, 5, 20에 따른 예측

![이웃 수별 예측](../assets/pdf/이웃-수별-예측.png)

파란 점은 훈련 농어, 선은 길이별 예측 무게. k=1은 가장 가까운 한 마리만 따라가서 예측선이 자주 변함. k=20은 여러 농어의 평균을 사용해 선이 완만해지고 큰 농어의 무게를 충분히 따라가지 못함.

세 그림의 점은 같은 훈련 데이터이고, 바뀐 것은 예측에 사용하는 이웃의 수 k임. 가로축은 길이, 세로축은 무게이므로 선의 높이를 통해 해당 길이에서 모델이 예측한 무게를 읽을 수 있음.

k=1은 가까운 한 점의 무게를 그대로 사용하므로 훈련 데이터의 작은 변화에도 민감함. k=5는 주변 다섯 점을 평균해 변동이 줄어들고, k=20은 더 넓은 범위를 평균해 가장 큰 농어의 무게를 낮게 예측하는 모습이 보임.

### 이웃 수에 따른 회귀선

![이웃 수별 회귀](../assets/이웃-수별-회귀.png)

위와 같은 비교를 주황색 예측선으로 나타낸 그림. 선이 계단처럼 보이는 이유는 가까운 이웃의 구성이 그대로인 구간에서는 무게의 평균도 같기 때문임. k가 커질수록 한 샘플의 영향은 줄어듦.

예측할 길이가 조금 변해도 선택된 이웃의 목록이 바뀌지 않으면 평균 무게도 변하지 않음. 그래서 주황색 선이 일정한 높이를 유지하다가 이웃이 바뀌는 지점에서 계단처럼 올라감.

예를 들어 k=1에서는 한 마리만 바뀌어도 예측값이 그 농어의 무게로 바뀜. k=20에서는 한 마리의 변화가 전체 평균에 미치는 영향이 작아지지만 주변 관계를 지나치게 뭉뚱그릴 수 있음.

### 이웃 수 3, 5, 10 비교

![이웃 수 비교](../assets/이웃-수-비교.png)

같은 농어 데이터에서 k만 3, 5, 10으로 바꿈. 이웃 수가 적을 때는 주변 점의 변화에 더 민감하고, 많을 때는 더 넓은 범위의 무게를 평균함. 어떤 k가 좋은지는 그래프뿐 아니라 훈련과 테스트 점수도 함께 확인해야 함.

왼쪽에서 오른쪽으로 갈수록 평균에 사용하는 이웃이 많아짐. 그래프를 비교할 때는 같은 길이에서 주황 선의 높이가 어떻게 바뀌는지, 특히 데이터가 드문 양쪽 끝에서 점들과 얼마나 차이가 나는지 살펴보면 됨.

k가 작으면 가까운 일부 샘플에 지나치게 맞춰질 수 있고, 너무 크면 멀리 있는 샘플까지 평균해서 중요한 변화를 놓칠 수 있음. 적절한 k는 검증 데이터를 이용해 비교하고 테스트 데이터는 최종 평가에 사용함.

### 모델 복잡도와 과대적합

![모델 복잡도](../assets/모델-복잡도.png)

점은 예시 데이터, 선은 각각 1차, 4차, 15차 모델의 예측. 1차는 곡선 형태의 흐름을 충분히 표현하지 못하고, 15차는 점 주변에서 크게 흔들림. 지나치게 단순하거나 복잡한 모델의 모습을 비교한 개념 그림이며, 선의 모양만으로 테스트 성능을 확정할 수는 없음.

세 그래프는 농어 데이터가 아닌 예시 데이터로 모델의 복잡도를 비교함. 가로축은 입력, 세로축은 정답이며, 세 그림 모두 같은 점들을 사용함.

1차 모델은 거의 직선이라 가운데가 낮고 양쪽이 높은 흐름을 잘 담지 못함. 4차는 전체적인 곡선 흐름을 따라가고, 15차는 특히 양 끝에서 굴곡이 커짐. 복잡도가 너무 낮으면 과소적합, 훈련 점에 지나치게 맞으면 과대적합이 생길 수 있으므로 새로운 데이터에서의 점수로 확인해야 함.
