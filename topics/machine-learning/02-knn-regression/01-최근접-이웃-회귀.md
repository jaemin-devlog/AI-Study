# k-최근접 이웃 회귀

본문 코드는 개념별 부분 코드. 데이터 준비부터 독립 실행할 때는 [전체 실습](05-최근접-이웃-회귀-예제.md)을 사용.


## 분류와 회귀

| 구분 | 예측하는 것 | 농어와 생선 예시 |
| --- | --- | --- |
| 분류 | 범주 | 도미인지 빙어인지 |
| 회귀 | 연속적인 수치 | 길이를 바탕으로 농어의 무게 예측 |

- 생선 종류를 나타내는 1과 0은 이름표이므로 분류다. 농어의 실제 무게는 수치 자체가 타깃이므로 회귀다.
- KNN 분류는 가까운 이웃의 종류를 다수결하고, 기본 KNN 회귀는 가까운 이웃의 타깃값을 평균 낸다.
이웃의 무게가 각각 $100\,\mathrm{g}$, $80\,\mathrm{g}$, $60\,\mathrm{g}$이면 예측값은 다음과 같다.

$$
\hat{y} = \frac{100 + 80 + 60}{3} = 80\,\mathrm{g}
$$
- 새 농어의 무게는 아직 모른다. 길이로 가까운 이웃을 찾은 뒤 이웃들의 실제 무게로 예측한다.

## KNN 회귀의 예측 원리

회귀는 종류가 아닌 연속적인 수치를 예측한다. 길이가 비슷한 농어의 실제 무게가 비슷할 수 있다는 점을 이용해 새로운 농어의 무게를 추정한다.

새 길이 $x$에 가장 가까운 훈련 샘플의 인덱스 집합을 $N_k(x)$, 이웃의 무게를 $y_i$라고 하면 기본 예측값은 다음과 같다.

$$
\hat{y}(x) = \frac{1}{k}\sum_{i\in N_k(x)} y_i
$$

이웃은 입력 특성인 길이로 찾고, 평균은 이웃의 정답인 무게로 계산한다. `n_neighbors`는 이웃 수 k를 정하는 하이퍼파라미터다. `weights`를 바꾸면 같은 비중의 평균이 아닌 거리 가중 방식도 사용할 수 있다.

## 데이터 준비와 모델 학습

- 농어 56마리의 길이와 무게를 입력과 타깃으로 사용한다. 같은 위치의 길이와 무게는 같은 농어의 값이다.
- 실습은 `perch_length`, `perch_weight` 배열이 준비되어 있다고 가정한다.

```python
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsRegressor

train_input, test_input, train_target, test_target = train_test_split(
    perch_length, perch_weight, random_state=42
)
train_input = train_input.reshape(-1, 1)
test_input = test_input.reshape(-1, 1)

knr = KNeighborsRegressor()  # 기본 이웃 수: 5
knr.fit(train_input, train_target)
print(knr.score(test_input, test_target))  # 약 0.9928
```

실행 결과:

```text
0.992809406101064
```

- 기본 분할에서는 훈련 42마리, 테스트 14마리다.
- `reshape(-1, 1)`은 길이를 샘플별 한 행, 특성 한 열인 2차원 배열로 바꾼다. `-1`은 행 수를 자동으로 정한다.
- `(42, 1)`은 특성 42개가 아니라 농어 42마리와 특성 1개를 뜻한다. 타깃은 1차원으로 둔다.
- 회귀 모델의 `score()`는 정확도가 아닌 결정계수 R²를 반환한다.

### 배열을 2차원으로 바꾸는 이유

사이킷런의 입력은 일반적으로 **행이 샘플, 열이 특성**이다. 길이가 하나뿐이어도 생선 한 마리가 한 행을 차지해야 한다.

```text
[10, 20, 30]       → 1차원: 값 3개
[[10], [20], [30]] → 2차원: 생선 3마리 × 특성 1개
```

`reshape(-1, 1)`은 데이터 개수를 바꾸지 않고 열을 하나로 만든다. `-1`은 전체 원소 수에 맞게 행 수를 자동으로 계산한다. 무게 정답은 생선별 값 하나씩이므로 이 예제에서는 1차원 배열을 사용한다.

### 데이터와 실행 순서

입력은 농어 길이 56개인 1차원 NumPy 배열, 정답은 같은 순서의 실제 무게 56개다. 기본 비율로 나누면 훈련 42개와 테스트 14개다. `reshape(-1, 1)` 후 모델의 입력은 `(42, 1)`과 `(14, 1)`이고 정답은 `(42,)`, `(14,)`다.

`KNeighborsRegressor()`를 생성하고 `fit(train_input, train_target)`으로 훈련 사례를 준비한다. `predict([[30]])`은 길이 30cm 농어 한 마리의 무게를 배열로 반환한다. `score(test_input, test_target)`은 정답을 비교해 R²를 반환한다. 원자료 준비부터 실행하려면 [농어 회귀 실습](05-최근접-이웃-회귀-예제.md)을 사용한다.

`distances, indexes = knr.kneighbors([[30]])`의 두 반환값은 각각 거리와 훈련 배열의 행 번호다. 각각 `(1, 5)`이며 첫 축은 입력 농어 1마리, 두 번째 축은 이웃 5마리다. `indexes[0]`은 첫 이웃 한 마리가 아니라 첫 입력에 대응하는 번호 다섯 개다. `train_target[indexes[0]]`은 그 번호의 무게 다섯 개이며 `.mean()`을 계산한 값은 기본 모델의 `predict([[30]])[0]`과 같다. `35`로 바꾼 실행도 실습에 포함한다.

## 이웃 확인

```python
distances, indexes = knr.kneighbors([[30]])
weights = train_target[indexes[0]]
print(weights)
print(weights.mean(), knr.predict([[30]])[0])
```

- `kneighbors()`로 이웃까지의 거리와 훈련 데이터의 인덱스를 확인한다.
- 예시 분할에서 30cm 농어의 이웃 무게는 300, 260, 265, 514, 218g이며 평균 311.4g이 예측값이다.
