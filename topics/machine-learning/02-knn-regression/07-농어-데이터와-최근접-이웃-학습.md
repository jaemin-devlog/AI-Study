# 농어 데이터와 KNN 회귀

농어 56마리의 길이와 무게 배열 `perch_length`, `perch_weight`를 사용

```python
from sklearn.model_selection import train_test_split

train_input, test_input, train_target, test_target = train_test_split(
    perch_length, perch_weight, random_state=42
)
train_input = train_input.reshape(-1, 1)
test_input = test_input.reshape(-1, 1)
print(train_input.shape, test_input.shape)
```

```text
(42, 1) (14, 1)
```

입력은 행이 생선, 열이 특성인 2차원 형태. `-1`은 원소 수에 맞춰 행 수를 자동 계산

특성이 하나여도 모델에 넣을 때 한 생선마다 `[길이]` 형태가 필요함

## 4. KNN 회귀 모델

```python
from sklearn.neighbors import KNeighborsRegressor

knr = KNeighborsRegressor()
knr.fit(train_input, train_target)
print(knr.score(test_input, test_target))
```

```text
0.992809406101064
```

기본 이웃 수는 5. 회귀 모델의 `score()`는 정확도가 아니라 결정계수 R²를 반환

길이가 30cm인 농어의 이웃을 직접 확인하고 평균을 계산

```python
distances, indexes = knr.kneighbors([[30]])
neighbor_weights = train_target[indexes[0]]
print(neighbor_weights)
print(neighbor_weights.mean())
print(knr.predict([[30]])[0])
```

```text
[300. 265. 260. 514. 218.]
311.4
311.4
```

이웃의 실제 무게 평균과 모델이 예측한 무게가 같음

같은 훈련 데이터로 35cm 농어를 입력하면 이웃 무게는 840, 556, 700, 685, 690g이고 평균 예측은 694.2g

거리나 같은 거리인 이웃의 출력 순서는 환경에 따라 달라질 수 있음

`kneighbors([[30]])`의 인덱스는 `(1, 5)` 형태. `indexes[0]`은 첫 농어에 대한 이웃 번호 5개 전체
