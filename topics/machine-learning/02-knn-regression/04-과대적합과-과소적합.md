# 4. 과대적합과 과소적합

학습 범위: 15에서 17쪽

## 훈련과 테스트 점수 비교

```python
print(round(knr.score(train_input, train_target), 4))
print(round(knr.score(test_input, test_target), 4))
```

```text
0.9699
0.9928
```

훈련보다 테스트 점수가 높음. 두 점수는 서로 다른 농어를 평가한 결과라서 데이터 구성과 난이도에 따라 이럴 수 있음. 이 사실만으로 과소적합이라고 단정할 수는 없음.

## 과대적합

훈련 데이터의 전체적인 관계뿐 아니라 개별 샘플의 우연한 차이와 잡음까지 지나치게 반영한 상태. 훈련에는 잘 맞아도 새 데이터에서는 예측이 나빠질 수 있음.

길이가 비슷한 농어들의 무게 차이를 지나치게 따라가면 모델이 전체적인 증가 관계보다 각 농어의 측정값에 민감해짐. 훈련 R²가 높고 테스트 R²가 크게 낮으면 이런 상태를 의심해야 함.

## 과소적합

모델이 너무 단순하거나 학습이 충분하지 않아 훈련 데이터의 중요한 패턴조차 제대로 반영하지 못한 상태. 훈련과 테스트 점수가 모두 낮게 나타날 수 있음.

길이가 늘어도 무게를 거의 같은 값으로 예측한다면 길이와 무게 관계를 놓친 것일 수 있음.

![모델 복잡도 비교](../assets/모델-복잡도.png)

이 그림은 별도 예시 데이터의 1차, 4차, 15차 예측선. 단순한 모델의 표현력 부족과 복잡한 모델의 민감도를 비교함. 실제 농어의 k별 결과나 성능을 이 그림에서 읽는 것은 아님.

과대적합과 과소적합의 점수 특징은 흔한 경향. 점수 차이뿐 아니라 두 점수의 수준, 데이터 분포와 예측 모양도 함께 확인해야 함.
