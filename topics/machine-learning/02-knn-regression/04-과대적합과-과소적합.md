# 4. 과대적합과 과소적합

테스트 점수가 높다고 끝내기보다 훈련에서도 어느 정도 맞는지 함께 봄. 두 결과를 비교하면 모델이 훈련 관계를 충분히 반영했는지, 훈련에만 지나치게 맞춰졌는지 살펴볼 수 있음.

## 같은 모델로 두 세트 평가하기

```python
print(round(knr.score(train_input, train_target), 4))
print(round(knr.score(test_input, test_target), 4))
```

```text
0.9699
0.9928
```

이웃 다섯 개 모델의 훈련 R²는 약 0.9699, 테스트 R²는 약 0.9928. 여기서는 테스트가 더 높음. 훈련과 테스트는 서로 다른 농어이며 무게 분포와 예측하기 쉬운 정도가 다를 수 있음. 테스트 점수가 높다는 사실만으로 과소적합이라고 결론 내릴 수는 없음.

또한 두 R²의 분모는 각각 해당 세트의 평균을 기준으로 계산함. 단순히 훈련 점수가 항상 더 높아야 한다는 규칙으로 읽지 않고 각 세트에서의 결과로 해석함.

## 훈련 사례에 지나치게 맞추는 과대적합

과대적합은 전체적인 관계뿐 아니라 개별 훈련 샘플의 우연한 차이까지 지나치게 반영한 상태. 훈련에서는 잘 맞지만 새 데이터에서 예측이 나빠질 수 있음. 길이가 비슷한 농어마다 무게가 달랐던 세부 차이를 너무 강하게 따라가는 경우를 생각할 수 있음.

훈련 R²가 높고 테스트 R²가 크게 낮다면 과대적합을 의심함. 훈련을 외우듯 잘 맞히는 것보다 학습하지 않은 데이터에서도 관계가 유지되는지가 중요함. 이런 예측 능력을 일반화라고 함.

## 중요한 관계도 놓치는 과소적합

과소적합은 모델이 너무 단순하거나 학습이 충분하지 않아 훈련 데이터의 중요한 패턴도 제대로 반영하지 못한 상태. 길이가 커져도 거의 같은 무게만 예측하면 증가 관계를 놓친 것일 수 있음. 훈련과 테스트 성능이 모두 낮게 나타날 수 있음.

![모델 복잡도 비교](../assets/모델-복잡도.png)

그림은 별도의 예시 데이터에서 1차, 4차, 15차 예측선을 비교함. 너무 단순한 선은 실제 굽은 관계를 놓치고, 너무 복잡한 선은 점 하나하나에 민감하게 움직일 수 있음. 실제 농어의 이웃 수별 결과를 그린 그림은 아니므로 곡선의 차수를 k로 읽으면 안 됨.

## 점수와 예측 모양을 함께 확인하기

과대적합과 과소적합의 점수 모습은 판단에 참고하는 경향임. 점수 차이만 줄이면 되는 것도 아니고, 테스트가 훈련보다 높으면 자동으로 과소적합인 것도 아님. 두 점수의 수준과 데이터 분포, 예측선이 주요 관계를 표현하는지도 확인함.
