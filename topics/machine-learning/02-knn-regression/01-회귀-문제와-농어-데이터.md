# 1. 회귀 문제와 농어 데이터

앞에서는 길이와 무게로 생선 종류를 골랐음. 이번에는 농어의 길이를 알고 있을 때 무게가 몇 g인지 예측함. 입력과 정답을 함께 제공하는 지도학습은 같지만 정답의 의미가 달라짐.

## 분류의 이름표와 회귀의 수치

| 구분 | 앞의 분류 | 이번 회귀 |
| --- | --- | --- |
| 입력 | 길이와 무게 | 길이 |
| 정답 | 도미 또는 빙어 | 실제 무게 |
| 예측 | 어떤 종류인가 | 몇 g인가 |

도미 1과 빙어 0은 이름을 숫자로 표시한 것이었음. 회귀의 무게 100g과 200g은 크기와 차이 자체가 의미 있음. 가격, 기온, 소요 시간처럼 수치가 얼마인지 예측하는 것도 회귀임.

이번에는 무게가 정답이므로 입력에서 빼야 함. 새 농어의 무게는 모르는 상태에서 길이만으로 예측해야 하기 때문임.

## KNN을 회귀에 사용하는 방법

가까운 이웃을 찾는 방식은 분류와 같음. 달라지는 것은 이웃의 정답으로 예측값을 만드는 방법임. 분류는 다수결을 사용했고 기본 KNN 회귀는 이웃 무게의 평균을 사용함.

$$
\hat y=\frac{1}{k}\sum_{i=1}^{k}y_i
$$

$\hat y$는 예측 무게, $y_i$는 선택된 이웃의 실제 무게, $k$는 이웃 수. 길이가 가까운 세 농어의 무게가 100g, 80g, 60g이면 평균 80g을 예측함. 이웃은 알고 있는 길이로 찾고, 찾은 이웃의 무게로 결과를 계산하는 순서임.

가로축 길이와 세로축 무게를 연결한 점 하나가 농어 한 마리. 길이가 길수록 무게도 커지는 경향이 있어 이를 이용해 예측할 수 있음. 다만 같은 길이에서도 무게가 다르므로 길이 하나로 모든 차이를 설명할 수 있는 것은 아님.

## 특성이 하나여도 입력은 2차원으로 만들기

```python
from sklearn.model_selection import train_test_split

train_input, test_input, train_target, test_target = train_test_split(
    perch_length, perch_weight, random_state=42
)
train_input = train_input.reshape(-1, 1)
test_input = test_input.reshape(-1, 1)
print(train_input.shape, test_input.shape)
print(train_target.shape, test_target.shape)
```

```text
(42, 1) (14, 1)
(42,) (14,)
```

기본 25%를 테스트로 남겨 훈련 42마리와 테스트 14마리로 나눔. `random_state=42`는 같은 분할을 재현함. 분할 직후 길이는 `(42,)`와 `(14,)`로 나열되어 있으므로 모델의 입력 형태에 맞게 바꿈.

`reshape(-1, 1)`에서 1은 열 하나, -1은 전체 원소 수에 맞춰 행 수를 자동 계산하라는 뜻. `[10, 20, 30]`이 `[[10], [20], [30]]`이 되는 형태임. `(42, 1)`은 샘플 42개와 특성 1개이므로 2차원 배열이라고 특성이 두 개가 된 것은 아님.

모양을 바꾸어도 값의 수는 유지됨. 원소 네 개를 2행 2열로 만들 수 있지만 2행 3열로 만들 수는 없음. 정답은 각 농어의 무게 하나씩이므로 `(42,)`와 `(14,)`인 1차원을 유지함. 다음에는 이 입력으로 실제 이웃을 찾아 평균을 확인함.
