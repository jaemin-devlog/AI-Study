## 종류 대신 무게 예측

앞의 분류는 도미인지 빙어인지 선택했고, 이번 회귀는 길이를 이용해 무게가 몇 g인지 예측함. 두 문제 모두 입력과 정답을 함께 제공하는 지도학습.

분류의 1과 0은 종류를 표시하는 이름표였지만, 이번 무게는 수치의 크기와 차이 자체가 의미 있음. 가격, 기온, 소요 시간처럼 연속적인 값을 예측하는 것도 회귀임.

## 최근접 이웃 회귀의 원리

길이가 가까운 농어 k마리를 찾은 뒤 실제 무게를 평균함. 기본 균일 가중치에서는 다음과 같음.

$$
\hat y=\frac{1}{k}\sum_{i=1}^{k} y_i
$$

이웃의 무게가 100g, 80g, 60g이면 예측값은 80g. 새 농어의 무게는 아직 모르므로 이웃을 찾을 때는 입력인 길이만 사용함.

## 분할하고 입력을 2차원으로 만들기

```python
from sklearn.model_selection import train_test_split

train_input, test_input, train_target, test_target = train_test_split(
    perch_length, perch_weight, random_state=42
)
train_input = train_input.reshape(-1, 1)
test_input = test_input.reshape(-1, 1)
print(train_input.shape, test_input.shape)
print(train_target.shape, test_target.shape)
```

```text
(42, 1) (14, 1)
(42,) (14,)
```

`reshape(-1, 1)`은 열을 하나로 정하고 행 수는 원소 수에 맞춰 자동 계산. 농어 42마리와 특성 1개를 의미하므로 입력이 2차원이라고 특성이 두 개가 된 것은 아님.

`np.array([1, 2, 3, 4]).reshape(2, 2)`는 값을 2행 2열로 다시 배치함. 원소 수는 유지돼야 하므로 2행 3열로는 바꿀 수 없음. 정답은 각 농어의 무게 하나씩이어서 1차원을 유지함.
