# 과대적합, 과소적합과 이웃 수

본문 코드는 개념별 부분 코드. 데이터 준비부터 독립 실행할 때는 [전체 실습](05-최근접-이웃-회귀-예제.md)을 사용.


## 훈련 점수와 테스트 점수

| 상태 | 흔히 나타나는 모습 | 의미 |
| --- | --- | --- |
| 과대적합 | 훈련 점수는 높지만 테스트 점수가 크게 낮음 | 훈련 데이터에 지나치게 맞춰져 새 데이터에서 성능 저하 |
| 과소적합 | 훈련 점수와 테스트 점수가 모두 낮음 | 데이터의 중요한 관계를 충분히 학습하지 못함 |

- 점수 차이만으로 모델 상태를 확정하지 않는다. 데이터의 양과 분포, 점수의 수준, 예측 결과를 함께 확인한다.
- 일반화는 학습에 사용하지 않은 데이터에서도 잘 예측하는 능력이다.

## 모델 복잡도와 일반화

모델 복잡도는 데이터의 세부적인 변화에 얼마나 민감하게 맞출 수 있는지와 관련된다. 훈련 데이터의 우연한 차이까지 따라가면 처음 보는 입력에서 성능이 낮아질 수 있다. 반대로 중요한 관계를 충분히 표현하지 못해 훈련과 테스트 성능이 모두 낮을 수도 있다.

훈련 점수와 테스트 점수의 순서만으로 과소적합을 판단하지 않는다. 점수의 절대 수준, 데이터 분포와 예측 결과도 확인한다.

## KNN의 k와 모델 복잡도

- k가 작으면 가까운 소수의 이웃에 민감하다. 작은 변화나 특이값의 영향을 크게 받아 과대적합할 수 있다.
- k가 크면 더 많은 이웃을 평균 내어 예측이 완만해진다. 너무 크면 주변 관계를 놓쳐 과소적합할 수 있다.

| 이웃 수 | 훈련 R² | 테스트 R² | 테스트 MAE |
| --- | --- | --- | --- |
| 5 | 0.9699 | 0.9928 | 약 19.16g |
| 3 | 0.9805 | 0.9746 | 약 35.42g |
| 42 | 0.0000 | 약 -0.0551 | 약 291.16g |

- 같은 농어 실습에서 k를 5에서 3으로 줄이자 훈련 점수는 높아졌지만 테스트 점수는 낮아졌다. k를 줄이면 항상 일반화 성능이 좋아지는 것은 아니다.
- k=42는 훈련 데이터 전체의 평균 무게를 모든 입력에 예측한다.
- 실제 모델 선택은 검증 데이터 또는 교차 검증으로 k를 비교하고, 테스트 데이터는 최종 평가에 사용한다. 위 표는 수업에서 k의 영향을 관찰한 결과다.

### 왜 훈련 점수가 높아져도 테스트 점수는 낮아질까?

이웃 수를 줄이면 모델이 가장 가까운 농어 몇 마리의 무게를 더 강하게 반영한다. 훈련 데이터에서는 개별 농어에 더 잘 맞을 수 있지만, 그 차이가 전체적인 경향이 아니라 우연한 측정 차이라면 새로운 농어에서는 오히려 오차가 커질 수 있다.

반대로 이웃 수가 너무 크면 길이가 짧은 농어와 긴 농어의 무게까지 함께 평균하여 길이에 따른 차이를 충분히 반영하지 못한다. k=42에서는 모든 훈련 농어를 사용하므로 입력 길이와 관계없이 같은 평균을 예측한다.

![합성 데이터의 복잡도 비교](../assets/모델-복잡도.png)

이 그림은 농어 실측이 아닌 별도 합성 데이터로 만든 개념 예시다. 점은 합성 데이터, 선은 다항 차수를 1, 4, 15로 바꾼 예측이다. 1차 선은 굽어진 흐름을 충분히 표현하기 어렵고 15차 선은 개별 점에 민감하게 굽는다. 그래프만으로 테스트 성능을 확정할 수는 없다.

![이웃 수 3, 5, 10의 농어 예측](../assets/이웃-수-비교.png)

같은 농어 훈련 데이터로 k만 변경한 응용 실습이다. 점은 실제 길이와 무게, 선은 각 길이에 대한 예측이다. 이웃 구성이 그대로인 구간에서 평균도 같아 계단형으로 나타난다. [그림 생성 코드](../examples/06-그림-생성.py)에서 세 모델을 직접 확인할 수 있다.

## 이웃 수에 따른 예측선

농어 훈련 데이터 `train_input`, `train_target`은 [KNN 회귀](01-최근접-이웃-회귀.md)의 분할 결과다.

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.neighbors import KNeighborsRegressor

x = np.linspace(8, 60, 500).reshape(-1, 1)
fig, axes = plt.subplots(1, 3, figsize=(12, 3.6), sharey=True)
for ax, k in zip(axes, [1, 5, 20]):
    model = KNeighborsRegressor(n_neighbors=k)
    model.fit(train_input, train_target)
    ax.scatter(train_input[:, 0], train_target, s=16)
    ax.plot(x, model.predict(x), color='darkorange')
    ax.set_title(f'k = {k}')
    ax.set_xlabel('Length (cm)')
    ax.set_xlim(8, 46)
axes[0].set_ylabel('Weight (g)')
plt.tight_layout()
plt.show()
```

![KNN 회귀의 이웃 수별 예측선](../assets/이웃-수별-회귀.png)

코드에서 `linspace()`는 비교할 길이 500개를 만들고, `reshape(-1, 1)`은 이를 모델 입력인 2차원 배열로 바꾼다. 반복문은 k마다 모델을 새로 학습하고 같은 길이에 대한 예측을 선으로 그린다. `sharey=True`는 세 그래프의 세로축 눈금을 같게 해 비교하기 위한 설정이다.

가로축은 길이(cm), 세로축은 무게(g)다. 파란 점은 훈련 농어, 주황색 선은 해당 길이에서 예측한 무게다.

- k=1: 가장 가까운 농어 한 마리의 무게를 사용해 개별 데이터에 민감하게 반응한다.
- k=5: 가까운 다섯 마리의 무게를 평균한다.
- k=20: 더 많은 무게를 평균해 예측 변화가 완만해지지만 길이별 차이를 충분히 반영하지 못할 수 있다.

이 그래프는 예측 방식의 차이를 보여 준다. 최적의 k는 그래프 모양만으로 고르지 않고 검증 데이터의 성능도 확인한다. 그래프는 실습 데이터를 사용해 직접 생성했다.
