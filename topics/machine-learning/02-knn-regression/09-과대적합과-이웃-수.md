# 과대적합과 이웃 수

과대적합은 훈련 데이터에 지나치게 맞춰져 새로운 데이터의 성능이 낮아지는 경우

과소적합은 데이터의 중요한 관계를 충분히 학습하지 못해 훈련과 테스트 성능이 모두 낮아질 수 있는 경우

점수 차이만으로 단정하지 않고 데이터 분포와 점수 수준도 함께 확인

| k | 훈련 R² | 테스트 R² | 테스트 MAE |
| --- | --- | --- | --- |
| 1 | 0.9853 | 0.9913 | 22.69g |
| 3 | 0.9805 | 0.9746 | 35.42g |
| 5 | 0.9699 | 0.9928 | 19.16g |
| 10 | 0.9616 | 0.9738 | 39.24g |
| 20 | 0.8613 | 0.8785 | 76.44g |
| 42 | 0.0000 | -0.0551 | 291.16g |

k를 5에서 3으로 줄이자 훈련 점수는 올랐지만 테스트 점수는 낮아짐

![이웃 수별 예측](../assets/pdf/이웃-수별-예측.png)

점은 실제 훈련 농어, 선은 길이별 예측값

k가 작으면 가까운 데이터에 민감하고, k가 크면 평균을 내는 범위가 커져 변화가 완만해짐

k=42는 모든 훈련 농어의 평균 무게를 예측. 테스트 평균과는 다를 수 있어 테스트 R²는 음수가 될 수 있음
