# 7. 예측선과 이웃 수 해석

점수 표는 전체 오차를 보여 주지만 길이의 어느 구간에서 예측이 변하는지는 바로 보이지 않음. 이번에는 같은 훈련 데이터로 k=1, 5, 20을 학습하고 여러 길이에 대한 예측을 선으로 연결해 봄.

## 실제 농어와 예측용 길이 구분하기

```python
x_grid = np.linspace(train_input.min(), train_input.max(), 500).reshape(-1, 1)
fig, axes = plt.subplots(1, 3, figsize=(14, 4), sharex=True, sharey=True)
for ax, k in zip(axes, [1, 5, 20]):
    model = KNeighborsRegressor(n_neighbors=k)
    model.fit(train_input, train_target)
    ax.scatter(train_input[:, 0], train_target, alpha=0.6)
    ax.step(x_grid[:, 0], model.predict(x_grid), where='mid')
    ax.set_title(f'k={k}')
    ax.set_xlabel('Length (cm)')
axes[0].set_ylabel('Weight (g)')
plt.tight_layout()
plt.show()
```

`linspace()`는 훈련 길이의 최소부터 최대까지 500개 지점을 만듦. 이 500개는 새로 측정한 농어가 아니라 예측선을 그리기 위한 입력임. 실제 무게 정답은 없으므로 평가용 샘플 수가 늘어난 것은 아님.

`reshape(-1, 1)`은 길이 한 열의 모델 입력으로 바꿈. `subplots()`로 세 그래프를 만들고 `zip()`으로 각 그래프와 k를 대응시킴. 점은 실제 훈련 농어이고 선은 각 길이에서 예측한 무게임. `sharex`, `sharey`로 같은 축 범위를 사용해 모양을 비교함.

![이웃 수별 예측선](../assets/pdf/이웃-수별-예측.png)

가로축은 길이, 세로축은 무게. k=1에서는 가장 가까운 한 농어의 무게가 그대로 반영되므로 이웃이 바뀔 때 큰 변화가 생길 수 있음. k=5는 주변 다섯 마리를 평균해 개별 사례의 영향을 줄임. k=20은 더 넓은 범위를 평균하여 변화가 완만하지만 특히 큰 농어의 무게 증가를 충분히 따라가지 못하는 모습임.

## 기본 KNN의 선이 계단형인 이유

입력 길이가 조금 바뀌어도 선택된 이웃들이 같으면 평균도 같음. 그래서 그 구간의 예측값은 수평으로 유지됨. 이웃 집합이 바뀌는 곳에서는 평균이 달라져 예측값이 갑자기 움직일 수 있음.

이것은 `step()` 때문에 모델이 계단 예측을 배우는 것이 아님. 기본 균일 가중치 KNN의 결과를 계단형으로 표현한 것임. 같은 이웃이면 같은 결과라는 계산 원리를 그림과 연결해야 함.

![이웃 수 3, 5, 10 비교](../assets/이웃-수-비교.png)

후보를 `[3, 5, 10]`으로 바꾸면 다른 범위의 이웃 수에서도 같은 경향을 비교할 수 있음. 이웃이 많아져 완만해졌다고 더 좋은 모델이라고 판단하지 않음. 중요한 관계를 충분히 표현하는지와 학습하지 않은 데이터의 R², MAE를 함께 봄.

## 다음 모델이 필요한 상황

KNN 분류는 이웃 종류의 다수결, KNN 회귀는 이웃 정답의 평균을 사용했음. 둘 다 훈련 사례에서 가까운 이웃을 찾는 방식임. 그렇다면 훈련에서 본 길이보다 훨씬 큰 농어에도 그 평균이 적절할까? 다음 파트에서는 범위 밖 입력의 한계를 확인하고 길이와 무게를 관계식으로 표현함.
