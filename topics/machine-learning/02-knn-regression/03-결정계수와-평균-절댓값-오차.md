# 3. 결정계수와 평균 절댓값 오차

학습 범위: 11에서 14쪽

## 결정계수 R²

$$
R^2=1-\frac{\sum_{i=1}^{n}(y_i-\hat y_i)^2}{\sum_{i=1}^{n}(y_i-\bar y)^2}
$$

$y_i$는 실제 무게, $\hat y_i$는 예측 무게, $\bar y$는 평가 대상 정답의 평균. 분자는 모델의 제곱오차 합이고 분모는 모든 값을 평균으로 예측했을 때의 제곱오차 합임.

실제값이 `[100, 200, 300]`, 예측이 `[110, 190, 290]`이라면 평균은 200. 평균 예측의 제곱오차 합은 20,000이고 모델의 합은 300이므로 다음과 같음.

$$
R^2=1-\frac{300}{20000}=0.985
$$

평균으로 예측하는 기준보다 제곱오차를 98.5% 줄였다는 뜻. 샘플의 98.5%를 맞혔다는 뜻은 아님.

| R² | 해석 |
| --- | --- |
| 1 | 모든 예측과 실제값 일치 |
| 0 | 평가 정답 평균으로 예측한 기준과 제곱오차가 같음 |
| 음수 | 평균 기준보다 제곱오차가 큼 |

## MAE는 무게 단위로 오차를 확인

$$
\mathrm{MAE}=\frac{1}{n}\sum_{i=1}^{n}|y_i-\hat y_i|
$$

앞의 세 농어는 절댓값 오차가 각각 10g이므로 MAE는 10g. 절댓값을 사용해 가볍게 예측한 오차와 무겁게 예측한 오차가 상쇄되지 않게 함.

```python
from sklearn.metrics import mean_absolute_error

prediction = knr.predict(test_input)
print(round(knr.score(test_input, test_target), 4))
print(round(mean_absolute_error(test_target, prediction), 2))
```

```text
0.9928
19.16
```

R²는 테스트 정답 평균으로 예측한 기준보다 제곱오차를 약 99.28% 줄였음을 뜻함. MAE는 실제 무게와 평균적으로 약 19.16g 차이가 났다는 뜻. 모든 농어의 오차가 19.16g 이하라는 의미는 아님.

R²에는 단위가 없고 MAE는 타깃과 같은 g 단위. 같은 데이터의 모델을 비교할 때 둘을 함께 읽으면 상대적인 오차 개선과 실제 오차 크기를 확인할 수 있음.
