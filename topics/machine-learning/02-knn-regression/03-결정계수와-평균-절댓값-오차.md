# 3. 결정계수와 평균 절댓값 오차

회귀에서는 예측 무게가 실제 무게와 얼마나 가까운지 평가함. 평균값으로만 예측하는 기준보다 나아졌는지는 R²로, 무게가 평균적으로 몇 g 차이 나는지는 MAE로 확인할 수 있음. 두 지표는 서로 다른 질문에 답함.

## 평균으로만 예측하는 기준 만들기

세 농어의 실제 무게가 100g, 200g, 300g이라고 해보면 평균은 200g. 아무 길이 정보도 사용하지 않고 모든 농어를 200g으로 예측할 수 있음. 모델은 이 단순한 기준보다 오차를 얼마나 줄였는지 비교함.

| 실제 무게 | 평균 예측 | 모델 예측 | 모델의 절댓값 오차 |
| --- | --- | --- | --- |
| 100g | 200g | 110g | 10g |
| 200g | 200g | 190g | 10g |
| 300g | 200g | 290g | 10g |

평균 예측의 제곱오차 합은 $(100-200)^2+(200-200)^2+(300-200)^2=20000$. 모델 예측의 제곱오차 합은 $10^2+10^2+10^2=300$임. 제곱하므로 양수와 음수 오차가 서로 상쇄되지 않고 큰 오차가 크게 반영됨.

## 결정계수 R² 계산하기

$$
R^2=1-\frac{\sum_{i=1}^{n}(y_i-\hat y_i)^2}{\sum_{i=1}^{n}(y_i-\bar y)^2}
$$

$y_i$는 실제값, $\hat y_i$는 예측값, $\bar y$는 평가하는 정답의 평균, $n$은 평가 샘플 수. 분자는 모델의 제곱오차 합이고 분모는 평균 예측의 제곱오차 합임.

위 숫자를 넣으면 $1-300/20000=0.985$. 평균 예측보다 제곱오차를 98.5% 줄였다는 뜻이며 샘플의 98.5%를 맞힌 비율은 아님.

| R² | 의미 |
| --- | --- |
| 1 | 예측값과 실제값이 모두 일치 |
| 0 | 평가 정답 평균으로 예측한 기준과 제곱오차가 같음 |
| 0 미만 | 평균 기준보다 제곱오차가 큼 |

테스트에서 계산한다면 분모의 평균은 테스트 정답의 평균임. 이 평균은 평가 기준을 계산하는 데 사용하는 것이며 모델 학습에 테스트 정답을 넣는 것과는 구분함.

## MAE로 실제 단위의 차이 읽기

R²만으로는 몇 g이나 틀렸는지 바로 알 수 없음. 평균 절댓값 오차인 MAE는 각 차이의 크기를 구한 뒤 평균함.

$$
\mathrm{MAE}=\frac{1}{n}\sum_{i=1}^{n}|y_i-\hat y_i|
$$

앞의 세 농어는 모두 절댓값 오차가 10g이므로 MAE도 10g. 절댓값을 사용해 무겁게 예측한 오차와 가볍게 예측한 오차가 더할 때 상쇄되지 않게 함.

```python
from sklearn.metrics import mean_absolute_error

prediction = knr.predict(test_input)
print(round(knr.score(test_input, test_target), 4))
print(round(mean_absolute_error(test_target, prediction), 2))
```

```text
0.9928
19.16
```

앞에서 학습한 이웃 다섯 개 모델의 테스트 R²는 약 0.9928. 테스트 평균 예측보다 제곱오차를 약 99.28% 줄였다는 뜻임. MAE는 약 19.16g으로, 14마리에서 절댓값 오차가 평균 이만큼 발생했음을 뜻함.

| 평가 지표 | 결과 | 읽는 방법 |
| --- | ---: | --- |
| 결정계수 R² | 0.9928 | 테스트 평균 예측 기준보다 제곱오차를 약 99.28% 줄임 |
| 평균 절댓값 오차 MAE | 19.16g | 실제 무게와 예측 무게의 절댓값 차이가 평균 약 19.16g |

모든 농어의 오차가 19.16g 이하이거나 정확히 19.16g이라는 뜻은 아님. R²는 단위 없는 상대 지표이고 MAE는 타깃과 같은 g 단위. 같은 데이터에서 모델을 비교할 때 둘을 함께 보면 개선 정도와 실제 오차 크기를 연결할 수 있음.
