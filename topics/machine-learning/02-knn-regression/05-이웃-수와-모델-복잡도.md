# 5. 이웃 수와 모델 복잡도

학습 범위: 18에서 20쪽

## k로 복잡도 조절

이웃 수 `n_neighbors`는 사람이 지정하는 하이퍼파라미터. k가 작으면 가까운 일부 농어에 민감해지고, 크면 넓은 범위의 농어를 평균해 예측이 완만해지는 방향으로 바뀜.

- 과대적합이 의심되면 k를 늘려 개별 샘플의 영향을 줄이는 방법을 시도.
- 과소적합이 의심되면 k를 줄여 데이터의 세부적인 변화를 더 반영하도록 시도.

조절 방향이지 성능 개선을 보장하는 규칙은 아님.

## 5개에서 3개로 변경

```python
knr.n_neighbors = 3
knr.fit(train_input, train_target)
print(round(knr.score(train_input, train_target), 4))
print(round(knr.score(test_input, test_target), 4))
```

```text
0.9805
0.9746
```

| 이웃 수 | 훈련 R² | 테스트 R² |
| --- | --- | --- |
| 5 | 0.9699 | 0.9928 |
| 3 | 0.9805 | 0.9746 |

소수의 가까운 농어를 참고하니 훈련 데이터는 더 잘 맞혔지만 테스트 점수는 낮아짐. 따라서 복잡도를 높여 훈련 점수가 올랐다고 새 데이터에서도 더 좋은 모델이 된 것은 아님.

이 실험만으로 원래 과소적합이었다거나 과소적합이 해결됐다고 단정하지 않음. 모델의 목표는 새로운 데이터에서도 좋은 성능을 유지하는 일반화임.
