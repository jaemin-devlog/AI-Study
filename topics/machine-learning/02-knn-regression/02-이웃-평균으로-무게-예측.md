# 2. 이웃 평균으로 무게 예측

학습 범위: 7에서 10쪽

## 회귀 모델 생성

```python
from sklearn.neighbors import KNeighborsRegressor

knr = KNeighborsRegressor(n_neighbors=5)
knr.fit(train_input, train_target)
```

분류의 `KNeighborsClassifier` 대신 회귀의 `KNeighborsRegressor` 사용. `fit()`은 길이와 실제 무게를 보관하고, `predict()`는 이웃의 무게로 새 농어의 무게를 계산함.

## 30cm 농어의 실제 이웃 확인

```python
new_fish = np.array([[30.0]])
distances, indexes = knr.kneighbors(new_fish)
neighbor_lengths = train_input[indexes[0], 0]
neighbor_weights = train_target[indexes[0]]
print(neighbor_lengths)
print(neighbor_weights)
print(np.round(distances[0], 1))
print(neighbor_weights.mean(), knr.predict(new_fish)[0])
```

```text
[28.7 27.5 27.5 32.8 26.5]
[300. 265. 260. 514. 218.]
[1.3 2.5 2.5 2.8 3.5]
311.4 311.4
```

`indexes[0]`은 새 농어 하나에 대응하는 다섯 이웃의 훈련 행 번호. 같은 번호로 길이와 무게를 선택해야 함.

$$
\hat y=\frac{300+260+265+514+218}{5}=311.4
$$

직접 평균과 모델의 출력이 같음. 길이가 같은 농어가 있어도 무게는 서로 다를 수 있으며, 같은 거리의 이웃 순서는 동률 처리에 따라 달라질 수 있음.

35cm로 바꾸면 기본 이웃 5개의 평균 예측은 약 694.2g. 입력값이 달라지면 선택되는 이웃과 무게 평균이 함께 바뀜.

## 회귀를 평가할 때 달라지는 점

실제 무게가 100g일 때 99g과 50g은 둘 다 정확히 일치하지 않지만 첫 예측이 훨씬 가까움. 회귀에서는 정답 일치 여부보다 실제값에서 얼마나 벗어났는지를 평가해야 함.

분류의 `score()`는 정확도였지만 이 회귀 모델의 `score()`는 결정계수 R². 같은 메서드 이름이라도 모델에 따라 반환하는 지표가 다름.
