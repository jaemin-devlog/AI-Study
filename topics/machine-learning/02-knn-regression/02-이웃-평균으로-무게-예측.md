# 2. 이웃 평균으로 무게 예측

앞 파일에서 입력은 농어 길이 한 열, 정답은 실제 무게로 준비했음. 이제 새 농어 30cm를 넣어 모델이 어떤 농어를 참고하고 어떻게 311.4g을 예측하는지 확인함.

## 분류 모델 대신 회귀 모델 만들기

```python
from sklearn.neighbors import KNeighborsRegressor

knr = KNeighborsRegressor(n_neighbors=5)
knr.fit(train_input, train_target)
```

`KNeighborsRegressor`는 회귀용 객체. `n_neighbors=5`이므로 길이가 가까운 훈련 농어 다섯 마리를 사용함. `fit(train_input, train_target)`은 길이와 무게를 대응시켜 예측에 참고할 사례를 준비함.

이 모델이 찾는 것은 무게가 비슷한 농어가 아님. 새 농어의 무게는 아직 모르므로 길이가 비슷한 농어를 찾음. 그 이웃을 고른 다음 저장된 무게를 꺼내 평균함.

## 선택된 이웃과 거리 확인하기

```python
new_fish = np.array([[30.0]])
distances, indexes = knr.kneighbors(new_fish)
neighbor_lengths = train_input[indexes[0], 0]
neighbor_weights = train_target[indexes[0]]
print(neighbor_lengths)
print(neighbor_weights)
print(np.round(distances[0], 1))
print(neighbor_weights.mean(), knr.predict(new_fish)[0])
```

```text
[28.7 27.5 27.5 32.8 26.5]
[300. 265. 260. 514. 218.]
[1.3 2.5 2.5 2.8 3.5]
311.4 311.4
```

`new_fish`는 샘플 한 개와 특성 하나인 `(1, 1)` 모양. `kneighbors()`는 이 입력에 가까운 이웃까지의 거리와 훈련 행 번호를 반환함. `indexes[0]`은 이 한 샘플의 다섯 이웃 번호이며 같은 번호로 길이와 정답 무게를 가져옴.

첫 이웃 28.7cm는 새 입력 30cm와 1.3cm 차이. 27.5cm 두 마리는 각각 2.5cm 차이이고 32.8cm는 2.8cm 차이임. 입력 특성이 길이뿐이므로 거리는 길이 차이로 계산됨. 같은 길이라도 서로 다른 농어라 무게는 다를 수 있음.

## 이웃의 무게로 예측값 만들기

$$
\hat y=\frac{300+265+260+514+218}{5}=311.4\ \mathrm{g}
$$

`neighbor_weights.mean()`은 선택된 정답 무게의 평균. `knr.predict(new_fish)[0]`은 모델이 계산한 첫 샘플의 예측 무게. 둘이 311.4로 같으므로 모델의 결과가 이웃 평균에서 나온 것을 확인할 수 있음.

같은 거리에 있는 이웃의 출력 순서는 동률 처리에 따라 달라질 수 있음. 이 경우 평균 계산에서는 순서보다 선택된 값들이 중요함. 35cm로 바꾸면 다섯 이웃도 바뀌어 예측은 약 694.2g이 됨.

## 회귀에서는 무엇을 잘 예측했다고 할까?

종류를 분류할 때는 정답과 이름이 같은지 셌음. 실제 무게가 100g인 농어를 99g 또는 50g으로 예측했다면 둘 다 정확히 같지는 않지만 99g이 훨씬 가까움. 따라서 회귀는 일치 여부 대신 실제값에서 벗어난 정도를 평가해야 함.

이 회귀 모델의 `score()`는 정확도가 아닌 결정계수 R²를 반환함. 메서드 이름이 같아도 모델에 따라 지표가 다르므로 다음 파일에서 계산식과 의미를 구분함.
