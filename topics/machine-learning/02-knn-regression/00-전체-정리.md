# k-최근접 이웃 회귀

농어의 길이로 실제 무게를 예측하고, 회귀 모델의 성능을 평가하는 과정

## 1. 분류와 회귀

분류는 도미나 빙어처럼 종류를 예측

회귀는 농어의 무게처럼 연속적인 숫자를 예측

생선 종류를 나타내는 0과 1은 숫자지만 종류를 구분하는 이름표이므로 분류

## 2. KNN 회귀의 예측 방식

KNN 분류는 가까운 이웃의 종류를 다수결로 선택

KNN 회귀는 가까운 이웃들의 실제 무게를 평균 내어 예측

예를 들어 이웃의 무게가 100g, 80g, 60g이면 예측 무게는 다음과 같음

$$
\hat{y} = \frac{100 + 80 + 60}{3} = 80\,g
$$

새 농어의 무게는 아직 모르므로 입력인 길이로 이웃을 찾고, 찾은 농어의 실제 무게를 평균

![농어 길이와 무게](../assets/농어-분포.png)

점 하나는 농어 한 마리의 실제 측정값. 길이가 길수록 대체로 무거워지는 경향 확인

## 3. 데이터 분할과 reshape

농어 56마리의 길이와 무게 배열 `perch_length`, `perch_weight`를 사용

```python
from sklearn.model_selection import train_test_split

train_input, test_input, train_target, test_target = train_test_split(
    perch_length, perch_weight, random_state=42
)
train_input = train_input.reshape(-1, 1)
test_input = test_input.reshape(-1, 1)
print(train_input.shape, test_input.shape)
```

```text
(42, 1) (14, 1)
```

입력은 행이 생선, 열이 특성인 2차원 형태. `-1`은 원소 수에 맞춰 행 수를 자동 계산

특성이 하나여도 모델에 넣을 때 한 생선마다 `[길이]` 형태가 필요함

## 4. KNN 회귀 모델

```python
from sklearn.neighbors import KNeighborsRegressor

knr = KNeighborsRegressor()
knr.fit(train_input, train_target)
print(knr.score(test_input, test_target))
```

```text
0.992809406101064
```

기본 이웃 수는 5. 회귀 모델의 `score()`는 정확도가 아니라 결정계수 R²를 반환

30cm 농어에서 찾은 다섯 이웃의 무게 평균은 311.4g. 모델의 예측값도 311.4g

`kneighbors([[30]])`의 인덱스는 `(1, 5)` 형태. `indexes[0]`은 첫 농어에 대한 이웃 번호 5개 전체

## 5. 회귀 모델 평가

R²는 평가 데이터의 실제 무게를 전부 평균값으로 예측하는 기준과 모델의 제곱오차를 비교

$$
R^2 = 1 - \frac{\sum_{i=1}^{n}(y_i-\hat{y}_i)^2}{\sum_{i=1}^{n}(y_i-\bar{y})^2}
$$

$y_i$는 실제 무게, $\hat{y}_i$는 예측 무게, $\bar{y}$는 평가 데이터의 실제 무게 평균

R²가 1이면 예측과 실제값이 모두 일치, 0이면 평균으로만 예측한 기준과 제곱오차가 같음

음수면 평균값으로만 예측할 때보다 제곱오차가 큼. 0.99가 99%를 맞혔다는 뜻은 아님

MAE는 실제값과 예측값 차이의 절댓값을 평균 낸 값

```python
from sklearn.metrics import mean_absolute_error

prediction = knr.predict(test_input)
print(mean_absolute_error(test_target, prediction))
```

```text
19.157142857142862
```

테스트 농어 14마리의 예측이 실제 무게와 평균적으로 약 19.16g 차이 났다는 뜻

모든 농어의 오차가 19.16g 이하라는 뜻은 아님

## 6. 과대적합과 과소적합

과대적합은 훈련 데이터에 지나치게 맞춰져 새로운 데이터의 성능이 낮아지는 경우

과소적합은 데이터의 중요한 관계를 충분히 학습하지 못해 훈련과 테스트 성능이 모두 낮아질 수 있는 경우

점수 차이만으로 단정하지 않고 데이터 분포와 점수 수준도 함께 확인

| k | 훈련 R² | 테스트 R² | 테스트 MAE |
| --- | --- | --- | --- |
| 1 | 0.9853 | 0.9913 | 22.69g |
| 3 | 0.9805 | 0.9746 | 35.42g |
| 5 | 0.9699 | 0.9928 | 19.16g |
| 10 | 0.9616 | 0.9738 | 39.24g |
| 20 | 0.8613 | 0.8785 | 76.44g |
| 42 | 0.0000 | -0.0551 | 291.16g |

k를 5에서 3으로 줄이자 훈련 점수는 올랐지만 테스트 점수는 낮아짐

![이웃 수별 예측](../assets/pdf/이웃-수별-예측.png)

점은 실제 훈련 농어, 선은 길이별 예측값

k가 작으면 가까운 데이터에 민감하고, k가 크면 평균을 내는 범위가 커져 변화가 완만해짐

k=42는 모든 훈련 농어의 평균 무게를 예측. 테스트 평균과는 다를 수 있어 테스트 R²는 음수가 될 수 있음
