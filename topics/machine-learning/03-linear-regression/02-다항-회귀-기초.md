# 다항 회귀

본문 코드는 개념별 부분 코드. 데이터 준비부터 독립 실행할 때는 [전체 실습](03-회귀-잔차-예제.md)을 사용.


## 길이의 제곱을 특성으로 추가

- 직선으로 농어 길이와 무게의 굽어진 관계를 표현하기 어려워 길이²를 새 특성으로 만든다.
- 길이²는 추가 측정값이 아니라 기존 길이를 가공한 값이다. 타깃인 무게는 바꾸지 않는다.

```python
import numpy as np
from sklearn.linear_model import LinearRegression

train_poly = np.column_stack((train_input ** 2, train_input))
test_poly = np.column_stack((test_input ** 2, test_input))
lr = LinearRegression()
lr.fit(train_poly, train_target)
print(lr.predict([[50 ** 2, 50]]))  # 약 1573.98g
print(lr.coef_, lr.intercept_)
```

- 입력 순서는 $[x^2, x]$이고 $x$는 길이다. 예측할 때도 훈련 때와 특성의 개수와 순서를 맞춘다.

$$
\hat{y} = ax^2 + bx + c \approx 1.0143x^2 - 21.5579x + 116.0502
$$

- $\hat{y}$는 예측 무게, $a$와 $b$는 각 특성의 계수, $c$는 절편이다.

### 곡선인데 선형 회귀인 이유

$x$를 제곱한 새 특성을 사용하므로 원래 길이 $x$에 대한 예측선은 곡선이 된다. 하지만 모델은 $x^2$과 $x$에 각각 계수를 곱하고 절편을 더한다. 학습하는 계수 $a, b, c$가 서로 곱해지거나 제곱되는 형태는 아니므로 계수에 대해서는 선형이다.

예측 입력은 `[길이², 길이]` 순서다. `[[50]]`에는 길이²가 빠져 있으므로 `[[50**2, 50]]`으로 입력한다.

![직선과 다항 회귀의 테스트 잔차](../assets/잔차-비교.png)

가로축은 농어의 실제 길이, 세로축은 실제 무게에서 예측 무게를 뺀 잔차(g)다. 점 하나는 테스트 농어 한 마리이며 0에 가까울수록 오차가 작다. 왼쪽 직선 모델은 가장 짧은 농어에서 큰 양의 잔차가 보이고, 오른쪽 다항 모델은 그 점이 0에 가깝다. 하나의 테스트 분할로 모든 길이에서 다항 모델이 낫다고 단정할 수는 없다. 두 모델의 예측, `np.abs()`, `np.argsort()`, `[-3:][::-1]`로 큰 잔차를 찾는 코드는 [잔차 실습](03-회귀-잔차-예제.md)에 있다.

## 잔차로 비교하기

잔차는 실제 무게에서 예측 무게를 뺀 값이다. 양수는 실제보다 작게 예측했고, 음수는 실제보다 크게 예측한 경우다. 잔차를 길이별로 그리면 특정 길이에서 오차가 반복되는지 살펴볼 수 있다.

8.4cm 테스트 농어는 실제 5.9g이다. 직선 회귀 예측은 약 -381.27g, 다항 회귀는 약 6.53g이다. 직선이 짧은 길이 영역에서 실제 무게와 크게 벗어날 수 있음을 보여 주는 사례다. 테스트는 14마리이므로 이 한 사례만으로 모든 길이에서의 성능을 단정하지 않는다.

## 같은 데이터에서 비교

| 모델 | 50cm 예측 | 테스트 R² | 테스트 MAE |
| --- | --- | --- | --- |
| KNN 회귀 k=3 | 약 1,033g | 약 0.9746 | 약 35.42g |
| 직선 회귀 | 약 1,242g | 약 0.8248 | 약 94.46g |
| 2차 다항 회귀 | 약 1,574g | 약 0.9776 | 약 37.77g |

- 50cm 농어의 실제 무게를 1,500g으로 가정한 예시다. 이 한 사례에서는 다항 회귀가 더 가까웠다.
- 50cm는 훈련 범위 밖이므로 다른 범위 밖 입력에도 정확하다고 보장할 수 없다.
- 이 테스트에서 다항 회귀는 직선 회귀보다 R²가 높고 MAE가 낮았다. 그렇다고 모든 데이터에서 더 좋다는 뜻은 아니다.

## 훈련 범위 밖에서 예측 비교

앞에서 분할한 농어의 `train_input`, `train_target`을 사용해 세 모델을 같은 조건에서 학습한다.

```python
import numpy as np
from sklearn.neighbors import KNeighborsRegressor
from sklearn.linear_model import LinearRegression

knr = KNeighborsRegressor(n_neighbors=3).fit(train_input, train_target)
linear = LinearRegression().fit(train_input, train_target)
train_poly = np.column_stack((train_input ** 2, train_input))
poly = LinearRegression().fit(train_poly, train_target)

print(knr.predict([[50], [100]]))
print(linear.predict([[50]]))
print(poly.predict([[50 ** 2, 50]]))
```

```text
[1033.33333333 1033.33333333]
[1241.83860323]
[1573.98423528]
```

예측선을 그리는 코드:

```python
import matplotlib.pyplot as plt

x = np.linspace(8, 60, 500).reshape(-1, 1)
x_poly = np.column_stack((x ** 2, x))
plt.scatter(train_input[:, 0], train_target, s=22, alpha=0.65, label='Training data')
plt.plot(x, knr.predict(x), label='KNN (k=3)')
plt.plot(x, linear.predict(x), label='Linear')
plt.plot(x, poly.predict(x_poly), label='Polynomial (degree=2)')
plt.axvline(train_input.max(), linestyle='--', color='gray', label='Training maximum')
plt.xlabel('Length (cm)')
plt.ylabel('Predicted weight (g)')
plt.legend()
plt.show()
```

![KNN, 선형 회귀와 다항 회귀 예측 비교](../assets/회귀모델-비교.png)

`x`는 8cm부터 60cm까지 예측할 길이 500개이고, `x_poly`는 같은 길이를 `[길이², 길이]` 순서로 변환한 입력이다. 다항 모델은 훈련할 때 두 열을 사용했으므로 예측할 때도 두 열이 필요하다. `axvline()`은 훈련 길이의 최댓값을 점선으로 표시한다.

가로축은 길이(cm), 세로축은 예측 무게(g)다. 점은 훈련 농어의 실제 무게이며, 선은 각 모델의 예측이다.

- 파란 KNN 선: 큰 길이에서 같은 이웃을 선택하므로 예측이 일정해진다. 코드의 50cm와 100cm 예측이 모두 약 1,033g이다.
- 주황 선형 회귀선: 직선을 연장하므로 길이가 일정하게 증가할 때 예측도 일정하게 증가한다.
- 초록 다항 회귀선: 길이의 제곱 특성을 사용해 곡선으로 예측한다.

점선 오른쪽은 훈련 범위 밖이다. 예측이 계산되더라도 실제 무게가 확인되지 않은 입력에서 정확하다고 보장할 수 없다. 그래프는 실습 데이터를 사용해 직접 생성했다.
