# 2. 선형 회귀와 모델 파라미터

KNN은 훈련 사례의 정답을 평균했음. 이번에는 길이가 변할 때 무게가 어떻게 변하는지 직선식으로 표현함. 입력 특성이 하나인 선형 회귀는 훈련 데이터에 맞는 직선을 찾는 모델임.

## 직선을 정하는 두 값

$$
\hat y=ax+b
$$

$x$는 농어 길이, $\hat y$는 예측 무게. 기울기 $a$는 길이가 1cm 증가할 때 예측 무게가 몇 g 변하는지 나타냄. 절편 $b$는 길이 0에서 식이 출력하는 값으로 직선의 위아래 위치를 정함.

여러 직선 중 어떤 것이 잘 맞는지는 실제 무게와 예측 무게의 차이로 비교함. 선형 회귀는 훈련 샘플들의 차이를 제곱해 더한 값이 작아지는 계수와 절편을 찾음. 길이가 길수록 무거운 현재 데이터에서는 오른쪽 위로 증가하는 관계를 학습함.

```python
from sklearn.linear_model import LinearRegression

lr_linear = LinearRegression()
lr_linear.fit(train_input, train_target)
print(lr_linear.coef_, lr_linear.intercept_)
print(lr_linear.predict([[50]]))
print(round(lr_linear.score(train_input, train_target), 4),
      round(lr_linear.score(test_input, test_target), 4))
```

```text
[39.01714496] -709.0186449535477
[1241.83860323]
0.9398 0.8248
```

앞 파일의 같은 훈련과 테스트를 사용함. `fit()`이 찾은 기울기는 약 39.0171, 절편은 약 -709.0186이며 각각 `coef_`, `intercept_`에 저장됨.

$$
\hat y\approx39.0171x-709.0186
$$

50cm에서는 $39.0171\times50-709.0186\approx1241.84$g이 됨. KNN의 약 1,033g보다 큰 값을 예측하며 길이가 더 늘면 같은 직선의 연장선에서 다시 계산함.

## 모델 파라미터와 하이퍼파라미터 구분하기

기울기와 절편은 직접 지정하지 않고 훈련 데이터에서 찾은 값이므로 모델 파라미터임. 반면 KNN의 k=3은 학습 전에 사람이 정한 하이퍼파라미터임. 누가 어떤 과정에서 정하는지가 다름.

선형 회귀처럼 파라미터를 찾아 식으로 예측하는 것을 모델 기반 학습, KNN처럼 저장한 훈련 사례에서 이웃을 찾는 것을 사례 기반 학습으로 구분할 수 있음.

![기울기와 절편](../assets/기울기와-절편.png)

그림에서 기울기가 달라지면 직선의 올라가는 정도가 달라지고, 절편이 달라지면 위아래 위치가 달라짐. 이번 절편이 음수라는 것은 실제 길이 0인 농어의 무게를 측정했다는 뜻이 아니라 데이터에 맞춘 직선의 위치임.

| 구분 | 결정하는 주체 | 예 |
| --- | --- | --- |
| 모델 파라미터 | 훈련 데이터에서 모델이 학습 | 선형 회귀의 기울기와 절편 |
| 하이퍼파라미터 | 모델을 학습하기 전에 사용자가 지정 | KNN의 이웃 수 k |

둘 다 예측 결과에 영향을 주지만, 데이터로부터 학습되는 값인지 학습 조건으로 정하는 값인지가 다름.

## 예측 직선과 데이터 함께 그리기

```python
point = np.array([[15.0], [50.0]])
plt.scatter(train_input[:, 0], train_target)
plt.plot(point[:, 0], lr_linear.predict(point))
plt.scatter(50, lr_linear.predict([[50]])[0], marker='^')
plt.xlabel('Length (cm)')
plt.ylabel('Weight (g)')
plt.show()
```

15cm와 50cm에서 모델이 예측한 두 점을 연결하면 학습한 직선을 그릴 수 있음. 산점도는 실제 훈련 농어이고 삼각형은 50cm의 예측값임. `predict()`는 모델의 실제 계수를 사용하므로 반올림 식을 직접 계산한 값과 끝자리가 조금 다를 수 있음.

훈련 R²는 약 0.9398, 테스트는 약 0.8248. 직선으로 범위 밖 값을 계산할 수 있게 됐지만 그 값이 반드시 정확한 것은 아님. 다음에는 이 점수와 산점도를 함께 보며 직선이 놓치는 관계를 확인함.
