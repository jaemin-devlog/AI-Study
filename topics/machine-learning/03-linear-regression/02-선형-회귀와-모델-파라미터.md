# 2. 선형 회귀와 모델 파라미터

학습 범위: 6에서 10쪽

## 직선의 계수 학습

$$
\hat y=ax+b
$$

$x$는 길이, $\hat y$는 예측 무게. $a$는 길이가 1cm 늘 때 무게 예측이 얼마나 바뀌는지 나타내는 기울기, $b$는 길이 0일 때 직선식의 값인 절편.

선형 회귀는 훈련 데이터의 실제값과 예측값 사이의 제곱오차 합을 작게 만드는 계수와 절편을 찾음.

```python
from sklearn.linear_model import LinearRegression

lr_linear = LinearRegression()
lr_linear.fit(train_input, train_target)
print(lr_linear.coef_, lr_linear.intercept_)
print(lr_linear.predict([[50]]))
print(round(lr_linear.score(train_input, train_target), 4),
      round(lr_linear.score(test_input, test_target), 4))
```

```text
[39.01714496] -709.0186449535477
[1241.83860323]
0.9398 0.8248
```

`coef_`와 `intercept_`는 모델이 학습한 파라미터. KNN의 k처럼 사람이 정하는 하이퍼파라미터와 다름. 선형 회귀는 학습한 식으로 예측하는 모델 기반 학습, KNN은 훈련 사례를 참고하는 사례 기반 학습으로 구분할 수 있음.

## 기울기와 절편 읽기

$$
\hat y\approx39.017x-709.019
$$

길이가 1cm 늘면 예측 무게는 약 39.017g 늘어남. 절편이 음수라는 것은 실제 0cm 농어의 무게를 관측한 결과가 아니라 학습한 직선의 위치를 뜻함.

![기울기와 절편](../assets/기울기와-절편.png)

```python
point = np.array([[15.0], [50.0]])
plt.scatter(train_input[:, 0], train_target)
plt.plot(point[:, 0], lr_linear.predict(point))
plt.scatter(50, lr_linear.predict([[50]])[0], marker='^')
plt.xlabel('Length (cm)')
plt.ylabel('Weight (g)')
plt.show()
```

직선은 두 점을 연결해도 전체 식을 나타낼 수 있음. 50cm 예측은 KNN보다 커졌지만, 훈련 범위 밖의 값을 계산할 수 있다는 사실이 그 값의 정확성을 보장하지는 않음.
