# 5. 회귀식 계산과 세 모델 비교

같은 농어를 학습했어도 KNN, 직선, 다항 회귀는 결과를 만드는 원리가 다름. 앞의 `knr`는 이웃 세 마리의 평균, `lr_linear`는 직선식, `lr_poly`는 2차식을 사용함. 세 모델의 훈련 길이 범위는 13.7cm부터 44cm까지임.

## 학습한 계수로 40cm 예측 직접 계산하기

직선에는 길이 40을 넣고, 2차식에는 40의 제곱과 40을 넣음. 계수를 출력에서 옮겨 적어 반올림하지 않고 모델 속성에서 직접 가져옴.

```python
length_value = 40.0
linear_manual = lr_linear.coef_[0] * length_value + lr_linear.intercept_
poly_manual = (lr_poly.coef_[0] * length_value**2
               + lr_poly.coef_[1] * length_value + lr_poly.intercept_)
print(round(linear_manual, 2), round(poly_manual, 2))
print(np.isclose(linear_manual, lr_linear.predict([[40]])[0]))
print(np.isclose(poly_manual, lr_poly.predict([[1600, 40]])[0]))
```

```text
851.67 876.66
True
True
```

직선은 약 851.67g, 2차식은 약 876.66g. 두 `True`는 직접 계산과 모델의 `predict()`가 가까운 값이라는 뜻임. `np.isclose()`는 부동소수점 계산의 작은 차이를 허용해 비교함.

이로써 `predict()`가 별도의 임의 숫자를 만드는 것이 아니라 학습된 계수와 절편의 식을 계산한다는 것을 확인함. 두 결과 중 어떤 것이 실제로 더 가까운지는 그 농어의 정답이 있어야 평가할 수 있음.

## 훈련 범위 안과 밖에서 비교하기

```python
lengths = np.array([30, 40, 50, 60]).reshape(-1, 1)
lengths_poly = np.column_stack((lengths**2, lengths))
for x, a, b, c in zip(lengths[:, 0], knr.predict(lengths),
                       lr_linear.predict(lengths), lr_poly.predict(lengths_poly)):
    print(x, round(a, 2), round(b, 2), round(c, 2))
```

```text
30 275.0 461.5 382.21
40 921.67 851.67 876.66
50 1033.33 1241.84 1573.98
60 1033.33 1632.01 2474.17
```

출력은 길이, KNN, 직선, 2차식 순서. 30cm와 40cm는 훈련 범위 안이고 50cm와 60cm는 밖임. 같은 입력이어도 결과가 다른 이유는 학습한 예측 방식이 다르기 때문임.

KNN은 50cm와 60cm에서 같은 세 이웃을 골라 약 1,033.33g으로 같음. 직선은 기울기가 일정해 길이가 10cm 늘면 약 390.17g씩 증가함. 2차식은 길이 제곱 항이 있어 큰 길이에서 증가 폭도 커짐.

![세 회귀 모델 비교](../assets/pdf/세-회귀모델.png)

그림의 훈련 최댓값 표시를 기준으로 오른쪽이 범위 밖임. 이곳에서는 모델 간 예측 차이가 커짐. 선이 계속 그려진다는 것과 그 영역에서 정확한지는 다른 문제임.

```python
x_grid = np.linspace(train_input.min(), 60, 400).reshape(-1, 1)
plt.scatter(train_input[:, 0], train_target, alpha=0.6)
plt.plot(x_grid[:, 0], knr.predict(x_grid), label='KNN')
plt.plot(x_grid[:, 0], lr_linear.predict(x_grid), label='Linear')
plt.plot(x_grid[:, 0], lr_poly.predict(np.column_stack((x_grid**2, x_grid))), label='Polynomial')
plt.axvline(train_input.max(), linestyle=':')
plt.legend()
plt.show()
```

`linspace()`로 촘촘한 길이를 만들고 각 모델의 `predict()` 결과를 그림. 다항 모델에만 제곱 열을 추가하며, `axvline()`은 훈련 최대 길이를 표시함. 점들은 훈련 데이터여서 범위 밖 예측의 정답을 보여 주지는 않음.

## 정답 없는 출력으로 판단할 수 있는 범위

처음 50cm와 1,500g을 비교한 상황은 정답을 가정해 제공한 사례였음. 여기서 길이 50과 60만 입력해 얻은 표 자체에는 새 관측 정답이 없음. 특히 60cm에서 어떤 모델이 더 정확한지는 예측값만으로 고를 수 없음.

35, 45, 55, 65cm로 바꿔도 같은 방식으로 비교할 수 있고 이 분할의 KNN은 45cm부터 같은 이웃을 사용함. 다음에는 실제 무게를 알고 있는 테스트 14마리에서 예측 오차를 직접 분석함.
