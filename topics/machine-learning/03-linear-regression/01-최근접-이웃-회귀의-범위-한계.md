# 1. 최근접 이웃 회귀의 범위 한계

앞의 KNN 회귀는 길이가 가까운 농어들의 무게를 평균해 예측했음. 이번에는 훈련에서 본 농어보다 훨씬 긴 농어가 들어와도 그 방식이 적절한지 확인함. 입력과 정답은 앞 파트와 같은 농어 56마리의 길이와 무게임.

## 훈련 범위 밖의 입력 준비하기

50cm 농어의 무게가 1,500g이라고 주어진 상황을 생각해 봄. 모델이 무게를 예측할 때는 길이 50cm만 입력하며, 1,500g은 결과를 비교하기 위해 주어진 값임. 이 값은 아래 56마리 데이터에 추가되는 훈련 정답이 아님.

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsRegressor

perch_length = np.array([
    8.4, 13.7, 15.0, 16.2, 17.4, 18.0, 18.7, 19.0, 19.6, 20.0,
    21.0, 21.0, 21.0, 21.3, 22.0, 22.0, 22.0, 22.0, 22.0, 22.5,
    22.5, 22.7, 23.0, 23.5, 24.0, 24.0, 24.6, 25.0, 25.6, 26.5,
    27.3, 27.5, 27.5, 27.5, 28.0, 28.7, 30.0, 32.8, 34.5, 35.0,
    36.5, 36.0, 37.0, 37.0, 39.0, 39.0, 39.0, 40.0, 40.0, 40.0,
    40.0, 42.0, 43.0, 43.0, 43.5, 44.0,
])

perch_weight = np.array([
    5.9, 32.0, 40.0, 51.5, 70.0, 100.0, 78.0, 80.0, 85.0, 85.0,
    110.0, 115.0, 125.0, 130.0, 120.0, 120.0, 130.0, 135.0, 110.0, 130.0,
    150.0, 145.0, 150.0, 170.0, 225.0, 145.0, 188.0, 180.0, 197.0, 218.0,
    300.0, 260.0, 265.0, 250.0, 250.0, 300.0, 320.0, 514.0, 556.0, 840.0,
    685.0, 700.0, 700.0, 690.0, 900.0, 650.0, 820.0, 850.0, 900.0, 1015.0,
    820.0, 1100.0, 1000.0, 1100.0, 1000.0, 1000.0,
])

train_input, test_input, train_target, test_target = train_test_split(
    perch_length, perch_weight, random_state=42
)
train_input = train_input.reshape(-1, 1)
test_input = test_input.reshape(-1, 1)
knr = KNeighborsRegressor(n_neighbors=3)
knr.fit(train_input, train_target)
print(knr.predict([[50], [100]]))
```

```text
[1033.33333333 1033.33333333]
```

같은 `random_state=42`로 훈련 42마리와 테스트 14마리를 나누고, 입력을 길이 한 열로 바꿈. 이웃 수는 3개임. 훈련 길이는 13.7cm부터 44cm까지인데 50cm와 100cm를 넣었더니 둘 다 약 1,033.33g이 나옴.

길이가 두 배인데 왜 같은 값을 예측할까? KNN의 결과를 확인하려면 먼저 어떤 이웃이 선택됐는지 살펴봐야 함.

## 이웃이 같으면 평균도 같음

```python
distances, indexes = knr.kneighbors([[50]])
print(train_input[indexes[0], 0])
print(train_target[indexes[0]])
print(train_target[indexes[0]].mean())
```

```text
[44. 43. 43.]
[1000. 1000. 1100.]
1033.3333333333333
```

50cm에서 가장 가까운 훈련 농어는 44cm, 43cm, 43cm이고 무게는 1,000g, 1,000g, 1,100g임.

$$
\hat y=\frac{1000+1000+1100}{3}\approx1033.33\ \mathrm{g}
$$

100cm를 넣어도 가장 가까운 세 마리는 같음. 이웃까지의 거리는 늘어나지만 기본 균일 가중치에서는 같은 세 무게를 평균하므로 예측은 그대로임.

![훈련 범위 밖의 이웃](../assets/훈련범위-밖-이웃.png)

그림의 마름모는 선택된 이웃, 삼각형은 모델의 예측 위치. 삼각형 높이를 실제 50cm나 100cm 농어에서 관측한 정답으로 읽으면 안 됨. 새 입력이 훈련 점들에서 멀어졌어도 모델이 참조할 수 있는 사례는 그대로임.

## 관계를 범위 밖으로 연장하지 않는 방식

KNN은 길이가 증가할 때 무게가 얼마나 증가하는지 관계식을 만들어 연장하지 않음. 훈련에서 고른 이웃의 정답을 사용하므로 같은 이웃이 선택되는 구간의 예측은 같음. 이것이 이번 범위 밖 입력에서 확인한 한계임.

50cm에 주어진 1,500g과 비교하면 약 1,033g은 차이가 큼. 단순히 이웃 수만 고치는 것 외에 길이와 무게 사이의 증가 관계를 식으로 학습하는 방법도 생각할 수 있음. 다음에는 훈련 데이터에 맞는 직선의 기울기와 절편을 찾음.
