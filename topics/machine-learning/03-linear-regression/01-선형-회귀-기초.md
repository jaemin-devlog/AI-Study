# 선형 회귀와 KNN의 한계

본문 코드는 개념별 부분 코드. 데이터 준비부터 독립 실행할 때는 [전체 실습](03-회귀-잔차-예제.md)을 사용.


## 훈련 범위 밖의 KNN 예측

- 길이 50cm 농어의 실제 무게가 1,500g인 예시에서 k=3인 KNN 회귀는 약 1,033g으로 예측한다.
- 50cm와 100cm는 모두 훈련 데이터의 가장 큰 농어 3마리를 이웃으로 선택해 같은 평균 무게를 예측한다.
- KNN 회귀는 길이에 따른 증가 추세를 식으로 연장하지 않는다. 선택한 이웃의 타깃값을 평균 낸다.

![훈련 범위 밖 농어와 이웃](../assets/훈련범위-밖-이웃.png)

가로축은 길이(cm), 세로축은 무게(g)다. 파란 점은 훈련 농어, 주황 마름모는 선택된 이웃, 초록 삼각형은 예측이다. 50cm와 100cm에서 같은 세 이웃을 사용해 같은 무게를 예측한다. 삼각형은 실제 생선의 측정값이 아니다. 50cm의 1,500g은 예시 조건이며 제공된 테스트 세트의 실제 관측값으로 확인한 수치가 아니다.

[이웃 확인 실행 코드](03-회귀-잔차-예제.md)에서는 길이 입력 `(42, 1)`과 무게 정답 `(42,)`으로 k=3 모델을 학습하고 `kneighbors()`의 행 번호로 이웃 무게를 확인한다.

## 선형 회귀가 필요한 이유

KNN 회귀는 훈련 범위 바깥에서 같은 끝쪽 이웃을 계속 선택하면 예측값이 일정하게 유지된다. 선형 회귀는 입력과 타깃의 관계를 식으로 나타내므로 범위 밖에서도 식을 계산할 수 있다. 다만 훈련하지 않은 범위에서 그 관계가 계속 유지된다는 보장은 없다.

## 선형 회귀

```python
from sklearn.linear_model import LinearRegression

lr = LinearRegression()
lr.fit(train_input, train_target)
print(lr.predict([[50]]))
print(lr.coef_, lr.intercept_)
```

- `train_input`은 길이 1개를 가진 2차원 입력, `train_target`은 농어의 무게다.
- 실습에서 50cm 예측은 약 1,241.84g, 기울기는 약 39.02, 절편은 약 -709.02다.
길이를 $x$, 예측 무게를 $\hat{y}$라고 하면 학습한 직선은 다음과 같다.

$$
\hat{y} = ax + b \approx 39.02x - 709.02
$$

- $a$는 기울기, $b$는 절편이다.
- 길이가 1cm 증가하면 예측 무게가 약 39.02g 증가한다. `coef_`는 계수, `intercept_`는 절편이다.
- 훈련 범위 밖에서도 직선을 연장해 계산할 수 있지만, 계산이 가능하다는 것과 정확하다는 것은 다르다.

![선형 회귀의 기울기와 절편](../assets/기울기와-절편.png)

직선은 학습한 계수와 절편으로 구한 예측값이다. 가로축은 길이(cm), 세로축은 예측 무게(g)다. 점선은 길이 30cm에서 40cm로 10cm 늘었을 때 예측 무게가 약 390g 증가하는 모습을 나타낸다. 증가량을 길이 변화로 나누면 기울기 약 39g/cm다. 길이 0의 점은 수학적 절편이며 실제 농어 관측값이 아니다. 그림 생성은 [코드](../examples/06-그림-생성.py) 참고.

### 파라미터와 하이퍼파라미터

- 모델 파라미터: 데이터로 학습해 구하는 값. 선형 회귀의 계수와 절편이 해당한다.
- 하이퍼파라미터: 학습 전에 설정하는 값. KNN의 이웃 수 k가 해당한다.

### KNN과 선형 회귀는 무엇을 학습할까?

KNN 회귀는 예측할 입력이 들어올 때 가까운 훈련 농어를 찾고 그 무게를 평균 낸다. 선형 회귀는 훈련 데이터의 오차를 줄이는 방향으로 기울기와 절편을 정하고, 예측할 때 이 식에 길이를 대입한다.

직선 회귀는 길이가 10cm 늘 때마다 예측값이 같은 양만큼 증가하지만, 실제 농어의 무게는 길이에 따라 증가 폭이 커질 수 있다. 따라서 모델의 식이 데이터의 모양을 충분히 표현하는지 확인해야 한다.

## 데이터와 예측선 확인

- 농어의 길이와 무게는 길이가 커질수록 증가 폭도 커지는 곡선 경향이 있어 직선만으로 충분히 표현하기 어려울 수 있다.
- 직선 모델의 테스트 R²는 약 0.8248이고 MAE는 약 94.46g이다. 예시에서 8.4cm 농어에 음수 무게를 예측하기도 한다.
- 점수뿐 아니라 데이터 분포와 잔차를 함께 살펴본다.
