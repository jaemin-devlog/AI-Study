# 6. 잔차 분석과 모델 개선

모델 간 예측 차이를 확인했지만 어느 구간에서 얼마나 틀렸는지는 실제 정답과 비교해야 함. 이번에는 같은 테스트 농어 14마리에서 직선과 2차식의 잔차를 구함. 앞 파일의 `lr_linear`, `lr_poly`, `test_input`, `test_poly`를 사용함.

## 잔차의 부호로 예측 방향 읽기

$$
e_i=y_i-\hat y_i
$$

잔차는 실제값에서 예측값을 뺀 값. 양수면 실제 무게가 더 커 모델이 가볍게 예측한 것이고, 음수면 실제보다 무겁게 예측한 것임. 0에 가까울수록 두 값이 가까움.

```python
from sklearn.metrics import mean_absolute_error

linear_prediction = lr_linear.predict(test_input)
poly_prediction = lr_poly.predict(test_poly)
linear_residual = test_target - linear_prediction
poly_residual = test_target - poly_prediction
idx = np.argmin(test_input[:, 0])
print(test_input[idx, 0], test_target[idx])
print(round(linear_prediction[idx], 2), round(linear_residual[idx], 2))
print(round(poly_prediction[idx], 2), round(poly_residual[idx], 2))
print(round(mean_absolute_error(test_target, linear_prediction), 2),
      round(mean_absolute_error(test_target, poly_prediction), 2))
```

```text
8.4 5.9
-381.27 387.17
6.53 -0.63
94.46 37.77
```

`argmin()`으로 테스트에서 가장 짧은 농어의 위치를 찾음. 이 농어는 길이 8.4cm, 실제 무게 5.9g이며 훈련 최소 13.7cm보다 작으므로 테스트 안에도 훈련 범위 밖 샘플이 있는 것임.

직선은 약 -381.27g을 예측해 잔차가 $5.9-(-381.27)\approx387.17$g. 실제보다 매우 가볍고 무게가 음수라는 문제도 보임. 2차식은 약 6.53g으로 잔차가 약 -0.63g이므로 이 샘플에서는 실제와 가까움.

테스트 MAE는 직선 약 94.46g, 2차식 약 37.77g임. 앞의 테스트 R² 약 0.8248과 0.9776도 같은 비교를 다른 기준에서 보여 줌. 잔차 제곱합이 줄면 R²가 높아지고 절댓값 평균이 줄면 MAE가 낮아짐.

## 길이별로 오차가 치우치는지 확인하기

```python
fig, axes = plt.subplots(1, 2, figsize=(12, 4), sharey=True)
for ax, residual, name in zip(axes, [linear_residual, poly_residual], ['Linear', 'Polynomial']):
    ax.scatter(test_input[:, 0], residual)
    ax.axhline(0, linestyle='--')
    ax.set_title(name)
    ax.set_xlabel('Length (cm)')
axes[0].set_ylabel('Actual - predicted (g)')
plt.tight_layout()
plt.show()
```

![잔차 비교](../assets/잔차-비교.png)

가로축은 길이, 세로축은 잔차. 0선 위는 가볍게 예측, 아래는 무겁게 예측한 경우임. `sharey=True`로 같은 세로축을 사용해야 오차 크기를 나란히 비교하기 쉬움.

왼쪽 직선 모델에서 특정 길이 구간의 잔차가 한 방향으로 크면 모델이 그 구간의 관계를 놓치는지 살펴봄. 오른쪽 2차식은 전반적으로 0에 가까워졌지만 모든 점이 좋아진 것은 아님. 샘플이 14개이므로 모양만으로 모든 길이의 성능을 확정하지 않음.

## 평균이 좋아져도 개별 오차는 커질 수 있음

```python
worst = np.argsort(np.abs(linear_residual))[-3:][::-1]
for i in worst:
    print(test_input[i, 0], round(linear_residual[i], 2), round(poly_residual[i], 2))
idx = np.argmax(test_input[:, 0])
print('가장 긴 농어', test_input[idx, 0],
      round(linear_residual[idx], 2), round(poly_residual[idx], 2))
```

```text
8.4 387.17 -0.63
30.0 -141.5 -62.21
28.0 -133.46 -57.66
가장 긴 농어 43.5 11.77 -97.65
```

`np.abs()`는 잔차의 크기만 남기고 `argsort()`는 작은 값부터의 위치를 구함. 마지막 세 위치를 역순으로 선택해 직선에서 크게 틀린 농어를 확인함. 같은 위치의 다항 잔차와 비교하므로 서로 다른 농어를 비교하는 것이 아님.

가장 긴 43.5cm 농어에서는 직선 잔차 약 +11.77g, 다항 잔차 약 -97.65g임. 이 농어는 직선이 더 정확함. 전체 MAE가 작은 모델도 모든 샘플에서 더 정확한 것은 아니며 이번 테스트에서는 세 마리가 다항 쪽에서 더 큰 오차를 보임.

KNN의 사례 평균에서 직선식, 제곱 특성을 사용한 곡선으로 확장하면서 예측 방식과 오차를 함께 확인했음. 다음에는 길이뿐 아니라 높이와 두께도 사용하고, 특성을 많이 만들었을 때 과대적합을 조절하는 규제를 배움.
