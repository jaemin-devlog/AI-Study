## 잔차로 오차의 방향과 크기 확인

$$
e_i=y_i-\hat y_i
$$

양의 잔차는 실제값이 더 커서 가볍게 예측했다는 뜻. 음수는 무겁게 예측, 0에 가까우면 실제값과 가까움.

```python
from sklearn.metrics import mean_absolute_error

linear_prediction = lr_linear.predict(test_input)
poly_prediction = lr_poly.predict(test_poly)
linear_residual = test_target - linear_prediction
poly_residual = test_target - poly_prediction
idx = np.argmin(test_input[:, 0])
print(test_input[idx, 0], test_target[idx])
print(round(linear_prediction[idx], 2), round(linear_residual[idx], 2))
print(round(poly_prediction[idx], 2), round(poly_residual[idx], 2))
print(round(mean_absolute_error(test_target, linear_prediction), 2),
      round(mean_absolute_error(test_target, poly_prediction), 2))
```

```text
8.4 5.9
-381.27 387.17
6.53 -0.63
94.46 37.77
```

`argmin()`은 가장 짧은 농어의 위치. 8.4cm는 훈련 최솟값 13.7cm보다 작으므로 이 테스트 샘플도 훈련 범위 밖임. 직선의 음수 예측이 큰 잔차로 나타남.

## 같은 세로축으로 잔차 그래프 비교

```python
fig, axes = plt.subplots(1, 2, figsize=(12, 4), sharey=True)
for ax, residual, name in zip(axes, [linear_residual, poly_residual], ['Linear', 'Polynomial']):
    ax.scatter(test_input[:, 0], residual)
    ax.axhline(0, linestyle='--')
    ax.set_title(name)
    ax.set_xlabel('Length (cm)')
axes[0].set_ylabel('Actual - predicted (g)')
plt.tight_layout()
plt.show()
```

![잔차 비교](../assets/잔차-비교.png)

왼쪽의 잔차는 길이에 따라 같은 방향으로 치우치는 구간이 있음. 오른쪽은 0 주변으로 더 가까워졌지만 모든 점이 개선된 것은 아님. 같은 축을 사용해야 오차의 크기를 공정하게 비교하기 쉬움.

## 많이 틀린 샘플과 평균의 한계

```python
worst = np.argsort(np.abs(linear_residual))[-3:][::-1]
for i in worst:
    print(test_input[i, 0], round(linear_residual[i], 2), round(poly_residual[i], 2))
idx = np.argmax(test_input[:, 0])
print('가장 긴 농어', test_input[idx, 0],
      round(linear_residual[idx], 2), round(poly_residual[idx], 2))
```

```text
8.4 387.17 -0.63
30.0 -141.5 -62.21
28.0 -133.46 -57.66
가장 긴 농어 43.5 11.77 -97.65
```

`abs()`로 오차 크기만 남기고 `argsort()`로 작은 순서의 위치를 구함. 마지막 세 개를 역순으로 읽으면 큰 오차 순서가 됨.

다항 회귀는 테스트 MAE가 작고 R²가 높지만 가장 긴 농어에서는 직선이 더 정확함. 평균 성능이 좋다는 것과 모든 샘플에서 좋다는 것은 다름.

KNN의 이웃 평균에서 직선 계수 학습, 다항 특성 추가로 확장했음. 다음에는 길이 외에 높이와 두께를 추가하고 특성이 지나치게 많아졌을 때 계수를 제한하는 규제를 살펴봄.
