## 직선이 놓치는 관계

훈련 R² 0.9398, 테스트 R² 0.8248이라는 점수와 실제 산점도를 함께 살펴봄. 농어 무게는 길이가 늘면서 증가 폭도 커지는데 직선은 같은 길이 변화에 항상 같은 무게 변화를 예측함.

짧은 길이에서는 음수 무게도 출력하므로 현실적인 관계를 충분히 표현하지 못한 모습. 훈련 점수가 테스트보다 높다는 사실 하나보다 데이터의 곡선 형태를 직선이 놓친다는 점이 중요함.

## 길이 제곱을 새 열로 추가

```python
train_poly = np.column_stack((train_input ** 2, train_input))
test_poly = np.column_stack((test_input ** 2, test_input))
print(train_poly.shape, test_poly.shape)
lr_poly = LinearRegression()
lr_poly.fit(train_poly, train_target)
print(lr_poly.predict([[50**2, 50]]))
print(lr_poly.coef_, lr_poly.intercept_)
```

```text
(42, 2) (14, 2)
[1573.98423528]
[  1.01433211 -21.55792498] 116.0502107827827
```

입력 한 행은 `[길이², 길이]`. 첫 계수는 길이²에, 둘째는 길이에 곱함. 샘플 수와 정답 무게는 그대로이며 원래 길이를 가공한 입력 열만 추가됨.

$$
\hat y\approx1.01433211x^2-21.55792498x+116.05021078
$$

50cm를 넣을 때도 훈련 순서와 같은 `[[2500, 50]]`을 전달. `[[50]]`은 열 수가 다르고 `[[50, 2500]]`은 의미가 바뀌므로 같은 예측이 아님.

KNN의 약 1,033g, 직선의 약 1,242g보다 2차식의 약 1,574g이 예시 조건 1,500g에 가까움. 이 한 사례로 모든 범위 밖 예측이 정확하다고 일반화할 수는 없음.
