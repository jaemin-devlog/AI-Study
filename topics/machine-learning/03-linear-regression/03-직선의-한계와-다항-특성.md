# 3. 직선의 한계와 다항 특성

앞의 직선 모델은 길이가 1cm 늘 때마다 약 39.02g씩 같은 양을 더해 예측했음. 하지만 농어의 산점도는 길이가 늘수록 무게의 증가 폭도 커지는 굽은 형태. 직선 하나로는 이 관계를 충분히 표현하기 어려움.

## 점수 차이보다 먼저 볼 관계

훈련 R² 약 0.9398과 테스트 약 0.8248을 확인했지만 두 값의 차이만으로 모델 상태를 정하지 않음. 예측선이 실제 점들의 흐름을 따라가는지 살펴봐야 함.

직선을 짧은 길이까지 연장하면 무게가 음수가 되는 구간도 생김. 실제 무게는 음수일 수 없으므로 모델 형태가 놓치는 관계가 있다는 신호임. 이처럼 중요한 패턴을 표현하기에 모델이 부족한 경우를 과소적합과 연결해 이해할 수 있음.

## 길이의 제곱을 새로운 입력 열로 만들기

길이에 따라 증가 폭이 달라지는 관계를 표현하기 위해 2차식을 사용함.

$$
\hat y=ax^2+bx+c
$$

기존 길이 $x$에 길이 제곱 $x^2$을 추가하면 같은 선형 회귀 모델로 이 식의 계수를 찾을 수 있음. 새로운 농어를 측정하는 것이 아니라 원래 입력을 가공해 표현 방식을 바꾸는 것임.

```python
train_poly = np.column_stack((train_input ** 2, train_input))
test_poly = np.column_stack((test_input ** 2, test_input))
print(train_poly.shape, test_poly.shape)
lr_poly = LinearRegression()
lr_poly.fit(train_poly, train_target)
print(lr_poly.predict([[50**2, 50]]))
print(lr_poly.coef_, lr_poly.intercept_)
```

```text
(42, 2) (14, 2)
[1573.98423528]
[  1.01433211 -21.55792498] 116.0502107827827
```

`train_input ** 2`는 각 길이를 제곱함. `column_stack()`은 제곱한 값을 첫 열, 원래 길이를 둘째 열로 붙임. 따라서 한 행이 `[길이², 길이]`가 됨. 훈련은 여전히 42마리, 테스트는 14마리이고 정답 무게도 같음. 특성 수만 1개에서 2개로 늘어남.

## 두 계수를 예측식과 연결하기

첫 계수는 길이 제곱에, 둘째 계수는 길이에 곱해지고 절편은 마지막에 더해짐.

$$
\hat y\approx1.01433211x^2-21.55792498x+116.05021078
$$

50cm를 예측할 때도 `[2500, 50]` 순서를 맞춰야 함. `[[50]]`은 열이 부족하고 `[[50, 2500]]`은 두 열의 의미가 뒤바뀜. 학습 때의 특성 개수와 순서를 예측에서도 유지해야 함.

예측은 약 1,573.98g으로 KNN 약 1,033g과 직선 약 1,242g보다 주어진 1,500g에 가까움. 제곱 항으로 굽어진 관계를 표현할 수 있게 된 결과임. 다만 이 한 사례로 모든 범위 밖 입력에서도 정확하다고 판단할 수는 없음. 다음에는 곡선의 모양과 전체 테스트 결과를 함께 확인함.
