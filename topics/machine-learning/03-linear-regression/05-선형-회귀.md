# 선형 회귀

선형 회귀는 입력과 타깃 사이의 관계를 식으로 나타내는 모델

```python
from sklearn.linear_model import LinearRegression

lr = LinearRegression()
lr.fit(train_input, train_target)
print(lr.predict([[50]]))
print(lr.coef_, lr.intercept_)
```

```text
[1241.83860323]
[39.01714496] -709.0186449535474
```

`coef_`는 학습한 계수, `intercept_`는 절편

길이를 $x$, 예측 무게를 $\hat{y}$라고 하면 이 실습의 식은 다음과 같음

$$
\hat{y} \approx 39.02x - 709.02
$$

길이가 1cm 증가하면 예측 무게는 약 39.02g 증가

![기울기와 절편](../assets/기울기와-절편.png)

점선은 길이가 30cm에서 40cm로 늘 때 예측값이 증가하는 양. 절편은 입력이 0일 때 식의 값이며 실제 관측 무게는 아님

훈련 범위 밖도 계산할 수 있지만 계산된 값이 실제로 정확한지는 별도 확인 필요
