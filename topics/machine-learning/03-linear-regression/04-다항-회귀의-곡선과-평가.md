# 4. 다항 회귀의 곡선과 평가

학습 범위: 15에서 17쪽

## 곡선인데 왜 LinearRegression을 사용할까?

$$
\hat y=ax^2+bx+c
$$

원래 길이 $x$에 대해서는 곡선이지만 학습할 계수 $a$, $b$, $c$는 각각 특성에 곱해져 더해짐. 계수를 제곱하거나 계수끼리 곱하는 형태가 아니므로 계수에 대해 선형인 모델임.

## 모델의 실제 예측으로 곡선 그리기

```python
point = np.arange(15, 50)
point_poly = np.column_stack((point ** 2, point))
plt.scatter(train_input[:, 0], train_target)
plt.plot(point, lr_poly.predict(point_poly))
plt.scatter(50, lr_poly.predict([[50**2, 50]])[0], marker='^')
plt.xlabel('Length (cm)')
plt.ylabel('Weight (g)')
plt.show()
print(round(lr_poly.score(train_poly, train_target), 4),
      round(lr_poly.score(test_poly, test_target), 4))
```

```text
0.9707 0.9776
```

`arange(15, 50)`은 15부터 49까지 생성. 예측용 길이도 제곱 열을 추가하고 `predict()`에 전달해 모델에 저장된 실제 계수로 계산함. 반올림한 계수를 직접 그래프 식에 넣는 오차를 줄일 수 있음.

| 모델 | 훈련 R² | 테스트 R² |
| --- | --- | --- |
| 직선 | 0.9398 | 0.8248 |
| 2차식 | 0.9707 | 0.9776 |

두 점수가 모두 개선됨. 데이터의 굽어진 흐름을 표현하도록 입력을 바꾼 것이 이번 데이터에서는 도움이 된 결과임. 특성을 추가하면 항상 성능이 좋아진다는 뜻은 아님.

테스트 점수가 훈련보다 조금 높다는 이유만으로 과소적합이라고 판단하지 않음. 모델이 관계를 얼마나 충분히 표현하는지 함께 확인해야 함.
