# 4. 다항 회귀의 곡선과 평가

앞에서 길이를 `[길이², 길이]`로 바꾸어 `lr_poly`를 학습했음. 원래 길이를 가로축에 놓으면 예측선은 곡선인데 여전히 `LinearRegression`을 사용함. 여기서 선형이 무엇을 뜻하는지 구분해야 함.

## 입력의 곡선과 계수의 선형성

$$
\hat y=ax^2+bx+c
$$

길이 $x$는 제곱되지만 학습하는 계수 $a$, $b$, $c$는 제곱되거나 서로 곱해지지 않음. 준비한 각 특성에 계수를 곱한 뒤 더하는 형태임. 따라서 길이에 대해서는 곡선이어도 계수에 대해서는 선형인 모델임.

모델 입장에서는 $x^2$과 $x$라는 두 입력 열이 주어진 것. 이 각각에 대한 계수와 절편을 찾으므로 같은 선형 회귀를 사용할 수 있음. 이런 다항 특성으로 관계를 표현하는 방법을 다항 회귀라고 함.

## 여러 길이에서 모델의 실제 예측 구하기

```python
point = np.arange(15, 50)
point_poly = np.column_stack((point ** 2, point))
plt.scatter(train_input[:, 0], train_target)
plt.plot(point, lr_poly.predict(point_poly))
plt.scatter(50, lr_poly.predict([[50**2, 50]])[0], marker='^')
plt.xlabel('Length (cm)')
plt.ylabel('Weight (g)')
plt.show()
print(round(lr_poly.score(train_poly, train_target), 4),
      round(lr_poly.score(test_poly, test_target), 4))
```

```text
0.9707 0.9776
```

`np.arange(15, 50)`은 15부터 49까지 길이를 만듦. 각 길이도 `[길이², 길이]`로 바꾼 뒤 `predict()`에 넣어야 함. 이 길이들은 곡선을 그리기 위한 입력이며 새로 관측한 농어가 아님.

`plt.plot()`은 이 예측 무게들을 연결함. 가로축은 길이, 세로축은 무게이고 산점도는 실제 훈련 샘플. 삼각형은 50cm의 예측 무게로 실제 정답 표시와 구분함. 반올림한 계수 대신 모델이 저장한 계수로 계산하므로 예측과 곡선의 계산 기준이 같음.

## 곡선을 추가한 효과 평가하기

| 모델 | 입력 특성 | 훈련 R² | 테스트 R² |
| --- | --- | --- | --- |
| 직선 | 길이 | 0.9398 | 0.8248 |
| 2차식 | 길이², 길이 | 0.9707 | 0.9776 |

둘 다 높아졌으며 특히 테스트 점수가 개선됨. 직선의 일정한 증가량 대신 길이에 따라 증가 폭이 달라지는 관계를 표현한 것이 이번 데이터에서 도움이 된 결과임.

그러나 표현할 수 있는 관계를 늘렸다는 것과 새 데이터의 성능이 좋아졌다는 것은 따로 확인해야 함. 특성을 추가하면 언제나 좋아지는 것은 아님. 또한 테스트가 훈련보다 조금 높다는 이유만으로 과소적합이라고 판단하지 않음.

이제 KNN, 직선, 2차식은 같은 길이를 서로 다른 방식으로 무게로 바꿈. 다음 파일에서는 모델의 계수로 직접 계산하고 훈련 범위 안팎에서 세 예측을 비교함.
