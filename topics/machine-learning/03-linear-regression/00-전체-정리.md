# 선형 회귀와 다항 회귀

KNN 회귀가 훈련 범위 밖에서 보이는 한계를 확인하고, 길이와 무게의 관계를 식으로 표현

## 1. KNN 회귀의 한계

농어의 길이와 무게로 훈련한 이웃 3개짜리 모델에 50cm와 100cm를 입력

```python
knr = KNeighborsRegressor(n_neighbors=3)
knr.fit(train_input, train_target)
print(knr.predict([[50], [100]]))
```

```text
[1033.33333333 1033.33333333]
```

두 입력 모두 가장 큰 훈련 농어 세 마리를 같은 이웃으로 선택해 평균 무게가 같음

![훈련 범위 밖 이웃](../assets/훈련범위-밖-이웃.png)

주황 마름모는 선택된 이웃, 초록 삼각형은 예측 무게. 실제 측정값을 나타내는 점은 아님

## 2. 선형 회귀

선형 회귀는 입력과 타깃 사이의 관계를 식으로 나타내는 모델

```python
from sklearn.linear_model import LinearRegression

lr = LinearRegression()
lr.fit(train_input, train_target)
print(lr.predict([[50]]))
print(lr.coef_, lr.intercept_)
```

```text
[1241.83860323]
[39.01714496] -709.0186449535474
```

`coef_`는 학습한 계수, `intercept_`는 절편

길이를 $x$, 예측 무게를 $\hat{y}$라고 하면 이 실습의 식은 다음과 같음

$$
\hat{y} \approx 39.02x - 709.02
$$

길이가 1cm 증가하면 예측 무게는 약 39.02g 증가

![기울기와 절편](../assets/기울기와-절편.png)

점선은 길이가 30cm에서 40cm로 늘 때 예측값이 증가하는 양. 절편은 입력이 0일 때 식의 값이며 실제 관측 무게는 아님

훈련 범위 밖도 계산할 수 있지만 계산된 값이 실제로 정확한지는 별도 확인 필요

## 3. 다항 회귀

농어의 무게는 길이가 늘수록 증가 폭도 커지는 경향이 있어 직선 하나로 표현하기 어려움

기존 길이에 길이의 제곱을 추가해 `[길이², 길이]` 두 특성을 입력

```python
train_poly = np.column_stack((train_input ** 2, train_input))
test_poly = np.column_stack((test_input ** 2, test_input))

lr = LinearRegression()
lr.fit(train_poly, train_target)
print(lr.predict([[50 ** 2, 50]]))
print(lr.coef_, lr.intercept_)
```

```text
[1573.98423528]
[  1.01433211 -21.55792498] 116.05021078278264
```

첫 계수는 길이², 두 번째 계수는 길이에 대응. 예측할 때도 특성 개수와 순서를 맞춰야 함

길이에 대한 예측선은 곡선이지만 계수를 곱해 더하는 형태이므로 계수에 대해서는 선형 회귀

## 4. 세 모델의 예측 비교

![세 회귀 모델 비교](../assets/pdf/세-회귀모델.png)

점은 실제 훈련 농어, 선은 각 길이에 대한 예측값. 점선은 훈련 길이의 최댓값

KNN은 범위 밖에서 같은 이웃을 선택하면 예측이 일정해짐

선형 회귀는 직선을 연장, 다항 회귀는 제곱 특성을 사용해 곡선으로 예측

훈련 범위 밖의 값은 계산할 수 있어도 정확하다고 보장할 수 없음

## 5. 잔차와 평가

잔차는 실제 무게에서 예측 무게를 뺀 값

양수면 실제보다 작게, 음수면 실제보다 크게 예측했다는 뜻

![테스트 잔차 비교](../assets/잔차-비교.png)

점 하나는 테스트 농어 한 마리. 가로축은 길이, 세로축은 잔차(g)

이번 테스트에서는 직선 회귀의 R²가 약 0.8248, MAE가 약 94.46g

다항 회귀는 R² 약 0.9776, MAE 약 37.77g. 이번 테스트에서 직선보다 성능이 좋았지만 모든 데이터에서 더 좋다는 뜻은 아님
