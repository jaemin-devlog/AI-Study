# 5. 입력 특성과 예측 확률 변화

앞에서는 계수의 부호로 점수가 변하는 방향을 읽었음. 이번에는 학습한 `lr_binary`를 그대로 두고 입력만 바꿔 계산을 확인함. 계수를 다시 학습하는 실험이 아니라 같은 모델의 반응을 비교하는 과정임.

## 무게 하나만 바꾸는 이유

무게와 길이를 동시에 바꾸면 점수 변화에 두 특성이 함께 작용함. 따라서 두 번째 훈련 생선의 입력 `train_binary[1:2]`를 복사해 무게만 바꾸고 나머지 네 값은 고정함. `.copy()`는 원래 입력을 보존하면서 비교용 데이터를 만들기 위한 것임.

표준화된 값에 1을 더하는 것은 1g 증가가 아님. 훈련 데이터 무게의 표준편차 한 개에 해당하는 변화임. 이 가상 측정 조합이 실제 생선에서 가능한지와 모델의 계산은 구분함.

```python
import numpy as np
import pandas as pd

original = train_binary[1:2].copy()
lighter = original.copy()
heavier = original.copy()
lighter[0, 0] -= 1.0
heavier[0, 0] += 1.0

comparison = np.vstack([lighter, original, heavier])
smelt_index = list(lr_binary.classes_).index('Smelt')
z = lr_binary.decision_function(comparison)
proba = lr_binary.predict_proba(comparison)[:, smelt_index]
pred = lr_binary.predict(comparison)

results = pd.DataFrame({
    '표준화 무게 변화': [-1.0, 0.0, 1.0],
    '점수(z)': np.round(z, 3),
    '빙어 확률': np.round(proba, 3),
    '예측 클래스': pred,
})
print(results.to_string(index=False))
```

```text
 표준화 무게 변화  점수(z)  빙어 확률 예측 클래스
       -1.0  3.975  0.982  Smelt
        0.0  3.570  0.973  Smelt
        1.0  3.166  0.960  Smelt
```

`np.vstack()`은 가벼운 경우, 원래 경우, 무거운 경우를 세 행으로 쌓음. `smelt_index`는 클래스 이름으로 빙어 확률의 열을 찾음. 각 행에 대해 점수와 확률, 최종 이름을 함께 확인함.

무게가 줄면 점수는 3.975, 원래는 3.570, 늘면 3.166. 무게 계수가 음수이기 때문에 무게와 점수는 반대 방향으로 움직임. 빙어 확률도 각각 약 0.982, 0.973, 0.960으로 낮아지지만 모두 0.5를 넘으므로 이름은 빙어로 같음.

## 변화량을 계수로 계산하기

다른 항이 고정됐으므로 점수의 차이는 무게 항에서만 발생함.

$$
\Delta z=w_{\text{무게}}\Delta x_{\text{무게}}
$$

```python
weight_coef = lr_binary.coef_[0, 0]
print(round(weight_coef, 4))
print(round(z[2] - z[1], 4))
print(np.isclose(z[2] - z[1], weight_coef * 1.0))
```

```text
-0.4045
-0.4045
True
```

무게를 1 늘리면 점수 차이는 약 -0.4045이며 계수와 같음. `np.isclose()`는 실제 점수 차이와 계수에 변화량을 곱한 결과가 가까운지 확인함.

확률은 바뀐 점수를 시그모이드에 다시 넣어 구함. 따라서 -0.4045는 확률이 40.45%포인트 내려간다는 뜻이 아님. 곡선의 어느 위치에서 움직이는지에 따라 확률 변화량은 달라짐.

## 무게를 2만큼 늘리기

점수 변화는 $-0.4045\times2\approx-0.8090$. 원래 점수 약 3.570에서 이만큼 내려가면 약 2.761이 됨.

```python
heavier_two = original.copy()
heavier_two[0, 0] += 2.0
z_two = lr_binary.decision_function(heavier_two)[0]
p_two = lr_binary.predict_proba(heavier_two)[0, smelt_index]
print(round(z_two, 3), round(p_two, 3))
```

```text
2.761 0.941
```

빙어 확률은 약 0.941. 점수 변화량은 두 배지만 확률 변화량이 반드시 두 배가 되지는 않음. 선형식은 입력과 점수의 관계를 정하고, 시그모이드는 점수와 확률의 관계를 정하기 때문임.
