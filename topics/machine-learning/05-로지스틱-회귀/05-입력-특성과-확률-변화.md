# 5. 입력 특성과 예측 확률 변화

학습 범위: 17에서 20쪽

학습한 모델을 그대로 둔 채 생선 한 마리의 입력 특성만 바꾸면 점수와 확률이 어떻게 변하는지 확인

앞에서 학습한 `lr_binary`, `train_binary`를 사용

## 1. 표준화된 무게만 바꾸기

두 번째 생선의 데이터를 복사하고 첫 번째 열인 무게만 -1, 0, +1만큼 변경. 길이, 대각선 길이, 높이, 두께는 그대로 유지

```python
import numpy as np
import pandas as pd

original = train_binary[1:2].copy()
lighter = original.copy()
heavier = original.copy()
lighter[0, 0] -= 1.0
heavier[0, 0] += 1.0

comparison = np.vstack([lighter, original, heavier])
smelt_index = list(lr_binary.classes_).index('Smelt')
z = lr_binary.decision_function(comparison)
proba = lr_binary.predict_proba(comparison)[:, smelt_index]
pred = lr_binary.predict(comparison)

results = pd.DataFrame({
    '표준화 무게 변화': [-1.0, 0.0, 1.0],
    '점수(z)': np.round(z, 3),
    '빙어 확률': np.round(proba, 3),
    '예측 클래스': pred,
})
print(results.to_string(index=False))
```

```text
 표준화 무게 변화  점수(z)  빙어 확률 예측 클래스
       -1.0  3.975  0.982  Smelt
        0.0  3.570  0.973  Smelt
        1.0  3.166  0.960  Smelt
```

무게가 증가하면 빙어 점수와 확률은 낮아짐. 그래도 세 경우 모두 빙어 확률이 0.5보다 높아 최종 예측은 빙어로 같음

이 실험은 실제 생선의 무게를 바꾼 것이 아니라 입력값 하나만 바꿔 모델의 반응을 확인한 것

표준화된 무게를 +1 하는 것은 1g을 더하는 것이 아님. 훈련 데이터의 무게 표준편차 1개에 해당하는 만큼 원래 무게를 바꾸는 것과 같음

## 2. 계수와 점수 변화

```python
weight_coef = lr_binary.coef_[0, 0]
print(round(weight_coef, 4))
print(round(z[2] - z[1], 4))
print(np.isclose(z[2] - z[1], weight_coef * 1.0))
```

```text
-0.4045
-0.4045
True
```

다른 특성은 고정하고 표준화된 무게만 바꿨으므로 점수의 변화량은 다음과 같음

$$
\Delta z=w_{\text{무게}}\times\Delta x_{\text{무게}}
$$

무게 계수가 약 -0.4045이므로 무게를 +1 하면 점수는 약 0.4045 감소. +2 하면 약 0.8090 감소

하지만 점수는 시그모이드 함수로 변환되므로 점수의 변화량과 확률의 변화량은 같은 비율이 아님. 계수는 확률 자체가 아니라 확률을 계산하기 전 점수에 작용함

## 3. 무게 변화량을 2로 바꾸면?

다른 특성을 고정하고 표준화된 무게를 2만큼 늘리면 점수의 변화는 $-0.4045 	imes 2=-0.8090$에 가까움. +1일 때보다 점수 변화량도 2배가 됨.

```python
heavier_two = original.copy()
heavier_two[0, 0] += 2.0
z_two = lr_binary.decision_function(heavier_two)[0]
p_two = lr_binary.predict_proba(heavier_two)[0, smelt_index]
print(round(z_two, 3), round(p_two, 3))
```

```text
2.761 0.941
```

점수는 선형식에 따라 일정한 비율로 바뀌지만 빙어 확률은 시그모이드의 굽은 곡선을 따라 바뀜. 따라서 무게 변화량이 2배가 되어도 확률 변화량이 반드시 2배가 되지는 않음.

표준화된 무게만 바꾼 이 가상 입력이 실제 생선의 측정 조합으로 가능한지와 모델의 계산 결과는 별개의 문제. 이 실험에서는 한 특성과 점수의 관계를 확인함.
