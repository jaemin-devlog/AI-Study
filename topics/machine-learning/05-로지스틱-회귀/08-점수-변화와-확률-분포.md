# 8. 점수 변화와 소프트맥스 확률

학습 범위: 28에서 30쪽

앞에서 학습한 `lr_multi`, `test_scaled`, `softmax`, `np`를 이어서 사용.

## 1. 최고 확률이 0.5보다 작아도 분류할 수 있을까?

다중 분류는 0.5를 넘는 클래스가 있는지 보는 것이 아니라 여러 확률 중 가장 높은 클래스를 선택함

다음은 첫 번째 생선의 점수에 같은 양의 배율을 곱해 확률 분포만 비교하는 실험. 학습된 모델 자체를 바꾸는 것은 아님

```python
scores = lr_multi.decision_function(test_scaled[:1])[0]
factors = [1.0, 0.5, 0.2, 0.1]

for factor in factors:
    probabilities = softmax(scores * factor)
    best = np.argmax(probabilities)
    print(factor, lr_multi.classes_[best], round(probabilities[best], 3))
```

```text
1.0 Perch 0.842
0.5 Perch 0.59
0.2 Perch 0.32
0.1 Perch 0.225
```

배율이 작아지면 점수 차이가 줄어들어 확률이 여러 클래스에 더 고르게 나뉨. 0.2배에서는 최고 확률이 0.32지만 다른 확률보다 높으므로 Perch가 선택됨

모든 점수에 같은 양수를 곱하면 크기 순서가 바뀌지 않아 이 예시에서는 최종 클래스가 유지됨. 배율을 크게 하면 상대적으로 높은 점수의 확률에 더 집중됨

## 2. 각 클래스의 확률 분포 비교

```python
import pandas as pd

scaled_scores = np.vstack([scores * factor for factor in factors])
scaled_proba = softmax(scaled_scores, axis=1)
table = pd.DataFrame(scaled_proba, columns=lr_multi.classes_,
                     index=[f'{factor}배' for factor in factors])
print(table.round(3).to_string())
print(np.allclose(scaled_proba[0], lr_multi.predict_proba(test_scaled[:1])[0]))
```

```text
       Bream  Parkki  Perch   Pike  Roach  Smelt  Whitefish
1.0배  0.000   0.014  0.842  0.000  0.135  0.007      0.003
0.5배  0.002   0.075  0.590  0.011  0.236  0.053      0.033
0.2배  0.031   0.140  0.320  0.066  0.222  0.122      0.100
0.1배  0.070   0.149  0.225  0.102  0.188  0.139      0.126
True
```

`np.vstack()`은 배율별 점수를 행으로 쌓음. `columns=lr_multi.classes_`는 7개 확률 열에 생선 이름을 붙임. `index`는 각 행이 어느 배율인지 표시함.

배율을 줄이면 Perch에 몰렸던 확률이 다른 클래스에도 더 고르게 나뉨. 가장 높은 값은 계속 Perch이고, `True`는 1.0배 점수의 소프트맥스와 모델 확률이 일치한다는 뜻.

## 3. 배율을 2로 늘리면?

```python
for factor in [0.2, 2.0]:
    probabilities = softmax(scores * factor)
    best = np.argmax(probabilities)
    print(factor, lr_multi.classes_[best], round(probabilities[best], 3))
```

```text
0.2 Perch 0.32
2.0 Perch 0.975
```

배율이 커지면 점수 차이도 커지므로 가장 높은 점수 쪽으로 확률이 더 집중됨. 두 경우 모두 양수를 곱했기 때문에 점수의 순서와 최종 클래스는 바뀌지 않음.
