# 6. 다중 분류 모델과 예측

학습 범위: 21에서 24쪽

도미와 빙어뿐 아니라 7종의 생선 전체를 분류하고, 클래스별 점수를 확률로 바꾸는 과정

아래 코드는 [생선 데이터 준비](01-생선-데이터와-최근접-이웃-확률.md)의 `train_scaled`, `test_scaled`, `train_target`, `test_target`을 사용

## 1. 모델 설정과 학습

```python
import numpy as np
from sklearn.linear_model import LogisticRegression

lr_multi = LogisticRegression(C=20, max_iter=1000)
lr_multi.fit(train_scaled, train_target)
print(lr_multi.score(train_scaled, train_target))
print(lr_multi.score(test_scaled, test_target))
```

```text
0.9327731092436975
0.925
```

훈련 정확도는 약 93.3%, 테스트 정확도는 92.5%. 같은 분할에서 최근접 이웃 3개의 테스트 정확도는 85%였음

이 비교는 해당 데이터와 설정의 결과. 모델과 설정을 고를 때는 검증 데이터나 교차 검증을 사용하고 테스트 데이터는 마지막 평가에 사용

| 설정 | 의미 |
| --- | --- |
| `max_iter=1000` | 최적화 계산을 최대 1,000회까지 허용. 수렴하면 더 일찍 끝날 수 있음 |
| `C=20` | 기본값 1보다 규제를 약하게 적용 |

이번 모델은 L2 규제를 사용. 로지스틱 회귀에서 `C`가 작을수록 규제가 강하고 클수록 약함. 릿지의 `alpha`는 커질수록 규제가 강해지므로 방향이 반대

## 2. 생선 7종의 예측과 확률

```python
print(lr_multi.classes_)
print(lr_multi.predict(test_scaled[:5]))
print(np.round(lr_multi.predict_proba(test_scaled[:5]), 3))
```

```text
['Bream' 'Parkki' 'Perch' 'Pike' 'Roach' 'Smelt' 'Whitefish']
['Perch' 'Smelt' 'Pike' 'Roach' 'Perch']
[[0.    0.014 0.842 0.    0.135 0.007 0.003]
 [0.    0.003 0.044 0.    0.007 0.946 0.   ]
 [0.    0.    0.034 0.934 0.015 0.016 0.   ]
 [0.011 0.034 0.305 0.006 0.567 0.    0.076]
 [0.    0.    0.904 0.002 0.089 0.002 0.001]]
```

한 행이 생선 한 마리, 한 열이 `classes_` 순서에 해당하는 생선 종류. 첫 번째 생선은 세 번째 열인 Perch 확률이 0.842로 가장 높아 Perch로 예측함

표시된 0.000은 반올림 결과일 수 있음. 출력된 숫자의 합도 반올림 때문에 정확히 1이 아닐 수 있음

## 3. 확률과 실제 정답 비교

`predict_proba()`의 열은 항상 해당 모델의 `classes_` 순서로 읽어야 함. 네 번째 샘플은 Perch 확률이 0.305, Roach 확률이 0.567이므로 Roach가 최종 예측으로 선택됨.

최종 예측은 가장 높은 확률의 이름이지만, 실제 생선의 종류가 그 이름인지는 `test_target`과 비교해야 알 수 있음. `score()`는 이런 비교를 테스트 샘플 전체에 적용한 정확도임.
