# 6. 다중 분류 모델과 예측

도미와 빙어만 남겼던 조건을 제거하고 7종 전체를 분류함. 첫 파일의 `train_scaled`, `test_scaled`는 표준화된 측정값이고 `train_target`, `test_target`은 같은 순서의 실제 종류임.

한 생선이 7종 중 어디에 속하는지 선택하는 것을 다중 분류라고 함. 입력은 여전히 다섯 개지만 클래스별 점수와 확률은 일곱 개가 필요함.

## 반복 횟수와 규제 설정하기

모델은 계수와 절편을 반복해서 조정함. `max_iter=1000`은 최적화 계산을 최대 1,000회 허용하는 설정. 수렴하면 더 일찍 끝날 수 있고, 횟수가 부족하면 충분히 안정되기 전에 끝나 수렴 경고가 나타날 수 있음.

L2 규제는 계수의 제곱합에 벌점을 부여해 불필요하게 큰 계수를 억제함. `C`는 이 규제의 강도를 조절하며 작을수록 강하고 클수록 약함. 릿지의 `alpha`는 커질수록 강해졌으므로 방향을 구분해야 함.

`C=20`은 기본값 1보다 약한 규제를 사용한다는 뜻이며 규제를 없애는 것은 아님. 계수를 더 자유롭게 조정해도 새로운 데이터의 성능이 항상 좋아지는 것은 아님.

```python
import numpy as np
from sklearn.linear_model import LogisticRegression

lr_multi = LogisticRegression(C=20, max_iter=1000)
lr_multi.fit(train_scaled, train_target)
print(lr_multi.score(train_scaled, train_target))
print(lr_multi.score(test_scaled, test_target))
```

```text
0.9327731092436975
0.925
```

훈련 정확도는 약 93.3%, 테스트 정확도는 92.5%. 테스트 40마리 중 37마리를 맞힌 비율이며 각 생선의 평균 확률을 뜻하지 않음. 같은 분할의 KNN 테스트 정확도 85%보다 높지만 이 데이터와 설정에서의 결과임.

## 일곱 확률에서 이름 선택하기

```python
print(lr_multi.classes_)
print(lr_multi.predict(test_scaled[:5]))
print(np.round(lr_multi.predict_proba(test_scaled[:5]), 3))
```

```text
['Bream' 'Parkki' 'Perch' 'Pike' 'Roach' 'Smelt' 'Whitefish']
['Perch' 'Smelt' 'Pike' 'Roach' 'Perch']
[[0.    0.014 0.842 0.    0.135 0.007 0.003]
 [0.    0.003 0.044 0.    0.007 0.946 0.   ]
 [0.    0.    0.034 0.934 0.015 0.016 0.   ]
 [0.011 0.034 0.305 0.006 0.567 0.    0.076]
 [0.    0.    0.904 0.002 0.089 0.002 0.001]]
```

확률표는 5행 7열. 행은 첫 다섯 테스트 생선, 열은 `classes_`에 있는 일곱 종류임. 첫 행의 세 번째 값 0.842는 Perch 확률이고 가장 크므로 농어를 선택함.

네 번째 행은 Perch 0.305와 Roach 0.567 중 Roach가 더 커 Roach를 선택함. 이 이름이 정답인지는 `test_target`과 비교해야 함. 표의 0.000은 작은 확률을 반올림한 결과일 수 있고 행의 표시값 합도 반올림으로 1과 조금 다를 수 있음.

모델이나 설정을 고를 때는 검증 데이터 또는 교차 검증을 사용하고 테스트는 최종 평가에 사용함. 다음에는 이 일곱 확률이 실제로 어떤 점수에서 계산됐는지 확인함.
