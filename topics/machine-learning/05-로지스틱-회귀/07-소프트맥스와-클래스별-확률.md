# 7. 소프트맥스와 클래스별 확률

다중 모델 `lr_multi`는 한 생선에 대한 확률 일곱 개를 반환했음. 계산을 거슬러 올라가면 종류마다 다른 계수와 절편으로 만든 점수 일곱 개가 있음. 같은 측정값을 각 종류의 식에 넣어 비교하는 방식임.

## 클래스별로 다른 선형식 사용하기

$$
z_k=w_{k1}x_1+w_{k2}x_2+w_{k3}x_3+w_{k4}x_4+w_{k5}x_5+b_k
$$

$k$는 생선 종류의 위치. 도미는 도미에 해당하는 계수 다섯 개와 절편 하나를, 농어는 농어에 해당하는 값을 사용함. 그래서 `coef_`는 7행 5열, `intercept_`는 일곱 값임.

```python
print(lr_multi.coef_.shape, lr_multi.intercept_.shape)
decisions = lr_multi.decision_function(test_scaled[:5])
print(np.round(decisions[0], 2))
```

```text
(7, 5) (7,)
[-6.51  1.04  5.17 -2.76  3.34  0.35 -0.63]
```

첫 생선의 점수는 `classes_` 순서로 나옴. Perch의 약 5.17이 가장 높지만 이것을 517%나 확률 5.17로 읽을 수는 없음. 음수인 점수도 있으므로 확률로 변환해야 함.

## 일곱 점수로 하나의 확률 분포 만들기

소프트맥스는 각 점수에 지수함수를 적용하고 그 값들의 합으로 나눔.

$$
p_k=\frac{e^{z_k}}{\sum_{j=1}^{7}e^{z_j}}
$$

분자의 $e^{z_k}$는 해당 클래스의 변환값이고 분모는 일곱 변환값의 전체 합. 지수함수는 음수 점수도 양수로 바꾸며 점수의 크기 순서를 유지함. 각각을 같은 합으로 나누므로 전체 확률을 더하면 1이 됨.

지수함수 적용 후 농어가 4, 나머지 여섯 종류가 각각 1이라면 합은 10. 농어 확률은 4/10, 나머지는 각각 1/10임. 이때 4와 1은 원래 점수가 아닌 변환 후 값임. 농어 확률은 0.4로 0.5 미만이어도 가장 크므로 농어를 선택함.

```python
from scipy.special import softmax

proba = softmax(decisions, axis=1)
print(np.round(proba[0], 3))
print(np.allclose(proba, lr_multi.predict_proba(test_scaled[:5])))
```

```text
[0.    0.014 0.842 0.    0.135 0.007 0.003]
True
```

`decisions`는 `(5, 7)` 배열. `axis=1`은 각 행의 일곱 값을 묶어 계산한다는 뜻임. 한 생선의 일곱 확률을 구해야 하므로 서로 다른 생선의 점수를 같은 분모로 합치면 안 됨. `np.allclose()`가 `True`이므로 직접 계산한 확률과 `predict_proba()`가 일치함.

![다중 분류 확률](../assets/pdf/다중-분류-확률.png)

그림에서 Perch의 가장 큰 점수는 변환 후에도 가장 큰 확률 약 0.842에 대응함. 한 클래스의 점수를 바꾸면 공통 분모도 달라지므로 다른 클래스의 확률도 바뀔 수 있음.

## 이진 분류와 연결하기

이진 분류는 양성 점수 하나를 시그모이드에 넣고 나머지 확률을 1에서 뺐음. 여기서는 일곱 점수를 소프트맥스로 함께 변환함. 두 방식 모두 점수와 확률을 구분하며 최종 예측은 계산한 확률에서 선택함.
