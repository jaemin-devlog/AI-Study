# 9. 핵심 개념 복습

학습 범위: 31에서 32쪽

생선의 종류를 예측하고, 각 생선일 확률을 어떻게 계산하는지 정리

## 전체 흐름

| 순서 | 내용 |
| --- | --- |
| 1 | 생선의 다섯 가지 측정값을 입력으로 사용하고 종류를 정답으로 준비 |
| 2 | 훈련과 테스트 데이터 분리 후 훈련 데이터 기준으로 표준화 |
| 3 | 최근접 이웃 3마리의 비율로 클래스별 확률 계산 |
| 4 | 로지스틱 회귀가 입력 특성으로 점수 $z$를 계산 |
| 5 | 이진 분류에서는 시그모이드로 양성 클래스의 확률 계산 |
| 6 | 다중 분류에서는 클래스별 점수를 소프트맥스로 바꾸고 가장 높은 확률 선택 |

## 1. 이번 문제

입력은 생선의 무게, 길이, 대각선 길이, 높이, 두께

정답은 도미, 빙어 등 7종의 생선 이름

예측하려는 대상이 생선의 종류이므로 분류 문제. 클래스별 확률이 숫자로 나온다고 해서 회귀 문제가 되는 것은 아님

## 2. 최근접 이웃의 확률

이웃 3마리가 농어 2마리, Roach 1마리라면 기본 설정에서 각 예측 확률은 다음과 같음

- 농어: $2/3 \approx 0.6667$
- Roach: $1/3 \approx 0.3333$
- 나머지: $0$

`predict_proba()`는 클래스별 확률, `classes_`는 그 확률의 열 순서를 보여줌

이웃이 3마리일 때 기본 설정의 확률은 0, 1/3, 2/3, 1 중 하나. 이웃의 수를 늘리면 표현 가능한 비율이 많아지지만 비율이 곧 실제 정답을 맞힐 가능성이라고 보장되지는 않음

## 3. 로지스틱 회귀와 시그모이드

로지스틱 회귀는 이름에 회귀가 들어가지만 분류에 사용하는 모델

각 특성에 계수를 곱하고 절편을 더해 점수 $z$를 계산

$$
z = w_1x_1+w_2x_2+w_3x_3+w_4x_4+w_5x_5+b
$$

$z$는 음수나 1보다 큰 값도 나올 수 있으므로 아직 확률이 아님. 이진 분류에서는 시그모이드를 이용해 양성 클래스의 확률로 바꿈

$$
p=\frac{1}{1+e^{-z}}
$$

$z=0$이면 $p=0.5$. 점수가 커질수록 양성 클래스의 확률은 1에 가까워짐

![로지스틱 분류 과정](../assets/pdf/로지스틱-분류-과정.png)

입력값 → 점수 → 확률 → 최종 클래스 순서로 읽으면 됨. 점수와 확률은 같은 값이 아니며 확률이 달라도 기준의 같은 쪽에 있으면 최종 분류는 같을 수 있음

## 4. 도미와 빙어의 이진 분류

`classes_`가 `['Bream', 'Smelt']`이면 첫 열은 도미, 둘째 열은 빙어 확률

이 모델에서는 빙어가 양성 클래스. `decision_function()`의 점수에 시그모이드를 적용하면 빙어 확률을 얻고, 도미 확률은 $1-p$로 계산

다른 특성을 고정하고 표준화된 무게를 1만큼 바꾸면 점수는 무게 계수만큼 변함. 표준화 값 1의 변화는 실제 무게 1g의 변화가 아님

## 5. 7종의 다중 분류와 소프트맥스

생선 한 마리에 대해 7개 클래스의 점수를 계산하고 소프트맥스로 7개의 확률을 만듦

$$
p_k=\frac{e^{z_k}}{\sum_{j=1}^{7}e^{z_j}}
$$

각 확률의 합은 1이며 가장 높은 확률의 클래스를 선택. 가장 높은 확률이 0.5보다 작아도 다른 클래스보다 크면 선택될 수 있음

| 모델 | 훈련 정확도 | 테스트 정확도 |
| --- | --- | --- |
| 최근접 이웃, $k=3$ | 약 0.891 | 0.850 |
| 로지스틱 회귀, $C=20$ | 약 0.933 | 0.925 |

이 결과는 해당 데이터와 설정에 대한 비교. 어떤 문제에서도 한 모델이 항상 더 좋다는 뜻은 아님

## 핵심 코드

| 코드 | 의미 |
| --- | --- |
| `train_test_split()` | 훈련 데이터와 테스트 데이터 분리 |
| `StandardScaler.fit()` | 훈련 데이터의 표준화 기준 계산 |
| `predict()` | 최종 예측 클래스 반환 |
| `predict_proba()` | 클래스별 예측 확률 반환 |
| `classes_` | 클래스와 확률 열의 순서 확인 |
| `coef_`, `intercept_` | 학습된 계수와 절편 |
| `decision_function()` | 확률로 바꾸기 전 점수 확인 |
| `expit()` | 점수에 시그모이드 적용 |
| `softmax(..., axis=1)` | 각 샘플의 클래스 점수를 확률로 변환 |

## 복습 질문

1. 최근접 이웃과 로지스틱 회귀는 확률을 어떻게 계산할까?
   - 최근접 이웃은 이웃의 비율을 사용하고, 로지스틱 회귀는 입력과 계수로 만든 점수를 확률로 변환함.
2. 이진 분류에서 `expit(z)`는 어떤 클래스의 확률일까?
   - 이번 도미와 빙어 모델에서는 `classes_[1]`인 빙어의 확률.
3. 7개 확률 중 가장 높은 값이 0.5보다 작아도 분류할 수 있을까?
   - 가능함. 다중 분류는 가장 높은 확률의 클래스를 선택함.
4. 최종 클래스가 같으면 예측 확률도 같을까?
   - 아님. 확률이 달라도 같은 클래스가 가장 높으면 예측 결과는 같을 수 있음.
