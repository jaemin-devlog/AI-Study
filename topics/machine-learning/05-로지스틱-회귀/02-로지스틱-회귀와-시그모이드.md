# 2. 로지스틱 회귀와 시그모이드

학습 범위: 7에서 9쪽

로지스틱 회귀는 입력 특성으로 점수를 계산한 뒤, 그 점수를 확률로 바꾸어 분류하는 모델

## 1. 선형식으로 점수 계산

생선의 표준화된 무게, 길이, 대각선 길이, 높이, 두께를 각각 $x_1$부터 $x_5$라고 하면 점수는 다음과 같음

$$
z=w_1x_1+w_2x_2+w_3x_3+w_4x_4+w_5x_5+b
$$

- $w_1$부터 $w_5$: 모델이 훈련 과정에서 학습한 각 특성의 계수
- $b$: 절편
- $z$: 계수와 입력으로 계산한 점수

선형 회귀에서는 계산한 값을 수치 예측에 직접 사용했음. 로지스틱 회귀에서는 이 점수를 확률로 변환하고 그 확률을 분류에 사용함

$z$는 -2, 0, 3처럼 어떤 실수도 될 수 있지만 확률은 0과 1 사이여야 함

## 2. 시그모이드 함수

시그모이드는 점수 하나를 0과 1 사이의 값으로 바꾸는 함수

$$
p=\sigma(z)=\frac{1}{1+e^{-z}}
$$

$e$는 자연상수. $z$가 증가하면 확률도 증가하며, $z=0$일 때 확률은 정확히 0.5

| 점수 $z$ | 양성 클래스 확률 | 기본 분류 |
| --- | --- | --- |
| -4 | 약 0.0180 | 음성 |
| -2 | 약 0.1192 | 음성 |
| 0 | 0.5000 | 음성 |
| 2 | 약 0.8808 | 양성 |
| 4 | 약 0.9820 | 양성 |

이진 로지스틱 회귀의 기본 판정에서는 $p>0.5$면 양성, $p\leq0.5$면 음성. 정확히 0.5일 때는 첫 번째 클래스가 선택됨

양성과 음성은 좋은 결과와 나쁜 결과를 뜻하는 말이 아니라 두 클래스를 구분하는 이름

```python
import numpy as np

z = np.array([-4.0, -2.0, 0.0, 2.0, 4.0])
p = 1 / (1 + np.exp(-z))
print(np.round(p, 4))
print(np.where(p > 0.5, '양성', '음성'))
```

```text
[0.018  0.1192 0.5    0.8808 0.982 ]
['음성' '음성' '음성' '양성' '양성']
```

$z=2$와 $z=4$는 양성 확률이 서로 다르지만 둘 다 0.5를 넘으므로 최종 분류는 같음

## 3. 그래프 확인

```python
import matplotlib.pyplot as plt

z = np.arange(-5, 5, 0.1)
p = 1 / (1 + np.exp(-z))
plt.plot(z, p)
plt.xlabel('z')
plt.ylabel('probability')
plt.grid()
plt.show()
```

![시그모이드 함수](../assets/시그모이드-함수.png)

가로축은 선형식의 점수, 세로축은 양성 클래스의 확률. S자 곡선은 음수 방향에서는 0, 양수 방향에서는 1에 가까워짐

![로지스틱 분류 과정](../assets/pdf/로지스틱-분류-과정.png)

그림을 왼쪽부터 읽으면 표준화된 5개 특성 → 점수 $z$ → 시그모이드 → 양성 확률 $p$ → 최종 클래스 순서

음성 확률은 $1-p$. 하나의 확률을 알면 두 클래스의 확률을 모두 구할 수 있음

## 4. 확률과 분류 결과의 차이

점수 -4와 -2를 비교하면 양성 확률은 약 1.8%와 11.9%로 다름. 하지만 두 값 모두 0.5 이하여서 음성으로 분류됨. 반대로 점수 2와 4는 확률이 약 88.1%와 98.2%지만 둘 다 양성으로 분류됨.

`predict()`는 최종 클래스만 알려 주고, `predict_proba()`는 클래스별 확률을 보여줌. 최종 예측이 같아도 확률에는 차이가 있을 수 있으므로 두 결과를 구분해 읽어야 함.

시그모이드 그래프가 양 끝에서 완만해지는 이유는 점수가 계속 커지거나 작아져도 확률은 1이나 0에 가까워지기 때문. 점수의 변화와 확률의 변화가 항상 같은 크기로 일어나지는 않음.
