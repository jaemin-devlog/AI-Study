# 3. 도미와 빙어의 이진 분류

앞에서는 임의의 점수를 시그모이드에 넣었음. 이제 측정값과 정답으로 모델을 학습해 실제 생선의 점수를 만들도록 함. 두 종류 중 하나를 선택하는 문제를 이진 분류라고 하며 여기서는 도미와 빙어만 남김.

아래 입력은 첫 파일에서 만든 `train_scaled`와 `train_target`임. 전자는 표준화된 훈련 측정값이고 후자는 같은 순서의 생선 이름임.

## 조건에 맞는 행만 선택하기

배열에서 필요한 위치를 `True`, 나머지를 `False`로 표시하면 `True` 위치만 선택할 수 있음. 이 방법이 불리언 인덱싱임.

```python
import numpy as np

char_arr = np.array(['A', 'B', 'C', 'D', 'E'])
print(char_arr[[True, False, True, False, False]])
```

```text
['A' 'C']
```

같은 원리를 생선의 정답에 적용함. 도미인지 비교한 결과와 빙어인지 비교한 결과를 `|`로 연결하면 두 종류 중 하나인 위치가 선택됨. 각 비교를 괄호로 묶고 입력과 정답에 같은 조건을 적용함.

```python
from sklearn.linear_model import LogisticRegression

mask = (train_target == 'Bream') | (train_target == 'Smelt')
train_binary = train_scaled[mask]
target_binary = train_target[mask]

lr_binary = LogisticRegression()
lr_binary.fit(train_binary, target_binary)
print(lr_binary.predict(train_binary[:5]))
```

```text
['Bream' 'Smelt' 'Bream' 'Bream' 'Bream']
```

`train_binary`와 `target_binary`에는 도미와 빙어만 남음. 표준화는 앞에서 전체 훈련 데이터로 계산한 기준을 그대로 사용하고, 여기서는 그중 두 종류의 행을 고른 것임.

`LogisticRegression()`은 모델을 만들고 `fit()`은 선택한 측정값과 정답을 사용해 계수와 절편을 학습함. 이후 첫 5마리의 예측 이름을 출력함. 훈련 데이터에 대한 출력이므로 이것만으로 새로운 생선의 성능을 판단할 수 없음.

## 예측 이름이 선택된 이유 확인하기

```python
print(lr_binary.classes_)
print(np.round(lr_binary.predict_proba(train_binary[:5]), 4))
```

```text
['Bream' 'Smelt']
[[0.9976 0.0024]
 [0.0274 0.9726]
 [0.9949 0.0051]
 [0.9859 0.0141]
 [0.9977 0.0023]]
```

`classes_`가 `['Bream', 'Smelt']`이므로 첫 열은 도미, 둘째 열은 빙어 확률. 첫 생선은 도미 0.9976이 빙어 0.0024보다 커 도미를 선택함. 두 번째는 빙어 0.9726이 커 빙어를 선택함.

| 샘플 | 도미 확률 | 빙어 확률 | 예측 |
| --- | ---: | ---: | --- |
| 첫 번째 | 99.76% | 0.24% | 도미 |
| 두 번째 | 2.74% | 97.26% | 빙어 |

각 행에서 더 높은 확률의 종류가 예측 결과임. 예측이 실제 정답과 일치하는지는 별도로 확인해야 함.

이진 로지스틱 회귀에서는 `classes_[1]`을 양성으로 사용함. 따라서 이번 시그모이드의 결과 $p$는 빙어 확률이고 도미 확률은 $1-p$. 빙어 확률이 0.5를 넘으면 빙어, 그 이하면 도미로 분류됨.

## 두 확률을 따로 학습하지 않아도 되는 이유

도미와 빙어 중 하나에만 속한다고 놓았으므로 두 확률의 합은 1. 빙어 확률이 0.8이면 도미 확률은 0.2로 정해짐. 그래서 이진 모델은 점수 하나를 시그모이드에 넣는 것으로 두 열의 확률을 만들 수 있음.

이 모델은 다른 5종을 선택지에 넣어 학습하지 않았음. 출력된 두 확률은 도미와 빙어 가운데서의 판단으로 읽어야 함. 어느 열이 무엇인지는 모델마다 `classes_`로 확인하고, 예측이 맞았는지는 실제 타깃과 비교함.
