# 3. 도미와 빙어의 이진 분류

학습 범위: 10에서 12쪽

7종 중 도미와 빙어만 선택한 뒤 학습된 점수가 어떻게 확률과 예측으로 이어지는지 확인

아래 코드는 [생선 데이터 준비](01-생선-데이터와-최근접-이웃-확률.md)에서 만든 `train_scaled`와 `train_target`을 이어서 사용

## 1. 불리언 인덱싱으로 두 종류 선택

```python
import numpy as np

char_arr = np.array(['A', 'B', 'C', 'D', 'E'])
print(char_arr[[True, False, True, False, False]])
```

```text
['A' 'C']
```

`True`인 위치의 원소만 선택됨. 생선 데이터에도 같은 방식을 적용

```python
from sklearn.linear_model import LogisticRegression

mask = (train_target == 'Bream') | (train_target == 'Smelt')
train_binary = train_scaled[mask]
target_binary = train_target[mask]

lr_binary = LogisticRegression()
lr_binary.fit(train_binary, target_binary)
print(lr_binary.predict(train_binary[:5]))
```

```text
['Bream' 'Smelt' 'Bream' 'Bream' 'Bream']
```

`|`는 두 조건 중 하나를 만족하는 위치를 선택. 입력과 정답에 같은 조건을 적용해야 생선과 종류가 서로 어긋나지 않음

여기서 처음 5개는 훈련 데이터의 예측을 살펴본 것. 이 결과만으로 새로운 데이터에 대한 성능을 평가할 수는 없음

## 2. 클래스 순서와 확률

```python
print(lr_binary.classes_)
print(np.round(lr_binary.predict_proba(train_binary[:5]), 4))
```

```text
['Bream' 'Smelt']
[[0.9976 0.0024]
 [0.0274 0.9726]
 [0.9949 0.0051]
 [0.9859 0.0141]
 [0.9977 0.0023]]
```

첫 열은 도미, 둘째 열은 빙어. 첫 생선은 도미 확률이 약 99.76%, 두 번째 생선은 빙어 확률이 약 97.26%

이진 로지스틱 회귀의 양성 클래스는 `classes_[1]`. 이번에는 빙어가 양성이고 도미가 음성

## 3. 한 클래스의 확률로 두 클래스를 구분

두 클래스 중 하나에만 속하는 문제이므로 도미와 빙어의 확률을 더하면 1이 됨. 예를 들어 빙어 확률이 0.8이면 도미 확률은 $1-0.8=0.2$.

이번 모델의 양성 클래스는 `classes_[1]`인 Smelt. 양성과 음성은 빙어인지 아닌지를 구분하는 기준이며, 생선의 좋고 나쁨을 뜻하지 않음.

첫 번째 생선의 도미 확률은 0.9976, 빙어 확률은 0.0024이므로 도미로 선택됨. 두 번째는 빙어 확률이 0.9726으로 더 높아 빙어로 선택됨. 이 값은 모델의 예측이고 실제 정답을 확인하기 전에는 맞혔는지 알 수 없음.

## 4. 코드 흐름 확인

| 코드 | 역할 |
| --- | --- |
| `(train_target == 'Bream')` | 정답이 도미인 위치를 `True`로 표시 |
| `|` | 도미 또는 빙어인 위치 선택 |
| `fit(train_binary, target_binary)` | 선택한 입력과 정답으로 모델 학습 |
| `predict()` | 최종 예측 클래스 확인 |
| `predict_proba()` | 각 클래스의 예측 확률 확인 |
| `classes_` | 확률 열에 대응하는 클래스 순서 확인 |
