# 5. 결정 트리의 하이퍼파라미터

결정 트리가 학습할 때는 각 노드에서 어떤 특성과 기준값으로 나눌지를 훈련 데이터로 결정함. 반면 최대 깊이처럼 모델을 학습하기 전에 사용자가 정하는 조건을 하이퍼파라미터라고 함.

## 모델이 찾는 값과 사용자가 정하는 조건

| 구분 | 결정 트리에서의 예 |
| --- | --- |
| 학습 결과 | 분할에 사용할 특성, 기준값, 리프의 클래스 분포 |
| 하이퍼파라미터 | 최대 깊이, 분할에 필요한 샘플 수, 불순도 감소 기준 |

여러 설정을 바꾸고 검증 성능을 비교해 적절한 조합을 고르는 과정이 하이퍼파라미터 튜닝임. 같은 훈련 데이터라도 제한 조건이 달라지면 가능한 트리의 크기와 학습한 규칙이 달라질 수 있음.

## 트리의 분할을 제한하는 설정

| 설정 | 확인하는 조건 | 복잡도를 줄이는 방향 |
| --- | --- | --- |
| `max_depth` | 루트에서 내려갈 수 있는 최대 깊이 | 값을 낮춤 |
| `min_samples_split` | 분할하려는 현재 노드에 필요한 최소 샘플 수 | 값을 높임 |
| `min_samples_leaf` | 분할 후 각 자식 노드에 남아야 하는 최소 샘플 수 | 값을 높임 |
| `min_impurity_decrease` | 분할로 얻는 가중 불순도 감소가 충분한지 | 기준을 높임 |

`min_samples_split`은 나누기 전 부모 노드의 샘플 수를 봄. `min_samples_leaf`는 나눈 뒤 각각의 자식에 남는 샘플 수를 제한함. 따라서 부모에 분할 가능한 샘플 수가 있어도 어느 한 자식이 최소 수를 만족하지 못하면 그 분할은 허용되지 않음.

앞에서 정보 이득을 계산할 때 부모와 두 자식의 지니 차이를 비교했음. `min_impurity_decrease`는 그 노드에 도착한 샘플의 전체 훈련 샘플 대비 비중도 반영해 분할 여부를 판단함. 이 값의 기준을 높이면 작은 감소만 얻는 분할은 더 쉽게 제한됨.

## 설정은 서로 영향을 줌

`max_depth=5`로 허용하더라도 `min_samples_split`을 크게 정하면 필요한 샘플 수를 채우지 못해 깊이 5에 도달하기 전에 멈출 수 있음. 최대 깊이는 반드시 그 깊이까지 성장하라는 뜻이 아니라 넘지 말라는 상한임.

분할을 너무 많이 허용하면 훈련 사례에 과대적합할 수 있고 지나치게 제한하면 중요한 관계도 놓쳐 과소적합할 수 있음. 한 설정의 좋은 값도 다른 설정에 따라 달라질 수 있으므로 조합을 비교해야 함.
