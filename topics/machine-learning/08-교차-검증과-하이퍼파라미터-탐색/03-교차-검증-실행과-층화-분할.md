# 3. 교차 검증 실행과 층화 분할

앞에서 만든 `train_input`, `train_target`에는 테스트를 제외한 5,197개 와인이 있음. 앞의 고정 검증용 `sub_input`만 전달하는 대신 이 전체 훈련 데이터에서 폴드를 나누어 평가함.

## cross_validate()의 결과 읽기

```python
import numpy as np
from sklearn.model_selection import cross_validate

scores = cross_validate(dt, train_input, train_target)
print(np.round(scores['test_score'], 4))
print(round(np.mean(scores['test_score']), 4))
```

```text
[0.8692 0.8462 0.8768 0.8489 0.8354]
0.8553
```

기본 설정의 분류 교차 검증은 5개 폴드를 사용하므로 검증 점수도 다섯 개임. `cross_validate()`는 전달한 `dt`의 설정을 복제해 각 회차의 학습 폴드로 새 모델을 만듦. 앞에서 `dt.fit()`으로 학습한 분할 규칙을 그대로 재사용하는 것이 아님.

결과에는 `fit_time`, `score_time`, `test_score`가 있음. 앞의 두 값은 각 회차의 학습과 점수 계산에 걸린 시간이라 실행 조건에 따라 달라짐. `test_score`는 이름과 달리 여기서는 교차 검증의 각 검증 폴드 점수임. 처음 분리한 `test_input`의 최종 점수가 아님.

| 반환 항목 | 내용 |
| --- | --- |
| `fit_time` | 각 폴드에서 모델을 학습하는 데 걸린 시간 |
| `score_time` | 각 폴드에서 점수를 계산하는 데 걸린 시간 |
| `test_score` | 각 검증 폴드의 점수. 별도로 남긴 최종 테스트 점수는 아님 |

다섯 점수의 평균 약 0.8553은 이 설정이 서로 다른 검증 폴드에서 얻은 평균 정확도. 한 번의 고정 검증 점수 0.8644와 평가에 사용한 데이터 구성이 다르므로 두 숫자가 같아야 할 이유는 없음. 평균 외에 각 폴드의 차이도 함께 살펴볼 수 있음.

## 분류에서 클래스 비율을 고려하는 이유

레드와 화이트가 폴드마다 크게 다른 비율로 들어가면 회차별 점수 차이가 클래스 구성의 영향일 수도 있음. `StratifiedKFold`는 각 폴드가 전체 훈련 데이터의 클래스 비율을 가능한 한 비슷하게 유지하도록 나눔.

```python
from sklearn.model_selection import StratifiedKFold

scores = cross_validate(
    dt, train_input, train_target,
    cv=StratifiedKFold(n_splits=5)
)
print(round(np.mean(scores['test_score']), 4))
```

```text
0.8553
```

이번 이진 분류 모델의 기본 5폴드 설정과 같은 분할이므로 앞의 평균과 같음. 비율을 최대한 유지한다는 뜻이지 각 폴드의 샘플이 완전히 같거나 클래스 수가 정확한 소수 비율로 떨어진다는 뜻은 아님.

## 섞어서 10개 폴드로 나누기

```python
splitter = StratifiedKFold(n_splits=10, shuffle=True, random_state=42)
scores = cross_validate(dt, train_input, train_target, cv=splitter)
print(round(np.mean(scores['test_score']), 4))
```

```text
0.8574
```

`n_splits=10`은 10개 부분으로 나누고 10번 학습과 평가를 한다는 뜻임. `shuffle=True`는 폴드를 만들기 전에 데이터를 섞고 `random_state=42`는 그 무작위 분할을 재현함. 여기서는 평균 약 0.8574임.

| 설정 | 역할 |
| --- | --- |
| `n_splits=10` | 훈련 데이터를 10개 폴드로 나눔 |
| `shuffle=True` | 폴드를 구성하기 전에 데이터를 섞음 |
| `random_state=42` | 같은 무작위 분할을 재현함 |

폴드 수가 많다고 점수가 반드시 높아지는 것은 아님. 회차가 늘면 학습 횟수와 계산 비용도 커짐. 한 번의 분할 영향을 줄이는 이점과 작업 비용을 함께 고려함.

평균이나 표준편차를 학습하는 전처리가 필요한 모델이라면 각 회차의 학습 폴드에서만 기준을 구해야 함. 전체 5,197개에서 먼저 기준을 구하면 검증 폴드의 정보가 변환에 들어갈 수 있음. 이런 경우 전처리와 모델을 파이프라인으로 묶어 폴드마다 함께 학습함. 이번 결정 트리는 원본 입력을 사용함.
