# 7. 그리드 서치 결과 해석

앞의 `gs_single`은 다섯 후보를 이미 평가했음. `cv_results_`를 읽어 표를 만드는 것은 저장된 결과를 정리하는 작업이며 모델을 다시 학습시키는 것이 아님.

## 후보별 평균과 변동 확인하기

```python
cv_results = gs_single.cv_results_
results_grid = pd.DataFrame({
    'min_impurity_decrease': [p['min_impurity_decrease'] for p in cv_results['params']],
    '평균 검증 정확도': cv_results['mean_test_score'],
    '검증 표준편차': cv_results['std_test_score'],
    '순위': cv_results['rank_test_score'],
})
print(results_grid.round(4).to_string(index=False))
```

실행 결과를 표로 정리하면 다음과 같음.

| `min_impurity_decrease` | 평균 검증 정확도 | 검증 표준편차 | 순위 |
| ---: | ---: | ---: | ---: |
| 0.0001 | 0.8682 | 0.0092 | 1 |
| 0.0002 | 0.8645 | 0.0084 | 5 |
| 0.0003 | 0.8649 | 0.0087 | 4 |
| 0.0004 | 0.8678 | 0.0113 | 2 |
| 0.0005 | 0.8676 | 0.0106 | 3 |

`params`에는 후보 설정이, `mean_test_score`에는 다섯 검증 점수의 평균이, `std_test_score`에는 그 점수의 표준편차가 들어 있음. `rank_test_score`는 평균 점수를 기준으로 매긴 순위임.

그리드 서치는 기본적으로 평균 점수가 가장 높은 후보를 선택하므로 0.0001이 1위. 표준편차가 가장 작은 후보는 0.0002임. 평균이 가장 높다는 것과 폴드별 점수가 가장 덜 달라졌다는 것은 별개의 정보임.

## 1위와 2위는 얼마나 차이 날까?

```python
ranked_grid = results_grid.sort_values('순위')
print(ranked_grid.round(4).to_string(index=False))
mean_scores = np.sort(cv_results['mean_test_score'])[::-1]
print(round(mean_scores[0] - mean_scores[1], 4))
```

```text
 min_impurity_decrease  평균 검증 정확도  검증 표준편차  순위
                0.0001      0.8682    0.0092   1
                0.0004      0.8678    0.0113   2
                0.0005      0.8676    0.0106   3
                0.0003      0.8649    0.0087   4
                0.0002      0.8645    0.0084   5
0.0004
```

`sort_values()`로 순위가 높은 순서로 보고 `np.sort(...)[::-1]`로 평균 점수를 내림차순으로 만듦. 1위와 2위의 차이는 약 0.0004, 즉 약 0.04%포인트임. 1위 후보의 표준편차 약 0.0092, 2위의 약 0.0113에 비하면 작은 차이임.

이 표준편차는 폴드 점수의 흩어진 정도이지, 두 후보의 차이가 통계적으로 유의한지 자동으로 알려 주는 값은 아님. 평균 1위라고 모든 폴드에서 1위였다는 뜻도 아님. 각 `split` 점수나 다른 분할에서의 결과도 필요하면 살펴봐야 함.

여기서는 불순도 감소 기준 하나만 변경하고 나머지는 기본 설정으로 두었음. 다른 조건과의 조합을 바꾸면 선택되는 값도 달라질 수 있음. 다음 파일에서 세 설정을 함께 탐색함.
