# 6. 그리드 서치와 최종 재학습

여러 하이퍼파라미터의 후보를 정했다면 같은 폴드 방식으로 각각 학습하고 평균 검증 점수를 비교해야 함. `GridSearchCV`는 지정한 후보 조합을 빠짐없이 평가하고 가장 높은 평균 검증 점수의 설정을 선택함.

## 불순도 감소 기준 다섯 개 비교하기

```python
from sklearn.model_selection import GridSearchCV
from sklearn.tree import DecisionTreeClassifier

params_single = {
    'min_impurity_decrease': [0.0001, 0.0002, 0.0003, 0.0004, 0.0005]
}
gs_single = GridSearchCV(
    DecisionTreeClassifier(random_state=42),
    params_single,
    n_jobs=-1
)
gs_single.fit(train_input, train_target)

print(gs_single.best_params_)
print(np.round(gs_single.cv_results_['mean_test_score'], 4))
```

```text
{'min_impurity_decrease': 0.0001}
[0.8682 0.8645 0.8649 0.8678 0.8676]
```

탐색할 트리 모델과 후보 목록을 전달함. `fit()`은 각 후보 설정으로 교차 검증을 수행하고 점수를 비교함. `n_jobs=-1`은 병렬로 사용할 수 있는 CPU를 활용하는 설정이며 기기의 자원에 맞춰 숫자를 줄일 수 있음.

분류 모델의 기본 교차 검증은 5폴드이므로 후보 5개마다 5번씩, 총 25번의 교차 검증용 학습이 필요함. 이 숫자는 선택한 모델의 최종 재학습을 제외한 횟수임. `train_input` 전체를 전달해 폴드를 만들며 별도의 `test_input`은 탐색에 사용하지 않음.

## 선택한 설정으로 전체 훈련 데이터를 다시 사용하는 이유

각 교차 검증 회차에서는 한 폴드를 검증용으로 남기므로 모델이 훈련 데이터 전부를 학습하지 않음. 설정이 정해진 뒤에는 그 설정으로 5,197개 전체를 사용해 최종 모델을 다시 만들 수 있음.

기본 `refit=True`에서는 `GridSearchCV`가 이 재학습을 자동으로 수행함. 25번의 교차 검증 학습 외에 전체 훈련 데이터에 대한 추가 학습이 한 번 수행됨.

```python
dt_single = gs_single.best_estimator_
print(round(dt_single.score(train_input, train_target), 4))
print(round(gs_single.best_score_, 4))
print(gs_single.cv_results_['params'][gs_single.best_index_])
```

```text
0.9615
0.8682
{'min_impurity_decrease': 0.0001}
```

`best_estimator_`는 선택된 설정으로 전체 훈련 데이터에 재학습한 모델. 0.9615는 이 모델의 전체 훈련 정확도이고 0.8682는 후보 선택에 사용한 최고 평균 검증 정확도임. 아직 최종 테스트 점수는 계산하지 않았음. `refit=False`라면 전체 훈련 재학습과 `best_estimator_`를 기본처럼 사용할 수 없으므로 설정을 확인해야 함.

## 결과 속성 연결하기

| 속성 | 확인할 내용 |
| --- | --- |
| `best_params_` | 선택된 설정 조합 |
| `best_index_` | 전체 결과 배열에서 선택된 후보 위치 |
| `best_score_` | 선택된 후보의 평균 검증 점수 |
| `cv_results_` | 모든 후보의 설정과 폴드별 결과 |
| `best_estimator_` | 기본 재학습을 거친 최종 모델 |

`mean_test_score`의 test도 교차 검증의 검증 폴드를 가리킴. 테스트 세트 점수와 구분해야 함. 다음에는 최고값 하나만이 아니라 다섯 후보의 평균과 변동, 순위를 비교함.
