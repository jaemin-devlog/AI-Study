# 10. 최종 모델과 테스트 평가

교차 검증은 후보를 비교하는 과정이고 그리드 서치와 랜덤 서치는 그 평가를 이용해 설정을 선택하는 과정임. 이제 선택한 설정의 모델을 처음에 따로 둔 테스트 데이터로 평가함.

## 최종 재학습된 모델 확인하기

`RandomizedSearchCV`도 기본 `refit=True`에서 최고 평균 검증 점수의 설정으로 전체 훈련 5,197개를 다시 학습함. `best_estimator_`는 그 모델임. 각 폴드에서 만든 다섯 모델을 투표로 합친 결과는 아님.

```python
dt_final = rs.best_estimator_
print('평균 검증 정확도:', round(rs.best_score_, 4))
print('최종 테스트 정확도:', round(dt_final.score(test_input, test_target), 4))
```

```text
평균 검증 정확도: 0.8695
최종 테스트 정확도: 0.86
```

| 점수 | 정확도 | 평가한 대상 | 용도 |
| --- | ---: | --- | --- |
| 최고 평균 교차 검증 정확도 | 0.8695 | 5개 검증 폴드의 점수 평균 | 후보 설정 비교와 선택 |
| 최종 테스트 정확도 | 0.8600 | 재학습한 모델의 테스트 세트 점수 | 선택한 모델 평가 |

평균 검증 약 86.95%는 후보 설정을 비교하기 위해 다섯 폴드에서 얻은 점수의 평균. 테스트 86.00%는 선택된 설정을 전체 훈련 데이터로 다시 학습한 모델이 테스트 1,300개에서 맞힌 비율임. 학습에 사용한 데이터의 양과 평가 대상이 다르므로 두 숫자가 같을 필요는 없음. 테스트 점수가 검증보다 반드시 낮아야 하는 것도 아님.

## 평가의 독립성을 확인하기

이 와인 데이터와 같은 `random_state=42` 분할의 테스트 결과는 앞의 결정 트리 학습에서 이미 확인했음. 따라서 여기서 계산한 0.86은 분리, 설정 선택, 재학습, 평가 절차를 따라가는 데 사용할 수 있지만, 대화와 학습 과정 전체에서 처음부터 숨겨 둔 독립 평가라고 보기는 어려움.

독립적인 최종 평가가 필요하면 설정을 선택하기 전까지 확인하지 않은 테스트 데이터를 별도로 유지해야 함. 테스트 결과를 보고 다시 깊이나 후보 범위를 고치면 그 데이터가 선택에 참여하게 됨. 한 번의 점수만으로 모든 새 와인에서 같은 성능을 보장할 수도 없음.

## 과정 전체를 다시 연결하기

1. 전체 데이터에서 테스트 세트를 먼저 남김.
2. 나머지 훈련 데이터에서 교차 검증으로 후보를 평가함.
3. 평균 검증 점수와 폴드별 변동을 살펴 설정을 선택함.
4. 선택한 설정으로 전체 훈련 데이터를 다시 학습함.
5. 남겨 둔 테스트 데이터로 최종 모델을 평가함.

폴드 수, 후보 범위, 점수 차이, 검증 데이터의 구성은 선택 근거를 해석할 때 함께 확인함. 후보를 더 많이 탐색한다고 일반화 성능이 반드시 좋아지는 것도 아님. 다음에는 여러 결정 트리의 예측을 결합하는 앙상블 학습으로 이어짐.
