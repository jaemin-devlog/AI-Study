# AI Study

AI를 공부하면서 배운 개념과 실습 내용을 정리하는 저장소입니다. 처음 읽을 때도 흐름을 따라갈 수 있도록 개념이 필요한 이유부터 코드, 실행 결과와 해석까지 함께 기록합니다.

## 학습 노트

| 주제 | 학습 내용 | 목차 |
| --- | --- | --- |
| Git과 GitHub | 변경 이력 관리, 브랜치와 병합, 원격 저장소, Pull Request | [Git과 GitHub 목차](topics/git-github/README.md) |
| 머신러닝 기초 | 데이터 준비부터 분류와 회귀, 모델 평가와 설정 탐색까지 | [머신러닝 목차](topics/machine-learning/README.md) |

## 학습 흐름

**Git과 GitHub**

저장소와 커밋 → 변경 사항 비교와 되돌리기 → 브랜치와 병합 → 원격 저장소와 Pull Request

파일의 변경을 기록하는 방법부터 다른 작업을 합치고 GitHub에 공유하는 과정까지 정리했습니다. [Git 기초부터 읽기](topics/git-github/git/01-git-basics.md)

**머신러닝**

KNN 분류와 데이터 준비 → KNN 회귀와 선형 회귀 → 특성 공학과 규제 → 로지스틱 회귀와 경사 하강법 → 결정 트리 → 교차 검증과 모델 선택

생선과 와인 데이터를 이용해 모델이 예측하는 방법을 살펴보고, 훈련하지 않은 데이터로 성능을 평가하는 과정까지 정리했습니다. [머신러닝 기초부터 읽기](topics/machine-learning/01-ml-basics/01-인공지능과-생선-분류-문제.md)

## 노트 읽는 방법

- 각 주제의 목차에서 파일을 순서대로 읽을 수 있습니다. 앞에서 준비한 데이터와 모델을 다음 파일에서 이어서 사용하는 코드도 있습니다.
- 개념 설명과 함께 필요한 코드, 실행 결과, 수식과 비교표를 정리했습니다. 그래프와 그림은 각 파트의 그림 살펴보기에서도 확인할 수 있습니다.
- Git 명령어의 목적과 사용 상황은 [자주 쓰는 명령어](topics/git-github/commands.md)에서 찾아볼 수 있습니다.
