## 학습 흐름

**Git과 GitHub**

저장소와 커밋 → 변경 사항 비교와 되돌리기 → 브랜치와 병합 → 원격 저장소와 Pull Request

**머신러닝**

KNN 분류와 회귀 → 선형 회귀와 규제 → 로지스틱 회귀와 경사 하강법 → 결정 트리와 모델 선택 → 비지도 학습

**딥러닝**

신경망 기초와 역전파 → 신경망 학습과 CNN → RNN·LSTM·GRU → Attention과 Transformer

**컴퓨터 비전**

[이미지 데이터와 모델 입력](topics/computer-vision/01-컴퓨터-비전과-이미지-데이터.md): 픽셀과 채널 → 자료형과 값 범위 → 이미지 텐서 구조 → PyTorch 입력 준비
